# uz · IP-сети

Актуальный набор IP-сетей «uz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `uz`. Тип: **ip**.

Правил: **776**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 776.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_uz_a1b83e9a.txt)
