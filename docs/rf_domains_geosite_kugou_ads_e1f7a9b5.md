# kugou@ads

Актуальный набор доменных правил «kugou@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kugou@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kugou_ads_e1f7a9b5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kugou_ads_e1f7a9b5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kugou@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads.service.kugou.com
domain_suffix: adserviceretry.kglink.cn
domain_suffix: adserviceretry.kugou.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
