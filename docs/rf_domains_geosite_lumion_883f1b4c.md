# lumion

Актуальный набор доменных правил «lumion» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lumion`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lumion_883f1b4c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lumion_883f1b4c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lumion.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lumion-la.com
domain_suffix: lumion.com
domain_suffix: lumion3d.com.my
domain_suffix: lumion3d.net
domain_suffix: lumiontech.net
domain_suffix: mylumion.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
