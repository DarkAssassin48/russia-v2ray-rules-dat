# linakesi

Актуальный набор доменных правил «linakesi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `linakesi`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_linakesi_7803a88a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_linakesi_7803a88a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-linakesi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: heiyu.space
domain_suffix: lazycat.cloud
domain_suffix: linakesi.cn
domain_suffix: linakesi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
