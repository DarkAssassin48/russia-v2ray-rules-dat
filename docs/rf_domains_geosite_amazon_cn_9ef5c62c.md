# amazon@cn

Актуальный набор доменных правил «amazon@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amazon@cn`. Тип: **domains**.

Правил: **57**. Точные домены: 2; доменные зоны: 53; фрагменты: 0; regex: 2; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amazon_cn_9ef5c62c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amazon_cn_9ef5c62c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amazon@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
