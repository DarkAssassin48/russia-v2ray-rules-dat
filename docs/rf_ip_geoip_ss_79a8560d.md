# ss · IP-сети

Актуальный набор IP-сетей «ss» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ss`. Тип: **ip**.

Правил: **174**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 174.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ss_79a8560d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ss_79a8560d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ss.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
