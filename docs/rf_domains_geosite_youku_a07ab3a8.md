# youku

Актуальный набор доменных правил «youku» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youku`. Тип: **domains**.

Правил: **31**. Точные домены: 1; доменные зоны: 30; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youku_a07ab3a8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youku_a07ab3a8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youku.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
