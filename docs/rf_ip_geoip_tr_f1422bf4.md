# tr · IP-сети

Актуальный набор IP-сетей «tr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tr`. Тип: **ip**.

Правил: **5436**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5436.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tr_f1422bf4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tr_f1422bf4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
