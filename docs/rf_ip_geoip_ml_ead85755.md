# ml · IP-сети

Актуальный набор IP-сетей «ml» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ml`. Тип: **ip**.

Правил: **152**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 152.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ml_ead85755.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ml_ead85755.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ml.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
