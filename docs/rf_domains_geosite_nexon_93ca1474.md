# nexon

Актуальный набор доменных правил «nexon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nexon`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nexon_93ca1474.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nexon_93ca1474.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nexon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nexon.co.jp
domain_suffix: nexon.com
domain_suffix: nexon.io
domain_suffix: nexon.net
domain_suffix: nexoncdn.co.kr
domain_suffix: nexongames.co.kr
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
