# magnit

Актуальный набор доменных правил «magnit» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `magnit`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_magnit_97a2bf7e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_magnit_97a2bf7e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-magnit.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kazanexpress.ru
domain_suffix: magnit.com
domain_suffix: magnit.ru
domain_suffix: mm.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
