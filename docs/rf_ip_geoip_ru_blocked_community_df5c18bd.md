# ru-blocked-community · IP-сети

Актуальный набор IP-сетей «ru-blocked-community» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-blocked-community`. Тип: **ip**.

Правил: **933**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 933.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ru_blocked_community_df5c18bd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ru_blocked_community_df5c18bd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ru-blocked-community.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
