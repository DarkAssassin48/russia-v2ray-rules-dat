# ru-blocked-community · IP-сети

Актуальный набор IP-сетей «ru-blocked-community» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-blocked-community`. Тип: **ip**.

Правил: **930**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 930.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ru_blocked_community_df5c18bd.txt)
