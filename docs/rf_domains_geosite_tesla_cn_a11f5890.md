# tesla@cn

Актуальный набор доменных правил «tesla@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tesla@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tesla_cn_a11f5890.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tesla_cn_a11f5890.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tesla@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tesla.cn
domain_suffix: tesla.com.cn
domain_suffix: teslamotors.cn
domain_suffix: teslamotors.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
