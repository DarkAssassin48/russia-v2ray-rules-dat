# voxmedia

Актуальный набор доменных правил «voxmedia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `voxmedia`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_voxmedia_a0d8087c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_voxmedia_a0d8087c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-voxmedia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
