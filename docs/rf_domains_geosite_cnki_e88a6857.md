# cnki

Актуальный набор доменных правил «cnki» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cnki`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cnki_e88a6857.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cnki_e88a6857.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cnki.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chndoi.org
domain_suffix: cnki.com.cn
domain_suffix: cnki.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
