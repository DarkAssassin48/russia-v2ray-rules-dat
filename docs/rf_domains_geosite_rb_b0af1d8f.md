# rb

Актуальный набор доменных правил «rb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rb`. Тип: **domains**.

Правил: **457**. Точные домены: 1; доменные зоны: 456; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rb_b0af1d8f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rb_b0af1d8f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
