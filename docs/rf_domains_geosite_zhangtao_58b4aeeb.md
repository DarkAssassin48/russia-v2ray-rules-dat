# zhangtao

Актуальный набор доменных правил «zhangtao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zhangtao`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zhangtao_58b4aeeb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zhangtao_58b4aeeb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zhangtao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: accuratead.cn
domain_suffix: dutils.com
domain_suffix: hiaiabc.com
domain_suffix: mob.com
domain_suffix: mobsdks.com
domain_suffix: sharesdk.cn
domain_suffix: tec73.com
domain_suffix: yksdks.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
