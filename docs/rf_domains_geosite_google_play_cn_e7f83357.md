# google-play@cn

Актуальный набор доменных правил «google-play@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google-play@cn`. Тип: **domains**.

Правил: **3**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 2; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_play_cn_e7f83357.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_play_cn_e7f83357.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google-play@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: redirector.c.play.google.com
domain_regex: ^r+[0-9]+(---|\.)sn-(2x3|ni5|j5o)\w{5}\.xn--ngstr-lra8j\.com$
domain_regex: ^r+[0-9]+(---|\.)sn-(2x3|ni5|j5o)\w{5}\.googlevideo\.com$
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
