# br · IP-сети

Актуальный набор IP-сетей «br» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `br`. Тип: **ip**.

Правил: **24000**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 24000.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_br_b0f1cd5e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_br_b0f1cd5e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-br.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
