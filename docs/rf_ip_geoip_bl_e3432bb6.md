# bl · IP-сети

Актуальный набор IP-сетей «bl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bl`. Тип: **ip**.

Правил: **108**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 108.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bl_e3432bb6.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bl_e3432bb6.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
