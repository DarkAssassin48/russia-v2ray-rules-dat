# hdrezka

Актуальный набор доменных правил «hdrezka» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hdrezka`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hdrezka_ea58fa5a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hdrezka_ea58fa5a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hdrezka.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
