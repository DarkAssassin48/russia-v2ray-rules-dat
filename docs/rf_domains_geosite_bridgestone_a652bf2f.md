# bridgestone

Актуальный набор доменных правил «bridgestone» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bridgestone`. Тип: **domains**.

Правил: **98**. Точные домены: 0; доменные зоны: 98; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bridgestone_a652bf2f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bridgestone_a652bf2f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bridgestone.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
