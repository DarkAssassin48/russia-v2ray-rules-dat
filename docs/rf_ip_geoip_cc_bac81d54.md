# cc · IP-сети

Актуальный набор IP-сетей «cc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cc`. Тип: **ip**.

Правил: **39**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 39.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cc_bac81d54.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cc_bac81d54.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
