# mortein@cn

Актуальный набор доменных правил «mortein@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mortein@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mortein_cn_f950f66a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mortein_cn_f950f66a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mortein@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mortein.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
