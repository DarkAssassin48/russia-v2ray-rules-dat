# faronics

Актуальный набор доменных правил «faronics» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `faronics`. Тип: **domains**.

Правил: **18**. Точные домены: 1; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_faronics_0df297d2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_faronics_0df297d2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-faronics.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
