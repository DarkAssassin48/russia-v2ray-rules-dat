# bilibili-game

Актуальный набор доменных правил «bilibili-game» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bilibili-game`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bilibili_game_d390ff2e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bilibili_game_d390ff2e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bilibili-game.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bilibiligame.cn
domain_suffix: bilibiligame.co
domain_suffix: bilibiligame.net
domain_suffix: biligame.co
domain_suffix: biligame.com
domain_suffix: biligame.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
