# dlsite

Актуальный набор доменных правил «dlsite» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dlsite`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dlsite_e05a02b5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dlsite_e05a02b5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dlsite.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chobit.cc
domain_suffix: ci-en.jp
domain_suffix: ci-en.net
domain_suffix: dlaf.jp
domain_suffix: dlsite.com
domain_suffix: dlsite.com.tw
domain_suffix: dlsite.jp
domain_suffix: dlsitestudio.com
domain_suffix: nijiyome.jp
domain_suffix: triokini.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
