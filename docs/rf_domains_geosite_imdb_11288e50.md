# imdb

Актуальный набор доменных правил «imdb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `imdb`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_imdb_11288e50.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_imdb_11288e50.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-imdb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .imdb
domain_suffix: boxofficemojo.com
domain_suffix: imdb.com
domain_suffix: imdb.to
domain_suffix: media-imdb.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
