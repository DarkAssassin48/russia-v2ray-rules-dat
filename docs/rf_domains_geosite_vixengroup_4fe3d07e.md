# vixengroup

Актуальный набор доменных правил «vixengroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vixengroup`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vixengroup_4fe3d07e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vixengroup_4fe3d07e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vixengroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: blacked.com
domain_suffix: blackedraw.com
domain_suffix: deeper.com
domain_suffix: milfy.com
domain_suffix: slayed.com
domain_suffix: tushy.com
domain_suffix: tushyraw.com
domain_suffix: vixen.com
domain_suffix: vixengroup.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
