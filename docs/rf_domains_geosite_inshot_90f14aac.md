# inshot

Актуальный набор доменных правил «inshot» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `inshot`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_inshot_90f14aac.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_inshot_90f14aac.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-inshot.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: inshot.cc
domain_suffix: inshot.com
domain_suffix: inshotapp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
