# category-acg

Актуальный набор доменных правил «category-acg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-acg`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_acg_26693169.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_acg_26693169.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-acg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bestdori.com
domain_suffix: bowlroll.net
domain_suffix: colorfulstage.com
domain_suffix: crypton.co.jp
domain_suffix: lapriere.jp
domain_suffix: magicalmirai.com
domain_suffix: mikuexpo.com
domain_suffix: piapro.net
domain_suffix: snowmiku.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
