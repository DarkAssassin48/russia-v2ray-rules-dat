# cbs

Актуальный набор доменных правил «cbs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cbs`. Тип: **domains**.

Правил: **29**. Точные домены: 4; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cbs_60ceb4c4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cbs_60ceb4c4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cbs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
