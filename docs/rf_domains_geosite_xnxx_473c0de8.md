# xnxx

Актуальный набор доменных правил «xnxx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xnxx`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xnxx_473c0de8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xnxx_473c0de8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xnxx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: xnxx-cdn.com
domain_suffix: xnxx.com
domain_suffix: xnxx.net
domain_suffix: xnxx.tv
domain_suffix: xnxx3.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
