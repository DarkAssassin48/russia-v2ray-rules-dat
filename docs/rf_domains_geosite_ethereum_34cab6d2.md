# ethereum

Актуальный набор доменных правил «ethereum» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ethereum`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ethereum_34cab6d2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ethereum_34cab6d2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ethereum.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: devcon.org
domain_suffix: ethereum.foundation
domain_suffix: ethereum.org
domain_suffix: etherscan.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
