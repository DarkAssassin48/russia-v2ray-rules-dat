# tor

Актуальный набор доменных правил «tor» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tor`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tor_79862361.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tor_79862361.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tor.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .exit
domain_suffix: .onion
domain_suffix: .tor
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
