# tidal

Актуальный набор доменных правил «tidal» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tidal`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tidal_d48d1fe4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tidal_d48d1fe4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tidal.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tidal.com
domain_suffix: tidalhifi.com
domain_suffix: wimpmusic.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
