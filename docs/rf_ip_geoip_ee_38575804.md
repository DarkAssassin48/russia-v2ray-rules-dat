# ee · IP-сети

Актуальный набор IP-сетей «ee» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ee`. Тип: **ip**.

Правил: **1726**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1726.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ee_38575804.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ee_38575804.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ee.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
