# chesscom

Актуальный набор доменных правил «chesscom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chesscom`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chesscom_d88e27bf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chesscom_d88e27bf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chesscom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chess.com
domain_suffix: chesscomfiles.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
