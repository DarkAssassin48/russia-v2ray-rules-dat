# gismeteo

Актуальный набор доменных правил «gismeteo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gismeteo`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gismeteo_0ecd1b3e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gismeteo_0ecd1b3e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gismeteo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gismeteo.by
domain_suffix: gismeteo.com
domain_suffix: gismeteo.net
domain_suffix: gismeteo.ru
domain_suffix: gismeteo.st
domain_suffix: meteofor.com
domain_suffix: meteofor.st
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
