# kurogames

Актуальный набор доменных правил «kurogames» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kurogames`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kurogames_e2c104ed.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kurogames_e2c104ed.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kurogames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
