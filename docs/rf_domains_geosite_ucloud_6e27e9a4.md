# ucloud

Актуальный набор доменных правил «ucloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ucloud`. Тип: **domains**.

Правил: **54**. Точные домены: 0; доменные зоны: 54; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ucloud_6e27e9a4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ucloud_6e27e9a4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ucloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
