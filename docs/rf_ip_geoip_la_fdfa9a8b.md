# la · IP-сети

Актуальный набор IP-сетей «la» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `la`. Тип: **ip**.

Правил: **269**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 269.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_la_fdfa9a8b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_la_fdfa9a8b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-la.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
