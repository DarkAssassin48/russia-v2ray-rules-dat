# rferl

Актуальный набор доменных правил «rferl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rferl`. Тип: **domains**.

Правил: **30**. Точные домены: 0; доменные зоны: 30; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rferl_b703cef4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rferl_b703cef4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rferl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
