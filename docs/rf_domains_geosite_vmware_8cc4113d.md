# vmware

Актуальный набор доменных правил «vmware» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vmware`. Тип: **domains**.

Правил: **104**. Точные домены: 1; доменные зоны: 103; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vmware_8cc4113d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vmware_8cc4113d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vmware.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
