# tilda

Актуальный набор доменных правил «tilda» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tilda`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tilda_06122931.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tilda_06122931.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tilda.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tilda.cc
domain_suffix: tilda.ru
domain_suffix: tilda.ws
domain_suffix: tildaapi.com
domain_suffix: tildacdn.com
domain_suffix: tildacdn.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
