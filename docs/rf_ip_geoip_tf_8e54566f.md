# tf · IP-сети

Актуальный набор IP-сетей «tf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tf`. Тип: **ip**.

Правил: **22**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 22.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tf_8e54566f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tf_8e54566f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
