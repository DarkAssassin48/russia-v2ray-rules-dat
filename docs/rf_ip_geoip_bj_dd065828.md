# bj · IP-сети

Актуальный набор IP-сетей «bj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bj`. Тип: **ip**.

Правил: **183**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 183.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bj_dd065828.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bj_dd065828.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bj.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
