# baltamatica

Актуальный набор доменных правил «baltamatica» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `baltamatica`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_baltamatica_48d4037d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_baltamatica_48d4037d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-baltamatica.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: baltamatica.cn
domain_suffix: baltamatica.com
domain_suffix: baltamatica.net
domain_suffix: baltamatica.org.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
