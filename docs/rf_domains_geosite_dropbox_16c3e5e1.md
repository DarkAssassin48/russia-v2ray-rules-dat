# dropbox

Актуальный набор доменных правил «dropbox» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dropbox`. Тип: **domains**.

Правил: **25**. Точные домены: 2; доменные зоны: 23; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dropbox_16c3e5e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dropbox_16c3e5e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dropbox.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
