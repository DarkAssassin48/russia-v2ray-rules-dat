# dingtalk

Актуальный набор доменных правил «dingtalk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dingtalk`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dingtalk_6c5c82e5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dingtalk_6c5c82e5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dingtalk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ddurl.to
domain_suffix: dingding.xin
domain_suffix: dingstore.cn
domain_suffix: dingtalk.cn
domain_suffix: dingtalk.com
domain_suffix: dingtalk.net
domain_suffix: dingtalkapps.com
domain_suffix: dingtalkcloud.com
domain_suffix: laiwang.com
domain_suffix: lwurl.to
domain_suffix: ztna-dingtalk.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
