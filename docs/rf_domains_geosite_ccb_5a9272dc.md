# ccb

Актуальный набор доменных правил «ccb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ccb`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ccb_5a9272dc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ccb_5a9272dc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ccb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: ccb-life.com.cn
domain_suffix: ccb.cn

domain_suffix: ccb.com.cn

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
