# kuaishou@telemetry

Актуальный набор доменных правил «kuaishou@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kuaishou@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kuaishou_telemetry_cc824c68.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kuaishou_telemetry_cc824c68.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kuaishou@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: apilog-web.acfun.cn
domain: log-sdk.gifshow.com
domain: wlog.kuaishou.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
