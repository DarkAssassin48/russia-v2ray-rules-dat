# cf · IP-сети

Актуальный набор IP-сетей «cf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cf`. Тип: **ip**.

Правил: **120**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 120.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cf_d795395e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cf_d795395e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
