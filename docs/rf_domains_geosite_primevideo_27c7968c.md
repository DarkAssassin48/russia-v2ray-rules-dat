# primevideo

Актуальный набор доменных правил «primevideo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `primevideo`. Тип: **domains**.

Правил: **24**. Точные домены: 10; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_primevideo_27c7968c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_primevideo_27c7968c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-primevideo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
