# okko

Актуальный набор доменных правил «okko» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `okko`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_okko_bbc58b76.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_okko_bbc58b76.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-okko.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: okko.sport
domain_suffix: okko.tv
domain_suffix: okkoapi.tv
domain_suffix: playfamily.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
