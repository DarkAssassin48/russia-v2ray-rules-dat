# GitHub — сайт, API и файлы

Домены GitHub, API, raw-файлов и доставки содержимого из категории GitHub.

Код: `github`. Тип: **domains**.

Правил: **66**. Точные домены: 33; доменные зоны: 33; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_github.txt)
- [Полный JSON с исходной логикой](../details/da_github.json)
- [Готовый SRS](../custom/github.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
