# 4399

Актуальный набор доменных правил «4399» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `4399`. Тип: **domains**.

Правил: **63**. Точные домены: 0; доменные зоны: 63; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_4399_3f4985cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_4399_3f4985cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-4399.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
