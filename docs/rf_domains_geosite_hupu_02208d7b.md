# hupu

Актуальный набор доменных правил «hupu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hupu`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hupu_02208d7b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hupu_02208d7b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hupu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hoopchina.com.cn
domain_suffix: hupu.com
domain_suffix: hupucdn.com
domain_suffix: shihuo.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
