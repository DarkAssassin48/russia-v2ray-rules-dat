# microsoft-dev@telemetry

Актуальный набор доменных правил «microsoft-dev@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft-dev@telemetry`. Тип: **domains**.

Правил: **2**. Точные домены: 2; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_dev_telemetry_2f8e1758.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_dev_telemetry_2f8e1758.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft-dev@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: dc.services.visualstudio.com
domain: rt.services.visualstudio.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
