# sy · IP-сети

Актуальный набор IP-сетей «sy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sy`. Тип: **ip**.

Правил: **400**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 400.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sy_88360aa7.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sy_88360aa7.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
