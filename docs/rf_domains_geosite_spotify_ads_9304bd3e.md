# spotify@ads

Актуальный набор доменных правил «spotify@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `spotify@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_spotify_ads_9304bd3e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_spotify_ads_9304bd3e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-spotify@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: adeventtracker.spotify.com
domain: adstudio-assets.scdn.co
domain: bloodhound.spotify.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
