# eduhk

Актуальный набор доменных правил «eduhk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eduhk`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_eduhk_51433a09.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_eduhk_51433a09.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-eduhk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: eduhk.edu.hk
domain_suffix: eduhk.hk
domain_suffix: xn--pssu7cz8nr8ibkx1e8a.xn--j6w193g
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
