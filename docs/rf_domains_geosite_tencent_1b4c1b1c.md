# tencent

Актуальный набор доменных правил «tencent» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent`. Тип: **domains**.

Правил: **688**. Точные домены: 1; доменные зоны: 687; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_1b4c1b1c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_1b4c1b1c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
