# monotype

Актуальный набор доменных правил «monotype» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `monotype`. Тип: **domains**.

Правил: **14**. Точные домены: 1; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_monotype_e49fb0d5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_monotype_e49fb0d5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-monotype.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: fontshop-prod-responsive-images.s3.amazonaws.com
domain_suffix: bitstream.com
domain_suffix: fontbook.com
domain_suffix: fontexplorerx.com
domain_suffix: fonts.com
domain_suffix: fonts.net
domain_suffix: fontshop.com
domain_suffix: fstopimages.com
domain_suffix: itcfonts.com
domain_suffix: linotype.com
domain_suffix: monotype.com
domain_suffix: monotypeimaging.com
domain_suffix: myfonts.com
domain_suffix: myfonts.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
