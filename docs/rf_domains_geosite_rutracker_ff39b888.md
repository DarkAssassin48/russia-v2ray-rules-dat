# rutracker

Актуальный набор доменных правил «rutracker» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rutracker`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rutracker_ff39b888.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rutracker_ff39b888.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rutracker.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: maintracker.org
domain_suffix: rutracker.cc
domain_suffix: rutracker.cr
domain_suffix: rutracker.me
domain_suffix: rutracker.net
domain_suffix: rutracker.nl
domain_suffix: rutracker.org
domain_suffix: rutracker.wiki
domain_suffix: rutrk.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
