# Meta

Актуальный набор доменных правил «Meta» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `meta`. Тип: **domains**.

Правил: **556**. Точные домены: 2; доменные зоны: 554; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_meta_049d8c56.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_meta_049d8c56.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-meta.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
