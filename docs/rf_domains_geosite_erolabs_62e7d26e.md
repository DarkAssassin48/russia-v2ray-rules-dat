# erolabs

Актуальный набор доменных правил «erolabs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `erolabs`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_erolabs_62e7d26e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_erolabs_62e7d26e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-erolabs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ero-labs.cloud
domain_suffix: ero-labs.com
domain_suffix: ero-labs.fun
domain_suffix: ero-labs.io
domain_suffix: ero-labs.net
domain_suffix: ero-labs.one
domain_suffix: ero-labs.online
domain_suffix: ero-labs.site
domain_suffix: erolabs.cloud
domain_suffix: erolabs.com
domain_suffix: erolabs.net
domain_suffix: erolabs.online
domain_suffix: erolabsshare.xyz
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
