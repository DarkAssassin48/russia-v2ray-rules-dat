# bestbuy

Актуальный набор доменных правил «bestbuy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bestbuy`. Тип: **domains**.

Правил: **82**. Точные домены: 0; доменные зоны: 82; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bestbuy_283b97b2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bestbuy_283b97b2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bestbuy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
