# gq · IP-сети

Актуальный набор IP-сетей «gq» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gq`. Тип: **ip**.

Правил: **121**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 121.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gq_0035fffd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gq_0035fffd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gq.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
