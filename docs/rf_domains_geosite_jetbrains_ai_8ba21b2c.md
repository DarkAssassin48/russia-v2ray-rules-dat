# jetbrains-ai

Актуальный набор доменных правил «jetbrains-ai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jetbrains-ai`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jetbrains_ai_8ba21b2c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jetbrains_ai_8ba21b2c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jetbrains-ai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: grazie.ai
domain_suffix: grazie.aws.intellij.net
domain_suffix: jetbrains.ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
