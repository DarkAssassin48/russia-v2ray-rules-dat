# category-urlshortner

Актуальный набор доменных правил «category-urlshortner» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-urlshortner`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_urlshortner_85d133de.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_urlshortner_85d133de.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-urlshortner.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bit.ly
domain_suffix: bitly.com
domain_suffix: bitly.is
domain_suffix: shorturl.at
domain_suffix: tinyurl.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
