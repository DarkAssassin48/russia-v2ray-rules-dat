# sv · IP-сети

Актуальный набор IP-сетей «sv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sv`. Тип: **ip**.

Правил: **445**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 445.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sv_5be8752e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sv_5be8752e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
