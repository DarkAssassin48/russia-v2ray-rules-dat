# kodik

Актуальный набор доменных правил «kodik» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kodik`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kodik_bfcdc863.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kodik_bfcdc863.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kodik.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kodik-storage.com
domain_suffix: kodik.biz
domain_suffix: kodik.cc
domain_suffix: kodik.info
domain_suffix: kodikplayer.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
