# bybit

Актуальный набор доменных правил «bybit» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bybit`. Тип: **domains**.

Правил: **16**. Точные домены: 2; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bybit_cd2af1df.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bybit_cd2af1df.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bybit.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: byabcde.com

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
