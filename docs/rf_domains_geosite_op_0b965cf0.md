# op

Актуальный набор доменных правил «op» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `op`. Тип: **domains**.

Правил: **2**. Точные домены: 1; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_op_0b965cf0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_op_0b965cf0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-op.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: opgg-static.akamaized.net
domain_suffix: op.gg
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
