# lu · IP-сети

Актуальный набор IP-сетей «lu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lu`. Тип: **ip**.

Правил: **1946**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1946.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lu_66baac79.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lu_66baac79.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
