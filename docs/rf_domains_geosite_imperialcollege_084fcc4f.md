# imperialcollege

Актуальный набор доменных правил «imperialcollege» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `imperialcollege`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_imperialcollege_084fcc4f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_imperialcollege_084fcc4f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-imperialcollege.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: imperial.insendi.com
domain_suffix: ic.ac.uk
domain_suffix: imperial.ac.uk
domain_suffix: imperialbusiness.school
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
