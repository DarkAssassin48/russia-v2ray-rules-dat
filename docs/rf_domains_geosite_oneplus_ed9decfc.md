# oneplus

Актуальный набор доменных правил «oneplus» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `oneplus`. Тип: **domains**.

Правил: **8**. Точные домены: 1; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_oneplus_ed9decfc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_oneplus_ed9decfc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-oneplus.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: community.oneplus.com
domain_suffix: h2os.com
domain_suffix: oneplus.cn
domain_suffix: oneplus.com
domain_suffix: oneplus.net
domain_suffix: oneplusbbs.com
domain_suffix: oneplusmobile.com
domain_suffix: opstatics.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
