# honor

Актуальный набор доменных правил «honor» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `honor`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_honor_8037f6fd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_honor_8037f6fd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-honor.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hihonor.cn
domain_suffix: hihonor.com
domain_suffix: hihonorcdn.com
domain_suffix: hihonorcloud.com
domain_suffix: honor.cn
domain_suffix: honor.com
domain_suffix: honor.com.cn
domain_suffix: honorfile.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
