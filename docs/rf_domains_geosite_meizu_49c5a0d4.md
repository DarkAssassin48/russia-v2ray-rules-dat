# meizu

Актуальный набор доменных правил «meizu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `meizu`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_meizu_49c5a0d4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_meizu_49c5a0d4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-meizu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: flyme.cn
domain_suffix: flyme.com
domain_suffix: flymeauto.com
domain_suffix: meizu.cn
domain_suffix: meizu.com
domain_suffix: mzres.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
