# dyna

Актуальный набор доменных правил «dyna» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dyna`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dyna_ef4baca6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dyna_ef4baca6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dyna.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dynacw.co.jp
domain_suffix: dynacw.com
domain_suffix: dynacw.com.cn
domain_suffix: dynacw.com.hk
domain_suffix: dynacw.com.tw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
