# Домены, доступные только из России

Актуальный набор доменных правил «Домены, доступные только из России» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-available-only-inside`. Тип: **domains**.

Правил: **170**. Точные домены: 0; доменные зоны: 170; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ru_available_only_inside_699c9e32.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ru_available_only_inside_699c9e32.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ru-available-only-inside.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
