# cnet

Актуальный набор доменных правил «cnet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cnet`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cnet_68a0f6f5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cnet_68a0f6f5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cnet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cnet.co.kr
domain_suffix: cnet.com
domain_suffix: cnet.de
domain_suffix: cnetfrance.fr
domain_suffix: download.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
