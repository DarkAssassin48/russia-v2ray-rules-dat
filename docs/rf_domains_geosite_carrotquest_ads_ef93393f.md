# carrotquest@ads

Актуальный набор доменных правил «carrotquest@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `carrotquest@ads`. Тип: **domains**.

Правил: **11**. Точные домены: 11; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_carrotquest_ads_ef93393f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_carrotquest_ads_ef93393f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-carrotquest@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

```text
domain: api-eu.carrotquest.app
domain: api-eu.carrotquest.io

domain: api-ru.carrotquest.io

domain: api-secure.carrottrack.app

domain: api.dashly.app

```
