# fengxing

Актуальный набор доменных правил «fengxing» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fengxing`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fengxing_69e2cdda.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fengxing_69e2cdda.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fengxing.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fspcdn.com
domain_suffix: fun.tv
domain_suffix: funshion.com
domain_suffix: funshion.net
domain_suffix: ibidian.com
domain_suffix: jvcsmart.cn
domain_suffix: jvcsmart.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
