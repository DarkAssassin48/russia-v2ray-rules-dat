# tg · IP-сети

Актуальный набор IP-сетей «tg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tg`. Тип: **ip**.

Правил: **144**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 144.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tg_31437f67.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tg_31437f67.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
