# category-bank-ru@ads

Актуальный набор доменных правил «category-bank-ru@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bank-ru@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 1; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bank_ru_ads_79fb06a4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bank_ru_ads_79fb06a4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bank-ru@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: visor.sberbank.ru
domain_suffix: ads.sber.ru
domain_suffix: clickstream.sberbank.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
