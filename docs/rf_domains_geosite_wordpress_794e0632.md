# wordpress

Актуальный набор доменных правил «wordpress» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wordpress`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wordpress_794e0632.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wordpress_794e0632.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wordpress.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: videopress.com
domain_suffix: w.org
domain_suffix: wordcamp.org
domain_suffix: wordpress.com
domain_suffix: wordpress.net
domain_suffix: wordpress.org
domain_suffix: wordpress.tv
domain_suffix: wp-themes.com
domain_suffix: wp.com
domain_suffix: wpvip.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
