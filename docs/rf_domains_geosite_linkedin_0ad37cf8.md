# linkedin

Актуальный набор доменных правил «linkedin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `linkedin`. Тип: **domains**.

Правил: **12**. Точные домены: 3; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_linkedin_0ad37cf8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_linkedin_0ad37cf8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-linkedin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
