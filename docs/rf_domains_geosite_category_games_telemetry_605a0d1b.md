# category-games@telemetry

Актуальный набор доменных правил «category-games@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games@telemetry`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games_telemetry_605a0d1b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games_telemetry_605a0d1b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: sentry.ppy.sh
domain_suffix: insights-collector.gog.com
domain_suffix: log-upload-os.hoyoverse.com
domain_suffix: log-upload.mihoyo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
