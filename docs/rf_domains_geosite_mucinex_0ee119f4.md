# mucinex

Актуальный набор доменных правил «mucinex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mucinex`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mucinex_0ee119f4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mucinex_0ee119f4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mucinex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mucinex.ca
domain_suffix: mucinex.cn
domain_suffix: mucinex.co.nz
domain_suffix: mucinex.com
domain_suffix: mucinex.com.cn
domain_suffix: mucinex.net
domain_suffix: mucinex.tv
domain_suffix: mucinexprofessional.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
