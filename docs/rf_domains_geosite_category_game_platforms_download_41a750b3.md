# category-game-platforms-download

Актуальный набор доменных правил «category-game-platforms-download» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-game-platforms-download`. Тип: **domains**.

Правил: **491**. Точные домены: 489; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_game_platforms_download_41a750b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_game_platforms_download_41a750b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-game-platforms-download.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
