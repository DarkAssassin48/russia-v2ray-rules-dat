# category-vpnservices

Актуальный набор доменных правил «category-vpnservices» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-vpnservices`. Тип: **domains**.

Правил: **69**. Точные домены: 0; доменные зоны: 69; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_vpnservices_36fb9c7a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_vpnservices_36fb9c7a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-vpnservices.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
