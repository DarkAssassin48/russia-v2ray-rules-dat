# es · IP-сети

Актуальный набор IP-сетей «es» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `es`. Тип: **ip**.

Правил: **14745**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 14745.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_es_ac73a5fa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_es_ac73a5fa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-es.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
