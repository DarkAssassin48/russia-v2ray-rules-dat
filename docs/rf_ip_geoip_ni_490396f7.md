# ni · IP-сети

Актуальный набор IP-сетей «ni» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ni`. Тип: **ip**.

Правил: **290**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 290.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ni_490396f7.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ni_490396f7.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ni.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
