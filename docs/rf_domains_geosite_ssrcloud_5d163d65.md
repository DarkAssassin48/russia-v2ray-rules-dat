# ssrcloud

Актуальный набор доменных правил «ssrcloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ssrcloud`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ssrcloud_5d163d65.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ssrcloud_5d163d65.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ssrcloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: airport-gov-cn.com
domain_suffix: cnix-gov-cn.com
domain_suffix: xn--d4ty0ojsqzfd.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
