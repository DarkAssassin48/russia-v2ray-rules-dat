# shuqi

Актуальный набор доменных правил «shuqi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `shuqi`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_shuqi_4380c556.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_shuqi_4380c556.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-shuqi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 11222.cn
domain_suffix: aliwx.com.cn
domain_suffix: aliwx.net
domain_suffix: ishuqi.com
domain_suffix: newstjk.com
domain_suffix: shuqi.com
domain_suffix: shuqiapi.com
domain_suffix: shuqiread.com
domain_suffix: shuqireader.com
domain_suffix: shuqistat.com
domain_suffix: sqreader.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
