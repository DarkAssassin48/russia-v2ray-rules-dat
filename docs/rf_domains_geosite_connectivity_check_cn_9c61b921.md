# connectivity-check@cn

Актуальный набор доменных правил «connectivity-check@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `connectivity-check@cn`. Тип: **domains**.

Правил: **10**. Точные домены: 9; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_connectivity_check_cn_9c61b921.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_connectivity_check_cn_9c61b921.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-connectivity-check@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: conn1.oppomobile.com
domain: conn2.oppomobile.com
domain: connect.rom.miui.com
domain: connectivity.samsung.com.cn
domain: connectivitycheck.platform.hicloud.com
domain: connectivitycheck.platform.hihonorcloud.com
domain: wifi.vivo.com.cn
domain: www.gstatic.com
domain: www.qualcomm.cn
domain_suffix: captive.apple.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
