# Блокировки РФ — все известные домены [большой набор]

Актуальный набор доменных правил «Блокировки РФ — все известные домены» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-blocked-all`. Тип: **domains**.

Правил: **1591831**. Точные домены: 0; доменные зоны: 1591831; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ru_blocked_all_cc323246.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ru_blocked_all_cc323246.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ru-blocked-all.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
