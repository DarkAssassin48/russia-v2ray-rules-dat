# yy

Актуальный набор доменных правил «yy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yy`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yy_40668822.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yy_40668822.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: duowan.com
domain_suffix: dwstatic.com
domain_suffix: yy.com
domain_suffix: yyeshop.cn
domain_suffix: yystatic.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
