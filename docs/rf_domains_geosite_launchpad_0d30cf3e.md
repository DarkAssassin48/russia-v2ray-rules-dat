# launchpad

Актуальный набор доменных правил «launchpad» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `launchpad`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_launchpad_0d30cf3e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_launchpad_0d30cf3e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-launchpad.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: launchpad.net
domain_suffix: launchpadcontent.net
domain_suffix: launchpadlibrarian.com
domain_suffix: launchpadlibrarian.net
domain_suffix: launchpadlibrarian.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
