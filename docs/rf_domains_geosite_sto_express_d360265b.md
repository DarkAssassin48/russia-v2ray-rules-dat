# sto-express

Актуальный набор доменных правил «sto-express» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sto-express`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sto_express_d360265b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sto_express_d360265b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sto-express.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: sto-express.cn
domain_suffix: sto-express.com
domain_suffix: sto-express.com.cn
domain_suffix: sto.cn
domain_suffix: stointl.com
domain_suffix: stosolution.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
