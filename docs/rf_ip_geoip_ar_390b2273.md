# ar · IP-сети

Актуальный набор IP-сетей «ar» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ar`. Тип: **ip**.

Правил: **5759**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5759.
