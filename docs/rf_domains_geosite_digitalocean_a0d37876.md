# digitalocean

Актуальный набор доменных правил «digitalocean» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `digitalocean`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_digitalocean_a0d37876.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_digitalocean_a0d37876.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-digitalocean.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: digitalocean-ui.com
domain_suffix: digitalocean.com
domain_suffix: digitaloceanspaces.com
domain_suffix: do.co
domain_suffix: nginxconfig.io
domain_suffix: ondigitalocean.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
