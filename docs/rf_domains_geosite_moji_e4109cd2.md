# moji

Актуальный набор доменных правил «moji» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `moji`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_moji_e4109cd2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_moji_e4109cd2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-moji.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ad.api.moji.com
domain_suffix: airnut.com
domain_suffix: moji.com
domain_suffix: moji001.com
domain_suffix: moji002.com
domain_suffix: mojicdn.com
domain_suffix: mojichina.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
