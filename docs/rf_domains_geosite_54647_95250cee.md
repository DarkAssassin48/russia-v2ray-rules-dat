# 54647

Актуальный набор доменных правил «54647» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `54647`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_54647_95250cee.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_54647_95250cee.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-54647.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 54647.global
domain_suffix: 54647.io
domain_suffix: 54647.online
domain_suffix: 54647.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
