# chinabroadnet

Актуальный набор доменных правил «chinabroadnet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinabroadnet`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinabroadnet_432d3390.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinabroadnet_432d3390.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinabroadnet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 10099.com.cn
domain_suffix: ahitv.com
domain_suffix: cbn.cn
domain_suffix: cqccn.com
domain_suffix: gcable.com.cn
domain_suffix: isxtv.com
domain_suffix: mnc015.mcc460.pub.3gppnetwork.org
domain_suffix: sc96655.com
domain_suffix: sdgdwljt.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
