# msn@telemetry

Актуальный набор доменных правил «msn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `msn@telemetry`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_msn_telemetry_b3e7d63f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_msn_telemetry_b3e7d63f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-msn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: browser.events.data.msn.cn
domain_suffix: browser.events.data.msn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
