# Epic Games

Актуальный набор доменных правил «Epic Games» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `epicgames`. Тип: **domains**.

Правил: **33**. Точные домены: 0; доменные зоны: 30; фрагменты: 0; regex: 3; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_epicgames_13c97172.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_epicgames_13c97172.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-epicgames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
