# pikpak@telemetry

Актуальный набор доменных правил «pikpak@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pikpak@telemetry`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pikpak_telemetry_c5beba49.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pikpak_telemetry_c5beba49.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pikpak@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: o4504926511693824.ingest.sentry.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
