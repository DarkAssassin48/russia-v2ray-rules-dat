# category-httpdns-cn

Актуальный набор доменных правил «category-httpdns-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-httpdns-cn`. Тип: **domains**.

Правил: **50**. Точные домены: 0; доменные зоны: 50; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_httpdns_cn_749e06dc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_httpdns_cn_749e06dc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-httpdns-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
