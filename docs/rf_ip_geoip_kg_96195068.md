# kg · IP-сети

Актуальный набор IP-сетей «kg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kg`. Тип: **ip**.

Правил: **423**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 423.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_kg_96195068.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_kg_96195068.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-kg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
