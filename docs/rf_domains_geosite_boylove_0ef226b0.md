# boylove

Актуальный набор доменных правил «boylove» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `boylove`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_boylove_0ef226b0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_boylove_0ef226b0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-boylove.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: boylove.cc
domain_suffix: boylove.live
domain_suffix: boylove1.cc
domain_suffix: boyloves.cc
domain_suffix: fuhouse.club
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
