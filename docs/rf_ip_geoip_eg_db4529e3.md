# eg · IP-сети

Актуальный набор IP-сетей «eg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eg`. Тип: **ip**.

Правил: **988**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 988.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_eg_db4529e3.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_eg_db4529e3.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-eg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
