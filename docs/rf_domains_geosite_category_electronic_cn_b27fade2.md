# category-electronic-cn

Актуальный набор доменных правил «category-electronic-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-electronic-cn`. Тип: **domains**.

Правил: **93**. Точные домены: 0; доменные зоны: 93; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_electronic_cn_b27fade2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_electronic_cn_b27fade2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-electronic-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
