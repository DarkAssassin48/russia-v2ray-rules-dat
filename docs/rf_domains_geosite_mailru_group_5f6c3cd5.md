# mailru-group

Актуальный набор доменных правил «mailru-group» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mailru-group`. Тип: **domains**.

Правил: **300**. Точные домены: 48; доменные зоны: 252; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mailru_group_5f6c3cd5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mailru_group_5f6c3cd5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mailru-group.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
