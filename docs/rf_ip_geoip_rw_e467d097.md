# rw · IP-сети

Актуальный набор IP-сетей «rw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rw`. Тип: **ip**.

Правил: **196**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 196.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_rw_e467d097.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_rw_e467d097.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-rw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
