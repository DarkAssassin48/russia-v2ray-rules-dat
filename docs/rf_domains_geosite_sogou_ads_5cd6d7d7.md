# sogou@ads

Актуальный набор доменных правил «sogou@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sogou@ads`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sogou_ads_5cd6d7d7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sogou_ads_5cd6d7d7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sogou@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: inte.sogou.com
domain_suffix: inte.sogoucdn.com
domain_suffix: lu.sogou.com
domain_suffix: lu.sogoucdn.com
domain_suffix: pb.i.sogou.com
domain_suffix: theta.sogoucdn.com
domain_suffix: uranus.sogou.com
domain_suffix: wuliao.epro.sogou.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
