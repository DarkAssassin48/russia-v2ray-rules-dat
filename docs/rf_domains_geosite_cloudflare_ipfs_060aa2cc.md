# cloudflare-ipfs

Актуальный набор доменных правил «cloudflare-ipfs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cloudflare-ipfs`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cloudflare_ipfs_060aa2cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cloudflare_ipfs_060aa2cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cloudflare-ipfs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cf-ipfs.com
domain_suffix: cloudflare-ipfs.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
