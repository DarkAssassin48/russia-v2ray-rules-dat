# teamviewer

Актуальный набор доменных правил «teamviewer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `teamviewer`. Тип: **domains**.

Правил: **5**. Точные домены: 2; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_teamviewer_0fea63b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_teamviewer_0fea63b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-teamviewer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: client-teamviewer-com.trafficmanager.net
domain: teamviewer.com.cdn.cloudflare.net
domain_suffix: teamviewer.cn
domain_suffix: teamviewer.com
domain_suffix: teamviewer.us
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
