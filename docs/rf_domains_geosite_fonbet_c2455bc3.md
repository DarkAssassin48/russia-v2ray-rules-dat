# fonbet

Актуальный набор доменных правил «fonbet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fonbet`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fonbet_c2455bc3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fonbet_c2455bc3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fonbet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bk6bba-resources.com
domain_suffix: bk6bba-resources.ru
domain_suffix: fon.bet
domain_suffix: fon.promo
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
