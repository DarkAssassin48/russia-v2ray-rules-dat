# WhatsApp — доменные сервисы

Домены WhatsApp. Голосовая связь может также использовать соединения по IP, которые не следует путать с доменными правилами.

Код: `whatsapp`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_whatsapp.txt)
- [Полный JSON с исходной логикой](../details/da_whatsapp.json)
- [Готовый SRS](../custom/whatsapp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wa.me
domain_suffix: whatsapp-plus.info
domain_suffix: whatsapp-plus.me
domain_suffix: whatsapp-plus.net
domain_suffix: whatsapp.cc
domain_suffix: whatsapp.com
domain_suffix: whatsapp.info
domain_suffix: whatsapp.net
domain_suffix: whatsapp.org
domain_suffix: whatsapp.tv
domain_suffix: whatsappbrand.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
