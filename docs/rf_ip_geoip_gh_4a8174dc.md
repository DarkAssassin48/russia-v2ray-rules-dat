# gh · IP-сети

Актуальный набор IP-сетей «gh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gh`. Тип: **ip**.

Правил: **582**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 582.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gh_4a8174dc.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gh_4a8174dc.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gh.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
