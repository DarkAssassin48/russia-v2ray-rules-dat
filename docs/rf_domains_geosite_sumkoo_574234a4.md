# sumkoo

Актуальный набор доменных правил «sumkoo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sumkoo`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sumkoo_574234a4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sumkoo_574234a4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sumkoo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gongqingyun.cn
domain_suffix: jzfz.net
domain_suffix: sumkoo.cn
domain_suffix: sumkoo.com
domain_suffix: sumkoo.net
domain_suffix: veeqi.net
domain_suffix: wenmingban.com
domain_suffix: zhiyuanhe.cn
domain_suffix: zhiyuanyun.com.cn
domain_suffix: zyhe.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
