# group-ib

Актуальный набор доменных правил «group-ib» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `group-ib`. Тип: **domains**.

Правил: **30**. Точные домены: 0; доменные зоны: 30; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_group_ib_29bdf762.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_group_ib_29bdf762.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-group-ib.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
