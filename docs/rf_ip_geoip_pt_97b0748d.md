# pt · IP-сети

Актуальный набор IP-сетей «pt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pt`. Тип: **ip**.

Правил: **3198**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3198.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pt_97b0748d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pt_97b0748d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
