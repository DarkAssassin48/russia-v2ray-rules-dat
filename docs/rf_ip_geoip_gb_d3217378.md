# gb · IP-сети

Актуальный набор IP-сетей «gb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gb`. Тип: **ip**.

Правил: **51224**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 51224.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gb_d3217378.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gb_d3217378.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
