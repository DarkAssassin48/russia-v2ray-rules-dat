# tj · IP-сети

Актуальный набор IP-сетей «tj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tj`. Тип: **ip**.

Правил: **255**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 255.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tj_d1bac232.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tj_d1bac232.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tj.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
