# hkt

Актуальный набор доменных правил «hkt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hkt`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hkt_2743da53.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hkt_2743da53.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hkt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

```text
domain_suffix: 1010.com.hk
domain_suffix: esmarthealth.com
domain_suffix: hkcsl.com
domain_suffix: hkt-enterprise.com
domain_suffix: hkt-eye.com
domain_suffix: hkt.com
domain_suffix: hkteducation.com
domain_suffix: hktpremier.com
domain_suffix: hktshop.com
domain_suffix: netvigator.com
domain_suffix: theclub.com.hk
domain_suffix: uhub.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
