# springer

Актуальный набор доменных правил «springer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `springer`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_springer_a18e0a32.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_springer_a18e0a32.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-springer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apress.com
domain_suffix: springer.com
domain_suffix: springerlink.com
domain_suffix: springernature.com
domain_suffix: wkap.nl
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
