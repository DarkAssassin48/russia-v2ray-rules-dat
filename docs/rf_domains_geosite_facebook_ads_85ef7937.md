# facebook@ads

Актуальный набор доменных правил «facebook@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `facebook@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_facebook_ads_85ef7937.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_facebook_ads_85ef7937.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-facebook@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: analytics.facebook.com
domain_suffix: facebookads.com
domain_suffix: pixel.facebook.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
