# category-bank-cn

Актуальный набор доменных правил «category-bank-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bank-cn`. Тип: **domains**.

Правил: **60**. Точные домены: 0; доменные зоны: 60; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bank_cn_1b0fc65d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bank_cn_1b0fc65d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bank-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
