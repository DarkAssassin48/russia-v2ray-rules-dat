# chinapost

Актуальный набор доменных правил «chinapost» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinapost`. Тип: **domains**.

Правил: **19**. Точные домены: 0; доменные зоны: 19; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinapost_9d7d2ab6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinapost_9d7d2ab6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinapost.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
