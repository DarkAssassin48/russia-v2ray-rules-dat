# strepsils

Актуальный набор доменных правил «strepsils» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `strepsils`. Тип: **domains**.

Правил: **33**. Точные домены: 0; доменные зоны: 33; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_strepsils_19779261.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_strepsils_19779261.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-strepsils.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
