# cainiao

Актуальный набор доменных правил «cainiao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cainiao`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cainiao_027d8e11.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cainiao_027d8e11.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cainiao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 56xiniao.com
domain_suffix: cainiao-inc.com
domain_suffix: cainiao.com
domain_suffix: cainiao.com.cn
domain_suffix: cainiaoyizhan.com
domain_suffix: danniao.com
domain_suffix: dianwoda.cn
domain_suffix: dianwoda.com
domain_suffix: guoguo-app.com
domain_suffix: v6-adashx.ut.cainiao.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
