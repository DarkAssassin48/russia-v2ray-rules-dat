# x5@ads

Актуальный набор доменных правил «x5@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `x5@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_x5_ads_7bbcc0a7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_x5_ads_7bbcc0a7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-x5@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ads.x5.ru
domain: ads.x5media.ru
domain: sentry.x5.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
