# mozilla

Актуальный набор доменных правил «mozilla» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mozilla`. Тип: **domains**.

Правил: **72**. Точные домены: 7; доменные зоны: 65; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mozilla_8d4e8628.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mozilla_8d4e8628.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mozilla.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
