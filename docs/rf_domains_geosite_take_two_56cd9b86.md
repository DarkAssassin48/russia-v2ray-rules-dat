# take-two

Актуальный набор доменных правил «take-two» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `take-two`. Тип: **domains**.

Правил: **17**. Точные домены: 3; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_take_two_56cd9b86.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_take_two_56cd9b86.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-take-two.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
