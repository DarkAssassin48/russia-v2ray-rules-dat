# alibaba

Актуальный набор доменных правил «alibaba» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibaba`. Тип: **domains**.

Правил: **466**. Точные домены: 5; доменные зоны: 461; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibaba_5cbdca72.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibaba_5cbdca72.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibaba.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
