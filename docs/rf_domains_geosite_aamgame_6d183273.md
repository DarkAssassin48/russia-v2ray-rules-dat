# aamgame

Актуальный набор доменных правил «aamgame» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aamgame`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aamgame_6d183273.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aamgame_6d183273.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aamgame.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aamgame.com
domain_suffix: aamgame.mobi
domain_suffix: aamgame.net
domain_suffix: aamsmart.com
domain_suffix: singworld.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
