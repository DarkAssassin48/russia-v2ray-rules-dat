# vu · IP-сети

Актуальный набор IP-сетей «vu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vu`. Тип: **ip**.

Правил: **278**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 278.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_vu_a5a6a031.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_vu_a5a6a031.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-vu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
