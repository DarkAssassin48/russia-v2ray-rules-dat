# bloomberg

Актуальный набор доменных правил «bloomberg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bloomberg`. Тип: **domains**.

Правил: **61**. Точные домены: 0; доменные зоны: 61; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bloomberg_9ea84bfc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bloomberg_9ea84bfc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bloomberg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
