# category-education-ir

Актуальный набор доменных правил «category-education-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-education-ir`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_education_ir_39e64caa.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_education_ir_39e64caa.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-education-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
