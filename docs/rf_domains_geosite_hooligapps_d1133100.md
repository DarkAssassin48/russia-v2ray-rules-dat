# hooligapps

Актуальный набор доменных правил «hooligapps» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hooligapps`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hooligapps_d1133100.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hooligapps_d1133100.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hooligapps.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cuntempire.com
domain_suffix: cuntwars.com
domain_suffix: dirtyleague.com
domain_suffix: faptitans.com
domain_suffix: hooligapps.com
domain_suffix: slotbitches.com
domain_suffix: smutstone.com
domain_suffix: townofsins.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
