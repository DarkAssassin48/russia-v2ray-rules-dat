# framer

Актуальный набор доменных правил «framer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `framer`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_framer_e295d3fe.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_framer_e295d3fe.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-framer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: framer.com
domain_suffix: framer.website
domain_suffix: framercanvas.com
domain_suffix: framerstatic.com
domain_suffix: framerusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
