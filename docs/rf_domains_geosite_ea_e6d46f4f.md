# ea

Актуальный набор доменных правил «ea» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ea`. Тип: **domains**.

Правил: **165**. Точные домены: 6; доменные зоны: 159; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ea_e6d46f4f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ea_e6d46f4f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ea.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
