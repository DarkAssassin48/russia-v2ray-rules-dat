# eleme

Актуальный набор доменных правил «eleme» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eleme`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_eleme_674533d0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_eleme_674533d0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-eleme.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adashx.ut.ele.me
domain_suffix: doservice.com
domain_suffix: ele.me
domain_suffix: ele.to
domain_suffix: eleme.cn
domain_suffix: eleme.io
domain_suffix: elemecdn.cn
domain_suffix: elemecdn.com
domain_suffix: elenet.me
domain_suffix: fengniaojipei.net
domain_suffix: h-adashx.ut.ele.me
domain_suffix: v6-adashx.ut.ele.me
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
