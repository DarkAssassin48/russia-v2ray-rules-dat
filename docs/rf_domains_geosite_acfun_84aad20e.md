# acfun

Актуальный набор доменных правил «acfun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `acfun`. Тип: **domains**.

Правил: **8**. Точные домены: 1; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_acfun_84aad20e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_acfun_84aad20e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-acfun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: apilog-web.acfun.cn
domain_suffix: ac.fun
domain_suffix: acfun.cn
domain_suffix: acfun.net
domain_suffix: acfunchina.cn
domain_suffix: acfunchina.com
domain_suffix: acfunchina.net
domain_suffix: aixifan.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
