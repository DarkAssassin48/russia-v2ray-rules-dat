# jd

Актуальный набор доменных правил «jd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jd`. Тип: **domains**.

Правил: **255**. Точные домены: 0; доменные зоны: 255; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jd_5caaa046.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jd_5caaa046.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
