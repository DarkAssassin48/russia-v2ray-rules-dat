# yuanbei

Актуальный набор доменных правил «yuanbei» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yuanbei`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yuanbei_e35df720.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yuanbei_e35df720.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yuanbei.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: i2oo.cn
domain_suffix: laoban100.com
domain_suffix: shengyi.ai
domain_suffix: shengyizhuanjia.com
domain_suffix: yuanbei.biz
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
