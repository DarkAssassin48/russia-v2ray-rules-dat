# category-companies@cn

Актуальный набор доменных правил «category-companies@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-companies@cn`. Тип: **domains**.

Правил: **843**. Точные домены: 507; доменные зоны: 332; фрагменты: 0; regex: 4; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_companies_cn_4ce579ce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_companies_cn_4ce579ce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-companies@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
