# roku

Актуальный набор доменных правил «roku» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `roku`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_roku_09dbca0d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_roku_09dbca0d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-roku.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fandango.com
domain_suffix: mgo-images.com
domain_suffix: mgo.com
domain_suffix: ravm.tv
domain_suffix: roku.com
domain_suffix: rokutime.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
