# cloudfront · IP-сети

Актуальный набор IP-сетей «cloudfront» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cloudfront`. Тип: **ip**.

Правил: **248**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 248.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cloudfront_772f52ea.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cloudfront_772f52ea.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cloudfront.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
