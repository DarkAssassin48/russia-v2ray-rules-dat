# tld-ru

Актуальный набор доменных правил «tld-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tld-ru`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tld_ru_f2cef463.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tld_ru_f2cef463.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tld-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .moscow
domain_suffix: .ru
domain_suffix: .su
domain_suffix: .tatar
domain_suffix: .xn--80adxhks
domain_suffix: .xn--80asehdb
domain_suffix: .xn--80aswg
domain_suffix: .xn--c1avg
domain_suffix: .xn--d1acj3b
domain_suffix: .xn--p1acf
domain_suffix: .xn--p1ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
