# longbridge

Актуальный набор доменных правил «longbridge» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `longbridge`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_longbridge_decaf0f6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_longbridge_decaf0f6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-longbridge.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lbctrl.com
domain_suffix: lbkrs.com
domain_suffix: longbridge.cloud
domain_suffix: longbridge.cn
domain_suffix: longbridge.com
domain_suffix: longbridge.global

domain_suffix: longbridge.sg
domain_suffix: longbridgeapp.com
domain_suffix: longbridgehk.com
domain_suffix: longportapp.com
domain_suffix: wbrks.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
