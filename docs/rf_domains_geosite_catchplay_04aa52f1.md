# catchplay

Актуальный набор доменных правил «catchplay» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `catchplay`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_catchplay_04aa52f1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_catchplay_04aa52f1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-catchplay.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: catchplay.com
domain_suffix: tra-ww000-cp.akamaized.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
