# th · IP-сети

Актуальный набор IP-сетей «th» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `th`. Тип: **ip**.

Правил: **3611**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3611.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_th_8109f1fa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_th_8109f1fa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-th.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
