# vn · IP-сети

Актуальный набор IP-сетей «vn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vn`. Тип: **ip**.

Правил: **3873**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3873.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_vn_9fd280e0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_vn_9fd280e0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-vn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
