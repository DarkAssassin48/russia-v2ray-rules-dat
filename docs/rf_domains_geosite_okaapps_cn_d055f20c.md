# okaapps@cn

Актуальный набор доменных правил «okaapps@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `okaapps@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_okaapps_cn_d055f20c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_okaapps_cn_d055f20c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-okaapps@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_regex: ^(.+\.)*zh\.okaapps\.com$
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
