# category-scholar-ir

Актуальный набор доменных правил «category-scholar-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-scholar-ir`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_scholar_ir_49400d8a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_scholar_ir_49400d8a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-scholar-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ac.ir
domain_suffix: edu.ir
domain_suffix: iranlms.ir
domain_suffix: jtt.ir
domain_suffix: sanjesh.org
domain_suffix: sharif.edu
domain_suffix: sharif.ir
domain_suffix: srttu.edu
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
