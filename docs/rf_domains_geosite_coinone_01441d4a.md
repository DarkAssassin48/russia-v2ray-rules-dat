# coinone

Актуальный набор доменных правил «coinone» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `coinone`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_coinone_01441d4a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_coinone_01441d4a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-coinone.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: coinone.co.kr
domain_suffix: coinonecore.com
domain_suffix: coinonecorp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
