# attwatchtv

Актуальный набор доменных правил «attwatchtv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `attwatchtv`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_attwatchtv_28b2e378.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_attwatchtv_28b2e378.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-attwatchtv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: att.tv
domain_suffix: atttvnow.com
domain_suffix: attwatchtv.com
domain_suffix: dtvce.com
domain_suffix: nettyinternet.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
