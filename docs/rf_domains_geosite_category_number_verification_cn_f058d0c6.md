# category-number-verification-cn

Актуальный набор доменных правил «category-number-verification-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-number-verification-cn`. Тип: **domains**.

Правил: **7**. Точные домены: 5; доменные зоны: 1; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_number_verification_cn_f058d0c6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_number_verification_cn_f058d0c6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-number-verification-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: enrichgw.10010.com
domain: hap.10010.com
domain: hs.wosms.cn
domain: id6.me
domain: opencloud.wostore.cn
domain_suffix: cmpassport.com
domain_regex: ^nis.+\.10010\.com$
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
