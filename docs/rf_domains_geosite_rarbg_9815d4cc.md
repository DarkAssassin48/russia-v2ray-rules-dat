# rarbg

Актуальный набор доменных правил «rarbg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rarbg`. Тип: **domains**.

Правил: **18**. Точные домены: 0; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rarbg_9815d4cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rarbg_9815d4cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rarbg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
