# chinatower

Актуальный набор доменных правил «chinatower» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinatower`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinatower_9f8641f6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinatower_9f8641f6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinatower.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: china-tower.com
domain_suffix: chinatowercom.cn
domain_suffix: tower.com.cn
domain_suffix: tower0788.cn
domain_suffix: tower0788.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
