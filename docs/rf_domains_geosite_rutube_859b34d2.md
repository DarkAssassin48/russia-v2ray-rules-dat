# rutube

Актуальный набор доменных правил «rutube» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rutube`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rutube_859b34d2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rutube_859b34d2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rutube.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: rtbcdn.ru
domain_suffix: rutube.ru
domain_suffix: rutube.sport
domain_suffix: rutubelist.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
