# private · IP-сети

Актуальный набор IP-сетей «private» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `private`. Тип: **ip**.

Правил: **28**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 28.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_private_15f92801.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_private_15f92801.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-private.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
