# clarivate

Актуальный набор доменных правил «clarivate» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `clarivate`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_clarivate_4c861092.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_clarivate_4c861092.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-clarivate.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: clarivate.com
domain_suffix: isiknowledge.com
domain_suffix: newisiknowledge.com
domain_suffix: webofknowledge.com
domain_suffix: webofscience.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
