# ve · IP-сети

Актуальный набор IP-сетей «ve» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ve`. Тип: **ip**.

Правил: **1637**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1637.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ve_0cf6ea02.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ve_0cf6ea02.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ve.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
