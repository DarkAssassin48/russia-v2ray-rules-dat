# Discord — исходная категория

Актуальный набор доменных правил «Discord — исходная категория» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `discord`. Тип: **domains**.

Правил: **28**. Точные домены: 2; доменные зоны: 26; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_discord_9e3cee5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_discord_9e3cee5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-discord.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
