# xunlei

Актуальный набор доменных правил «xunlei» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xunlei`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xunlei_d3df5e04.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xunlei_d3df5e04.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xunlei.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 00cdn.com
domain_suffix: 88cdn.com
domain_suffix: 8uri.cn
domain_suffix: guangyacdn.com
domain_suffix: guangyapan.com
domain_suffix: kanimg.com

domain_suffix: sandai.net
domain_suffix: thundercdn.com
domain_suffix: thunderurl.com
domain_suffix: xunlei.com
domain_suffix: xycdn.com
domain_suffix: xycloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
