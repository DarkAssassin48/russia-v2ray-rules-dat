# category-communication

Актуальный набор доменных правил «category-communication» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-communication`. Тип: **domains**.

Правил: **160**. Точные домены: 2; доменные зоны: 158; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_communication_59a8ee22.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_communication_59a8ee22.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-communication.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
