# alibabacloud@cn

Актуальный набор доменных правил «alibabacloud@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibabacloud@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 4; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibabacloud_cn_afb65172.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibabacloud_cn_afb65172.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibabacloud@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: account-cn.alibabacloud.com
domain: api.alibabacloud.com
domain: cn.alibabacloud.com
domain: status.alibabacloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
