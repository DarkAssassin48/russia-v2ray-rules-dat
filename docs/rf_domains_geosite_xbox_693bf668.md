# xbox

Актуальный набор доменных правил «xbox» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xbox`. Тип: **domains**.

Правил: **42**. Точные домены: 1; доменные зоны: 41; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xbox_693bf668.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xbox_693bf668.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xbox.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
