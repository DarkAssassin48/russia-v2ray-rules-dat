# category-gov-ir

Актуальный набор доменных правил «category-gov-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-gov-ir`. Тип: **domains**.

Правил: **29**. Точные домены: 0; доменные зоны: 29; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_gov_ir_d25a77cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_gov_ir_d25a77cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-gov-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
