# category-social-media-!cn

Актуальный набор доменных правил «category-social-media-!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-social-media-!cn`. Тип: **domains**.

Правил: **627**. Точные домены: 15; доменные зоны: 612; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_social_media__cn_09db56c0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_social_media__cn_09db56c0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-social-media-!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
