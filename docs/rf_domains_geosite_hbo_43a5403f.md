# hbo

Актуальный набор доменных правил «hbo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hbo`. Тип: **domains**.

Правил: **65**. Точные домены: 0; доменные зоны: 65; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hbo_43a5403f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hbo_43a5403f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hbo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
