# autoru

Актуальный набор доменных правил «autoru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `autoru`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_autoru_a3a35fb9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_autoru_a3a35fb9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-autoru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apiauto.ru
domain_suffix: auto.ru
domain_suffix: autoru.me
domain_suffix: avto.ru
domain_suffix: cm.expert
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
