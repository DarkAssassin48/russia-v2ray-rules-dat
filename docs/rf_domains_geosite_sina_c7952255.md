# sina

Актуальный набор доменных правил «sina» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sina`. Тип: **domains**.

Правил: **58**. Точные домены: 0; доменные зоны: 58; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sina_c7952255.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sina_c7952255.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sina.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
