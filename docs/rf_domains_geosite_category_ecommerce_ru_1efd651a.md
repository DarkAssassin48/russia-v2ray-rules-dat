# category-ecommerce-ru

Актуальный набор доменных правил «category-ecommerce-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce-ru`. Тип: **domains**.

Правил: **201**. Точные домены: 34; доменные зоны: 167; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_ru_1efd651a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_ru_1efd651a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
