# fqnovel

Актуальный набор доменных правил «fqnovel» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fqnovel`. Тип: **domains**.

Правил: **47**. Точные домены: 17; доменные зоны: 30; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fqnovel_a2e3f3f6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fqnovel_a2e3f3f6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fqnovel.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
