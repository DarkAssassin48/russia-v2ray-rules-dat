# ctrip@!cn

Актуальный набор доменных правил «ctrip@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ctrip@!cn`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ctrip__cn_0e6250e7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ctrip__cn_0e6250e7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ctrip@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
