# azure@cn

Актуальный набор доменных правил «azure@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `azure@cn`. Тип: **domains**.

Правил: **89**. Точные домены: 0; доменные зоны: 89; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_azure_cn_2a991839.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_azure_cn_2a991839.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-azure@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
