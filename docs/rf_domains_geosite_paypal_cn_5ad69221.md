# paypal@cn

Актуальный набор доменных правил «paypal@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `paypal@cn`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_paypal_cn_5ad69221.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_paypal_cn_5ad69221.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-paypal@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: anfutong.cn
domain_suffix: anfutong.com.cn
domain_suffix: beibao.cn
domain_suffix: beibao.com.cn
domain_suffix: paypal.com.cn
domain_suffix: paypal.net.cn
domain_suffix: paypal.org.cn
domain_suffix: paypalcommunity.cn
domain_suffix: paypalhere.cn
domain_suffix: paypalhere.com.cn
domain_suffix: xn--bnq297cix3a.cn
domain_suffix: xoom.net.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
