# ucoz

Актуальный набор доменных правил «ucoz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ucoz`. Тип: **domains**.

Правил: **37**. Точные домены: 0; доменные зоны: 37; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ucoz_3e1f6805.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ucoz_3e1f6805.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ucoz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
