# weathercn

Актуальный набор доменных правил «weathercn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `weathercn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_weathercn_43f1cdf2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_weathercn_43f1cdf2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-weathercn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hf-aw.cn
domain_suffix: hf-aw.com
domain_suffix: huafeng-accuweather.cn
domain_suffix: huafengaw.com
domain_suffix: weathercn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
