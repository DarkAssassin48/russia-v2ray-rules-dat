# kubakuba

Актуальный набор доменных правил «kubakuba» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kubakuba`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kubakuba_f5b1a5ed.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kubakuba_f5b1a5ed.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kubakuba.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kubakuba.global
domain_suffix: kubakuba1996.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
