# changyou

Актуальный набор доменных правил «changyou» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `changyou`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_changyou_cdf7f278.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_changyou_cdf7f278.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-changyou.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 17173.com
domain_suffix: 17173cdn.com
domain_suffix: changyou.com
domain_suffix: cy.com
domain_suffix: playcool.com
domain_suffix: yeyou.com
domain_suffix: yeyoucdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
