# cctv

Актуальный набор доменных правил «cctv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cctv`. Тип: **domains**.

Правил: **44**. Точные домены: 0; доменные зоны: 44; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cctv_2eadb7e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cctv_2eadb7e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cctv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
