# category-dev

Актуальный набор доменных правил «category-dev» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-dev`. Тип: **domains**.

Правил: **689**. Точные домены: 91; доменные зоны: 597; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_dev_1f5814a2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_dev_1f5814a2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-dev.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
