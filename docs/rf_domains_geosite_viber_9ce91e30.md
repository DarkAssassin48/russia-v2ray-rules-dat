# viber

Актуальный набор доменных правил «viber» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `viber`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_viber_9ce91e30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_viber_9ce91e30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-viber.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: s-bid.rmp.rakuten.com
domain_suffix: vbcdn.com
domain_suffix: vbcdn.net
domain_suffix: viber.co
domain_suffix: viber.com
domain_suffix: viber.me
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
