# fluxer

Актуальный набор доменных правил «fluxer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fluxer`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fluxer_d3a0528b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fluxer_d3a0528b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fluxer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fluxer.app
domain_suffix: fluxer.com
domain_suffix: fluxer.dev
domain_suffix: fluxer.gg
domain_suffix: fluxer.gift
domain_suffix: fluxer.media
domain_suffix: fluxer.tools
domain_suffix: fluxerapp.com
domain_suffix: fluxerstatic.com
domain_suffix: fluxerstatus.com
domain_suffix: fluxerusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
