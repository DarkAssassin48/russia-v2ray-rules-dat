# trustasia

Актуальный набор доменных правил «trustasia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `trustasia`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_trustasia_15e0824a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_trustasia_15e0824a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-trustasia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 51ssl.cn
domain_suffix: 51ssl.com
domain_suffix: geossl.cn
domain_suffix: litessl.cn
domain_suffix: litessl.com
domain_suffix: myssl-uri.com
domain_suffix: myssl.com
domain_suffix: trustasia.cn
domain_suffix: trustasia.com
domain_suffix: trustasia.com.cn
domain_suffix: trustasia.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
