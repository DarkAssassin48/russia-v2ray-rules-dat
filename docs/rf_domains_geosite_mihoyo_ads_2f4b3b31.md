# mihoyo@ads

Актуальный набор доменных правил «mihoyo@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mihoyo@ads`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mihoyo_ads_2f4b3b31.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mihoyo_ads_2f4b3b31.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mihoyo@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: log-upload-os.hoyoverse.com
domain_suffix: log-upload.mihoyo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
