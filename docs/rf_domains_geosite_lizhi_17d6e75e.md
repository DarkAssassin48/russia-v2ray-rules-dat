# lizhi

Актуальный набор доменных правил «lizhi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lizhi`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lizhi_17d6e75e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lizhi_17d6e75e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lizhi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gzlzfm.com
domain_suffix: lizhi.fm
domain_suffix: lizhifm.com
domain_suffix: lizhiinc.com
domain_suffix: lz310.com
domain_suffix: lzpipi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
