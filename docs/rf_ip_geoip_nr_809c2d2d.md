# nr · IP-сети

Актуальный набор IP-сетей «nr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nr`. Тип: **ip**.

Правил: **110**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 110.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nr_809c2d2d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nr_809c2d2d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
