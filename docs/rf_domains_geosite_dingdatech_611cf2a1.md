# dingdatech

Актуальный набор доменных правил «dingdatech» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dingdatech`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dingdatech_611cf2a1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dingdatech_611cf2a1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dingdatech.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: diiing.cn
domain_suffix: dingdachuxing.com
domain_suffix: dingdatech.com
domain_suffix: jintdev.com
domain_suffix: xiangbababus.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
