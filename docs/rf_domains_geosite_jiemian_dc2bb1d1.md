# jiemian

Актуальный набор доменных правил «jiemian» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jiemian`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jiemian_dc2bb1d1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jiemian_dc2bb1d1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jiemian.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cailianpress.com
domain_suffix: chinastarmarket.cn
domain_suffix: cls.cn
domain_suffix: jiemian.com
domain_suffix: jiemian.com.cn
domain_suffix: jingpt.com
domain_suffix: lanjinger.com
domain_suffix: moer.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
