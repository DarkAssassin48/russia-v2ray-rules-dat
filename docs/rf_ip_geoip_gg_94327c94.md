# gg · IP-сети

Актуальный набор IP-сетей «gg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gg`. Тип: **ip**.

Правил: **180**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 180.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gg_94327c94.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gg_94327c94.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
