# aisiku

Актуальный набор доменных правил «aisiku» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aisiku`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aisiku_0fe25bbd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aisiku_0fe25bbd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aisiku.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1tyy.cn
domain_suffix: bbdc.cn
domain_suffix: beingfine.cn
domain_suffix: beingfine.com.cn
domain_suffix: bubei.com.cn
domain_suffix: coolab.top
domain_suffix: is-cool.cn
domain_suffix: is-cool.com.cn
domain_suffix: langeasy.cn
domain_suffix: langeasy.com.cn
domain_suffix: learnywhere.cn
domain_suffix: learnywhere.com.cn
domain_suffix: qlisten.cn
domain_suffix: qtyy.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
