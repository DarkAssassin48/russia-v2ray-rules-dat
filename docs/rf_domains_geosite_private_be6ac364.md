# private

Актуальный набор доменных правил «private» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `private`. Тип: **domains**.

Правил: **133**. Точные домены: 14; доменные зоны: 118; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_private_be6ac364.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_private_be6ac364.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-private.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
