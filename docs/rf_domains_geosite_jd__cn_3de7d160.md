# jd@!cn

Актуальный набор доменных правил «jd@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jd@!cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jd__cn_3de7d160.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jd__cn_3de7d160.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jd@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jd.co.th
domain_suffix: jd.hk
domain_suffix: jd.id
domain_suffix: jd.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
