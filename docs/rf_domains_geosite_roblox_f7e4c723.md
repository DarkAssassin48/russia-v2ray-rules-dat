# roblox

Актуальный набор доменных правил «roblox» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `roblox`. Тип: **domains**.

Правил: **51**. Точные домены: 7; доменные зоны: 44; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_roblox_f7e4c723.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_roblox_f7e4c723.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-roblox.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
