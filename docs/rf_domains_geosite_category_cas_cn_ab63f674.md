# category-cas@cn

Актуальный набор доменных правил «category-cas@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cas@cn`. Тип: **domains**.

Правил: **31**. Точные домены: 18; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cas_cn_ab63f674.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cas_cn_ab63f674.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cas@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
