# np · IP-сети

Актуальный набор IP-сетей «np» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `np`. Тип: **ip**.

Правил: **751**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 751.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_np_3370b53a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_np_3370b53a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-np.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
