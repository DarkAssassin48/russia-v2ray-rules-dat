# kr · IP-сети

Актуальный набор IP-сетей «kr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kr`. Тип: **ip**.

Правил: **5577**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5577.
