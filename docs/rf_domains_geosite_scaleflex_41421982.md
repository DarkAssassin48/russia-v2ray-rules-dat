# scaleflex

Актуальный набор доменных правил «scaleflex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `scaleflex`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_scaleflex_41421982.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_scaleflex_41421982.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-scaleflex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cloudimage.io
domain_suffix: cloudimg.io
domain_suffix: scaleflex.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
