# category-ai-cn

Актуальный набор доменных правил «category-ai-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ai-cn`. Тип: **domains**.

Правил: **129**. Точные домены: 2; доменные зоны: 127; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ai_cn_27a04671.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ai_cn_27a04671.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ai-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
