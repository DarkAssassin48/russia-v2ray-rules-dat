# haier

Актуальный набор доменных правил «haier» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `haier`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_haier_e06a3301.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_haier_e06a3301.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-haier.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ehaier.com
domain_suffix: haier.com
domain_suffix: haier.net
domain_suffix: haiersmarthomes.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
