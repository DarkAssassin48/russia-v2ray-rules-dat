# lenovo

Актуальный набор доменных правил «lenovo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lenovo`. Тип: **domains**.

Правил: **58**. Точные домены: 0; доменные зоны: 58; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lenovo_ebdaa1c9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lenovo_ebdaa1c9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lenovo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
