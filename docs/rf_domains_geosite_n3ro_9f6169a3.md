# n3ro

Актуальный набор доменных правил «n3ro» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `n3ro`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_n3ro_9f6169a3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_n3ro_9f6169a3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-n3ro.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: n3ro.lol
domain_suffix: n3ro.net
domain_suffix: n3ro.wtf
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
