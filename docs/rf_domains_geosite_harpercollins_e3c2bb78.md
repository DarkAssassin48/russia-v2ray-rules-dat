# harpercollins

Актуальный набор доменных правил «harpercollins» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `harpercollins`. Тип: **domains**.

Правил: **20**. Точные домены: 0; доменные зоны: 20; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_harpercollins_e3c2bb78.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_harpercollins_e3c2bb78.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-harpercollins.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
