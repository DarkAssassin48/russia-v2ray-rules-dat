# id · IP-сети

Актуальный набор IP-сетей «id» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `id`. Тип: **ip**.

Правил: **11101**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 11101.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_id_e95c756a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_id_e95c756a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-id.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
