# kingkonglive

Актуальный набор доменных правил «kingkonglive» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kingkonglive`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kingkonglive_5942c7bd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kingkonglive_5942c7bd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kingkonglive.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kingkong.com.tw
domain_suffix: kingkongapp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
