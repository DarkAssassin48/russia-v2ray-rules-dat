# yokaverse

Актуальный набор доменных правил «yokaverse» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yokaverse`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yokaverse_e0247a2e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yokaverse_e0247a2e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yokaverse.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dobest.com
domain_suffix: langrenclub.com
domain_suffix: sanguosha.com
domain_suffix: xhlsgs.com
domain_suffix: xinwuji.com
domain_suffix: yokaverse.com
domain_suffix: zhuoyou.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
