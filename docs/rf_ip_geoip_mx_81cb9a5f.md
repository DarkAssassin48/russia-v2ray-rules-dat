# mx · IP-сети

Актуальный набор IP-сетей «mx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mx`. Тип: **ip**.

Правил: **6299**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 6299.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mx_81cb9a5f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mx_81cb9a5f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
