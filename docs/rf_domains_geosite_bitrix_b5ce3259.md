# bitrix

Актуальный набор доменных правил «bitrix» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bitrix`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bitrix_b5ce3259.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bitrix_b5ce3259.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bitrix.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1c-bitrix.ru
domain_suffix: bitrix.info
domain_suffix: bitrix24.com
domain_suffix: bitrix24.net
domain_suffix: bitrix24.ru
domain_suffix: bitrix24.tech
domain_suffix: bitrix24public.com
domain_suffix: bitrix24shop.ru
domain_suffix: bitrix24site.ru
domain_suffix: bitrixphone.com
domain_suffix: bitrixsoft.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
