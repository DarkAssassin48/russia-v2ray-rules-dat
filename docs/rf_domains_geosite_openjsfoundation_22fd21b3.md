# openjsfoundation

Актуальный набор доменных правил «openjsfoundation» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `openjsfoundation`. Тип: **domains**.

Правил: **13**. Точные домены: 2; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_openjsfoundation_22fd21b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_openjsfoundation_22fd21b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-openjsfoundation.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: amp.akamaized.net
domain: cdn.ampproject.org
domain_suffix: amp.dev
domain_suffix: ampproject.com
domain_suffix: ampproject.net
domain_suffix: ampproject.org
domain_suffix: electronjs.org
domain_suffix: jquery.com
domain_suffix: jquerymobile.com
domain_suffix: jqueryui.com
domain_suffix: mochajs.org
domain_suffix: nodejs.org
domain_suffix: openjsf.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
