# category-games-cn@cn

Актуальный набор доменных правил «category-games-cn@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games-cn@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games_cn_cn_6653c1d7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games_cn_cn_6653c1d7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games-cn@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
