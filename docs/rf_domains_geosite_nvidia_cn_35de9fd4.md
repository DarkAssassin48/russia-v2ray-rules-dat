# nvidia@cn

Актуальный набор доменных правил «nvidia@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nvidia@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nvidia_cn_35de9fd4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nvidia_cn_35de9fd4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nvidia@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: cn.download.nvidia.com
domain_suffix: geforce.cn
domain_suffix: gputechconf.cn
domain_suffix: nvidia.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
