# co · IP-сети

Актуальный набор IP-сетей «co» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `co`. Тип: **ip**.

Правил: **3858**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3858.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_co_4419aace.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_co_4419aace.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-co.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
