# okx

Актуальный набор доменных правил «okx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `okx`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_okx_94344608.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_okx_94344608.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-okx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: okex.com
domain_suffix: oklink.com
domain_suffix: okx-dns.com
domain_suffix: okx-dns1.com
domain_suffix: okx-dns2.com
domain_suffix: okx.ac
domain_suffix: okx.cab
domain_suffix: okx.com
domain_suffix: okx.com.cdn.cloudflare.net
domain_suffix: xlayer.tech
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
