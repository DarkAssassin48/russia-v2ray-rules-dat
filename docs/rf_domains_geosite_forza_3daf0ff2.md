# forza

Актуальный набор доменных правил «forza» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `forza`. Тип: **domains**.

Правил: **5**. Точные домены: 1; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_forza_3daf0ff2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_forza_3daf0ff2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-forza.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: prodforza.blob.core.windows.net
domain_suffix: forza.net
domain_suffix: forzamotorsport.net
domain_suffix: forzaracingchampionship.com
domain_suffix: forzarc.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
