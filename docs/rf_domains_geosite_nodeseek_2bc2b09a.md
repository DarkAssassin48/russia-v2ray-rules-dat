# nodeseek

Актуальный набор доменных правил «nodeseek» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nodeseek`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nodeseek_2bc2b09a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nodeseek_2bc2b09a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nodeseek.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 22112211.xyz
domain_suffix: deepflood.com
domain_suffix: nodeget.com
domain_suffix: nodeimage.com
domain_suffix: nodequality.com
domain_suffix: nodeseek.com
domain_suffix: nodeseek.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
