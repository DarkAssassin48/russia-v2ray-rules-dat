# category-entertainment@!cn

Актуальный набор доменных правил «category-entertainment@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment@!cn`. Тип: **domains**.

Правил: **40**. Точные домены: 6; доменные зоны: 34; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment__cn_2d501adc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment__cn_2d501adc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
