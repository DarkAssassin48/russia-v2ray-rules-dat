# tongcheng

Актуальный набор доменных правил «tongcheng» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tongcheng`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tongcheng_66c01589.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tongcheng_66c01589.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tongcheng.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 17u.cn
domain_suffix: 17u.net
domain_suffix: 17usoft.com
domain_suffix: 17usoft.net
domain_suffix: 40017.cn
domain_suffix: elong.com
domain_suffix: elongstatic.com
domain_suffix: ly.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
