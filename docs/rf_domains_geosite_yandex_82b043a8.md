# yandex

Актуальный набор доменных правил «yandex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yandex`. Тип: **domains**.

Правил: **155**. Точные домены: 18; доменные зоны: 137; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yandex_82b043a8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yandex_82b043a8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yandex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
