# ma · IP-сети

Актуальный набор IP-сетей «ma» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ma`. Тип: **ip**.

Правил: **715**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 715.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ma_72f134c3.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ma_72f134c3.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ma.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
