# seasun

Актуальный набор доменных правил «seasun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `seasun`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_seasun_37b4f435.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_seasun_37b4f435.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-seasun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cbjq.com
domain_suffix: seasungames.cn
domain_suffix: seasungames.com
domain_suffix: seasunwbl.com
domain_suffix: testplus.cn
domain_suffix: xishanju.com
domain_suffix: xoyo.com
domain_suffix: xoyocdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
