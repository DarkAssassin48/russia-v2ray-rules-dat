# shopify

Актуальный набор доменных правил «shopify» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `shopify`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_shopify_bd22696f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_shopify_bd22696f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-shopify.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: myshopify.com
domain_suffix: shop.app
domain_suffix: shopify.com
domain_suffix: shopify.dev
domain_suffix: shopifycdn.com
domain_suffix: shopifycloud.com
domain_suffix: shopifystatus.com
domain_suffix: shopifysvc.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
