# aliyun@!cn

Актуальный набор доменных правил «aliyun@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aliyun@!cn`. Тип: **domains**.

Правил: **17**. Точные домены: 0; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aliyun__cn_f858ac60.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aliyun__cn_f858ac60.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aliyun@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
