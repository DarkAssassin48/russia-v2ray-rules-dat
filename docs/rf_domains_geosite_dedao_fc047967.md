# dedao

Актуальный набор доменных правил «dedao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dedao`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dedao_fc047967.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dedao_fc047967.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dedao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: biji.com
domain_suffix: ddmogo.com
domain_suffix: dedao.cn
domain_suffix: igetget.cn
domain_suffix: igetget.com
domain_suffix: luojilab.com
domain_suffix: mogoo.com
domain_suffix: sao.cn
domain_suffix: saolife.com
domain_suffix: umiwi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
