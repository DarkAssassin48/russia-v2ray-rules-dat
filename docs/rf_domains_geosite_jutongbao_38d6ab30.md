# jutongbao

Актуальный набор доменных правил «jutongbao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jutongbao`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jutongbao_38d6ab30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jutongbao_38d6ab30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jutongbao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: guanggaotongapp.cn
domain_suffix: jutongbao.online
domain_suffix: jutongbao.top
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
