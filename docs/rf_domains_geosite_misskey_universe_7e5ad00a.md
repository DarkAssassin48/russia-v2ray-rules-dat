# misskey-universe

Актуальный набор доменных правил «misskey-universe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `misskey-universe`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_misskey_universe_7e5ad00a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_misskey_universe_7e5ad00a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-misskey-universe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
