# thesun

Актуальный набор доменных правил «thesun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thesun`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thesun_c7fa800e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thesun_c7fa800e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-thesun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dreamteamfc.com
domain_suffix: page3.com
domain_suffix: sunbingo.co.uk
domain_suffix: talksport.com
domain_suffix: thescottishsun.co.uk
domain_suffix: thesun.co.uk
domain_suffix: thesun.ie
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
