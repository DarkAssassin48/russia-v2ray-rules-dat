# wallhaven

Актуальный набор доменных правил «wallhaven» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wallhaven`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wallhaven_c50d88a2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wallhaven_c50d88a2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wallhaven.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wallhaven.cc
domain_suffix: whvn.cc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
