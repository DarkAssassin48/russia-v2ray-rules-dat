# jm · IP-сети

Актуальный набор IP-сетей «jm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jm`. Тип: **ip**.

Правил: **362**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 362.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_jm_da51ee52.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_jm_da51ee52.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-jm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
