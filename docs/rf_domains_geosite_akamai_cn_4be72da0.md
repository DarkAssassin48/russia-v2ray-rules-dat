# akamai@cn

Актуальный набор доменных правил «akamai@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `akamai@cn`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_akamai_cn_4be72da0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_akamai_cn_4be72da0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-akamai@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: accdn.com.cn
domain_suffix: akadns88.net
domain_suffix: akadns99.net
domain_suffix: akamai.com
domain_suffix: akcdn.com.cn
domain_suffix: aptdn.net
domain_suffix: edgekey88.net
domain_suffix: janrain.biz
domain_suffix: janrainservices.com
domain_suffix: skycdn.com.cn
domain_suffix: tl88.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
