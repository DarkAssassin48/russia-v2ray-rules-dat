# ie · IP-сети

Актуальный набор IP-сетей «ie» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ie`. Тип: **ip**.

Правил: **8783**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 8783.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ie_3fa1b483.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ie_3fa1b483.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ie.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
