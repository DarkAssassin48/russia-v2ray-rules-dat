# dj · IP-сети

Актуальный набор IP-сетей «dj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dj`. Тип: **ip**.

Правил: **148**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 148.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_dj_40fafd02.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_dj_40fafd02.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-dj.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
