# microsoft@cn

Актуальный набор доменных правил «microsoft@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft@cn`. Тип: **domains**.

Правил: **189**. Точные домены: 50; доменные зоны: 139; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_cn_3712f29c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_cn_3712f29c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
