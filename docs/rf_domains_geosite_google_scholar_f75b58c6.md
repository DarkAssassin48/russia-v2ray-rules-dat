# google-scholar

Актуальный набор доменных правил «google-scholar» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google-scholar`. Тип: **domains**.

Правил: **76**. Точные домены: 76; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_scholar_f75b58c6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_scholar_f75b58c6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google-scholar.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
