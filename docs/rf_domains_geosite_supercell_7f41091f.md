# supercell

Актуальный набор доменных правил «supercell» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `supercell`. Тип: **domains**.

Правил: **23**. Точные домены: 2; доменные зоны: 21; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_supercell_7f41091f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_supercell_7f41091f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-supercell.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
