# tt · IP-сети

Актуальный набор IP-сетей «tt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tt`. Тип: **ip**.

Правил: **275**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 275.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tt_9feae78a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tt_9feae78a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
