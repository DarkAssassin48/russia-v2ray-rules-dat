# pccw

Актуальный набор доменных правил «pccw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pccw`. Тип: **domains**.

Правил: **29**. Точные домены: 4; доменные зоны: 24; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pccw_1016094a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pccw_1016094a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pccw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
