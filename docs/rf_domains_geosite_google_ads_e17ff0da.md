# google@ads

Актуальный набор доменных правил «google@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google@ads`. Тип: **domains**.

Правил: **54**. Точные домены: 1; доменные зоны: 53; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_ads_e17ff0da.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_ads_e17ff0da.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
