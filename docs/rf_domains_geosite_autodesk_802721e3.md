# autodesk

Актуальный набор доменных правил «autodesk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `autodesk`. Тип: **domains**.

Правил: **558**. Точные домены: 0; доменные зоны: 558; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_autodesk_802721e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_autodesk_802721e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-autodesk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
