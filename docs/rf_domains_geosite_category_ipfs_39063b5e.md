# category-ipfs

Актуальный набор доменных правил «category-ipfs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ipfs`. Тип: **domains**.

Правил: **21**. Точные домены: 0; доменные зоны: 21; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ipfs_39063b5e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ipfs_39063b5e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ipfs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
