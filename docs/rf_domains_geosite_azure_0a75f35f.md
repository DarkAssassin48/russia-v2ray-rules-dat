# azure

Актуальный набор доменных правил «azure» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `azure`. Тип: **domains**.

Правил: **154**. Точные домены: 4; доменные зоны: 150; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_azure_0a75f35f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_azure_0a75f35f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-azure.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
