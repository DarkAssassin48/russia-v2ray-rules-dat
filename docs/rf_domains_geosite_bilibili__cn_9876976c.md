# bilibili@!cn

Актуальный набор доменных правил «bilibili@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bilibili@!cn`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bilibili__cn_9876976c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bilibili__cn_9876976c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bilibili@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: upos-hz-mirrorakam.akamaized.net
domain_suffix: bilibili.tv
domain_suffix: biliintl.com
domain_suffix: dreamcast.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
