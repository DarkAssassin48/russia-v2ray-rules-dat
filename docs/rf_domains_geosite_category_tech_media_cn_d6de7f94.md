# category-tech-media@cn

Актуальный набор доменных правил «category-tech-media@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-tech-media@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_tech_media_cn_d6de7f94.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_tech_media_cn_d6de7f94.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-tech-media@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: thetype.cloud
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
