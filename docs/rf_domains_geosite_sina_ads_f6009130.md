# sina@ads

Актуальный набор доменных правил «sina@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sina@ads`. Тип: **domains**.

Правил: **24**. Точные домены: 0; доменные зоны: 24; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sina_ads_f6009130.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sina_ads_f6009130.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sina@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
