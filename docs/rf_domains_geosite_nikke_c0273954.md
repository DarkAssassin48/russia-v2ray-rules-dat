# nikke

Актуальный набор доменных правил «nikke» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nikke`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nikke_c0273954.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nikke_c0273954.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nikke.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nikke-de.com
domain_suffix: nikke-en.com
domain_suffix: nikke-fr.com
domain_suffix: nikke-jp.com
domain_suffix: nikke-kr.com
domain_suffix: nikke-sea.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
