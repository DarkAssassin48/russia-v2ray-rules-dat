# pinterest

Актуальный набор доменных правил «pinterest» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pinterest`. Тип: **domains**.

Правил: **52**. Точные домены: 0; доменные зоны: 52; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pinterest_167619b1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pinterest_167619b1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pinterest.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
