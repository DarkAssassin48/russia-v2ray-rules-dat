# Windows — телеметрия

Актуальный набор доменных правил «Windows — телеметрия» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `win-spy`. Тип: **domains**.

Правил: **327**. Точные домены: 0; доменные зоны: 327; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_win_spy_f32e117e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_win_spy_f32e117e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-win-spy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
