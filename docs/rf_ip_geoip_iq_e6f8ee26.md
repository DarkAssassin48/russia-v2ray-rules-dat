# iq · IP-сети

Актуальный набор IP-сетей «iq» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `iq`. Тип: **ip**.

Правил: **1640**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1640.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_iq_e6f8ee26.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_iq_e6f8ee26.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-iq.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
