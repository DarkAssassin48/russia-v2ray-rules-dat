# archiveofourown

Актуальный набор доменных правил «archiveofourown» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `archiveofourown`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_archiveofourown_84b634ad.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_archiveofourown_84b634ad.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-archiveofourown.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ao3.org
domain_suffix: archiveofourown.com
domain_suffix: archiveofourown.net
domain_suffix: archiveofourown.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
