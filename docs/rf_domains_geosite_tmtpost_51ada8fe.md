# tmtpost

Актуальный набор доменных правил «tmtpost» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tmtpost`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tmtpost_51ada8fe.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tmtpost_51ada8fe.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tmtpost.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 72whys.com
domain_suffix: chaindd.com
domain_suffix: checkzeit.com
domain_suffix: tigeek.net.cn
domain_suffix: tivitv.com
domain_suffix: tmtpost.com
domain_suffix: tmtsmartlife.com
domain_suffix: tmtsmartrun.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
