# NVIDIA — полная исходная категория

Актуальный набор доменных правил «NVIDIA — полная исходная категория» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nvidia`. Тип: **domains**.

Правил: **66**. Точные домены: 3; доменные зоны: 63; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nvidia_ade59124.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nvidia_ade59124.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nvidia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
