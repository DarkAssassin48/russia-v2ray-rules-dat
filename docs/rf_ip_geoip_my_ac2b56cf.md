# my · IP-сети

Актуальный набор IP-сетей «my» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `my`. Тип: **ip**.

Правил: **3989**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3989.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_my_ac2b56cf.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_my_ac2b56cf.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-my.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
