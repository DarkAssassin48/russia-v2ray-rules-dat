# zynga

Актуальный набор доменных правил «zynga» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zynga`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zynga_4cf3ed4e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zynga_4cf3ed4e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zynga.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: zynga.com
domain_suffix: zyngaplayersupport.com
domain_suffix: zyngapoker.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
