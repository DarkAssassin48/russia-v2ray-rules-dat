# ba · IP-сети

Актуальный набор IP-сетей «ba» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ba`. Тип: **ip**.

Правил: **457**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 457.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ba_99564bd0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ba_99564bd0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ba.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
