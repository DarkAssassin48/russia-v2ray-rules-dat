# movefree

Актуальный набор доменных правил «movefree» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `movefree`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_movefree_4c2d56bd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_movefree_4c2d56bd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-movefree.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: keepmovingwithmovefree.com
domain_suffix: move-free.net
domain_suffix: movefree.cn
domain_suffix: movefreeoffers.com
domain_suffix: movefreerewards.com
domain_suffix: movefrees.com
domain_suffix: schiffvitamins.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
