# sony

Актуальный набор доменных правил «sony» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sony`. Тип: **domains**.

Правил: **120**. Точные домены: 0; доменные зоны: 120; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sony_1fcf76c1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sony_1fcf76c1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sony.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
