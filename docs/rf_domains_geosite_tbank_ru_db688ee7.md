# tbank-ru

Актуальный набор доменных правил «tbank-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tbank-ru`. Тип: **domains**.

Правил: **112**. Точные домены: 2; доменные зоны: 110; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tbank_ru_db688ee7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tbank_ru_db688ee7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tbank-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
