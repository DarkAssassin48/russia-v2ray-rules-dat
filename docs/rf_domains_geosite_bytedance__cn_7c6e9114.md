# bytedance@!cn

Актуальный набор доменных правил «bytedance@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bytedance@!cn`. Тип: **domains**.

Правил: **54**. Точные домены: 7; доменные зоны: 47; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bytedance__cn_7c6e9114.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bytedance__cn_7c6e9114.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bytedance@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
