# okjike

Актуальный набор доменных правил «okjike» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `okjike`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_okjike_42cbd886.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_okjike_42cbd886.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-okjike.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jike.city
domain_suffix: jikecdn.com
domain_suffix: okjike.com
domain_suffix: okjk.co
domain_suffix: ruguoapp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
