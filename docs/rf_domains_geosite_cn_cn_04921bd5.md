# cn@cn

Актуальный набор доменных правил «cn@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cn@cn`. Тип: **domains**.

Правил: **76**. Точные домены: 19; доменные зоны: 54; фрагменты: 0; regex: 3; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cn_cn_04921bd5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cn_cn_04921bd5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cn@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
