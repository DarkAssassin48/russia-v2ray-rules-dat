# pingan

Актуальный набор доменных правил «pingan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pingan`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pingan_ab699943.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pingan_ab699943.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pingan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pingan.com
domain_suffix: pingan.com.cn
domain_suffix: pingan.com.hk
domain_suffix: yqb.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
