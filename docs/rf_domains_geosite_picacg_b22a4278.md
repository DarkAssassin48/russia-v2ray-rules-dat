# picacg

Актуальный набор доменных правил «picacg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `picacg`. Тип: **domains**.

Правил: **13**. Точные домены: 2; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_picacg_b22a4278.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_picacg_b22a4278.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-picacg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain: ad-channel.diwodiwo.xyz
domain: ad-display.diwodiwo.xyz
domain_suffix: bikaa.xyz
domain_suffix: bikac.xyz
