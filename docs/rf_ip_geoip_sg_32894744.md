# sg · IP-сети

Актуальный набор IP-сетей «sg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sg`. Тип: **ip**.

Правил: **14448**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 14448.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sg_32894744.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sg_32894744.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
