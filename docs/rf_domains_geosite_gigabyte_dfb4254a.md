# gigabyte

Актуальный набор доменных правил «gigabyte» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gigabyte`. Тип: **domains**.

Правил: **7**. Точные домены: 3; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gigabyte_dfb4254a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gigabyte_dfb4254a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gigabyte.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: gigabyte2.azureedge.net
domain: sa78gs.wpc.edgecastcdn.net
domain: sni1dcb6gl.wpc.edgecastcdn.net
domain_suffix: aorus.com
domain_suffix: aoruszone.cn
domain_suffix: gigabyte.cn
domain_suffix: gigabyte.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
