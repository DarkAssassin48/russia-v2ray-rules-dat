# jianshu

Актуальный набор доменных правил «jianshu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jianshu`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jianshu_209b8ae5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jianshu_209b8ae5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jianshu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jianshu.com
domain_suffix: jianshu.io
domain_suffix: jianshuapi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
