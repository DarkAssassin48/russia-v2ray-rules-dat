# mini

Актуальный набор доменных правил «mini» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mini`. Тип: **domains**.

Правил: **214**. Точные домены: 0; доменные зоны: 214; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mini_648b49ef.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mini_648b49ef.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mini.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
