# notion

Актуальный набор доменных правил «notion» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `notion`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_notion_9c163e1a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_notion_9c163e1a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-notion.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: notion-static.com
domain_suffix: notion-status.com
domain_suffix: notion.com
domain_suffix: notion.new
domain_suffix: notion.site
domain_suffix: notion.so
domain_suffix: notionusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
