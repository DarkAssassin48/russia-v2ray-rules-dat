# mn · IP-сети

Актуальный набор IP-сетей «mn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mn`. Тип: **ip**.

Правил: **492**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 492.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mn_804f688d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mn_804f688d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
