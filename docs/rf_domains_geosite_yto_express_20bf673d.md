# yto-express

Актуальный набор доменных правил «yto-express» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yto-express`. Тип: **domains**.

Правил: **43**. Точные домены: 0; доменные зоны: 43; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yto_express_20bf673d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yto_express_20bf673d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yto-express.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
