# kuaishou

Актуальный набор доменных правил «kuaishou» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kuaishou`. Тип: **domains**.

Правил: **40**. Точные домены: 3; доменные зоны: 37; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kuaishou_5858c223.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kuaishou_5858c223.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kuaishou.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
