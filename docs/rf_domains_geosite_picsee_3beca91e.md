# picsee

Актуальный набор доменных правил «picsee» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `picsee`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_picsee_3beca91e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_picsee_3beca91e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-picsee.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pics.ee
domain_suffix: picsee.co
domain_suffix: picsee.pro
domain_suffix: pise.pw
domain_suffix: pros.ee
domain_suffix: pse.is
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
