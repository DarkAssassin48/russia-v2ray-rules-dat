# zhimeishe

Актуальный набор доменных правил «zhimeishe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zhimeishe`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zhimeishe_073e93c9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zhimeishe_073e93c9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zhimeishe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 168sex.top
domain_suffix: a7sex.com
domain_suffix: ctotires.com
domain_suffix: ferryclean.com
domain_suffix: zhimeishe888.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
