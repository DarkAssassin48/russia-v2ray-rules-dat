# perplexity

Актуальный набор доменных правил «perplexity» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `perplexity`. Тип: **domains**.

Правил: **5**. Точные домены: 2; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_perplexity_1876c19d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_perplexity_1876c19d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-perplexity.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ppl-ai-file-upload.s3.amazonaws.com
domain: pplx-res.cloudinary.com
domain_suffix: perplexity.ai
domain_suffix: perplexity.com
domain_suffix: pplx.ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
