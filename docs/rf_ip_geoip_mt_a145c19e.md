# mt · IP-сети

Актуальный набор IP-сетей «mt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mt`. Тип: **ip**.

Правил: **423**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 423.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mt_a145c19e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mt_a145c19e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
