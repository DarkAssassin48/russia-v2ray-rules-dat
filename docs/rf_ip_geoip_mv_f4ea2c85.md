# mv · IP-сети

Актуальный набор IP-сетей «mv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mv`. Тип: **ip**.

Правил: **232**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 232.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mv_f4ea2c85.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mv_f4ea2c85.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
