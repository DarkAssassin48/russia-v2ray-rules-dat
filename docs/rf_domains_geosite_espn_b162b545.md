# espn

Актуальный набор доменных правил «espn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `espn`. Тип: **domains**.

Правил: **11**. Точные домены: 3; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_espn_b162b545.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_espn_b162b545.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-espn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: espn.api.edge.bamgrid.com
domain: espn.hb.omtrdc.net
domain: espndotcom.tt.omtrdc.net
domain_suffix: dtci.co
domain_suffix: dtci.technology
domain_suffix: espn.co.uk
domain_suffix: espn.com
domain_suffix: espn.net
domain_suffix: espncdn.com
domain_suffix: espnqa.com
domain_suffix: watchespn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
