# pixnet

Актуальный набор доменных правил «pixnet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pixnet`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pixnet_a02e190b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pixnet_a02e190b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pixnet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pimg.tw
domain_suffix: pixanalytics.com
domain_suffix: pixfs.net
domain_suffix: pixinsight.com.tw
domain_suffix: pixnet.cc
domain_suffix: pixnet.net
domain_suffix: pixnet.pro
domain_suffix: pixnet.tw
domain_suffix: pixplug.in
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
