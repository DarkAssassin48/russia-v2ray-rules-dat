# picacg@ads

Актуальный набор доменных правил «picacg@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `picacg@ads`. Тип: **domains**.

Правил: **2**. Точные домены: 2; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_picacg_ads_ae0f9bd7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_picacg_ads_ae0f9bd7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-picacg@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ad-channel.diwodiwo.xyz
domain: ad-display.diwodiwo.xyz
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
