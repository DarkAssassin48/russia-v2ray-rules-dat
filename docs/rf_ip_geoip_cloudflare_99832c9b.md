# cloudflare · IP-сети

Актуальный набор IP-сетей «cloudflare» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cloudflare`. Тип: **ip**.

Правил: **911**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 911.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cloudflare_99832c9b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cloudflare_99832c9b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cloudflare.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
