# gy · IP-сети

Актуальный набор IP-сетей «gy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gy`. Тип: **ip**.

Правил: **144**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 144.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gy_3dc91246.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gy_3dc91246.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
