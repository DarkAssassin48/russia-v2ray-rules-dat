# embl

Актуальный набор доменных правил «embl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `embl`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_embl_a3ea2750.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_embl_a3ea2750.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-embl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ebi.ac.uk
domain_suffix: embl-hamburg.de
domain_suffix: embl.de
domain_suffix: embl.fr
domain_suffix: embl.it
domain_suffix: embl.org
domain_suffix: emblstatic.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
