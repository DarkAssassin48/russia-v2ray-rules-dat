# Мобильные белые списки РФ · IP-сети

Актуальный набор IP-сетей «Мобильные белые списки РФ» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-whitelist`. Тип: **ip**.

Правил: **30222**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 30222.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ru_whitelist_549ca7e3.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ru_whitelist_549ca7e3.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ru-whitelist.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
