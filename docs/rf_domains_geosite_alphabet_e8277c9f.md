# alphabet

Актуальный набор доменных правил «alphabet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alphabet`. Тип: **domains**.

Правил: **1064**. Точные домены: 213; доменные зоны: 849; фрагменты: 0; regex: 2; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alphabet_e8277c9f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alphabet_e8277c9f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alphabet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
