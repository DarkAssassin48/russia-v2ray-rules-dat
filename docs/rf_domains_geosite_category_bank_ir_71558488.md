# category-bank-ir

Актуальный набор доменных правил «category-bank-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bank-ir`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bank_ir_71558488.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bank_ir_71558488.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bank-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
