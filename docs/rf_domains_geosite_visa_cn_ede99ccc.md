# visa@cn

Актуальный набор доменных правил «visa@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `visa@cn`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_visa_cn_ede99ccc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_visa_cn_ede99ccc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-visa@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: financialsoccer.com.cn
domain_suffix: practicalmoneyskills.cn
domain_suffix: practicalmoneyskills.com.cn
domain_suffix: visa.cn
domain_suffix: visa.com.cn
domain_suffix: visainfinite.cn
domain_suffix: visapay.cn
domain_suffix: visaplatinum.cn
domain_suffix: visaplatinum.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
