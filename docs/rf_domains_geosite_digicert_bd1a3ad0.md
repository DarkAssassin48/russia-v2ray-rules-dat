# digicert

Актуальный набор доменных правил «digicert» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `digicert`. Тип: **domains**.

Правил: **74**. Точные домены: 0; доменные зоны: 74; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_digicert_bd1a3ad0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_digicert_bd1a3ad0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-digicert.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
