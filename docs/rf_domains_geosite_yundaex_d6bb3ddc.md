# yundaex

Актуальный набор доменных правил «yundaex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yundaex`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yundaex_d6bb3ddc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yundaex_d6bb3ddc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yundaex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: udalogistic.cn
domain_suffix: udalogistic.com
domain_suffix: ydsys.cn
domain_suffix: yunda56.com
domain_suffix: yundaex.cn
domain_suffix: yundaex.com
domain_suffix: yundalog.com
domain_suffix: yundaltl.com
domain_suffix: yundasys.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
