# category-emby

Актуальный набор доменных правил «category-emby» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-emby`. Тип: **domains**.

Правил: **83**. Точные домены: 52; доменные зоны: 31; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_emby_3983cb03.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_emby_3983cb03.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-emby.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
