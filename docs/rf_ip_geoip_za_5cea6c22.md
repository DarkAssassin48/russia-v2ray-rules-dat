# za · IP-сети

Актуальный набор IP-сетей «za» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `za`. Тип: **ip**.

Правил: **5534**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5534.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_za_5cea6c22.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_za_5cea6c22.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-za.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
