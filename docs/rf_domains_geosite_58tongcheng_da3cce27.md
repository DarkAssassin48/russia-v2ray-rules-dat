# 58tongcheng

Актуальный набор доменных правил «58tongcheng» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `58tongcheng`. Тип: **domains**.

Правил: **42**. Точные домены: 0; доменные зоны: 42; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_58tongcheng_da3cce27.txt)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
