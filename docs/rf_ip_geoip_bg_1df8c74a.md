# bg · IP-сети

Актуальный набор IP-сетей «bg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bg`. Тип: **ip**.

Правил: **3229**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3229.
