# category-tech-media

Актуальный набор доменных правил «category-tech-media» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-tech-media`. Тип: **domains**.

Правил: **26**. Точные домены: 0; доменные зоны: 26; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_tech_media_83ac4f5e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_tech_media_83ac4f5e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-tech-media.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
