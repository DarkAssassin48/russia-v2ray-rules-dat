# timeweb

Актуальный набор доменных правил «timeweb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `timeweb`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_timeweb_b4ec9fef.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_timeweb_b4ec9fef.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-timeweb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: timeweb.cloud
domain_suffix: timeweb.com
domain_suffix: timeweb.tech
domain_suffix: timewebcloud.kz
domain_suffix: twcstorage.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
