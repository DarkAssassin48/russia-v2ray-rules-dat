# wisekey

Актуальный набор доменных правил «wisekey» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wisekey`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wisekey_fc61a619.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wisekey_fc61a619.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wisekey.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wisecoin.com
domain_suffix: wiseid.com
domain_suffix: wisekey.com
domain_suffix: wisekey.com.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
