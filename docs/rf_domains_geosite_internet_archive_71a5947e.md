# internet-archive

Актуальный набор доменных правил «internet-archive» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `internet-archive`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_internet_archive_71a5947e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_internet_archive_71a5947e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-internet-archive.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: archive-it.org
domain_suffix: archive.org
domain_suffix: openlibrary.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
