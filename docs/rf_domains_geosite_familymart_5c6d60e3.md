# familymart

Актуальный набор доменных правил «familymart» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `familymart`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_familymart_5c6d60e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_familymart_5c6d60e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-familymart.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: famifun.com.tw
domain_suffix: family.co.jp
domain_suffix: family.com.tw
domain_suffix: familymart.com.cn
domain_suffix: familymart.com.my
domain_suffix: familymart.com.ph
domain_suffix: famima.vn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
