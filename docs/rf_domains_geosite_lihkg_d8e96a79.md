# lihkg

Актуальный набор доменных правил «lihkg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lihkg`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lihkg_d8e96a79.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lihkg_d8e96a79.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lihkg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lih.kg
domain_suffix: lihkg.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
