# fi · IP-сети

Актуальный набор IP-сетей «fi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fi`. Тип: **ip**.

Правил: **46615**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 46615.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fi_175f909c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fi_175f909c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
