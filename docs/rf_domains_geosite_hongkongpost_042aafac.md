# hongkongpost

Актуальный набор доменных правил «hongkongpost» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hongkongpost`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hongkongpost_042aafac.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hongkongpost_042aafac.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hongkongpost.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ecert.gov.hk
domain_suffix: hongkongpost.gov.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
