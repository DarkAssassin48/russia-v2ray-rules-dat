# tv · IP-сети

Актуальный набор IP-сетей «tv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tv`. Тип: **ip**.

Правил: **119**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 119.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tv_1253ac9c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tv_1253ac9c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
