# km · IP-сети

Актуальный набор IP-сетей «km» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `km`. Тип: **ip**.

Правил: **111**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 111.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_km_79ba3851.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_km_79ba3851.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-km.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
