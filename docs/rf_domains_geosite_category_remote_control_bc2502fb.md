# category-remote-control

Актуальный набор доменных правил «category-remote-control» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-remote-control`. Тип: **domains**.

Правил: **8**. Точные домены: 2; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_remote_control_bc2502fb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_remote_control_bc2502fb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-remote-control.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: client-teamviewer-com.trafficmanager.net
domain: teamviewer.com.cdn.cloudflare.net
domain_suffix: anydesk.com
domain_suffix: nomachine.com
domain_suffix: rustdesk.com
domain_suffix: teamviewer.cn
domain_suffix: teamviewer.com
domain_suffix: teamviewer.us
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
