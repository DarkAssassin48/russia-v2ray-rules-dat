# mafengwo

Актуальный набор доменных правил «mafengwo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mafengwo`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mafengwo_023cb167.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mafengwo_023cb167.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mafengwo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mafengwo.cn
domain_suffix: mafengwo.com
domain_suffix: mafengwo.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
