# juejin

Актуальный набор доменных правил «juejin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `juejin`. Тип: **domains**.

Правил: **12**. Точные домены: 9; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_juejin_958c62ad.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_juejin_958c62ad.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-juejin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: p1-juejin.byteimg.com
domain: p2-juejin.byteimg.com
domain: p3-juejin.byteimg.com
domain: p4-juejin.byteimg.com
domain: p5-juejin.byteimg.com
domain: p6-juejin.byteimg.com
domain: p7-juejin.byteimg.com
domain: p8-juejin.byteimg.com
domain: p9-juejin.byteimg.com
domain_suffix: juejin.cn
domain_suffix: juejin.im
domain_suffix: xitu.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
