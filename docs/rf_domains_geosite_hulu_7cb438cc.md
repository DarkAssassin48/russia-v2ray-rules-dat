# hulu

Актуальный набор доменных правил «hulu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hulu`. Тип: **domains**.

Правил: **48**. Точные домены: 1; доменные зоны: 47; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hulu_7cb438cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hulu_7cb438cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hulu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
