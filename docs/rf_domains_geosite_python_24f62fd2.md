# python

Актуальный набор доменных правил «python» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `python`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_python_24f62fd2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_python_24f62fd2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-python.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pycon.org
domain_suffix: pypa.io
domain_suffix: pypi.io
domain_suffix: pypi.org
domain_suffix: python.org
domain_suffix: pythonhosted.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
