# am · IP-сети

Актуальный набор IP-сетей «am» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `am`. Тип: **ip**.

Правил: **771**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 771.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_am_634badb0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_am_634badb0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-am.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
