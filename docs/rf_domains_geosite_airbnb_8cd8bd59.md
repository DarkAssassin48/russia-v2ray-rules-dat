# airbnb

Актуальный набор доменных правил «airbnb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `airbnb`. Тип: **domains**.

Правил: **83**. Точные домены: 0; доменные зоны: 83; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_airbnb_8cd8bd59.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_airbnb_8cd8bd59.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-airbnb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
