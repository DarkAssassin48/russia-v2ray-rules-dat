# durex

Актуальный набор доменных правил «durex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `durex`. Тип: **domains**.

Правил: **62**. Точные домены: 0; доменные зоны: 62; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_durex_211c5a59.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_durex_211c5a59.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-durex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
