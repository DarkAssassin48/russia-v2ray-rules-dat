# nationalgeographic

Актуальный набор доменных правил «nationalgeographic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nationalgeographic`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nationalgeographic_f0d392b0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nationalgeographic_f0d392b0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nationalgeographic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: natgeomaps.com
domain_suffix: nationalgeographic.com
domain_suffix: nationalgeographicpartners.com
domain_suffix: ngeo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
