# meduza

Актуальный набор доменных правил «meduza» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `meduza`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_meduza_8e0a7b28.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_meduza_8e0a7b28.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-meduza.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: meduza-flutter.firebaseapp.com
domain_suffix: meduza.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
