# category-ip-geo-detect

Актуальный набор доменных правил «category-ip-geo-detect» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ip-geo-detect`. Тип: **domains**.

Правил: **1682**. Точные домены: 105; доменные зоны: 1577; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ip_geo_detect_84bc4a5d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ip_geo_detect_84bc4a5d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ip-geo-detect.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
