# kinopub

Актуальный набор доменных правил «kinopub» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kinopub`. Тип: **domains**.

Правил: **19**. Точные домены: 0; доменные зоны: 18; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kinopub_ab6ee8f5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kinopub_ab6ee8f5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kinopub.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
