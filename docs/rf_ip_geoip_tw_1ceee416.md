# tw · IP-сети

Актуальный набор IP-сетей «tw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tw`. Тип: **ip**.

Правил: **4885**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 4885.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tw_1ceee416.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tw_1ceee416.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
