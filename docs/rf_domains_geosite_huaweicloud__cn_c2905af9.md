# huaweicloud@!cn

Актуальный набор доменных правил «huaweicloud@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huaweicloud@!cn`. Тип: **domains**.

Правил: **44**. Точные домены: 0; доменные зоны: 44; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huaweicloud__cn_c2905af9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huaweicloud__cn_c2905af9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huaweicloud@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
