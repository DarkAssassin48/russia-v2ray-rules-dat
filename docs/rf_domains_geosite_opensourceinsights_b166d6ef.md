# opensourceinsights

Актуальный набор доменных правил «opensourceinsights» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `opensourceinsights`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_opensourceinsights_b166d6ef.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_opensourceinsights_b166d6ef.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-opensourceinsights.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: deps.dev
domain_suffix: deps.info
domain_suffix: opensourceinsight.dev
domain_suffix: opensourceinsights.dev
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
