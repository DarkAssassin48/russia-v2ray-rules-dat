# amc

Актуальный набор доменных правил «amc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amc`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amc_0154d22c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amc_0154d22c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: amc.com
domain_suffix: amcn.com
domain_suffix: amcnetworks.com
domain_suffix: amcplus.com
domain_suffix: e5a6ae085b6c43020dea230eb0c0ecc33a188227507da97b8ecc05eb8beace6.us-east-1.prod.service.minerva.devices.a2z.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
