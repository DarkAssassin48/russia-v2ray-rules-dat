# aliyun@telemetry

Актуальный набор доменных правил «aliyun@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aliyun@telemetry`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aliyun_telemetry_484e3170.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aliyun_telemetry_484e3170.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aliyun@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adash-emas.cn-hangzhou.aliyuncs.com
domain_suffix: adash.man.aliyuncs.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
