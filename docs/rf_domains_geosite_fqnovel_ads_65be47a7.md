# fqnovel@ads

Актуальный набор доменных правил «fqnovel@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fqnovel@ads`. Тип: **domains**.

Правил: **15**. Точные домены: 15; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fqnovel_ads_65be47a7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fqnovel_ads_65be47a7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fqnovel@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
