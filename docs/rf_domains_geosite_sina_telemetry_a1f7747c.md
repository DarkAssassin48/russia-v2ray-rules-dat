# sina@telemetry

Актуальный набор доменных правил «sina@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sina@telemetry`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sina_telemetry_a1f7747c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sina_telemetry_a1f7747c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sina@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beacon.sina.com.cn
domain_suffix: log.sina.cn
domain_suffix: log2.sina.cn
domain_suffix: sbeacon.sina.com.cn
domain_suffix: slog.sina.cn
domain_suffix: slog.sina.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
