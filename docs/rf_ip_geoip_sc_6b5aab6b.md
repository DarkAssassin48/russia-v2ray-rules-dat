# sc · IP-сети

Актуальный набор IP-сетей «sc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sc`. Тип: **ip**.

Правил: **4932**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 4932.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sc_6b5aab6b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sc_6b5aab6b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
