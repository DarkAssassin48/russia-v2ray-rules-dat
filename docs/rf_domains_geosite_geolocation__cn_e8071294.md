# Домены вне Китая — общий набор

Актуальный набор доменных правил «Домены вне Китая — общий набор» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `geolocation-!cn`. Тип: **domains**.

Правил: **24450**. Точные домены: 770; доменные зоны: 23529; фрагменты: 0; regex: 151; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_geolocation__cn_e8071294.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_geolocation__cn_e8071294.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-geolocation-!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
