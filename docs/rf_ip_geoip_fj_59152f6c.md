# fj · IP-сети

Актуальный набор IP-сетей «fj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fj`. Тип: **ip**.

Правил: **204**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 204.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fj_59152f6c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fj_59152f6c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fj.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
