# samsung@cn

Актуальный набор доменных правил «samsung@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `samsung@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_samsung_cn_78d4915e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_samsung_cn_78d4915e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-samsung@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: samsung.com.cn
domain_suffix: samsungcloudcn.com
domain_suffix: samsungeshop.com.cn
domain_suffix: samsunghealthcn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
