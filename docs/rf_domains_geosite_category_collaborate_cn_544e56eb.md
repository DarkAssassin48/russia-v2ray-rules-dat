# category-collaborate-cn

Актуальный набор доменных правил «category-collaborate-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-collaborate-cn`. Тип: **domains**.

Правил: **26**. Точные домены: 0; доменные зоны: 26; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_collaborate_cn_544e56eb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_collaborate_cn_544e56eb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-collaborate-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
