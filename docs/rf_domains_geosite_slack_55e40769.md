# slack

Актуальный набор доменных правил «slack» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `slack`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_slack_55e40769.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_slack_55e40769.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-slack.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: slack-core.com
domain_suffix: slack-edge.com
domain_suffix: slack-files.com
domain_suffix: slack-imgs.com
domain_suffix: slack-msgs.com
domain_suffix: slack-redir.net
domain_suffix: slack.com
domain_suffix: slackb.com
domain_suffix: slackcertified.com
domain_suffix: slackdemo.com
domain_suffix: slackhq.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
