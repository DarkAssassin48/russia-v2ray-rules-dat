# ctrip

Актуальный набор доменных правил «ctrip» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ctrip`. Тип: **domains**.

Правил: **46**. Точные домены: 0; доменные зоны: 46; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ctrip_f3ed36cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ctrip_f3ed36cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ctrip.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
