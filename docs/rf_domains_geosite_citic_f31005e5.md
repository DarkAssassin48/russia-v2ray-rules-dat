# citic

Актуальный набор доменных правил «citic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `citic`. Тип: **domains**.

Правил: **17**. Точные домены: 0; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_citic_f31005e5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_citic_f31005e5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-citic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
