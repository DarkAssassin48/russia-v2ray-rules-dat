# dell

Актуальный набор доменных правил «dell» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dell`. Тип: **domains**.

Правил: **210**. Точные домены: 1; доменные зоны: 209; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dell_217621d5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dell_217621d5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dell.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
