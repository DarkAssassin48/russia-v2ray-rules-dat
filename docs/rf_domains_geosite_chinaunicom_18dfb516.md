# chinaunicom

Актуальный набор доменных правил «chinaunicom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinaunicom`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinaunicom_18dfb516.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinaunicom_18dfb516.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinaunicom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
