# category-cryptocurrency

Актуальный набор доменных правил «category-cryptocurrency» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cryptocurrency`. Тип: **domains**.

Правил: **240**. Точные домены: 8; доменные зоны: 232; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cryptocurrency_8360fa8b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cryptocurrency_8360fa8b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cryptocurrency.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
