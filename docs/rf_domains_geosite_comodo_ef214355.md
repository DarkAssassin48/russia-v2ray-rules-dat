# comodo

Актуальный набор доменных правил «comodo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `comodo`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_comodo_ef214355.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_comodo_ef214355.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-comodo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: comodo.com
domain_suffix: comodo.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
