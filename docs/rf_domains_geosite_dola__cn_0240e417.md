# dola@!cn

Актуальный набор доменных правил «dola@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dola@!cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dola__cn_0240e417.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dola__cn_0240e417.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dola@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cici.com
domain_suffix: ciciai.com
domain_suffix: ciciaicdn.com
domain_suffix: dola.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
