# dcard

Актуальный набор доменных правил «dcard» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dcard`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dcard_4b01fd1b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dcard_4b01fd1b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dcard.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dcard.cc
domain_suffix: dcard.io
domain_suffix: dcard.link
domain_suffix: dcard.tw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
