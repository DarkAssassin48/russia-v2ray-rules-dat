# javwide

Актуальный набор доменных правил «javwide» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `javwide`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_javwide_3abf3020.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_javwide_3abf3020.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-javwide.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: javwide.com
domain_suffix: javwide.tv
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
