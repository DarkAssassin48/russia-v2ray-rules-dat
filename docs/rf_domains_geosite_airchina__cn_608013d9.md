# airchina@!cn

Актуальный набор доменных правил «airchina@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `airchina@!cn`. Тип: **domains**.

Правил: **28**. Точные домены: 0; доменные зоны: 28; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_airchina__cn_608013d9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_airchina__cn_608013d9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-airchina@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
