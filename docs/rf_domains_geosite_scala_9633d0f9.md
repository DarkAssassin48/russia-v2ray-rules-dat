# scala

Актуальный набор доменных правил «scala» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `scala`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_scala_9633d0f9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_scala_9633d0f9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-scala.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: scala-lang.org
domain_suffix: scala-sbt.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
