# walmart

Актуальный набор доменных правил «walmart» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `walmart`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_walmart_b1b8e895.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_walmart_b1b8e895.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-walmart.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .walmart
domain_suffix: w-mt.co
domain_suffix: wal-mart.com
domain_suffix: wal.co
domain_suffix: walmart-content.com
domain_suffix: walmart.cn
domain_suffix: walmart.com
domain_suffix: walmart.pharmacy
domain_suffix: walmartimages.com
domain_suffix: wmt.co
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
