# ruanmei

Актуальный набор доменных правил «ruanmei» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ruanmei`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ruanmei_94274deb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ruanmei_94274deb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ruanmei.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 6655.com
domain_suffix: cooldock.com
domain_suffix: ithome.com
domain_suffix: lapin365.com
domain_suffix: ruanmei.com
domain_suffix: saayaa.com
domain_suffix: win7china.com
domain_suffix: win8china.com
domain_suffix: zuihuimai.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
