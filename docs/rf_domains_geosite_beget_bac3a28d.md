# beget

Актуальный набор доменных правил «beget» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `beget`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_beget_bac3a28d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_beget_bac3a28d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-beget.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beget.app
domain_suffix: beget.cloud
domain_suffix: beget.com

domain_suffix: beget.email
domain_suffix: beget.hosting
domain_suffix: beget.pro

domain_suffix: beget.tech
domain_suffix: begetcdn.cloud
domain_suffix: beserver.ru
domain_suffix: bget.ru
domain_suffix: sprut.io
domain_suffix: xn--90aefb9d.xn--p1ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
