# lc · IP-сети

Актуальный набор IP-сетей «lc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lc`. Тип: **ip**.

Правил: **178**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 178.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lc_ca830168.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lc_ca830168.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
