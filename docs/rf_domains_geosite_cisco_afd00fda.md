# cisco

Актуальный набор доменных правил «cisco» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cisco`. Тип: **domains**.

Правил: **121**. Точные домены: 2; доменные зоны: 119; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cisco_afd00fda.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cisco_afd00fda.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cisco.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
