# baidu

Актуальный набор доменных правил «baidu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `baidu`. Тип: **domains**.

Правил: **132**. Точные домены: 0; доменные зоны: 132; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_baidu_43a92be1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_baidu_43a92be1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-baidu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
