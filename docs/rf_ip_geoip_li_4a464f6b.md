# li · IP-сети

Актуальный набор IP-сетей «li» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `li`. Тип: **ip**.

Правил: **489**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 489.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_li_4a464f6b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_li_4a464f6b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-li.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
