# cu · IP-сети

Актуальный набор IP-сетей «cu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cu`. Тип: **ip**.

Правил: **184**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 184.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cu_ec33c87c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cu_ec33c87c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
