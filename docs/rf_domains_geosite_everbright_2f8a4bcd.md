# everbright

Актуальный набор доменных правил «everbright» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `everbright`. Тип: **domains**.

Правил: **15**. Точные домены: 0; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_everbright_2f8a4bcd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_everbright_2f8a4bcd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-everbright.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
