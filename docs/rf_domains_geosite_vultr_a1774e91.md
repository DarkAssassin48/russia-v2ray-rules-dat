# vultr

Актуальный набор доменных правил «vultr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vultr`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vultr_a1774e91.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vultr_a1774e91.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vultr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: vultr.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
