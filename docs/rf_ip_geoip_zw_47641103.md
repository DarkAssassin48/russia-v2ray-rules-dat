# zw · IP-сети

Актуальный набор IP-сетей «zw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zw`. Тип: **ip**.

Правил: **367**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 367.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_zw_47641103.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_zw_47641103.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-zw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
