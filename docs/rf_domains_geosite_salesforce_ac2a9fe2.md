# salesforce

Актуальный набор доменных правил «salesforce» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `salesforce`. Тип: **domains**.

Правил: **41**. Точные домены: 0; доменные зоны: 41; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_salesforce_ac2a9fe2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_salesforce_ac2a9fe2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-salesforce.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
