# canon

Актуальный набор доменных правил «canon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `canon`. Тип: **domains**.

Правил: **71**. Точные домены: 0; доменные зоны: 71; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_canon_f7a2e947.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_canon_f7a2e947.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-canon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
