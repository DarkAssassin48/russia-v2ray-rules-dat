# tl · IP-сети

Актуальный набор IP-сетей «tl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tl`. Тип: **ip**.

Правил: **176**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 176.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tl_a73322dc.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tl_a73322dc.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
