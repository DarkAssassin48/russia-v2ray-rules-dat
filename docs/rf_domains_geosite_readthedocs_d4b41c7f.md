# readthedocs

Актуальный набор доменных правил «readthedocs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `readthedocs`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_readthedocs_d4b41c7f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_readthedocs_d4b41c7f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-readthedocs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: readthedocs-hosted.com
domain_suffix: readthedocs.com
domain_suffix: readthedocs.io
domain_suffix: readthedocs.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
