# madshi

Актуальный набор доменных правил «madshi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `madshi`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_madshi_494c0150.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_madshi_494c0150.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-madshi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: madshi.net
domain_suffix: madvr.com
domain_suffix: madvr.net
domain_suffix: madvrlabs.llc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
