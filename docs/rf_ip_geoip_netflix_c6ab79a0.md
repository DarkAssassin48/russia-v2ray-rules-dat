# Netflix · IP-сети

Актуальный набор IP-сетей «Netflix» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `netflix`. Тип: **ip**.

Правил: **122**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 122.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_netflix_c6ab79a0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_netflix_c6ab79a0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-netflix.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
