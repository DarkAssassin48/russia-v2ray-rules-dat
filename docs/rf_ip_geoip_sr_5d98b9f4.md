# sr · IP-сети

Актуальный набор IP-сетей «sr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sr`. Тип: **ip**.

Правил: **141**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 141.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sr_5d98b9f4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sr_5d98b9f4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
