# carrotquest

Актуальный набор доменных правил «carrotquest» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `carrotquest`. Тип: **domains**.

Правил: **23**. Точные домены: 11; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_carrotquest_57f1430c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_carrotquest_57f1430c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-carrotquest.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
