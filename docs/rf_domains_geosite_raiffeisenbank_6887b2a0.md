# raiffeisenbank

Актуальный набор доменных правил «raiffeisenbank» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `raiffeisenbank`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_raiffeisenbank_6887b2a0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_raiffeisenbank_6887b2a0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-raiffeisenbank.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
