# al · IP-сети

Актуальный набор IP-сетей «al» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `al`. Тип: **ip**.

Правил: **1446**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1446.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_al_627c62fb.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_al_627c62fb.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-al.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
