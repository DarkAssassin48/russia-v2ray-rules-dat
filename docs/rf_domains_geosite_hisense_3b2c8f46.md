# hisense

Актуальный набор доменных правил «hisense» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hisense`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hisense_3b2c8f46.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hisense_3b2c8f46.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hisense.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hisense-home.com
domain_suffix: hisense.com
domain_suffix: hisensehitachi.com
domain_suffix: hisensekf.com
domain_suffix: hismarttv.com
domain_suffix: juhaokan.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
