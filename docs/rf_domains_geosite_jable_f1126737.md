# jable

Актуальный набор доменных правил «jable» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jable`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jable_f1126737.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jable_f1126737.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jable.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cdnlab.live
domain_suffix: jable.tv
domain_suffix: mushroomtrack.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
