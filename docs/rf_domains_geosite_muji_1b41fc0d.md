# muji

Актуальный набор доменных правил «muji» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `muji`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_muji_1b41fc0d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_muji_1b41fc0d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-muji.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: muji.com
domain_suffix: muji.com.cn
domain_suffix: muji.com.hk
domain_suffix: muji.eu
domain_suffix: muji.net
domain_suffix: muji.tw
domain_suffix: muji.us
domain_suffix: mujikorea.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
