# wildberries@ads

Актуальный набор доменных правил «wildberries@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wildberries@ads`. Тип: **domains**.

Правил: **15**. Точные домены: 15; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wildberries_ads_a4c7826b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wildberries_ads_a4c7826b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wildberries@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
