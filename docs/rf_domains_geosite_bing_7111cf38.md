# bing

Актуальный набор доменных правил «bing» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bing`. Тип: **domains**.

Правил: **41**. Точные домены: 2; доменные зоны: 39; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bing_7111cf38.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bing_7111cf38.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bing.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
