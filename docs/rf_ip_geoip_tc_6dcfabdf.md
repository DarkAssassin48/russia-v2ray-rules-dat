# tc · IP-сети

Актуальный набор IP-сетей «tc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tc`. Тип: **ip**.

Правил: **126**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 126.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tc_6dcfabdf.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tc_6dcfabdf.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
