# mihoyo-cn@cn

Актуальный набор доменных правил «mihoyo-cn@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mihoyo-cn@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mihoyo_cn_cn_f108c1b8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mihoyo_cn_cn_f108c1b8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mihoyo-cn@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_regex: ^.+-mihayo\.akamaized\.net$
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
