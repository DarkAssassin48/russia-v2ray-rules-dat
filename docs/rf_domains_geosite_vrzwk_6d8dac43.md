# vrzwk

Актуальный набор доменных правил «vrzwk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vrzwk`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vrzwk_6d8dac43.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vrzwk_6d8dac43.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vrzwk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: vrzwk.cn
domain_suffix: vrzwk.com
domain_suffix: vrzwk.net
domain_suffix: vrzwk.top
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
