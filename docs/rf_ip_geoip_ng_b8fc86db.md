# ng · IP-сети

Актуальный набор IP-сетей «ng» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ng`. Тип: **ip**.

Правил: **1678**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1678.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ng_b8fc86db.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ng_b8fc86db.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ng.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
