# bytedance

Актуальный набор доменных правил «bytedance» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bytedance`. Тип: **domains**.

Правил: **961**. Точные домены: 33; доменные зоны: 928; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bytedance_b36c97be.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bytedance_b36c97be.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bytedance.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
