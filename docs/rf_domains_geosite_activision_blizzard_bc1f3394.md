# activision-blizzard

Актуальный набор доменных правил «activision-blizzard» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `activision-blizzard`. Тип: **domains**.

Правил: **52**. Точные домены: 9; доменные зоны: 43; фрагменты: 0; regex: 0; IP-сети: 0.
