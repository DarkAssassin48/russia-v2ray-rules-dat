# category-scholar-hk

Актуальный набор доменных правил «category-scholar-hk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-scholar-hk`. Тип: **domains**.

Правил: **22**. Точные домены: 0; доменные зоны: 22; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_scholar_hk_1280d8be.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_scholar_hk_1280d8be.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-scholar-hk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
