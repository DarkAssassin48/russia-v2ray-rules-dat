# category-food-cn@cn

Актуальный набор доменных правил «category-food-cn@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-food-cn@cn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_food_cn_cn_0cbb3600.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_food_cn_cn_0cbb3600.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-food-cn@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 4008-517-517.cn
domain_suffix: mcd.cn
domain_suffix: mcdchina.net
domain_suffix: mcdonalds.com.cn
domain_suffix: starbucks.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
