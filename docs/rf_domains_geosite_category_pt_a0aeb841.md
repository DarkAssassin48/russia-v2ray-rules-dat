# category-pt

Актуальный набор доменных правил «category-pt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-pt`. Тип: **domains**.

Правил: **126**. Точные домены: 0; доменные зоны: 126; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_pt_a0aeb841.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_pt_a0aeb841.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-pt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
