# mu · IP-сети

Актуальный набор IP-сетей «mu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mu`. Тип: **ip**.

Правил: **625**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 625.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mu_029f6e9e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mu_029f6e9e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
