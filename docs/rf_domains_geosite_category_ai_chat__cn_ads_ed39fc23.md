# category-ai-chat-!cn@ads

Актуальный набор доменных правил «category-ai-chat-!cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ai-chat-!cn@ads`. Тип: **domains**.

Правил: **4**. Точные домены: 4; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ai_chat__cn_ads_ed39fc23.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ai_chat__cn_ads_ed39fc23.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ai-chat-!cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
