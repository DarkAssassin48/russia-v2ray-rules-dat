# z-library

Актуальный набор доменных правил «z-library» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `z-library`. Тип: **domains**.

Правил: **48**. Точные домены: 0; доменные зоны: 48; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_z_library_c5075084.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_z_library_c5075084.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-z-library.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
