# unext

Актуальный набор доменных правил «unext» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `unext`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_unext_60a8b55b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_unext_60a8b55b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-unext.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nxtv.jp
domain_suffix: unext-info.jp
domain_suffix: unext.co.jp
domain_suffix: unext.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
