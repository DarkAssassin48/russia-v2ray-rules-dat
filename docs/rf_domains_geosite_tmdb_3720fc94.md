# tmdb

Актуальный набор доменных правил «tmdb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tmdb`. Тип: **domains**.

Правил: **4**. Точные домены: 2; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tmdb_3720fc94.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tmdb_3720fc94.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tmdb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: tmdb-image-prod.b-cdn.net
domain: tmdb-web-image-prod.b-cdn.net
domain_suffix: themoviedb.org
domain_suffix: tmdb.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
