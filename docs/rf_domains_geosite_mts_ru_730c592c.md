# mts-ru

Актуальный набор доменных правил «mts-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mts-ru`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mts_ru_730c592c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mts_ru_730c592c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mts-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

```text
domain_suffix: a.mts.ru
domain_suffix: dbo-dengi.online
domain_suffix: kion.ru
domain_suffix: mts-link.ru
domain_suffix: mts-ws.net
domain_suffix: mts.ru
domain_suffix: mtsbank.ru
domain_suffix: mtsdengi.ru
domain_suffix: mtsmedia.ru
domain_suffix: mymts.ru
domain_suffix: obs.mts.ru
domain_suffix: on-media.ru
domain_suffix: tvoyodbo.online
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
