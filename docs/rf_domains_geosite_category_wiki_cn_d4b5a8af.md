# category-wiki-cn

Актуальный набор доменных правил «category-wiki-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-wiki-cn`. Тип: **domains**.

Правил: **15**. Точные домены: 2; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_wiki_cn_d4b5a8af.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_wiki_cn_d4b5a8af.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-wiki-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
