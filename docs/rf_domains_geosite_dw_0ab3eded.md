# dw

Актуальный набор доменных правил «dw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dw`. Тип: **domains**.

Правил: **2**. Точные домены: 1; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dw_0ab3eded.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dw_0ab3eded.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: deutschewelle.h-cdn.com
domain_suffix: dw.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
