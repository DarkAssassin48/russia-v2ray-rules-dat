# va · IP-сети

Актуальный набор IP-сетей «va» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `va`. Тип: **ip**.

Правил: **112**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 112.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_va_612e54a5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_va_612e54a5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-va.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
