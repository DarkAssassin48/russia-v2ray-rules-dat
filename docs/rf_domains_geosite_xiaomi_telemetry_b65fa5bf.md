# xiaomi@telemetry

Актуальный набор доменных правил «xiaomi@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xiaomi@telemetry`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xiaomi_telemetry_b65fa5bf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xiaomi_telemetry_b65fa5bf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xiaomi@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: data.mistat.india.xiaomi.com
domain_suffix: data.mistat.intl.xiaomi.com
domain_suffix: data.mistat.rus.xiaomi.com
domain_suffix: data.mistat.xiaomi.com
domain_suffix: logupdate.avlyun.sec.miui.com
domain_suffix: sentry.d.mi.com
domain_suffix: sentry.d.xiaomi.net
domain_suffix: stats.music.xiaomi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
