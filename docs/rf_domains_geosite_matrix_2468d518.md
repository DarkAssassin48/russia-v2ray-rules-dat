# matrix

Актуальный набор доменных правил «matrix» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `matrix`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_matrix_2468d518.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_matrix_2468d518.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-matrix.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: arewereadyyet.com
domain_suffix: cinny.in
domain_suffix: element.io
domain_suffix: fluffychat.im
domain_suffix: matrix.org
domain_suffix: matrix.to
domain_suffix: modular.im
domain_suffix: riot.im
domain_suffix: vector.im
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
