# bt · IP-сети

Актуальный набор IP-сетей «bt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bt`. Тип: **ip**.

Правил: **252**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 252.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bt_8bd242b1.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bt_8bd242b1.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
