# schwab

Актуальный набор доменных правил «schwab» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `schwab`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_schwab_0e660030.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_schwab_0e660030.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-schwab.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aboutschwab.com
domain_suffix: schwab.co.uk
domain_suffix: schwab.com
domain_suffix: schwab.com.hk
domain_suffix: schwab.com.sg
domain_suffix: schwabassetmanagement.com
domain_suffix: schwabcdn.com
domain_suffix: schwabplan.com
domain_suffix: thinkorswim.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
