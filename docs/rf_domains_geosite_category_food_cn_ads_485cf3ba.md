# category-food-cn@ads

Актуальный набор доменных правил «category-food-cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-food-cn@ads`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_food_cn_ads_485cf3ba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_food_cn_ads_485cf3ba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-food-cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: logger.qmai.cn
domain_suffix: tracking.mcdonalds.com.cn
domain_suffix: trackingprd.hwwt8.com
domain_suffix: trackserver.shuxinyc.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
