# re · IP-сети

Актуальный набор IP-сетей «re» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `re`. Тип: **ip**.

Правил: **306**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 306.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_re_6eff606e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_re_6eff606e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-re.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
