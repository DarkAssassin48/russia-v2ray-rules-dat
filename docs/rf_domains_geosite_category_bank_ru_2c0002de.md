# category-bank-ru

Актуальный набор доменных правил «category-bank-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bank-ru`. Тип: **domains**.

Правил: **356**. Точные домены: 3; доменные зоны: 353; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bank_ru_2c0002de.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bank_ru_2c0002de.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bank-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
