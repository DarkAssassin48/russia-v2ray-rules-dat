# cygames

Актуальный набор доменных правил «cygames» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cygames`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cygames_4a1eb508.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cygames_4a1eb508.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cygames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cygames.co.jp
domain_suffix: cygames.jp
domain_suffix: umamusume.akamaized.net
domain_suffix: worldflipper.akamaized.net
domain_suffix: worldflipper.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
