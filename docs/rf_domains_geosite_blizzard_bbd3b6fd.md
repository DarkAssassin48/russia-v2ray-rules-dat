# Blizzard / Battle.net

Актуальный набор доменных правил «Blizzard / Battle.net» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `blizzard`. Тип: **domains**.

Правил: **25**. Точные домены: 9; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_blizzard_bbd3b6fd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_blizzard_bbd3b6fd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-blizzard.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
