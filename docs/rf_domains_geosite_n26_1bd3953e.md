# n26

Актуальный набор доменных правил «n26» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `n26`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_n26_1bd3953e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_n26_1bd3953e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-n26.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: n26.com
domain_suffix: number26.de
domain_suffix: tech26.de
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
