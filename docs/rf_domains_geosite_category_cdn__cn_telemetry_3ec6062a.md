# category-cdn-!cn@telemetry

Актуальный набор доменных правил «category-cdn-!cn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cdn-!cn@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cdn__cn_telemetry_3ec6062a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cdn__cn_telemetry_3ec6062a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cdn-!cn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: akstat.io
domain_suffix: cloudflareinsights-cn.com
domain_suffix: cloudflareinsights.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
