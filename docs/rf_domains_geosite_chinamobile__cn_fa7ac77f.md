# chinamobile@!cn

Актуальный набор доменных правил «chinamobile@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinamobile@!cn`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinamobile__cn_fa7ac77f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinamobile__cn_fa7ac77f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinamobile@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: speedtest.hk.chinamobile.com
domain_suffix: speedtestbb.hk.chinamobile.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
