# emojipedia

Актуальный набор доменных правил «emojipedia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `emojipedia`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_emojipedia_aa8f3aea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_emojipedia_aa8f3aea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-emojipedia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: emojipedia.org
domain_suffix: worldemojiawards.com
domain_suffix: worldemojiday.com
domain_suffix: xn--yt8h.la
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
