# category-password-management

Актуальный набор доменных правил «category-password-management» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-password-management`. Тип: **domains**.

Правил: **32**. Точные домены: 1; доменные зоны: 31; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_password_management_4436917f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_password_management_4436917f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-password-management.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
