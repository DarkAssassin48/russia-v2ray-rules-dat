# qualcomm

Актуальный набор доменных правил «qualcomm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qualcomm`. Тип: **domains**.

Правил: **49**. Точные домены: 1; доменные зоны: 48; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qualcomm_a895974c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qualcomm_a895974c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qualcomm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
