# projectmoon

Актуальный набор доменных правил «projectmoon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `projectmoon`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_projectmoon_1636322f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_projectmoon_1636322f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-projectmoon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: limbuscompany.global
domain_suffix: limbuscompanyapi.com
domain_suffix: limbuscompanycdn.org
domain_suffix: projectmoon.studio
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
