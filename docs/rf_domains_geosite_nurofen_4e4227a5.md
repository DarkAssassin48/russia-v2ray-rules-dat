# nurofen

Актуальный набор доменных правил «nurofen» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nurofen`. Тип: **domains**.

Правил: **28**. Точные домены: 1; доменные зоны: 27; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nurofen_4e4227a5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nurofen_4e4227a5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nurofen.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
