# now

Актуальный набор доменных правил «now» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `now`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_now_36160e71.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_now_36160e71.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-now.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: now-ashare.com
domain_suffix: now-tv.com
domain_suffix: now.com
domain_suffix: now.com.hk
domain_suffix: nowe.com
domain_suffix: nowe.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
