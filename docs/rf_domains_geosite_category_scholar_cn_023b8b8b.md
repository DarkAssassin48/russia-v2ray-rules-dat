# category-scholar-cn

Актуальный набор доменных правил «category-scholar-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-scholar-cn`. Тип: **domains**.

Правил: **96**. Точные домены: 0; доменные зоны: 96; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_scholar_cn_023b8b8b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_scholar_cn_023b8b8b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-scholar-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
