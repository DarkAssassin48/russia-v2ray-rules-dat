# appledaily

Актуальный набор доменных правил «appledaily» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `appledaily`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_appledaily_942e7304.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_appledaily_942e7304.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-appledaily.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
