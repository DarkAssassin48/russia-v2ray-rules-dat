# tn · IP-сети

Актуальный набор IP-сетей «tn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tn`. Тип: **ip**.

Правил: **336**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 336.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tn_88e47aca.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tn_88e47aca.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
