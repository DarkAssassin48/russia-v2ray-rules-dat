# playstation

Актуальный набор доменных правил «playstation» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `playstation`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_playstation_e8bbde2d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_playstation_e8bbde2d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-playstation.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .playstation
domain_suffix: playstation.com
domain_suffix: playstation.net
domain_suffix: playstationnetwork.com
domain_suffix: sonyentertainmentnetwork.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
