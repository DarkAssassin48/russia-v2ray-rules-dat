# gp · IP-сети

Актуальный набор IP-сетей «gp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gp`. Тип: **ip**.

Правил: **304**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 304.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gp_abe91e0e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gp_abe91e0e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
