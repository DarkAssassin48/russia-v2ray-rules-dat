# jd@ads

Актуальный набор доменных правил «jd@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jd@ads`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jd_ads_0355d14e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jd_ads_0355d14e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jd@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads-union.jd.com
domain_suffix: ads.union.jd.com
domain_suffix: c-nfa.jd.com
domain_suffix: cps.360buy.com
domain_suffix: gia.jd.com
domain_suffix: img-x.jd.com
domain_suffix: jzt.jd.com
domain_suffix: stat.m.jd.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
