# in · IP-сети

Актуальный набор IP-сетей «in» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `in`. Тип: **ip**.

Правил: **21342**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 21342.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_in_264450c6.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_in_264450c6.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-in.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
