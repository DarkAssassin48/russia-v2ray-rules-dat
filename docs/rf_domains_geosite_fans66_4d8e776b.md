# fans66

Актуальный набор доменных правил «fans66» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fans66`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fans66_4d8e776b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fans66_4d8e776b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fans66.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fans66.tw
domain_suffix: fansking.tw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
