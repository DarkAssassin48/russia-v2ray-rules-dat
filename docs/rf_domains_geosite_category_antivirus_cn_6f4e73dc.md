# category-antivirus@cn

Актуальный набор доменных правил «category-antivirus@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-antivirus@cn`. Тип: **domains**.

Правил: **98**. Точные домены: 96; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_antivirus_cn_6f4e73dc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_antivirus_cn_6f4e73dc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-antivirus@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
