# rust

Актуальный набор доменных правил «rust» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rust`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rust_4ee9a01e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rust_4ee9a01e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rust.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: crates.io
domain_suffix: docs.rs
domain_suffix: rust-lang.org
domain_suffix: rustup.rs
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
