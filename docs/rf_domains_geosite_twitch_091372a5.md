# Twitch

Актуальный набор доменных правил «Twitch» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `twitch`. Тип: **domains**.

Правил: **35**. Точные домены: 27; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_twitch_091372a5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_twitch_091372a5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-twitch.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
