# baishancloud

Актуальный набор доменных правил «baishancloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `baishancloud`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_baishancloud_27466ed3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_baishancloud_27466ed3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-baishancloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bsclink.cn
domain_suffix: qingcdn.com
domain_suffix: trpcdn.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
