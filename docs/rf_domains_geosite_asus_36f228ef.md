# asus

Актуальный набор доменных правил «asus» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `asus`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_asus_36f228ef.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_asus_36f228ef.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-asus.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: asus.com
domain_suffix: asus.com.cn
domain_suffix: asuscloud.com
domain_suffix: asuswebstorage.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
