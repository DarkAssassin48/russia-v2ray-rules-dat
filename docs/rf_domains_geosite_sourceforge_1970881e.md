# sourceforge

Актуальный набор доменных правил «sourceforge» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sourceforge`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sourceforge_1970881e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sourceforge_1970881e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sourceforge.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fsdn.com
domain_suffix: sf.net
domain_suffix: sourceforge.com
domain_suffix: sourceforge.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
