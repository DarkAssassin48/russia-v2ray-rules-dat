# au · IP-сети

Актуальный набор IP-сетей «au» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `au`. Тип: **ip**.

Правил: **18052**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 18052.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_au_4f0c02dd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_au_4f0c02dd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-au.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
