# cx · IP-сети

Актуальный набор IP-сетей «cx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cx`. Тип: **ip**.

Правил: **72**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 72.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cx_f83021f3.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cx_f83021f3.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
