# golang

Актуальный набор доменных правил «golang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `golang`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_golang_fedd637a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_golang_fedd637a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-golang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: go-lang.com
domain_suffix: go-lang.net
domain_suffix: go-lang.org
domain_suffix: go.dev
domain_suffix: godoc.org
domain_suffix: golang.com
domain_suffix: golang.net
domain_suffix: golang.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
