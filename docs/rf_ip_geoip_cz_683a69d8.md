# cz · IP-сети

Актуальный набор IP-сетей «cz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cz`. Тип: **ip**.

Правил: **5775**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5775.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cz_683a69d8.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cz_683a69d8.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
