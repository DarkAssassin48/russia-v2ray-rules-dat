# category-ntp

Актуальный набор доменных правил «category-ntp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ntp`. Тип: **domains**.

Правил: **116**. Точные домены: 75; доменные зоны: 41; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ntp_7fee7b60.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ntp_7fee7b60.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ntp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
