# tcl

Актуальный набор доменных правил «tcl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tcl`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tcl_acba4ab8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tcl_acba4ab8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tcl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
