# category-cas

Актуальный набор доменных правил «category-cas» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cas`. Тип: **domains**.

Правил: **259**. Точные домены: 27; доменные зоны: 232; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cas_ee9e0877.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cas_ee9e0877.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cas.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
