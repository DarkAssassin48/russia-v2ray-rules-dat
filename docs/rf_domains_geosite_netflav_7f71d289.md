# netflav

Актуальный набор доменных правил «netflav» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `netflav`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_netflav_7f71d289.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_netflav_7f71d289.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-netflav.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: netflav.com
domain_suffix: netflav1.com
domain_suffix: netflav5.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
