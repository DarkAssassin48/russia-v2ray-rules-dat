# category-finance@telemetry

Актуальный набор доменных правил «category-finance@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-finance@telemetry`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_finance_telemetry_6298aa3a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_finance_telemetry_6298aa3a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-finance@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: clickstream.sberbank.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
