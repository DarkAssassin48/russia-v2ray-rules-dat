# qiniu

Актуальный набор доменных правил «qiniu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qiniu`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qiniu_ed7a67b1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qiniu_ed7a67b1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qiniu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: qbox.me
domain_suffix: qiniu.com
domain_suffix: qiniucdn.com
domain_suffix: qiniudn.com
domain_suffix: qiniudns.com
domain_suffix: qiniup.com
domain_suffix: qnsdk.com
domain_suffix: qnssl.com
domain_suffix: staticfile.net
domain_suffix: staticfile.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
