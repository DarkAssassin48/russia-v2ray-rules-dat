# ag · IP-сети

Актуальный набор IP-сетей «ag» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ag`. Тип: **ip**.

Правил: **265**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 265.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ag_9b24a03c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ag_9b24a03c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ag.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
