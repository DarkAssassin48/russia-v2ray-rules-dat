# apple@cn

Актуальный набор доменных правил «apple@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple@cn`. Тип: **domains**.

Правил: **298**. Точные домены: 237; доменные зоны: 61; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_cn_44e02a60.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_cn_44e02a60.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
