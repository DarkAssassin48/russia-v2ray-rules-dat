# baidu@ads

Актуальный набор доменных правил «baidu@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `baidu@ads`. Тип: **domains**.

Правил: **50**. Точные домены: 0; доменные зоны: 50; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_baidu_ads_72d03380.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_baidu_ads_72d03380.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-baidu@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
