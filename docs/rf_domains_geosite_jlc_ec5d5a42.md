# jlc

Актуальный набор доменных правил «jlc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jlc`. Тип: **domains**.

Правил: **43**. Точные домены: 0; доменные зоны: 43; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jlc_ec5d5a42.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jlc_ec5d5a42.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jlc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
