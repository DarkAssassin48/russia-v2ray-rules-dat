# redtube

Актуальный набор доменных правил «redtube» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `redtube`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_redtube_5da3fe1c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_redtube_5da3fe1c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-redtube.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: livehdcams.com
domain_suffix: rdtcdn.com
domain_suffix: redtube.com
domain_suffix: redtube.com.br
domain_suffix: redtubepremium.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
