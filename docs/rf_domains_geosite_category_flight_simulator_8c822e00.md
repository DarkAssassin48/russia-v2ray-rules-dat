# category-flight-simulator

Актуальный набор доменных правил «category-flight-simulator» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-flight-simulator`. Тип: **domains**.

Правил: **79**. Точные домены: 2; доменные зоны: 77; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_flight_simulator_8c822e00.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_flight_simulator_8c822e00.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-flight-simulator.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
