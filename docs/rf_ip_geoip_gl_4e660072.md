# gl · IP-сети

Актуальный набор IP-сетей «gl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gl`. Тип: **ip**.

Правил: **253**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 253.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gl_4e660072.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gl_4e660072.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
