# polyu

Актуальный набор доменных правил «polyu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `polyu`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_polyu_8dc7e7a3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_polyu_8dc7e7a3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-polyu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cpce-polyu.edu.hk
domain_suffix: hkcc-polyu.edu.hk
domain_suffix: polyu.edu.hk
domain_suffix: polyu.hk
domain_suffix: speed-polyu.edu.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
