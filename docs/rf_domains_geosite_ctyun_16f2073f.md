# ctyun

Актуальный набор доменных правил «ctyun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ctyun`. Тип: **domains**.

Правил: **67**. Точные домены: 0; доменные зоны: 67; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ctyun_16f2073f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ctyun_16f2073f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ctyun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
