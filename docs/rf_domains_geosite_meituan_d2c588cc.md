# meituan

Актуальный набор доменных правил «meituan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `meituan`. Тип: **domains**.

Правил: **19**. Точные домены: 0; доменные зоны: 19; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_meituan_d2c588cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_meituan_d2c588cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-meituan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
