# category-entertainment@telemetry

Актуальный набор доменных правил «category-entertainment@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment@telemetry`. Тип: **domains**.

Правил: **4**. Точные домены: 2; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_telemetry_854aa1d5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_telemetry_854aa1d5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: disney.my.sentry.io
domain: sentry.ppy.sh
domain_suffix: insights-collector.gog.com
domain_suffix: log-upload-os.hoyoverse.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
