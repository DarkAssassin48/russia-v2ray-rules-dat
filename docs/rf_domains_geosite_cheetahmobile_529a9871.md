# cheetahmobile

Актуальный набор доменных правил «cheetahmobile» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cheetahmobile`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cheetahmobile_529a9871.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cheetahmobile_529a9871.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cheetahmobile.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cheetahfun.com
domain_suffix: cmcm.com
domain_suffix: cmcmcdn.com
domain_suffix: drivergenius.com
domain_suffix: duba.com
domain_suffix: duba.net
domain_suffix: ijinshan.com
domain_suffix: keniu.com
domain_suffix: liebao.cn
domain_suffix: yuanqidesk.com
domain_suffix: zhhainiao.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
