# pixiv

Актуальный набор доменных правил «pixiv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pixiv`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pixiv_0667d5fc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pixiv_0667d5fc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pixiv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads-pixiv.net
domain_suffix: booth.pm
domain_suffix: fanbox.cc
domain_suffix: pixiv-recommend.net
domain_suffix: pixiv.co.jp
domain_suffix: pixiv.help
domain_suffix: pixiv.me
domain_suffix: pixiv.net
domain_suffix: pixiv.org
domain_suffix: pixivision.net
domain_suffix: pximg.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
