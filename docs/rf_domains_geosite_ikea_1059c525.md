# ikea

Актуальный набор доменных правил «ikea» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ikea`. Тип: **domains**.

Правил: **95**. Точные домены: 0; доменные зоны: 95; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ikea_1059c525.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ikea_1059c525.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ikea.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
