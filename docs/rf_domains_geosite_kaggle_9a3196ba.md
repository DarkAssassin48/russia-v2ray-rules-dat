# kaggle

Актуальный набор доменных правил «kaggle» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kaggle`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kaggle_9a3196ba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kaggle_9a3196ba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kaggle.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kaggle.com
domain_suffix: kaggle.io
domain_suffix: kaggle.net
domain_suffix: kaggleusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
