# agora

Актуальный набор доменных правил «agora» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `agora`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_agora_751a66a9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_agora_751a66a9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-agora.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: agora.io
domain_suffix: agoraio.cn
domain_suffix: agoralab.co
domain_suffix: easemob.com
domain_suffix: shengwang.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
