# starbucks

Актуальный набор доменных правил «starbucks» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `starbucks`. Тип: **domains**.

Правил: **67**. Точные домены: 0; доменные зоны: 67; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_starbucks_fb0ff062.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_starbucks_fb0ff062.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-starbucks.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
