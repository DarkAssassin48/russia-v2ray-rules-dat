# missav

Актуальный набор доменных правил «missav» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `missav`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_missav_56801083.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_missav_56801083.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-missav.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: missav.ai
domain_suffix: missav.com
domain_suffix: missav.live
domain_suffix: missav.uno
domain_suffix: missav.vip
domain_suffix: missav.ws
domain_suffix: missav123.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
