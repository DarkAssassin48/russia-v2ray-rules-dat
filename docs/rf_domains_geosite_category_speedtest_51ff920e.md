# category-speedtest

Актуальный набор доменных правил «category-speedtest» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-speedtest`. Тип: **domains**.

Правил: **329**. Точные домены: 2; доменные зоны: 326; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_speedtest_51ff920e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_speedtest_51ff920e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-speedtest.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
