# pa · IP-сети

Актуальный набор IP-сетей «pa» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pa`. Тип: **ip**.

Правил: **985**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 985.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pa_b2fd6a95.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pa_b2fd6a95.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pa.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
