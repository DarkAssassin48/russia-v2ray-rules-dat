# ehentai

Актуальный набор доменных правил «ehentai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ehentai`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ehentai_1d3bc258.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ehentai_1d3bc258.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ehentai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: e-hentai.org
domain_suffix: ehgt.org
domain_suffix: ehtracker.org
domain_suffix: ehwiki.org
domain_suffix: exhentai.org
domain_suffix: hath.network
domain_suffix: hentaiathome.net
domain_suffix: hentaiverse.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
