# zee

Актуальный набор доменных правил «zee» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zee`. Тип: **domains**.

Правил: **22**. Точные домены: 1; доменные зоны: 21; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zee_76692060.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zee_76692060.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zee.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
