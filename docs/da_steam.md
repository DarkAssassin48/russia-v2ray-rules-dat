# Steam / Valve — магазин, вход и загрузки

Домены Steam и Valve: магазин, сообщество, авторизация и доставка контента. Маршруты игровых серверов по отдельным IP не добавляются автоматически.

Код: `steam`. Тип: **domains**.

Правил: **61**. Точные домены: 19; доменные зоны: 42; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_steam.txt)
- [Полный JSON с исходной логикой](../details/da_steam.json)
- [Готовый SRS](../custom/steam.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
