# beats

Актуальный набор доменных правил «beats» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `beats`. Тип: **domains**.

Правил: **716**. Точные домены: 1; доменные зоны: 715; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_beats_f049f7d3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_beats_f049f7d3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-beats.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
