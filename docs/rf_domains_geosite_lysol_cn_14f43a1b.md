# lysol@cn

Актуальный набор доменных правил «lysol@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lysol@cn`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lysol_cn_14f43a1b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lysol_cn_14f43a1b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lysol@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lysol.cn
domain_suffix: lysol.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
