# nc · IP-сети

Актуальный набор IP-сетей «nc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nc`. Тип: **ip**.

Правил: **182**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 182.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nc_699aa2b4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nc_699aa2b4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
