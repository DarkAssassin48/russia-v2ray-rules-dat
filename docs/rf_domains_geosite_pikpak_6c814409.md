# pikpak

Актуальный набор доменных правил «pikpak» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pikpak`. Тип: **domains**.

Правил: **7**. Точные домены: 1; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pikpak_6c814409.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pikpak_6c814409.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pikpak.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: o4504926511693824.ingest.sentry.io
domain_suffix: mypikpak.com
domain_suffix: mypikpak.net
domain_suffix: pickpackapp.com
domain_suffix: pikpak.io
domain_suffix: pikpak.me
domain_suffix: pikpakdrive.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
