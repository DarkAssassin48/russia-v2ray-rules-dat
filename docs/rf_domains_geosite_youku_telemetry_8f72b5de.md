# youku@telemetry

Актуальный набор доменных правил «youku@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youku@telemetry`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youku_telemetry_8f72b5de.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youku_telemetry_8f72b5de.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youku@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adashx.ut.youku.com
domain_suffix: e.stat.ykimg.com
domain_suffix: h-adashx.ut.youku.com
domain_suffix: lstat.youku.com
domain_suffix: p-log.ykimg.com
domain_suffix: passport-log.youku.com
domain_suffix: s-adashx.ut.youku.com
domain_suffix: stat.youku.com
domain_suffix: statis.api.3g.youku.com
domain_suffix: v6-adashx.ut.youku.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
