# flickr

Актуальный набор доменных правил «flickr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `flickr`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_flickr_aeb1704c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_flickr_aeb1704c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-flickr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .flickr
domain_suffix: flic.kr
domain_suffix: flickr.com
domain_suffix: flickr.net
domain_suffix: staticflickr.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
