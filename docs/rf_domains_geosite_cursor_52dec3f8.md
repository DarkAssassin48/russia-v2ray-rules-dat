# cursor

Актуальный набор доменных правил «cursor» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cursor`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cursor_52dec3f8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cursor_52dec3f8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cursor.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cursor-cdn.com
domain_suffix: cursor.com
domain_suffix: cursor.sh
domain_suffix: cursorapi.com
domain_suffix: cursorvm.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
