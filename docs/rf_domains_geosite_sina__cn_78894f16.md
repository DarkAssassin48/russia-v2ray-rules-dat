# sina@!cn

Актуальный набор доменных правил «sina@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sina@!cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sina__cn_78894f16.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sina__cn_78894f16.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sina@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hk.weibo.com
domain_suffix: my.weibo.com
domain_suffix: overseas.weibo.com
domain_suffix: sg.weibo.com
domain_suffix: th.weibo.com
domain_suffix: tw.weibo.com
domain_suffix: us.weibo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
