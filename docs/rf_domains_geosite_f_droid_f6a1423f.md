# f-droid

Актуальный набор доменных правил «f-droid» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `f-droid`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_f_droid_f6a1423f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_f_droid_f6a1423f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-f-droid.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: f-dro1d.org
domain_suffix: f-droid.com
domain_suffix: f-droid.org
domain_suffix: fdroid.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
