# apple-pki

Актуальный набор доменных правил «apple-pki» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-pki`. Тип: **domains**.

Правил: **8**. Точные домены: 8; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_pki_15dadc72.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_pki_15dadc72.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-pki.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: certs-lb.apple.com.akadns.net
domain: certs.apple.com
domain: crl-lb.apple.com.akadns.net
domain: crl.apple.com
domain: ocsp.apple.com
domain: ocsp2.apple.com
domain: valid.apple.com
domain: valid.origin-apple.com.akadns.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
