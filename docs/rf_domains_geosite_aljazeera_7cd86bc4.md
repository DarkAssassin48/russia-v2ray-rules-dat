# aljazeera

Актуальный набор доменных правил «aljazeera» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aljazeera`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aljazeera_7cd86bc4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aljazeera_7cd86bc4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aljazeera.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ajplus.net
domain_suffix: aljazeera.com
domain_suffix: aljazeera.net
domain_suffix: palestineremix.com
domain_suffix: sarajevopodopsadom.com
domain_suffix: srebrenica360.com
domain_suffix: syhacked.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
