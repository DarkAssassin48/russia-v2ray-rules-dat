# patreon

Актуальный набор доменных правил «patreon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `patreon`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_patreon_d2de7e7f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_patreon_d2de7e7f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-patreon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: live-patreon-marketing.pantheonsite.io
domain_suffix: patreon.com
domain_suffix: patreoncommunity.com
domain_suffix: patreonusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
