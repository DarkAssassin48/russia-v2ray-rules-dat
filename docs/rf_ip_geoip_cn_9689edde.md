# cn · IP-сети

Актуальный набор IP-сетей «cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cn`. Тип: **ip**.

Правил: **9647**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 9647.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cn_9689edde.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cn_9689edde.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
