# apple-intelligence

Актуальный набор доменных правил «apple-intelligence» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-intelligence`. Тип: **domains**.

Правил: **5**. Точные домены: 5; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_intelligence_e530221b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_intelligence_e530221b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-intelligence.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: apple-relay.apple.com
domain: apple-relay.cloudflare.com
domain: apple-relay.fastly-edge.com
domain: apple-relay.mask.apple-dns.net
domain: gspe1-ssl.ls.apple.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
