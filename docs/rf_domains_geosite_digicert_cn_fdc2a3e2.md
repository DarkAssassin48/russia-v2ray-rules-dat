# digicert@cn

Актуальный набор доменных правил «digicert@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `digicert@cn`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_digicert_cn_fdc2a3e2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_digicert_cn_fdc2a3e2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-digicert@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dcocsp.cn
domain_suffix: digicert.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
