# beisen

Актуальный набор доменных правил «beisen» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `beisen`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_beisen_589bfce7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_beisen_589bfce7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-beisen.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beisen.cn
domain_suffix: beisen.com
domain_suffix: beisenapp.com
domain_suffix: beisencloud.com
domain_suffix: beisenpaas.com
domain_suffix: bsurl.cc
domain_suffix: bsurl.cn
domain_suffix: zhiye.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
