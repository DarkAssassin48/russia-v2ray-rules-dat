# boomerang

Актуальный набор доменных правил «boomerang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `boomerang`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_boomerang_8a2fc6c0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_boomerang_8a2fc6c0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-boomerang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: boomerang.com
domain_suffix: wbdnbo.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
