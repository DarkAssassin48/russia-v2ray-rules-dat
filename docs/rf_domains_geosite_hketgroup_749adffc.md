# hketgroup

Актуальный набор доменных правил «hketgroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hketgroup`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hketgroup_749adffc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hketgroup_749adffc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hketgroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

```text
domain_suffix: apexprint.com.hk
domain_suffix: eprc.com.hk
domain_suffix: etbc.com.hk
domain_suffix: etnet.com.cn
domain_suffix: etnet.com.hk
domain_suffix: etnetchina.com.cn
domain_suffix: etpress.com.hk
domain_suffix: ettrade.com.hk
domain_suffix: etwealth.com
domain_suffix: hket.com
domain_suffix: hketgroup.com
domain_suffix: ulifestyle.com.hk
domain_suffix: umagazine.com.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
