# kw · IP-сети

Актуальный набор IP-сетей «kw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kw`. Тип: **ip**.

Правил: **589**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 589.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_kw_22c4592e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_kw_22c4592e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-kw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
