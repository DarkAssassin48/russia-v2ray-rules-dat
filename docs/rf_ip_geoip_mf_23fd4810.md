# mf · IP-сети

Актуальный набор IP-сетей «mf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mf`. Тип: **ip**.

Правил: **149**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 149.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mf_23fd4810.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mf_23fd4810.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
