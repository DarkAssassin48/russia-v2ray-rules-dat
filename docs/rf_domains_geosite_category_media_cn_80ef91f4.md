# category-media@cn

Актуальный набор доменных правил «category-media@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media@cn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_cn_80ef91f4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_cn_80ef91f4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cn-cdn1.skymansion.net
domain_suffix: etnet.com.cn
domain_suffix: etnetchina.com.cn
domain_suffix: thetype.cloud
domain_suffix: tvbc.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
