# qweather

Актуальный набор доменных правил «qweather» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qweather`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qweather_b43c3e67.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qweather_b43c3e67.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qweather.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hecdn.net
domain_suffix: heweather.net
domain_suffix: qweather.com
domain_suffix: qweather.net
domain_suffix: qweatherapi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
