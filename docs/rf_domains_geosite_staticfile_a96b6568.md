# staticfile

Актуальный набор доменных правил «staticfile» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `staticfile`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_staticfile_a96b6568.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_staticfile_a96b6568.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-staticfile.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: staticfile.net
domain_suffix: staticfile.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
