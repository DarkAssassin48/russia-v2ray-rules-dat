# Блокировки РФ — сводный набор

Актуальный набор доменных правил «Блокировки РФ — сводный набор» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru-blocked`. Тип: **domains**.

Правил: **73515**. Точные домены: 0; доменные зоны: 73515; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ru_blocked_bff8eb6d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ru_blocked_bff8eb6d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ru-blocked.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
