# cloudinary

Актуальный набор доменных правил «cloudinary» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cloudinary`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cloudinary_e252bd5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cloudinary_e252bd5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cloudinary.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cloudinary.com
domain_suffix: cloudinary.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
