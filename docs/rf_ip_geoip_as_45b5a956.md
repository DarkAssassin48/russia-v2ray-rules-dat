# as · IP-сети

Актуальный набор IP-сетей «as» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `as`. Тип: **ip**.

Правил: **428**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 428.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_as_45b5a956.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_as_45b5a956.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-as.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
