# category-bank-jp

Актуальный набор доменных правил «category-bank-jp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bank-jp`. Тип: **domains**.

Правил: **84**. Точные домены: 0; доменные зоны: 84; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bank_jp_714ecf5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bank_jp_714ecf5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bank-jp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
