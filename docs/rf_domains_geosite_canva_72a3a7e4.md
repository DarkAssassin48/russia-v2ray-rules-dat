# canva

Актуальный набор доменных правил «canva» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `canva`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_canva_72a3a7e4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_canva_72a3a7e4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-canva.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: affinity-beta.s3.amazonaws.com
domain_suffix: affinity-lessons.s3.amazonaws.com
domain_suffix: affinity.api.serifservices.com
domain_suffix: affinity.studio
domain_suffix: canva.com
domain_suffix: canvastatus.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
