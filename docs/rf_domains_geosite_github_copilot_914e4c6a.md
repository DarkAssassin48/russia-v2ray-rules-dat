# github-copilot

Актуальный набор доменных правил «github-copilot» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `github-copilot`. Тип: **domains**.

Правил: **6**. Точные домены: 5; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_github_copilot_914e4c6a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_github_copilot_914e4c6a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-github-copilot.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: copilot-proxy.githubusercontent.com
domain: copilot-telemetry-service.githubusercontent.com
domain: copilot-telemetry.githubusercontent.com
domain: copilot-workspace.githubnext.com
domain: copilotprodattachments.blob.core.windows.net
domain_suffix: githubcopilot.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
