# taikang

Актуальный набор доменных правил «taikang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `taikang`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_taikang_80198637.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_taikang_80198637.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-taikang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: taikang.com
domain_suffix: taikanglife.com
domain_suffix: taikangzhijia.com
domain_suffix: tkhealthcare.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
