# braveux

Актуальный набор доменных правил «braveux» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `braveux`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_braveux_03890a30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_braveux_03890a30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-braveux.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: braventures.com
domain_suffix: braveux.com
domain_suffix: compass.is
domain_suffix: fightforux.com
domain_suffix: forthebadge.com
domain_suffix: stockagainstphotography.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
