# ximalaya

Актуальный набор доменных правил «ximalaya» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ximalaya`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ximalaya_1e811e06.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ximalaya_1e811e06.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ximalaya.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adbehavior.ximalaya.com
domain_suffix: adse.wsa.ximalaya.com
domain_suffix: adse.ximalaya.com
domain_suffix: ximalaya.com
domain_suffix: xmcdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
