# ok

Актуальный набор доменных правил «ok» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ok`. Тип: **domains**.

Правил: **19**. Точные домены: 2; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ok_61f9fc83.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ok_61f9fc83.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ok.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
