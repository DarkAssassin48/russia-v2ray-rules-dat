# hsbc-cn

Актуальный набор доменных правил «hsbc-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hsbc-cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hsbc_cn_c598d53c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hsbc_cn_c598d53c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hsbc-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hsbc.com.cn
domain_suffix: hsbcinsurance.com.cn
domain_suffix: hsbcqh.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
