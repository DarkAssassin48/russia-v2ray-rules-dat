# drweb

Актуальный набор доменных правил «drweb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `drweb`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_drweb_c51dab3e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_drweb_c51dab3e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-drweb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: drweb-av.de
domain_suffix: drweb-av.es
domain_suffix: drweb-av.it
domain_suffix: drweb-av.pl
domain_suffix: drweb.by

domain_suffix: drweb.com
domain_suffix: drweb.fr
domain_suffix: drweb.kz

```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
