# category-ntp-cn

Актуальный набор доменных правил «category-ntp-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ntp-cn`. Тип: **domains**.

Правил: **23**. Точные домены: 19; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ntp_cn_37b9f84b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ntp_cn_37b9f84b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ntp-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
