# rockstar

Актуальный набор доменных правил «rockstar» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rockstar`. Тип: **domains**.

Правил: **7**. Точные домены: 3; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rockstar_dd91c46a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rockstar_dd91c46a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rockstar.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: gamedownloads-rockstargames-com.akamaized.net
domain: media-rockstargames-com.akamaized.net
domain: videos-rockstargames-com.akamaized.net
domain_suffix: rockstargames.com
domain_suffix: rockstarnorth.com
domain_suffix: rsg.ms
domain_suffix: rsg.sc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
