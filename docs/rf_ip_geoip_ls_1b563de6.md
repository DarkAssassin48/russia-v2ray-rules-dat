# ls · IP-сети

Актуальный набор IP-сетей «ls» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ls`. Тип: **ip**.

Правил: **144**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 144.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ls_1b563de6.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ls_1b563de6.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ls.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
