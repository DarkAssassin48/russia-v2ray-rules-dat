# si · IP-сети

Актуальный набор IP-сетей «si» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `si`. Тип: **ip**.

Правил: **1533**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1533.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_si_40852689.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_si_40852689.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-si.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
