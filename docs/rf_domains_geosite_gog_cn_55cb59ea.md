# gog@cn

Актуальный набор доменных правил «gog@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gog@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gog_cn_55cb59ea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gog_cn_55cb59ea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gog@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: gog.qtlglb.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
