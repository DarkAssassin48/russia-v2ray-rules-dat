# aw · IP-сети

Актуальный набор IP-сетей «aw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aw`. Тип: **ip**.

Правил: **159**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 159.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_aw_ebfee3cc.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_aw_ebfee3cc.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-aw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
