# cian

Актуальный набор доменных правил «cian» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cian`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cian_cc946a91.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cian_cc946a91.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cian.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cian.ru
domain_suffix: cian.site
domain_suffix: ciangroup.ru
domain_suffix: dmir.ru
domain_suffix: poudobnee.com
domain_suffix: xn--80aaafbpzn5blfby1p.xn--p1ai
domain_suffix: xn--80aaeib8abrryx4k.xn--p1ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
