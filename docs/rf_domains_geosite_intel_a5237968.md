# intel

Актуальный набор доменных правил «intel» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `intel`. Тип: **domains**.

Правил: **287**. Точные домены: 0; доменные зоны: 287; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_intel_a5237968.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_intel_a5237968.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-intel.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
