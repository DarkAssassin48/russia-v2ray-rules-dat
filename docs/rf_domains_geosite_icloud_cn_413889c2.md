# icloud@cn

Актуальный набор доменных правил «icloud@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `icloud@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_icloud_cn_413889c2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_icloud_cn_413889c2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-icloud@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apple-icloud.cn
domain_suffix: appleicloud.cn
domain_suffix: icloud-apple.cn
domain_suffix: icloud-content.com.cn
domain_suffix: icloud.com.cn
domain_suffix: icloud.net.cn
domain_suffix: icloudapple.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
