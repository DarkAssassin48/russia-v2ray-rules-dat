# citic@!cn

Актуальный набор доменных правил «citic@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `citic@!cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_citic__cn_7647cfdf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_citic__cn_7647cfdf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-citic@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: citics.com.hk
domain_suffix: cncbinternational.com
domain_suffix: csci.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
