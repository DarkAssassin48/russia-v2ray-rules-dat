# tendcloud

Актуальный набор доменных правил «tendcloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tendcloud`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tendcloud_49925200.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tendcloud_49925200.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tendcloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cpatrk.net
domain_suffix: talkingdata.com
domain_suffix: talkinggame.com
domain_suffix: tdsdk.cpatrk.net
domain_suffix: tendcloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
