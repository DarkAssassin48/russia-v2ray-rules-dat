# lg

Актуальный набор доменных правил «lg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lg`. Тип: **domains**.

Правил: **10**. Точные домены: 1; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lg_631a9270.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lg_631a9270.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: lgelectronics.122.2o7.net
domain_suffix: lg.com
domain_suffix: lgappstv.com
domain_suffix: lge.co.kr
domain_suffix: lge.com
domain_suffix: lgecareers.com
domain_suffix: lghvac.com
domain_suffix: lghvacstory.com
domain_suffix: lgrecyclingprogram.com
domain_suffix: lgsalesportal.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
