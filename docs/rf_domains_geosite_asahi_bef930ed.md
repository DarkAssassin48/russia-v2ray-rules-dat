# asahi

Актуальный набор доменных правил «asahi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `asahi`. Тип: **domains**.

Правил: **7**. Точные домены: 1; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_asahi_bef930ed.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_asahi_bef930ed.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-asahi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: asahishimbun.sc.omtrdc.net
domain_suffix: aiasahi.jp
domain_suffix: asagaku.com
domain_suffix: asahi.com
domain_suffix: asahicom.jp
domain_suffix: asakonet.co.jp
domain_suffix: nikkansports.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
