# sf-express

Актуальный набор доменных правил «sf-express» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sf-express`. Тип: **domains**.

Правил: **15**. Точные домены: 0; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sf_express_18e6a771.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sf_express_18e6a771.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sf-express.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
