# bohemia

Актуальный набор доменных правил «bohemia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bohemia`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bohemia_8cb3b5ce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bohemia_8cb3b5ce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bohemia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: arma3.com
domain_suffix: armaplatform.com
domain_suffix: bistudio.com
domain_suffix: bohemia.net
domain_suffix: dayz.com
domain_suffix: makearmanotwar.com
domain_suffix: silicagame.com
domain_suffix: vigorgame.com
domain_suffix: ylands.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
