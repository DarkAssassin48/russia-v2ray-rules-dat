# 17zuoye

Актуальный набор доменных правил «17zuoye» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `17zuoye`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_17zuoye_d58f589f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_17zuoye_d58f589f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-17zuoye.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 17zuoye.cn
domain_suffix: 17zuoye.com
domain_suffix: 17zuoye.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
