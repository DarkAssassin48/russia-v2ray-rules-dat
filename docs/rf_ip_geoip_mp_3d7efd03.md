# mp · IP-сети

Актуальный набор IP-сетей «mp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mp`. Тип: **ip**.

Правил: **107**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 107.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mp_3d7efd03.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mp_3d7efd03.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
