# nf · IP-сети

Актуальный набор IP-сетей «nf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nf`. Тип: **ip**.

Правил: **107**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 107.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nf_bd6cf8d8.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nf_bd6cf8d8.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
