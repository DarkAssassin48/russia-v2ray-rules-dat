# squareup

Актуальный набор доменных правил «squareup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `squareup`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_squareup_c66527c4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_squareup_c66527c4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-squareup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cash.app
domain_suffix: cashbycashapp.com
domain_suffix: gosq.co
domain_suffix: gosq.com
domain_suffix: issquaredown.com
domain_suffix: issquareup.com
domain_suffix: mkt.com
domain_suffix: sellercommunity.com
domain_suffix: squarecapital.com
domain_suffix: squarecdn.com
domain_suffix: squarecloudservices.com
domain_suffix: squareup.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
