# itiger

Актуальный набор доменных правил «itiger» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `itiger`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_itiger_67821564.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_itiger_67821564.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-itiger.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: itiger.com
domain_suffix: itigergrowth.com
domain_suffix: itigergrowtha.com
domain_suffix: itigerup.com
domain_suffix: laohu8.com
domain_suffix: skytigris.cn
domain_suffix: tigerbbs.cn
domain_suffix: tigerbbs.com
domain_suffix: xiaohu8.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
