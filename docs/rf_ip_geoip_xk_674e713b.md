# xk · IP-сети

Актуальный набор IP-сетей «xk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xk`. Тип: **ip**.

Правил: **108**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 108.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_xk_674e713b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_xk_674e713b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-xk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
