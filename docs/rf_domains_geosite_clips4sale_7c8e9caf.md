# clips4sale

Актуальный набор доменных правил «clips4sale» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `clips4sale`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_clips4sale_7c8e9caf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_clips4sale_7c8e9caf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-clips4sale.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: c4slive.com
domain_suffix: clips4sale.com
domain_suffix: videos4sale.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
