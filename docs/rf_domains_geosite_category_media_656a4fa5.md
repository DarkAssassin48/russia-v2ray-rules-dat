# category-media

Актуальный набор доменных правил «category-media» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media`. Тип: **domains**.

Правил: **1580**. Точные домены: 24; доменные зоны: 1556; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_656a4fa5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_656a4fa5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
