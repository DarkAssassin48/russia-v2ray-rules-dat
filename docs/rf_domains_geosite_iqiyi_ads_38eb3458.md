# iqiyi@ads

Актуальный набор доменных правил «iqiyi@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `iqiyi@ads`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_iqiyi_ads_38eb3458.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_iqiyi_ads_38eb3458.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-iqiyi@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ad.m.iqiyi.com
domain_suffix: afp.iqiyi.com
domain_suffix: c.uaa.iqiyi.com
domain_suffix: cloudpush.iqiyi.com
domain_suffix: cupid.iqiyi.com
domain_suffix: ifacelog.iqiyi.com
domain_suffix: mbdlog.iqiyi.com
domain_suffix: msg.video.qiyi.com
domain_suffix: msg2.video.qiyi.com
domain_suffix: policy.video.iqiyi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
