# kurogames@!cn

Актуальный набор доменных правил «kurogames@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kurogames@!cn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kurogames__cn_05229c54.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kurogames__cn_05229c54.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kurogames@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aki-game.net
domain_suffix: aki-game2.net
domain_suffix: kurogame-service.com
domain_suffix: kurogame.net
domain_suffix: kurogames.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
