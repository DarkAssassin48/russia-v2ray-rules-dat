# Riot Games

Актуальный набор доменных правил «Riot Games» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `riot`. Тип: **domains**.

Правил: **54**. Точные домены: 1; доменные зоны: 53; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_riot_b15d170e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_riot_b15d170e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-riot.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
