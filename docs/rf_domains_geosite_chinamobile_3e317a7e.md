# chinamobile

Актуальный набор доменных правил «chinamobile» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinamobile`. Тип: **domains**.

Правил: **39**. Точные домены: 0; доменные зоны: 39; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinamobile_3e317a7e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinamobile_3e317a7e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinamobile.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
