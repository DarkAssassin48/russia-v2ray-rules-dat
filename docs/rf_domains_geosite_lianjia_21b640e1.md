# lianjia

Актуальный набор доменных правил «lianjia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lianjia`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lianjia_21b640e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lianjia_21b640e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lianjia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beckyroom.com
domain_suffix: bkzhibo.com
domain_suffix: ke.com
domain_suffix: lianjia.com
domain_suffix: ljcdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
