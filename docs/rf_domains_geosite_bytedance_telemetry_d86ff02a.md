# bytedance@telemetry

Актуальный набор доменных правил «bytedance@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bytedance@telemetry`. Тип: **domains**.

Правил: **12**. Точные домены: 8; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bytedance_telemetry_d86ff02a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bytedance_telemetry_d86ff02a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bytedance@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: log3-applog-hl.fqnovel.com
domain: log3-applog.fqnovel.com
domain: log5-applog-hl.fqnovel.com
domain: log5-applog.fqnovel.com
domain: rtlog3-applog-hl.fqnovel.com
domain: rtlog3-applog.fqnovel.com
domain: rtlog5-applog-hl.fqnovel.com
domain: rtlog5-applog.fqnovel.com
domain_suffix: applogcdn.com
domain_suffix: extlog.snssdk.com
domain_suffix: log.zijieapi.com
domain_suffix: volceapplog.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
