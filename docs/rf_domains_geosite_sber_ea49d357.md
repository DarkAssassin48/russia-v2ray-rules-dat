# sber

Актуальный набор доменных правил «sber» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sber`. Тип: **domains**.

Правил: **100**. Точные домены: 6; доменные зоны: 94; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sber_ea49d357.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sber_ea49d357.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sber.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
