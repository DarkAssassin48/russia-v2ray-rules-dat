# category-ads-and-telemetry

Актуальный набор доменных правил «category-ads-and-telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ads-and-telemetry`. Тип: **domains**.

Правил: **890**. Точные домены: 173; доменные зоны: 716; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ads_and_telemetry_6ae0e8a5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ads_and_telemetry_6ae0e8a5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ads-and-telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
