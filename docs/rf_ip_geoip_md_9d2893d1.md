# md · IP-сети

Актуальный набор IP-сетей «md» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `md`. Тип: **ip**.

Правил: **2752**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2752.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_md_9d2893d1.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_md_9d2893d1.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-md.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
