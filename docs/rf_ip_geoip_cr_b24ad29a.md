# cr · IP-сети

Актуальный набор IP-сетей «cr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cr`. Тип: **ip**.

Правил: **926**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 926.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cr_b24ad29a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cr_b24ad29a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
