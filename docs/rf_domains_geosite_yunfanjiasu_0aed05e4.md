# yunfanjiasu

Актуальный набор доменных правил «yunfanjiasu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yunfanjiasu`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yunfanjiasu_0aed05e4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yunfanjiasu_0aed05e4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yunfanjiasu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: yfcache.com
domain_suffix: yfcalc.com
domain_suffix: yfcdn.net
domain_suffix: yfcloud.com
domain_suffix: yfdts.net
domain_suffix: yfp2p.net
domain_suffix: yfscdn.net
domain_suffix: yunfancdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
