# mk · IP-сети

Актуальный набор IP-сетей «mk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mk`. Тип: **ip**.

Правил: **420**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 420.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mk_34e4df0a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mk_34e4df0a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
