# homebrew

Актуальный набор доменных правил «homebrew» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `homebrew`. Тип: **domains**.

Правил: **2**. Точные домены: 1; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_homebrew_da11e802.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_homebrew_da11e802.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-homebrew.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: homebrew.bintray.com
domain_suffix: brew.sh
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
