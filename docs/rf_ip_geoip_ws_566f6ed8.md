# ws · IP-сети

Актуальный набор IP-сетей «ws» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ws`. Тип: **ip**.

Правил: **140**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 140.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ws_566f6ed8.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ws_566f6ed8.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ws.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
