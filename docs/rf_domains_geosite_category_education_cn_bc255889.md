# category-education-cn

Актуальный набор доменных правил «category-education-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-education-cn`. Тип: **domains**.

Правил: **202**. Точные домены: 3; доменные зоны: 199; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_education_cn_bc255889.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_education_cn_bc255889.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-education-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
