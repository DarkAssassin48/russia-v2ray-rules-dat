# Instagram — приложение и медиа

Домены Instagram и связанных ресурсов; отдельные категории Meta и Facebook доступны в полном каталоге.

Код: `instagram`. Тип: **domains**.

Правил: **74**. Точные домены: 0; доменные зоны: 74; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_instagram.txt)
- [Полный JSON с исходной логикой](../details/da_instagram.json)
- [Готовый SRS](../custom/instagram.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
