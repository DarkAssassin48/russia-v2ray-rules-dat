# gannett

Актуальный набор доменных правил «gannett» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gannett`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gannett_0e627eb8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gannett_0e627eb8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gannett.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gannett-cdn.com
domain_suffix: gannett.com
domain_suffix: gannettdigital.com
domain_suffix: usatoday.com
domain_suffix: usatodaynetworkservice.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
