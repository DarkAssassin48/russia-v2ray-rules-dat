# amd

Актуальный набор доменных правил «amd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amd`. Тип: **domains**.

Правил: **6**. Точные домены: 1; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amd_378dfc60.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amd_378dfc60.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: drivers.amd.com
domain_suffix: amd.com
domain_suffix: amd.com.cn
domain_suffix: amdfanstore.com
domain_suffix: amdgaming.com
domain_suffix: radeon.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
