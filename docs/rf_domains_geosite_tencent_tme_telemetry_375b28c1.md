# tencent-tme@telemetry

Актуальный набор доменных правил «tencent-tme@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent-tme@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_tme_telemetry_375b28c1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_tme_telemetry_375b28c1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent-tme@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: monitor.music.qq.com
domain_suffix: report.tencentmusic.com
domain_suffix: stat.y.qq.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
