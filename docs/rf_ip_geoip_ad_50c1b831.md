# ad · IP-сети

Актуальный набор IP-сетей «ad» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ad`. Тип: **ip**.

Правил: **378**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 378.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ad_50c1b831.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ad_50c1b831.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ad.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
