# sx · IP-сети

Актуальный набор IP-сетей «sx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sx`. Тип: **ip**.

Правил: **109**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 109.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sx_d6d956b5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sx_d6d956b5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
