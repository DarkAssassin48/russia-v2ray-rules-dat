# apple-music@cn

Актуальный набор доменных правил «apple-music@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-music@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 7; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_music_cn_7af18a07.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_music_cn_7af18a07.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-music@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: amp-api-edge.music.apple.com
domain: amp-api.music.apple.com
domain: js-cdn.music.apple.com
domain: music.apple.com
domain: musicstatus.music.apple.com
domain: play.music.apple.com
domain: speedysub.music.apple.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
