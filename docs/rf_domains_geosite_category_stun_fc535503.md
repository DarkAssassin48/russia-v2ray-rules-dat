# category-stun

Актуальный набор доменных правил «category-stun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-stun`. Тип: **domains**.

Правил: **359**. Точные домены: 358; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_stun_fc535503.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_stun_fc535503.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-stun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
