# npmjs

Актуальный набор доменных правил «npmjs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `npmjs`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_npmjs_8f6e10c3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_npmjs_8f6e10c3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-npmjs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: npm.community
domain_suffix: npmjs.com
domain_suffix: npmjs.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
