# ck101

Актуальный набор доменных правил «ck101» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ck101`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ck101_54b909d9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ck101_54b909d9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ck101.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ck101.com
domain_suffix: ckcdn.com
domain_suffix: ckck.fun
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
