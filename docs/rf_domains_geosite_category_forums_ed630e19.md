# category-forums

Актуальный набор доменных правил «category-forums» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-forums`. Тип: **domains**.

Правил: **111**. Точные домены: 2; доменные зоны: 109; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_forums_ed630e19.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_forums_ed630e19.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-forums.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
