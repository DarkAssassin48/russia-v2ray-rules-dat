# category-shopping-ir

Актуальный набор доменных правил «category-shopping-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-shopping-ir`. Тип: **domains**.

Правил: **15**. Точные домены: 0; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_shopping_ir_178d872c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_shopping_ir_178d872c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-shopping-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
