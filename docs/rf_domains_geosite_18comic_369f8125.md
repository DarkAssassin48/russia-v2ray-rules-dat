# 18comic

Актуальный набор доменных правил «18comic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `18comic`. Тип: **domains**.

Правил: **52**. Точные домены: 0; доменные зоны: 52; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_18comic_369f8125.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_18comic_369f8125.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-18comic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
