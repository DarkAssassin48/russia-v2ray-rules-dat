# wildberries@telemetry

Актуальный набор доменных правил «wildberries@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wildberries@telemetry`. Тип: **domains**.

Правил: **5**. Точные домены: 5; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wildberries_telemetry_9c29484b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wildberries_telemetry_9c29484b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wildberries@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: analytics-stage.wildberries.ru
domain: analytics.wildberries.ru
domain: marketplace-sentry.wb.ru
domain: sentry.wb.ru
domain: web-analytics.wildberries.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
