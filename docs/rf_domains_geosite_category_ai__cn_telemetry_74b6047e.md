# category-ai-!cn@telemetry

Актуальный набор доменных правил «category-ai-!cn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ai-!cn@telemetry`. Тип: **domains**.

Правил: **7**. Точные домены: 7; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ai__cn_telemetry_74b6047e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ai__cn_telemetry_74b6047e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ai-!cn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
