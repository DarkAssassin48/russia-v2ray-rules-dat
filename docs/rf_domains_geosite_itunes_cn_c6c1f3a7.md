# itunes@cn

Актуальный набор доменных правил «itunes@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `itunes@cn`. Тип: **domains**.

Правил: **51**. Точные домены: 46; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_itunes_cn_c6c1f3a7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_itunes_cn_c6c1f3a7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-itunes@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
