# formula1

Актуальный набор доменных правил «formula1» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `formula1`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_formula1_83621971.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_formula1_83621971.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-formula1.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: f1.com
domain_suffix: f1tv.com
domain_suffix: formula1.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
