# airwick

Актуальный набор доменных правил «airwick» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `airwick`. Тип: **domains**.

Правил: **40**. Точные домены: 0; доменные зоны: 40; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_airwick_86a3714f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_airwick_86a3714f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-airwick.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
