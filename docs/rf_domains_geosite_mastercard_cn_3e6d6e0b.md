# mastercard@cn

Актуальный набор доменных правил «mastercard@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mastercard@cn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mastercard_cn_3e6d6e0b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mastercard_cn_3e6d6e0b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mastercard@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mastercard.cn
domain_suffix: mastercard.com.cn
domain_suffix: priceless.com.cn
domain_suffix: pricelessbeijing.cn
domain_suffix: pricelessbeijing.com.cn
domain_suffix: travelex.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
