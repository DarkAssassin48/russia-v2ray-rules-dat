# bandwagonhost

Актуальный набор доменных правил «bandwagonhost» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bandwagonhost`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bandwagonhost_b0c55b46.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bandwagonhost_b0c55b46.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bandwagonhost.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bandwagonhost.com
domain_suffix: bwh1.net
domain_suffix: bwh8.net
domain_suffix: bwh81.net
domain_suffix: bwh88.net
domain_suffix: bwh89.net
domain_suffix: bwhstatus.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
