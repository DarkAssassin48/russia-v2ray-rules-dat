# pinduoduo

Актуальный набор доменных правил «pinduoduo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pinduoduo`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pinduoduo_b3c92509.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pinduoduo_b3c92509.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pinduoduo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pddcdn.com
domain_suffix: pddim.com
domain_suffix: pddpic.com
domain_suffix: pddugc.com
domain_suffix: pinduoduo.com
domain_suffix: pinduoduo.net
domain_suffix: yangkeduo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
