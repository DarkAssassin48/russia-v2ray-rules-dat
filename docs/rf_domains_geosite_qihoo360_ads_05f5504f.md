# qihoo360@ads

Актуальный набор доменных правил «qihoo360@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qihoo360@ads`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qihoo360_ads_05f5504f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qihoo360_ads_05f5504f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qihoo360@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: c.sayhi.360.cn
domain_suffix: fenxi.360.cn
domain_suffix: fenxi.com
domain_suffix: lianmeng.360.cn
domain_suffix: mediav.com
domain_suffix: mvad.com
domain_suffix: qhupdate.com
domain_suffix: s.360.cn
domain_suffix: s.so.360.cn
domain_suffix: s.union.360.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
