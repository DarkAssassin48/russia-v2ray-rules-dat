# ro · IP-сети

Актуальный набор IP-сетей «ro» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ro`. Тип: **ip**.

Правил: **5387**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5387.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ro_5324eba5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ro_5324eba5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ro.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
