# Telegram · IP-сети

Актуальный набор IP-сетей «Telegram» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `telegram`. Тип: **ip**.

Правил: **12**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 12.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_telegram_a7a1cd08.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_telegram_a7a1cd08.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-telegram.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
