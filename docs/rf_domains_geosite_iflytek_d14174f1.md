# iflytek

Актуальный набор доменных правил «iflytek» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `iflytek`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_iflytek_d14174f1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_iflytek_d14174f1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-iflytek.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: changyan.com
domain_suffix: ets100.com
domain_suffix: iflyink.com
domain_suffix: iflyrec.com
domain_suffix: iflysec.com
domain_suffix: iflytek.com
domain_suffix: voicecloud.cn
domain_suffix: xfyun.cn
domain_suffix: xunfei.cn
domain_suffix: xunfeixxj.com
domain_suffix: zhixue.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
