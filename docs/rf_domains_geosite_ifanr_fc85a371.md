# ifanr

Актуальный набор доменных правил «ifanr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ifanr`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ifanr_fc85a371.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ifanr_fc85a371.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ifanr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: coolbuy.com
domain_suffix: ifanr.cn
domain_suffix: ifanr.com
domain_suffix: ifanr.in
domain_suffix: ifanrusercontent.com
domain_suffix: ifanrx.com
domain_suffix: minapp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
