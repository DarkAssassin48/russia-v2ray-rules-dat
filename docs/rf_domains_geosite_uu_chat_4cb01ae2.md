# uu-chat

Актуальный набор доменных правил «uu-chat» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `uu-chat`. Тип: **domains**.

Правил: **22**. Точные домены: 0; доменные зоны: 22; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_uu_chat_4cb01ae2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_uu_chat_4cb01ae2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-uu-chat.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
