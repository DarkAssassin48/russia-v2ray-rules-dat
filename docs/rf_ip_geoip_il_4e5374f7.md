# il · IP-сети

Актуальный набор IP-сетей «il» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `il`. Тип: **ip**.

Правил: **4343**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 4343.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_il_4e5374f7.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_il_4e5374f7.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-il.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
