# category-games-cn

Актуальный набор доменных правил «category-games-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games-cn`. Тип: **domains**.

Правил: **179**. Точные домены: 2; доменные зоны: 176; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games_cn_bef15789.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games_cn_bef15789.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
