# yunlaopo

Актуальный набор доменных правил «yunlaopo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yunlaopo`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yunlaopo_16158bec.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yunlaopo_16158bec.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yunlaopo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: doure.net
domain_suffix: kuaipa.net
domain_suffix: miaopa.net
domain_suffix: yunlaopo.cc
domain_suffix: yunlaopo.com
domain_suffix: yunlaopo.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
