# motorola

Актуальный набор доменных правил «motorola» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `motorola`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_motorola_2a81e4fc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_motorola_2a81e4fc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-motorola.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
