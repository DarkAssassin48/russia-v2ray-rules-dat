# redotpay

Актуальный набор доменных правил «redotpay» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `redotpay`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_redotpay_3dae524f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_redotpay_3dae524f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-redotpay.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pod-15-sunco-ws.zendesk.com
domain_suffix: redotpay.com
domain_suffix: redotpay.zendesk.com
domain_suffix: rp-static-apne1.s3.ap-northeast-1.amazonaws.com
domain_suffix: xhpjc6-cdn-settings.appsflyersdk.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
