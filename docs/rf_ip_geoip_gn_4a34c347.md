# gn · IP-сети

Актуальный набор IP-сетей «gn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gn`. Тип: **ip**.

Правил: **153**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 153.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gn_4a34c347.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gn_4a34c347.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
