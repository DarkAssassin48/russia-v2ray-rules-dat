# sd · IP-сети

Актуальный набор IP-сетей «sd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sd`. Тип: **ip**.

Правил: **206**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 206.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sd_038b455d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sd_038b455d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
