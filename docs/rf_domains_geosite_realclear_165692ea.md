# realclear

Актуальный набор доменных правил «realclear» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `realclear`. Тип: **domains**.

Правил: **17**. Точные домены: 0; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_realclear_165692ea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_realclear_165692ea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-realclear.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
