# volcengine

Актуальный набор доменных правил «volcengine» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `volcengine`. Тип: **domains**.

Правил: **279**. Точные домены: 0; доменные зоны: 279; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_volcengine_9b38af4f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_volcengine_9b38af4f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-volcengine.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
