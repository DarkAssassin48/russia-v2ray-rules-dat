# avito@ads

Актуальный набор доменных правил «avito@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `avito@ads`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_avito_ads_44d488bc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_avito_ads_44d488bc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-avito@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: stats.avito.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
