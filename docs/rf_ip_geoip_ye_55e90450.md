# ye · IP-сети

Актуальный набор IP-сетей «ye» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ye`. Тип: **ip**.

Правил: **230**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 230.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ye_55e90450.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ye_55e90450.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ye.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
