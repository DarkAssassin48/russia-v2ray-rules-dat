# chaoxing

Актуальный набор доменных правил «chaoxing» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chaoxing`. Тип: **domains**.

Правил: **35**. Точные домены: 0; доменные зоны: 35; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chaoxing_44e3a4b7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chaoxing_44e3a4b7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chaoxing.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
