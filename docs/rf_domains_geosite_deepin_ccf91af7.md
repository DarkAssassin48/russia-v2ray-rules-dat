# deepin

Актуальный набор доменных правил «deepin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `deepin`. Тип: **domains**.

Правил: **15**. Точные домены: 0; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_deepin_ccf91af7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_deepin_ccf91af7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-deepin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
