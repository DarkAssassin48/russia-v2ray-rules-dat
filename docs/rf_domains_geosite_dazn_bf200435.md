# dazn

Актуальный набор доменных правил «dazn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dazn`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dazn_bf200435.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dazn_bf200435.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dazn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dazn-api.com
domain_suffix: dazn.com
domain_suffix: dazndn.com
domain_suffix: daznfeeds.com
domain_suffix: daznplayer.com
domain_suffix: daznservices.com
domain_suffix: indazn.com
domain_suffix: indaznlab.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
