# annas-archive

Актуальный набор доменных правил «annas-archive» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `annas-archive`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_annas_archive_d7a60cac.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_annas_archive_d7a60cac.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-annas-archive.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: annas-archive.gd
domain_suffix: annas-archive.gl
domain_suffix: annas-archive.in
domain_suffix: annas-archive.li
domain_suffix: annas-archive.org
domain_suffix: annas-archive.pk
domain_suffix: annas-archive.pm
domain_suffix: annas-archive.se
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
