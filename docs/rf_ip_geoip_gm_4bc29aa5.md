# gm · IP-сети

Актуальный набор IP-сетей «gm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gm`. Тип: **ip**.

Правил: **157**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 157.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gm_4bc29aa5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gm_4bc29aa5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
