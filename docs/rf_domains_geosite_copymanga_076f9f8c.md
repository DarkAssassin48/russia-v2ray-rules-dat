# copymanga

Актуальный набор доменных правил «copymanga» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `copymanga`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_copymanga_076f9f8c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_copymanga_076f9f8c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-copymanga.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 2025copy.com
domain_suffix: copy-manga.com
domain_suffix: copy20.com
domain_suffix: copy2000.online
domain_suffix: mangacopy.com
domain_suffix: mangafuna.xyz
domain_suffix: mangafunb.fun
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
