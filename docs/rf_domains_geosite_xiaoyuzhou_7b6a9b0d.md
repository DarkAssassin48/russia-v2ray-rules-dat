# xiaoyuzhou

Актуальный набор доменных правил «xiaoyuzhou» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xiaoyuzhou`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xiaoyuzhou_7b6a9b0d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xiaoyuzhou_7b6a9b0d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xiaoyuzhou.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: podcast.xyz
domain_suffix: xiaoyuzhoufm.com
domain_suffix: xyzcdn.net
domain_suffix: xyzfm.link
domain_suffix: xyzfm.space
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
