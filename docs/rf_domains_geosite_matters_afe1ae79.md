# matters

Актуальный набор доменных правил «matters» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `matters`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_matters_afe1ae79.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_matters_afe1ae79.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-matters.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: matters.news
domain_suffix: matters.one
domain_suffix: matters.town
domain_suffix: mattersprotocol.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
