# ozon@ads

Актуальный набор доменных правил «ozon@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ozon@ads`. Тип: **domains**.

Правил: **18**. Точные домены: 18; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ozon_ads_60fa668a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ozon_ads_60fa668a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ozon@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
