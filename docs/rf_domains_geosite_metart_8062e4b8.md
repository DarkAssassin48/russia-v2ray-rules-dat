# metart

Актуальный набор доменных правил «metart» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `metart`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_metart_8062e4b8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_metart_8062e4b8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-metart.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: metart.com
domain_suffix: metartnetwork.com
domain_suffix: metcams.com
domain_suffix: naiadsystems.com
domain_suffix: nsimg.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
