# dlercloud

Актуальный набор доменных правил «dlercloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dlercloud`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dlercloud_685d5d99.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dlercloud_685d5d99.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dlercloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dlercloud.com
domain_suffix: dlercloud.me
domain_suffix: dlercloud.org
domain_suffix: dleris.best
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
