# aligames

Актуальный набор доменных правил «aligames» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aligames`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aligames_ef47c2e4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aligames_ef47c2e4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aligames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 9game.cn
domain_suffix: aligames.com
domain_suffix: jiaoyimao.cn
domain_suffix: jiaoyimao.com
domain_suffix: lingxigames.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
