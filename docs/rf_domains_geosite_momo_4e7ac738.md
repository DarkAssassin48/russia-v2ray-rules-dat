# momo

Актуальный набор доменных правил «momo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `momo`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_momo_4e7ac738.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_momo_4e7ac738.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-momo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: momo.dm
domain_suffix: momo5188.com
domain_suffix: momomall.com.tw
domain_suffix: momoshop.com.tw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
