# envato

Актуальный набор доменных правил «envato» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `envato`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_envato_6567fa3e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_envato_6567fa3e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-envato.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: envato-static.com
domain_suffix: envato.com
domain_suffix: envatousercontent.com
domain_suffix: themeforest.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
