# openai@telemetry

Актуальный набор доменных правил «openai@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `openai@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_openai_telemetry_80115746.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_openai_telemetry_80115746.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-openai@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: browser-intake-datadoghq.com
domain: o33249.ingest.sentry.io
domain: o33249.ingest.us.sentry.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
