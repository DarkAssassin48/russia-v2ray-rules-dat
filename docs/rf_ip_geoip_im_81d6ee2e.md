# im · IP-сети

Актуальный набор IP-сетей «im» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `im`. Тип: **ip**.

Правил: **346**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 346.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_im_81d6ee2e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_im_81d6ee2e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-im.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
