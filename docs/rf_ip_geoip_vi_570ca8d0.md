# vi · IP-сети

Актуальный набор IP-сетей «vi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vi`. Тип: **ip**.

Правил: **264**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 264.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_vi_570ca8d0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_vi_570ca8d0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-vi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
