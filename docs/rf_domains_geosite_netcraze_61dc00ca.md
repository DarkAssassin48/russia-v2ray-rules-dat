# netcraze

Актуальный набор доменных правил «netcraze» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `netcraze`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_netcraze_61dc00ca.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_netcraze_61dc00ca.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-netcraze.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: crazedns.ru
domain_suffix: netcraze.club
domain_suffix: netcraze.link
domain_suffix: netcraze.pro
domain_suffix: netcraze.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
