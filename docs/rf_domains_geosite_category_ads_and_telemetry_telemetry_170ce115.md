# category-ads-and-telemetry@telemetry

Актуальный набор доменных правил «category-ads-and-telemetry@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ads-and-telemetry@telemetry`. Тип: **domains**.

Правил: **237**. Точные домены: 64; доменные зоны: 173; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ads_and_telemetry_telemetry_170ce115.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ads_and_telemetry_telemetry_170ce115.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ads-and-telemetry@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
