# category-news-ir

Актуальный набор доменных правил «category-news-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-news-ir`. Тип: **domains**.

Правил: **55**. Точные домены: 0; доменные зоны: 55; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_news_ir_0035a08c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_news_ir_0035a08c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-news-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
