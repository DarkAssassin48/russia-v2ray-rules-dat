# huaweicloud

Актуальный набор доменных правил «huaweicloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huaweicloud`. Тип: **domains**.

Правил: **291**. Точные домены: 0; доменные зоны: 291; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huaweicloud_07add46a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huaweicloud_07add46a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huaweicloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
