# lanzou

Актуальный набор доменных правил «lanzou» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lanzou`. Тип: **domains**.

Правил: **28**. Точные домены: 0; доменные зоны: 28; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lanzou_45914d0f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lanzou_45914d0f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lanzou.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
