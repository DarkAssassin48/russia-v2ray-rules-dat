# jp · IP-сети

Актуальный набор IP-сетей «jp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jp`. Тип: **ip**.

Правил: **18029**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 18029.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_jp_c4ef2368.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_jp_c4ef2368.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-jp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
