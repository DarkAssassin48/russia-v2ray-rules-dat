# shadowsockscom

Актуальный набор доменных правил «shadowsockscom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `shadowsockscom`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_shadowsockscom_ac7730ed.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_shadowsockscom_ac7730ed.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-shadowsockscom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: shadowsocks.com
domain_suffix: shadowsocks.nl
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
