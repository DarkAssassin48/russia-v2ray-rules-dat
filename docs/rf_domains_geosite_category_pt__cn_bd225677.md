# category-pt@!cn

Актуальный набор доменных правил «category-pt@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-pt@!cn`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_pt__cn_bd225677.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_pt__cn_bd225677.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-pt@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dmhy.best
domain_suffix: dmhy.org
domain_suffix: m-team.cc
domain_suffix: m-team.io
domain_suffix: mt.cc
domain_suffix: myanonamouse.net
domain_suffix: nebulance.io
domain_suffix: skyey2.com
domain_suffix: skyeysnow.com
domain_suffix: torrentleech.cc
domain_suffix: torrentleech.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
