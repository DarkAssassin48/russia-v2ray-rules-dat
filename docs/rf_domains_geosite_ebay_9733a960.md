# ebay

Актуальный набор доменных правил «ebay» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ebay`. Тип: **domains**.

Правил: **363**. Точные домены: 1; доменные зоны: 362; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ebay_9733a960.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ebay_9733a960.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ebay.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
