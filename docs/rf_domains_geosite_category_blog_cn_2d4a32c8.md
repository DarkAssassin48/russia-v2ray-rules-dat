# category-blog-cn

Актуальный набор доменных правил «category-blog-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-blog-cn`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_blog_cn_2d4a32c8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_blog_cn_2d4a32c8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-blog-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
