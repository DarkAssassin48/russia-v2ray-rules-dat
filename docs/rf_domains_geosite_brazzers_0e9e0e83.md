# brazzers

Актуальный набор доменных правил «brazzers» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `brazzers`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_brazzers_0e9e0e83.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_brazzers_0e9e0e83.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-brazzers.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: brazzer.com
domain_suffix: brazzers.com
domain_suffix: brazzers.xxx
domain_suffix: brazzersnetwork.com
domain_suffix: mofos.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
