# nl · IP-сети

Актуальный набор IP-сетей «nl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nl`. Тип: **ip**.

Правил: **77596**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 77596.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nl_23ccb9cd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nl_23ccb9cd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
