# category-cryptocurrency@cn

Актуальный набор доменных правил «category-cryptocurrency@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cryptocurrency@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cryptocurrency_cn_50f1fa05.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cryptocurrency_cn_50f1fa05.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cryptocurrency@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: oklink.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
