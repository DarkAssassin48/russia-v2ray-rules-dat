# cabletv

Актуальный набор доменных правил «cabletv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cabletv`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cabletv_b1849c56.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cabletv_b1849c56.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cabletv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cabletv.com.hk
domain_suffix: fantv.hk
domain_suffix: hkopentv.com
domain_suffix: hoy.tv
domain_suffix: i-cable.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
