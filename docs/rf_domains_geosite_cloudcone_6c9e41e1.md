# cloudcone

Актуальный набор доменных правил «cloudcone» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cloudcone`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cloudcone_6c9e41e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cloudcone_6c9e41e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cloudcone.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: clco.cc
domain_suffix: cloudc.one
domain_suffix: cloudcone.com
domain_suffix: cloudcone.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
