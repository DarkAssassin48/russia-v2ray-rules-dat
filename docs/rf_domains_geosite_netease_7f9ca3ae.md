# netease

Актуальный набор доменных правил «netease» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `netease`. Тип: **domains**.

Правил: **55**. Точные домены: 0; доменные зоны: 55; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_netease_7f9ca3ae.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_netease_7f9ca3ae.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-netease.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
