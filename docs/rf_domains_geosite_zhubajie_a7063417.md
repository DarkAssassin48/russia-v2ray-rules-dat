# zhubajie

Актуальный набор доменных правил «zhubajie» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zhubajie`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zhubajie_a7063417.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zhubajie_a7063417.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zhubajie.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tianpeng.com
domain_suffix: zbj.com
domain_suffix: zbjdev.com
domain_suffix: zbjimg.com
domain_suffix: zhubajie.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
