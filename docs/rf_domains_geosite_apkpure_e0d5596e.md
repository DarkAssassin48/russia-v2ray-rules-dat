# apkpure

Актуальный набор доменных правил «apkpure» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apkpure`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apkpure_e0d5596e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apkpure_e0d5596e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apkpure.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apkpure.com
domain_suffix: apkpure.net
domain_suffix: apkpures.xyz
domain_suffix: cdnpure.com
domain_suffix: pureapk.com
domain_suffix: winudf.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
