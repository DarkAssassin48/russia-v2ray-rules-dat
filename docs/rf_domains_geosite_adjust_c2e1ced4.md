# adjust

Актуальный набор доменных правил «adjust» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `adjust`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_adjust_c2e1ced4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_adjust_c2e1ced4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-adjust.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adjust.com
domain_suffix: adjust.io
domain_suffix: adjust.net.in
domain_suffix: adjust.world
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
