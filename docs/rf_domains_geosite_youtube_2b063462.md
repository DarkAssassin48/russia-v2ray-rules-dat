# YouTube

Актуальный набор доменных правил «YouTube» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youtube`. Тип: **domains**.

Правил: **178**. Точные домены: 1; доменные зоны: 177; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youtube_2b063462.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youtube_2b063462.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youtube.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
