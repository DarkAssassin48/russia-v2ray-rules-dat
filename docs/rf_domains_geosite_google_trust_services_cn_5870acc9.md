# google-trust-services@cn

Актуальный набор доменных правил «google-trust-services@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google-trust-services@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 7; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_trust_services_cn_5870acc9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_trust_services_cn_5870acc9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google-trust-services@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: c.pki.goog
domain: crl.pki.goog
domain: crls.pki.goog
domain: i.pki.goog
domain: o.pki.goog
domain: ocsp.pki.goog
domain: pki-goog.l.google.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
