# growingio

Актуальный набор доменных правил «growingio» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `growingio`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_growingio_c75c2725.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_growingio_c75c2725.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-growingio.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: datayi.cn
domain_suffix: gio.ren
domain_suffix: giocdn.com
domain_suffix: growin.cn
domain_suffix: growingio.cn
domain_suffix: growingio.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
