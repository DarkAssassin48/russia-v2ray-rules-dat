# beats@cn

Актуальный набор доменных правил «beats@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `beats@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_beats_cn_23a93791.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_beats_cn_23a93791.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-beats@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beats1.cn
domain_suffix: beats1.com.cn
domain_suffix: beats2.com.cn
domain_suffix: beats4.cn
domain_suffix: beatsbydre.com
domain_suffix: beatsbydre.com.cn
domain_suffix: beatsep.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
