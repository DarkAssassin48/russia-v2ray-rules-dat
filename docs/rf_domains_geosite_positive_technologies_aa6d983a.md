# positive-technologies

Актуальный набор доменных правил «positive-technologies» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `positive-technologies`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_positive_technologies_aa6d983a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_positive_technologies_aa6d983a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-positive-technologies.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ptcloud.ru
domain_suffix: ptsecurity.com
domain_suffix: standoff365.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
