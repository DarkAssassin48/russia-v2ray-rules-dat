# na · IP-сети

Актуальный набор IP-сетей «na» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `na`. Тип: **ip**.

Правил: **222**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 222.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_na_e76c9b60.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_na_e76c9b60.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-na.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
