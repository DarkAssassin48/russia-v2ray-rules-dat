# midea

Актуальный набор доменных правил «midea» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `midea`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_midea_3fff6e21.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_midea_3fff6e21.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-midea.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: irsnp.com
domain_suffix: mdcdn.cn
domain_suffix: midea.cn
domain_suffix: midea.com
domain_suffix: midea.com.cn
domain_suffix: mideaepayuat.com
domain_suffix: msmartlife.cn
domain_suffix: msmartlife.com
domain_suffix: smartmidea.net
domain_suffix: xiaomaigui.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
