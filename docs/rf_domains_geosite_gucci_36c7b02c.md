# gucci

Актуальный набор доменных правил «gucci» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gucci`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gucci_36c7b02c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gucci_36c7b02c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gucci.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .gucci
domain_suffix: chimeforchange.org
domain_suffix: gucci.cn
domain_suffix: gucci.com
domain_suffix: guccimuseo.com
domain_suffix: guccitimeless.com
domain_suffix: regiongold.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
