# category-ecommerce@telemetry

Актуальный набор доменных правил «category-ecommerce@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce@telemetry`. Тип: **domains**.

Правил: **7**. Точные домены: 7; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_telemetry_21ee81c9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_telemetry_21ee81c9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: analytics-stage.wildberries.ru
domain: analytics.wildberries.ru
domain: marketplace-sentry.wb.ru
domain: sentry.ozon.ru
domain: sentry.wb.ru
domain: stats.avito.ru
domain: web-analytics.wildberries.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
