# epochmediagroup

Актуальный набор доменных правил «epochmediagroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `epochmediagroup`. Тип: **domains**.

Правил: **68**. Точные домены: 0; доменные зоны: 68; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_epochmediagroup_34351ead.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_epochmediagroup_34351ead.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-epochmediagroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
