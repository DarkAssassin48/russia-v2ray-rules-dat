# megafon

Актуальный набор доменных правил «megafon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `megafon`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_megafon_2d35a808.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_megafon_2d35a808.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-megafon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: inplat.ru
domain_suffix: megafon.com
domain_suffix: megafon.ru
domain_suffix: megafonpro.ru
domain_suffix: mgfn.ru
domain_suffix: report-megafon.ru
domain_suffix: scartel.ru
domain_suffix: xn--80a9a4b.xn--p1ai
domain_suffix: xn--80aj3b.xn--p1ai
domain_suffix: xn--80arpq.xn--p1ai
domain_suffix: yota.ru
domain_suffix: yotagamer.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
