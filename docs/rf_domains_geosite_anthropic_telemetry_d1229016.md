# anthropic@telemetry

Актуальный набор доменных правил «anthropic@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `anthropic@telemetry`. Тип: **domains**.

Правил: **2**. Точные домены: 2; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_anthropic_telemetry_d1229016.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_anthropic_telemetry_d1229016.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-anthropic@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: http-intake.logs.us5.datadoghq.com
domain: o1158394.ingest.us.sentry.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
