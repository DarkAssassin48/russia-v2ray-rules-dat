# ubisoft

Актуальный набор доменных правил «ubisoft» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ubisoft`. Тип: **domains**.

Правил: **31**. Точные домены: 27; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ubisoft_cfd406af.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ubisoft_cfd406af.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ubisoft.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
