# hamivideo

Актуальный набор доменных правил «hamivideo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hamivideo`. Тип: **domains**.

Правил: **19**. Точные домены: 19; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hamivideo_95d8954a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hamivideo_95d8954a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hamivideo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
