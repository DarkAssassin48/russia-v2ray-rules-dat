# wf · IP-сети

Актуальный набор IP-сетей «wf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wf`. Тип: **ip**.

Правил: **92**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 92.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_wf_04bd014e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_wf_04bd014e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-wf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
