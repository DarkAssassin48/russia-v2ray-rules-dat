# cityu-hk

Актуальный набор доменных правил «cityu-hk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cityu-hk`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cityu_hk_0fc454e8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cityu_hk_0fc454e8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cityu-hk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cityu.edu.hk
domain_suffix: cityu.hk
domain_suffix: xn----fr0b94b15d2ue8q7a1o3e.xn--wcvs22d.xn--j6w193g
domain_suffix: xn--uis44a.xn--j6w193g
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
