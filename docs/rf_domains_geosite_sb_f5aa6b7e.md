# sb

Актуальный набор доменных правил «sb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sb`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sb_f5aa6b7e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sb_f5aa6b7e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dns.sb
domain_suffix: ip.gs
domain_suffix: ip.sb
domain_suffix: loli.net
domain_suffix: sb.sb
domain_suffix: sm.ms
domain_suffix: u.nu
domain_suffix: www.sb
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
