# manorama

Актуальный набор доменных правил «manorama» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `manorama`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_manorama_78926413.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_manorama_78926413.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-manorama.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: malayalamanorama.com

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
