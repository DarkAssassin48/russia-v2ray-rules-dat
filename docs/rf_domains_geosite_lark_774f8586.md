# lark

Актуальный набор доменных правил «lark» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lark`. Тип: **domains**.

Правил: **88**. Точные домены: 0; доменные зоны: 88; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lark_774f8586.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lark_774f8586.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lark.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
