# apple@ads

Актуальный набор доменных правил «apple@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple@ads`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_ads_0b2cf07e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_ads_0b2cf07e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: advertising.apple.com
domain_suffix: api-adservices.apple.com
domain_suffix: iad.apple.com
domain_suffix: iadsdk.apple.com
domain_suffix: qwapi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
