# wps

Актуальный набор доменных правил «wps» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wps`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wps_16915d47.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wps_16915d47.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wps.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
