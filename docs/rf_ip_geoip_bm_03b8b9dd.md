# bm · IP-сети

Актуальный набор IP-сетей «bm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bm`. Тип: **ip**.

Правил: **432**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 432.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bm_03b8b9dd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bm_03b8b9dd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
