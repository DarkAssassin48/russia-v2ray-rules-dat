# webflow

Актуальный набор доменных правил «webflow» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `webflow`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_webflow_d0ce6e70.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_webflow_d0ce6e70.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-webflow.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: webflow-ext.com
domain_suffix: webflow.com
domain_suffix: webflow.io
domain_suffix: website-files.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
