# bitauto

Актуальный набор доменных правил «bitauto» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bitauto`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bitauto_794bc9e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bitauto_794bc9e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bitauto.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bitauto.com
domain_suffix: bitautoimg.com
domain_suffix: cheyisou.com
domain_suffix: yccdn.com
domain_suffix: yiche.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
