# se · IP-сети

Актуальный набор IP-сетей «se» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `se`. Тип: **ip**.

Правил: **14458**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 14458.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_se_7e93a4ad.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_se_7e93a4ad.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-se.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
