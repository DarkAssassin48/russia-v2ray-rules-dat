# category-food-cn

Актуальный набор доменных правил «category-food-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-food-cn`. Тип: **domains**.

Правил: **66**. Точные домены: 0; доменные зоны: 66; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_food_cn_e4f4e41d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_food_cn_e4f4e41d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-food-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
