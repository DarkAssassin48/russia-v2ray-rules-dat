# jiguang

Актуальный набор доменных правил «jiguang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jiguang`. Тип: **domains**.

Правил: **18**. Точные домены: 0; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jiguang_a8a4d42c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jiguang_a8a4d42c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jiguang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
