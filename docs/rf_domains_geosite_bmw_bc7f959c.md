# bmw

Актуальный набор доменных правил «bmw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bmw`. Тип: **domains**.

Правил: **729**. Точные домены: 0; доменные зоны: 729; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bmw_bc7f959c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bmw_bc7f959c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bmw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
