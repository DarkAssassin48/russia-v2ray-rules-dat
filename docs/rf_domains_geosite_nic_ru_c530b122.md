# nic-ru

Актуальный набор доменных правил «nic-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nic-ru`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nic_ru_c530b122.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nic_ru_c530b122.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nic-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nic.ru
domain_suffix: nichost.ru
domain_suffix: r01.ru
domain_suffix: sweb.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
