# et · IP-сети

Актуальный набор IP-сетей «et» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `et`. Тип: **ip**.

Правил: **197**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 197.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_et_72681435.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_et_72681435.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-et.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
