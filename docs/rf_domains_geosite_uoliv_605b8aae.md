# uoliv

Актуальный набор доменных правил «uoliv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `uoliv`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_uoliv_605b8aae.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_uoliv_605b8aae.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-uoliv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: liv.ac.uk
domain_suffix: liverpool.ac.uk
domain_suffix: livinno.org
domain_suffix: opac-project.eu
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
