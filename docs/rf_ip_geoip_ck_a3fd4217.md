# ck · IP-сети

Актуальный набор IP-сетей «ck» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ck`. Тип: **ip**.

Правил: **115**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 115.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ck_a3fd4217.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ck_a3fd4217.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ck.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
