# java

Актуальный набор доменных правил «java» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `java`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_java_b2c82c89.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_java_b2c82c89.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-java.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .java
domain_suffix: java.com
domain_suffix: java.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
