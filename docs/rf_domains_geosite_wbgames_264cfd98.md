# wbgames

Актуальный набор доменных правил «wbgames» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wbgames`. Тип: **domains**.

Правил: **6**. Точные домены: 2; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wbgames_264cfd98.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wbgames_264cfd98.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wbgames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: datarouter.apps.netherrealm.com
domain: wb-agora-hydra-file-storage-k1.s3.amazonaws.com
domain_suffix: warnerbrosgames.com
domain_suffix: wbagora.com
domain_suffix: wbgames.com
domain_suffix: wbinsights.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
