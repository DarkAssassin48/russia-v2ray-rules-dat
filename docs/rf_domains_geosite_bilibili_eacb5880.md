# bilibili

Актуальный набор доменных правил «bilibili» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bilibili`. Тип: **domains**.

Правил: **53**. Точные домены: 1; доменные зоны: 52; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bilibili_eacb5880.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bilibili_eacb5880.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bilibili.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
