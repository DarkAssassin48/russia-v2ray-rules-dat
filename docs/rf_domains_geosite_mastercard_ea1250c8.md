# mastercard

Актуальный набор доменных правил «mastercard» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mastercard`. Тип: **domains**.

Правил: **184**. Точные домены: 0; доменные зоны: 184; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mastercard_ea1250c8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mastercard_ea1250c8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mastercard.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
