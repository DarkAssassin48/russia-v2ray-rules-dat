# category-media-cn@ads

Актуальный набор доменных правил «category-media-cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media-cn@ads`. Тип: **domains**.

Правил: **18**. Точные домены: 0; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_cn_ads_20fed7fa.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_cn_ads_20fed7fa.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media-cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
