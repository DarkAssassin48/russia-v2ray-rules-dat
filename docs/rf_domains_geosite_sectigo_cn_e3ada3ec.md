# sectigo@cn

Актуальный набор доменных правил «sectigo@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sectigo@cn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sectigo_cn_e3ada3ec.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sectigo_cn_e3ada3ec.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sectigo@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: oemssl.cn
domain_suffix: oemssl.cn.cdn.cloudflare.net
domain_suffix: sectigochina.com
domain_suffix: sectigochina.com.cdn.cloudflare.net
domain_suffix: trust-provider.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
