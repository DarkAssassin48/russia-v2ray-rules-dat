# pubg

Актуальный набор доменных правил «pubg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pubg`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pubg_abc09970.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pubg_abc09970.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pubg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: pubg1.battleye.com
domain_suffix: kraftonde.com
domain_suffix: playbattlegrounds.com
domain_suffix: pubg.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
