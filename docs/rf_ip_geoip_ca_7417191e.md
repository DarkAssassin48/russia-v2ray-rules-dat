# ca · IP-сети

Актуальный набор IP-сетей «ca» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ca`. Тип: **ip**.

Правил: **26982**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 26982.
