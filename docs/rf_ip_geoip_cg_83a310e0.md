# cg · IP-сети

Актуальный набор IP-сетей «cg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cg`. Тип: **ip**.

Правил: **171**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 171.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cg_83a310e0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cg_83a310e0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
