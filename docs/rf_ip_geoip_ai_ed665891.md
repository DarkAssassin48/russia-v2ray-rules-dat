# ai · IP-сети

Актуальный набор IP-сетей «ai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ai`. Тип: **ip**.

Правил: **148**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 148.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ai_ed665891.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ai_ed665891.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
