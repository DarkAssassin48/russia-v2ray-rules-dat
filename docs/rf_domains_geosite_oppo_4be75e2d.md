# oppo

Актуальный набор доменных правил «oppo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `oppo`. Тип: **domains**.

Правил: **46**. Точные домены: 1; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_oppo_4be75e2d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_oppo_4be75e2d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-oppo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
