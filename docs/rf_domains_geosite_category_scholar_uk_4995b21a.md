# category-scholar-uk

Актуальный набор доменных правил «category-scholar-uk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-scholar-uk`. Тип: **domains**.

Правил: **38**. Точные домены: 1; доменные зоны: 37; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_scholar_uk_4995b21a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_scholar_uk_4995b21a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-scholar-uk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
