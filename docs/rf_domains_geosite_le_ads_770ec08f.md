# le@ads

Актуальный набор доменных правил «le@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `le@ads`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_le_ads_770ec08f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_le_ads_770ec08f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-le@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apple.www.letv.com
domain_suffix: ark.letv.com
domain_suffix: dc.letv.com
domain_suffix: g3.letv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
