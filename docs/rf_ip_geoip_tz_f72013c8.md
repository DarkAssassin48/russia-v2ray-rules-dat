# tz · IP-сети

Актуальный набор IP-сетей «tz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tz`. Тип: **ip**.

Правил: **529**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 529.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tz_f72013c8.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tz_f72013c8.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
