# category-dev@telemetry

Актуальный набор доменных правил «category-dev@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-dev@telemetry`. Тип: **domains**.

Правил: **14**. Точные домены: 9; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_dev_telemetry_7b696750.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_dev_telemetry_7b696750.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-dev@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
