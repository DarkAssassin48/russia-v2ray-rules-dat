# ec · IP-сети

Актуальный набор IP-сетей «ec» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ec`. Тип: **ip**.

Правил: **1342**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1342.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ec_376bf5e0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ec_376bf5e0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ec.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
