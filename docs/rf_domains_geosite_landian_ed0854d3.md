# landian

Актуальный набор доменных правил «landian» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `landian`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_landian_ed0854d3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_landian_ed0854d3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-landian.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lancdn.com
domain_suffix: landian.news
domain_suffix: landian.vip
domain_suffix: landian.xyz
domain_suffix: landiannews.com
domain_suffix: ourl.co
domain_suffix: wsoso.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
