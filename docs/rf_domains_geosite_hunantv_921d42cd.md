# hunantv

Актуальный набор доменных правил «hunantv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hunantv`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hunantv_921d42cd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hunantv_921d42cd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hunantv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: click.hunantv.com
domain_suffix: da.hunantv.com
domain_suffix: da.mgtv.com
domain_suffix: hifuntv.com
domain_suffix: hitv.com
domain_suffix: hnbntv.com
domain_suffix: hunaniptv.com
domain_suffix: hunantv.com
domain_suffix: imgo.tv
domain_suffix: log.hunantv.com
domain_suffix: log.v2.hunantv.com
domain_suffix: mgtv.com
domain_suffix: res.hunantv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
