# hp

Актуальный набор доменных правил «hp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hp`. Тип: **domains**.

Правил: **158**. Точные домены: 1; доменные зоны: 157; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hp_ab718581.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hp_ab718581.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
