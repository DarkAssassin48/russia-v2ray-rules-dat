# nz · IP-сети

Актуальный набор IP-сетей «nz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nz`. Тип: **ip**.

Правил: **3884**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3884.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nz_90226fe9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nz_90226fe9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
