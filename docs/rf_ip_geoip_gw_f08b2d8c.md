# gw · IP-сети

Актуальный набор IP-сетей «gw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gw`. Тип: **ip**.

Правил: **127**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 127.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gw_f08b2d8c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gw_f08b2d8c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
