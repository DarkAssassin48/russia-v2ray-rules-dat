# unitychina

Актуальный набор доменных правил «unitychina» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `unitychina`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_unitychina_cfbc3504.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_unitychina_cfbc3504.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-unitychina.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads.unitychina.cn
domain_suffix: splash-ads.cdn.unity.cn
domain_suffix: splash-ads.unitychina.cn
domain_suffix: u3d.cn
domain_suffix: unity.cn
domain_suffix: unity3dcloud.cn
domain_suffix: unityads.unity.cn
domain_suffix: unityads.unitychina.cn
domain_suffix: unitychina.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
