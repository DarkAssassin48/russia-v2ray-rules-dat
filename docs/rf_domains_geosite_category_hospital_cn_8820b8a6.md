# category-hospital-cn

Актуальный набор доменных правил «category-hospital-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-hospital-cn`. Тип: **domains**.

Правил: **11**. Точные домены: 2; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_hospital_cn_8820b8a6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_hospital_cn_8820b8a6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-hospital-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: hospital.pku.edu.cn
domain: ss.bjmu.edu.cn
domain_suffix: ba-hospital.com
domain_suffix: cd120.com
domain_suffix: cd120.info
domain_suffix: fuwai.com
domain_suffix: hnxzctec.com
domain_suffix: pkuh6.cn
domain_suffix: puh3.net.cn
domain_suffix: smuszh.com
domain_suffix: yctdyy.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
