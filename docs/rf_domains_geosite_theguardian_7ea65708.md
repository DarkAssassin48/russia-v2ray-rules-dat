# theguardian

Актуальный набор доменных правил «theguardian» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `theguardian`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_theguardian_7ea65708.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_theguardian_7ea65708.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-theguardian.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dev-guardianapis.com
domain_suffix: dev-theguardian.com
domain_suffix: gu-web.net
domain_suffix: guardianapis.com
domain_suffix: guardianapps.co.uk
domain_suffix: guim.co.uk
domain_suffix: guimcode.co.uk
domain_suffix: theguardian.com
domain_suffix: theguardiandns.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
