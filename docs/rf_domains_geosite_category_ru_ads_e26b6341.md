# category-ru@ads

Актуальный набор доменных правил «category-ru@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ru@ads`. Тип: **domains**.

Правил: **189**. Точные домены: 125; доменные зоны: 64; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ru_ads_e26b6341.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ru_ads_e26b6341.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ru@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
