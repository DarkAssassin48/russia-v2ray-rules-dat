# us · IP-сети

Актуальный набор IP-сетей «us» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `us`. Тип: **ip**.

Правил: **259483**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 259483.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_us_f55d523c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_us_f55d523c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-us.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
