# kuaidi100

Актуальный набор доменных правил «kuaidi100» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kuaidi100`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kuaidi100_5c75fc51.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kuaidi100_5c75fc51.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kuaidi100.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ckd.im
domain_suffix: kd100.com
domain_suffix: kuaidi100.com
domain_suffix: kuaidilab.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
