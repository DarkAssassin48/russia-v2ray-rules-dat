# category-ecommerce@ads

Актуальный набор доменных правил «category-ecommerce@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce@ads`. Тип: **domains**.

Правил: **45**. Точные домены: 34; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_ads_682e6df8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_ads_682e6df8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
