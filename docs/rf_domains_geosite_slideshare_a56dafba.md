# slideshare

Актуальный набор доменных правил «slideshare» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `slideshare`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_slideshare_a56dafba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_slideshare_a56dafba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-slideshare.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: slideshare.com
domain_suffix: slideshare.net
domain_suffix: slidesharecdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
