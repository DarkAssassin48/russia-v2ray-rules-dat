# javbus

Актуальный набор доменных правил «javbus» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `javbus`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_javbus_8bc650f7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_javbus_8bc650f7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-javbus.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: javbus.com
domain_suffix: javbus22.com
domain_suffix: javcdn.cc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
