# adobe@telemetry

Актуальный набор доменных правил «adobe@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `adobe@telemetry`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_adobe_telemetry_6754f0a6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_adobe_telemetry_6754f0a6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-adobe@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adobestats.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
