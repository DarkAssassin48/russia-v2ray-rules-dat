# je · IP-сети

Актуальный набор IP-сетей «je» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `je`. Тип: **ip**.

Правил: **219**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 219.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_je_f01462da.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_je_f01462da.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-je.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
