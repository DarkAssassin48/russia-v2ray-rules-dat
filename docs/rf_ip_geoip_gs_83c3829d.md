# gs · IP-сети

Актуальный набор IP-сетей «gs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gs`. Тип: **ip**.

Правил: **30**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 30.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gs_83c3829d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gs_83c3829d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
