# Windows — обновления

Актуальный набор доменных правил «Windows — обновления» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `win-update`. Тип: **domains**.

Правил: **364**. Точные домены: 0; доменные зоны: 364; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_win_update_2dfd1f66.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_win_update_2dfd1f66.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-win-update.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
