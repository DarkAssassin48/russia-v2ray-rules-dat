# category-payment-ir

Актуальный набор доменных правил «category-payment-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-payment-ir`. Тип: **domains**.

Правил: **17**. Точные домены: 0; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_payment_ir_cc305ebb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_payment_ir_cc305ebb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-payment-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
