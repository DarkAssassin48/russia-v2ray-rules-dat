# sn · IP-сети

Актуальный набор IP-сетей «sn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sn`. Тип: **ip**.

Правил: **234**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 234.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sn_5c582723.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sn_5c582723.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
