# qingcloud

Актуальный набор доменных правил «qingcloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qingcloud`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qingcloud_d5bcc784.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qingcloud_d5bcc784.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qingcloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: frontwize.com
domain_suffix: qingcache.com
domain_suffix: qingcloud.com
domain_suffix: qingstor.com
domain_suffix: routewize.com
domain_suffix: yunify.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
