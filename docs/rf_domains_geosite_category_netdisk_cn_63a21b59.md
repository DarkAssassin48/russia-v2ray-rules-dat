# category-netdisk-cn

Актуальный набор доменных правил «category-netdisk-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-netdisk-cn`. Тип: **domains**.

Правил: **91**. Точные домены: 0; доменные зоны: 91; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_netdisk_cn_63a21b59.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_netdisk_cn_63a21b59.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-netdisk-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
