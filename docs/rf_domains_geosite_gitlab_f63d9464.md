# gitlab

Актуальный набор доменных правил «gitlab» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gitlab`. Тип: **domains**.

Правил: **5**. Точные домены: 1; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gitlab_f63d9464.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gitlab_f63d9464.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gitlab.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: gitlab-assets.oss-cn-hongkong.aliyuncs.com
domain_suffix: gitlab-static.net
domain_suffix: gitlab.com
domain_suffix: gitlab.io
domain_suffix: gitlab.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
