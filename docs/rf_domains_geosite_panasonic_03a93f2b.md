# panasonic

Актуальный набор доменных правил «panasonic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `panasonic`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_panasonic_03a93f2b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_panasonic_03a93f2b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-panasonic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .panasonic
domain_suffix: panasonic.cn
domain_suffix: panasonic.com
domain_suffix: panasonic.jp
domain_suffix: technics.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
