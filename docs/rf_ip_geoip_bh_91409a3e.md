# bh · IP-сети

Актуальный набор IP-сетей «bh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bh`. Тип: **ip**.

Правил: **458**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 458.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bh_91409a3e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bh_91409a3e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bh.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
