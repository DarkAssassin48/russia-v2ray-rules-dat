# borneoschematics

Актуальный набор доменных правил «borneoschematics» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `borneoschematics`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_borneoschematics_576096a1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_borneoschematics_576096a1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-borneoschematics.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: borneo.world
domain_suffix: borneoasia.com
domain_suffix: borneoschematic.com
domain_suffix: bosharso.net
domain_suffix: hostborneo.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
