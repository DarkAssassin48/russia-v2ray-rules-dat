# Google Gemini — домены сервиса

Актуальная категория Google Gemini. Общий набор всех доменов Google доступен отдельно и значительно шире.

Код: `google-gemini`. Тип: **domains**.

Правил: **49**. Точные домены: 16; доменные зоны: 33; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_google_gemini.txt)
- [Полный JSON с исходной логикой](../details/da_google_gemini.json)
- [Готовый SRS](../custom/google-gemini.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
