# googlefcm@!cn

Актуальный набор доменных правил «googlefcm@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `googlefcm@!cn`. Тип: **domains**.

Правил: **7**. Точные домены: 7; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_googlefcm__cn_5dc5da79.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_googlefcm__cn_5dc5da79.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-googlefcm@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: alt1-mtalk.google.com
domain: alt2-mtalk.google.com
domain: alt3-mtalk.google.com
domain: alt4-mtalk.google.com
domain: alt5-mtalk.google.com
domain: alt6-mtalk.google.com
domain: mtalk.google.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
