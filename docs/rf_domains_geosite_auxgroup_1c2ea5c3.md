# auxgroup

Актуальный набор доменных правил «auxgroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `auxgroup`. Тип: **domains**.

Правил: **31**. Точные домены: 0; доменные зоны: 31; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_auxgroup_1c2ea5c3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_auxgroup_1c2ea5c3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-auxgroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
