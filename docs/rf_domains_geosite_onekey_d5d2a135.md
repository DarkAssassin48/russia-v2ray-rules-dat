# onekey

Актуальный набор доменных правил «onekey» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `onekey`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_onekey_d5d2a135.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_onekey_d5d2a135.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-onekey.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: onekey.zendesk.com
domain_suffix: onekey-asset.com
domain_suffix: onekey.so
domain_suffix: onekeycn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
