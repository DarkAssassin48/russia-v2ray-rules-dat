# ht · IP-сети

Актуальный набор IP-сетей «ht» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ht`. Тип: **ip**.

Правил: **204**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 204.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ht_0e76bfe0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ht_0e76bfe0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ht.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
