# cuhk

Актуальный набор доменных правил «cuhk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cuhk`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cuhk_089f311e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cuhk_089f311e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cuhk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cuhk.edu.hk
domain_suffix: cuhk.hk
domain_suffix: xn--fiq80y.hk
domain_suffix: xn--fiq80y.xn--j6w193g
domain_suffix: xn--fiq80y3xbiwr.hk
domain_suffix: xn--fiq80y3xbiwr.xn--j6w193g
domain_suffix: xn--fiq80y3xbiwrs0kiu9d.hk
domain_suffix: xn--fiq80y3xbiwrs0kiu9d.xn--j6w193g
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
