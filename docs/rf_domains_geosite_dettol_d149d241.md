# dettol

Актуальный набор доменных правил «dettol» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dettol`. Тип: **domains**.

Правил: **35**. Точные домены: 0; доменные зоны: 35; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dettol_d149d241.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dettol_d149d241.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dettol.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
