# ke · IP-сети

Актуальный набор IP-сетей «ke» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ke`. Тип: **ip**.

Правил: **1321**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1321.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ke_1377c0e4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ke_1377c0e4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ke.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
