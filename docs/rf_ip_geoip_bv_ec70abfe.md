# bv · IP-сети

Актуальный набор IP-сетей «bv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bv`. Тип: **ip**.

Правил: **38**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 38.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bv_ec70abfe.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bv_ec70abfe.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
