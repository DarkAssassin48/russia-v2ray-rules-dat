# kz · IP-сети

Актуальный набор IP-сетей «kz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kz`. Тип: **ip**.

Правил: **2379**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2379.
