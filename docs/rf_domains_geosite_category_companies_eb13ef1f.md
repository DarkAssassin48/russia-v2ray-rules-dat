# category-companies

Актуальный набор доменных правил «category-companies» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-companies`. Тип: **domains**.

Правил: **8643**. Точные домены: 947; доменные зоны: 7690; фрагменты: 0; regex: 6; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_companies_eb13ef1f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_companies_eb13ef1f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-companies.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
