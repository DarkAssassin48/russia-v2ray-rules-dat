# vanish

Актуальный набор доменных правил «vanish» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vanish`. Тип: **domains**.

Правил: **47**. Точные домены: 0; доменные зоны: 47; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vanish_7e8554ea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vanish_7e8554ea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vanish.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
