# category-doh

Актуальный набор доменных правил «category-doh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-doh`. Тип: **domains**.

Правил: **127**. Точные домены: 124; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_doh_4bc2a9f4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_doh_4bc2a9f4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-doh.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
