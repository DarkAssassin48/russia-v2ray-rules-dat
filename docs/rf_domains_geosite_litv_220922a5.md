# litv

Актуальный набор доменных правил «litv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `litv`. Тип: **domains**.

Правил: **11**. Точные домены: 8; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_litv_220922a5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_litv_220922a5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-litv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ntdfreemobile-tgc.cdn.hinet.net
domain: ntdfreepc-tgc.cdn.hinet.net
domain: ntdfreetv-tgc.cdn.hinet.net
domain: ntdfreevcpc-tgc.cdn.hinet.net
domain: ntdofifreemobile-tgc.cdn.hinet.net
domain: ntdofifreepc-tgc.cdn.hinet.net
domain: ntdofifreetv-tgc.cdn.hinet.net
domain: ntdofifreevcpc-tgc.cdn.hinet.net
domain_suffix: litv.tv
domain_suffix: litvfreepc.akamaized.net
domain_suffix: ofiii.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
