# thelinuxfoundation@cn

Актуальный набор доменных правил «thelinuxfoundation@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thelinuxfoundation@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thelinuxfoundation_cn_8d53a0fc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thelinuxfoundation_cn_8d53a0fc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-thelinuxfoundation@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: cdn.ampproject.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
