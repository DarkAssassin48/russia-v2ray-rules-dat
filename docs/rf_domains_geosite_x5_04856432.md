# x5

Актуальный набор доменных правил «x5» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `x5`. Тип: **domains**.

Правил: **35**. Точные домены: 3; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_x5_04856432.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_x5_04856432.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-x5.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
