# sm · IP-сети

Актуальный набор IP-сетей «sm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sm`. Тип: **ip**.

Правил: **171**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 171.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sm_de5c24a2.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sm_de5c24a2.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
