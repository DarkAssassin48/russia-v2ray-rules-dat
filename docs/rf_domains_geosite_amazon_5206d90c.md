# amazon

Актуальный набор доменных правил «amazon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amazon`. Тип: **domains**.

Правил: **250**. Точные домены: 12; доменные зоны: 235; фрагменты: 0; regex: 3; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amazon_5206d90c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amazon_5206d90c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amazon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
