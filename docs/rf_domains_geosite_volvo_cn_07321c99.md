# volvo@cn

Актуальный набор доменных правил «volvo@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `volvo@cn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_volvo_cn_07321c99.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_volvo_cn_07321c99.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-volvo@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: vfsco.com.cn
domain_suffix: volvo.cn
domain_suffix: volvo.com.cn
domain_suffix: volvogroup.cn
domain_suffix: volvogroup.com.cn
domain_suffix: volvotrucks.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
