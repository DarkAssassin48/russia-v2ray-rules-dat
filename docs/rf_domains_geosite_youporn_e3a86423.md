# youporn

Актуальный набор доменных правил «youporn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youporn`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youporn_e3a86423.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youporn_e3a86423.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youporn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: extremetube.com
domain_suffix: keezmovies.com
domain_suffix: yopornshop.com
domain_suffix: youporn.com
domain_suffix: youporngay.com
domain_suffix: youpornpremium.com
domain_suffix: youpornru.com
domain_suffix: ypncdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
