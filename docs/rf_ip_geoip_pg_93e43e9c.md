# pg · IP-сети

Актуальный набор IP-сетей «pg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pg`. Тип: **ip**.

Правил: **353**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 353.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pg_93e43e9c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pg_93e43e9c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
