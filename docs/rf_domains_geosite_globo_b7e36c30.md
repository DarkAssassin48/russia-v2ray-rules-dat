# globo

Актуальный набор доменных правил «globo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `globo`. Тип: **domains**.

Правил: **40**. Точные домены: 0; доменные зоны: 40; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_globo_b7e36c30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_globo_b7e36c30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-globo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
