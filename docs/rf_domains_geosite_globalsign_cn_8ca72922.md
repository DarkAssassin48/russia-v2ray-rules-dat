# globalsign@cn

Актуальный набор доменных правил «globalsign@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `globalsign@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 2; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_globalsign_cn_8ca72922.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_globalsign_cn_8ca72922.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-globalsign@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: cdn.globalsigncdn.com.cdn.cloudflare.net
domain: crl.globalsign.net
domain_suffix: alphassl.com
domain_suffix: easy-signing.com
domain_suffix: globalsign.cn
domain_suffix: globalsign.com
domain_suffix: globalsigncdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
