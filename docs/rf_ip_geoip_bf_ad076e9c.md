# bf · IP-сети

Актуальный набор IP-сетей «bf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bf`. Тип: **ip**.

Правил: **247**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 247.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bf_ad076e9c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bf_ad076e9c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
