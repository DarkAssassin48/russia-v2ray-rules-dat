# ifast

Актуальный набор доменных правил «ifast» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ifast`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ifast_d94535d3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ifast_d94535d3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ifast.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: fsmone.com

domain_suffix: fsmone.com.my
domain_suffix: fundsupermart.com

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
