# cambridge

Актуальный набор доменных правил «cambridge» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cambridge`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cambridge_c552f2a5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cambridge_c552f2a5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cambridge.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cam.ac.uk
domain_suffix: cambridge.org
domain_suffix: cambridgedigital.net
domain_suffix: cambridgemaths.org
domain_suffix: cambridgeschoolshakespeare.com
domain_suffix: dlib.eastview.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
