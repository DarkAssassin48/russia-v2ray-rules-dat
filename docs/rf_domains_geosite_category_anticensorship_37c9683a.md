# category-anticensorship

Актуальный набор доменных правил «category-anticensorship» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-anticensorship`. Тип: **domains**.

Правил: **126**. Точные домены: 6; доменные зоны: 120; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_anticensorship_37c9683a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_anticensorship_37c9683a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-anticensorship.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
