# gu · IP-сети

Актуальный набор IP-сетей «gu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gu`. Тип: **ip**.

Правил: **259**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 259.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gu_4331e952.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gu_4331e952.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
