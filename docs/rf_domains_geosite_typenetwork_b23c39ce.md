# typenetwork

Актуальный набор доменных правил «typenetwork» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `typenetwork`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_typenetwork_b23c39ce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_typenetwork_b23c39ce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-typenetwork.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: typenetwork.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
