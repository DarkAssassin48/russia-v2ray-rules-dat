# eleme@telemetry

Актуальный набор доменных правил «eleme@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eleme@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_eleme_telemetry_f84dfd59.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_eleme_telemetry_f84dfd59.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-eleme@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adashx.ut.ele.me
domain_suffix: h-adashx.ut.ele.me
domain_suffix: v6-adashx.ut.ele.me
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
