# category-social-media-cn

Актуальный набор доменных правил «category-social-media-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-social-media-cn`. Тип: **domains**.

Правил: **54**. Точные домены: 0; доменные зоны: 54; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_social_media_cn_5350cce5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_social_media_cn_5350cce5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-social-media-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
