# tutanota

Актуальный набор доменных правил «tutanota» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tutanota`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tutanota_0d56ddbf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tutanota_0d56ddbf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tutanota.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: keemail.me
domain_suffix: tuta.com
domain_suffix: tuta.io
domain_suffix: tutamail.com
domain_suffix: tutanota.com
domain_suffix: tutanota.de
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
