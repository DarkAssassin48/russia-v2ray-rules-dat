# fm · IP-сети

Актуальный набор IP-сетей «fm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fm`. Тип: **ip**.

Правил: **150**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 150.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fm_00ca3ae9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fm_00ca3ae9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
