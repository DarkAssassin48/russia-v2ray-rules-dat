# wanfang

Актуальный набор доменных правил «wanfang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wanfang`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wanfang_ac70b402.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wanfang_ac70b402.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wanfang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wanfangdata.com.cn
domain_suffix: wf.pub
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
