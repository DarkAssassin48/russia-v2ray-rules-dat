# ne · IP-сети

Актуальный набор IP-сетей «ne» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ne`. Тип: **ip**.

Правил: **138**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 138.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ne_f4ce1a4e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ne_f4ce1a4e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ne.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
