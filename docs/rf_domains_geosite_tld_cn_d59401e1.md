# tld-cn

Актуальный набор доменных правил «tld-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tld-cn`. Тип: **domains**.

Правил: **49**. Точные домены: 0; доменные зоны: 49; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tld_cn_d59401e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tld_cn_d59401e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tld-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
