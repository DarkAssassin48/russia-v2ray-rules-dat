# theporndude

Актуальный набор доменных правил «theporndude» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `theporndude`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_theporndude_1ab1a495.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_theporndude_1ab1a495.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-theporndude.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: porndude2.com

domain_suffix: pornsites.com
domain_suffix: pornwebmasters.com
domain_suffix: theporndude.cc
domain_suffix: theporndude.com
```
