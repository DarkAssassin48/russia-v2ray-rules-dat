# category-retail-ru@ads

Актуальный набор доменных правил «category-retail-ru@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-retail-ru@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_retail_ru_ads_777dc62c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_retail_ru_ads_777dc62c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-retail-ru@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ads.x5.ru
domain: ads.x5media.ru
domain: sentry.x5.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
