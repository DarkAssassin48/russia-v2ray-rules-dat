# jkf

Актуальный набор доменных правил «jkf» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jkf`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jkf_1785e604.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jkf_1785e604.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jkf.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jkf.net
domain_suffix: jkface.net
domain_suffix: jkforum.net
domain_suffix: jr24h.com
domain_suffix: jvid.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
