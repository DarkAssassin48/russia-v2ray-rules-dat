# category-finance

Актуальный набор доменных правил «category-finance» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-finance`. Тип: **domains**.

Правил: **661**. Точные домены: 5; доменные зоны: 656; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_finance_c6a0a296.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_finance_c6a0a296.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-finance.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
