# epicgames@cn

Актуальный набор доменных правил «epicgames@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `epicgames@cn`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 2; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_epicgames_cn_07fa2676.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_epicgames_cn_07fa2676.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-epicgames@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_regex: ^cdn\d-epicgames-\d+\.file\.myqcloud\.com$
domain_regex: ^epicgames-download\d-\d+\.file\.myqcloud\.com$
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
