# wix

Актуальный набор доменных правил «wix» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wix`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wix_09d315c3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wix_09d315c3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wix.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: editorx.com
domain_suffix: parastorage.com
domain_suffix: wix-code.com
domain_suffix: wix.com
domain_suffix: wixanswers.com
domain_suffix: wixapps.net
domain_suffix: wixmp.com
domain_suffix: wixsite.com
domain_suffix: wixstatic.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
