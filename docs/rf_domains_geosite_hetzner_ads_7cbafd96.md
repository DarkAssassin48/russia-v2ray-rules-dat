# hetzner@ads

Актуальный набор доменных правил «hetzner@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hetzner@ads`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hetzner_ads_7cbafd96.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hetzner_ads_7cbafd96.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hetzner@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: sentry.hetzner.company
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
