# bn · IP-сети

Актуальный набор IP-сетей «bn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bn`. Тип: **ip**.

Правил: **198**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 198.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bn_6678bdf0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bn_6678bdf0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
