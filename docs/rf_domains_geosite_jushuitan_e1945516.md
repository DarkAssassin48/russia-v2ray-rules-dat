# jushuitan

Актуальный набор доменных правил «jushuitan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jushuitan`. Тип: **domains**.

Правил: **24**. Точные домены: 0; доменные зоны: 24; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jushuitan_e1945516.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jushuitan_e1945516.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jushuitan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
