# youquan

Актуальный набор доменных правил «youquan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youquan`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youquan_cccdc76d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youquan_cccdc76d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youquan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aitcfw.com
domain_suffix: aizgtc.com
domain_suffix: hangzhouyq.cn
domain_suffix: hangzhouyq.com
domain_suffix: zgxytc.com
domain_suffix: zgzsa.com
domain_suffix: zhonshian.cn
domain_suffix: zhonshian.com
domain_suffix: zhonshian.com.cn
domain_suffix: zjzsa.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
