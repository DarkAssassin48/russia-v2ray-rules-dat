# mojang

Актуальный набор доменных правил «mojang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mojang`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mojang_2d97b6d6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mojang_2d97b6d6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mojang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: callersbane.com
domain_suffix: minecraft-services.net
domain_suffix: minecraft.net
domain_suffix: minecraftservices.com
domain_suffix: minecraftshop.com
domain_suffix: mojang.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
