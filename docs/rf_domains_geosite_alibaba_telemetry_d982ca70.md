# alibaba@telemetry

Актуальный набор доменных правил «alibaba@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibaba@telemetry`. Тип: **domains**.

Правил: **47**. Точные домены: 0; доменные зоны: 47; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibaba_telemetry_d982ca70.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibaba_telemetry_d982ca70.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibaba@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
