# ctexcel

Актуальный набор доменных правил «ctexcel» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ctexcel`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ctexcel_4ac0e668.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ctexcel_4ac0e668.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ctexcel.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ctexcel.ca
domain_suffix: ctexcel.com
domain_suffix: ctexcel.com.hk
domain_suffix: ctexcel.fr
domain_suffix: ctexcel.us
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
