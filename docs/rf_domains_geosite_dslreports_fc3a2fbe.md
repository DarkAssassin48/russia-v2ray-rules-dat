# dslreports

Актуальный набор доменных правил «dslreports» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dslreports`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dslreports_fc3a2fbe.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dslreports_fc3a2fbe.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dslreports.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: broadbandreports.com
domain_suffix: dslr.net
domain_suffix: dslreports.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
