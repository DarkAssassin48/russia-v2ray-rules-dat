# t2-ru

Актуальный набор доменных правил «t2-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `t2-ru`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_t2_ru_ef6bec90.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_t2_ru_ef6bec90.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-t2-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: b2c-digest.ru
domain_suffix: t2.ru
domain_suffix: tele2.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
