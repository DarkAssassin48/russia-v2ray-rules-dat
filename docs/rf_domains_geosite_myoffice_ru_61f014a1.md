# myoffice-ru

Актуальный набор доменных правил «myoffice-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `myoffice-ru`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_myoffice_ru_61f014a1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_myoffice_ru_61f014a1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-myoffice-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: myoffice.ru
domain_suffix: myoffice.team
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
