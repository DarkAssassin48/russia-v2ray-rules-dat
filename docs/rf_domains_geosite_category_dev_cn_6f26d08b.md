# category-dev@cn

Актуальный набор доменных правил «category-dev@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-dev@cn`. Тип: **domains**.

Правил: **24**. Точные домены: 15; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_dev_cn_6f26d08b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_dev_cn_6f26d08b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-dev@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
