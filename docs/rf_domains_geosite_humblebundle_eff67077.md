# humblebundle

Актуальный набор доменных правил «humblebundle» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `humblebundle`. Тип: **domains**.

Правил: **2**. Точные домены: 1; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_humblebundle_eff67077.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_humblebundle_eff67077.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-humblebundle.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: hb.imgix.net
domain_suffix: humblebundle.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
