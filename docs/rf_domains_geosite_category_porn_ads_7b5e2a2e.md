# category-porn@ads

Актуальный набор доменных правил «category-porn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-porn@ads`. Тип: **domains**.

Правил: **3**. Точные домены: 2; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_porn_ads_7b5e2a2e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_porn_ads_7b5e2a2e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-porn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ad-channel.diwodiwo.xyz
domain: ad-display.diwodiwo.xyz
domain_suffix: collector.xhamster.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
