# 115

Актуальный набор доменных правил «115» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `115`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_115_5dfc8d8e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_115_5dfc8d8e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-115.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 115.com
domain_suffix: 115cdn.com
domain_suffix: 115cdn.net
domain_suffix: 115cloud.cn
domain_suffix: 115cloud.com
domain_suffix: 115cloud.net
domain_suffix: 115img.com
domain_suffix: 115meta.com
domain_suffix: 115vod.com
domain_suffix: 116cd.cn
domain_suffix: 116cd.com
domain_suffix: 116cd.net
domain_suffix: anxia.com
domain_suffix: sq.cc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
