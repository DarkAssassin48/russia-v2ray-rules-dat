# stripe

Актуальный набор доменных правил «stripe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `stripe`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_stripe_6923b7c1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_stripe_6923b7c1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-stripe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: link.com
domain_suffix: stripe-terminal-local-reader.net
domain_suffix: stripe.com
domain_suffix: stripe.dev
domain_suffix: stripe.events
domain_suffix: stripe.global
domain_suffix: stripe.network
domain_suffix: stripecdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
