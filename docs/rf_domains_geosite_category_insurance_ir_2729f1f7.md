# category-insurance-ir

Актуальный набор доменных правил «category-insurance-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-insurance-ir`. Тип: **domains**.

Правил: **19**. Точные домены: 0; доменные зоны: 19; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_insurance_ir_2729f1f7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_insurance_ir_2729f1f7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-insurance-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
