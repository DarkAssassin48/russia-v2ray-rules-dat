# suruga-ya

Актуальный набор доменных правил «suruga-ya» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `suruga-ya`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_suruga_ya_6b0b0814.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_suruga_ya_6b0b0814.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-suruga-ya.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: suruga-ya.com
domain_suffix: suruga-ya.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
