# logitech

Актуальный набор доменных правил «logitech» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `logitech`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_logitech_1dd94321.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_logitech_1dd94321.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-logitech.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: logi.com
domain_suffix: logicool.co.jp
domain_suffix: logicoolg.com
domain_suffix: logitech.biz
domain_suffix: logitech.com
domain_suffix: logitech.com.cn
domain_suffix: logitech.fr
domain_suffix: logitech.io
domain_suffix: logitechg.com
domain_suffix: logitechg.com.cn
domain_suffix: logitechg.fr
domain_suffix: logitechio.com.cn
domain_suffix: worldsfastestgamer.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
