# fontshop

Актуальный набор доменных правил «fontshop» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fontshop`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fontshop_4cec6874.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fontshop_4cec6874.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fontshop.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: fontshop-prod-responsive-images.s3.amazonaws.com
domain_suffix: fontbook.com
domain_suffix: fontshop.com
domain_suffix: fstopimages.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
