# category-entertainment-cn@telemetry

Актуальный набор доменных правил «category-entertainment-cn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment-cn@telemetry`. Тип: **domains**.

Правил: **18**. Точные домены: 11; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_cn_telemetry_e7841d09.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_cn_telemetry_e7841d09.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment-cn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
