# qnap

Актуальный набор доменных правил «qnap» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qnap`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qnap_2c468c25.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qnap_2c468c25.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qnap.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mycloudnas.com
domain_suffix: myqnapcloud.cn
domain_suffix: myqnapcloud.com
domain_suffix: qlink.to
domain_suffix: qlinkto.cn
domain_suffix: qnap.com
domain_suffix: qnap.com.cn
domain_suffix: qnapsupport.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
