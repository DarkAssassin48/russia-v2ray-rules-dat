# mozilla@ads

Актуальный набор доменных правил «mozilla@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mozilla@ads`. Тип: **domains**.

Правил: **2**. Точные домены: 2; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mozilla_ads_b080c0b4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mozilla_ads_b080c0b4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mozilla@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ads-img.mozilla.org
domain: ads.mozilla.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
