# douyu

Актуальный набор доменных правил «douyu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `douyu`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_douyu_4928f1fd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_douyu_4928f1fd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-douyu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: douyu.com
domain_suffix: douyu.tv
domain_suffix: douyucdn.cn
domain_suffix: douyucdn2.cn
domain_suffix: douyuscdn.com
domain_suffix: douyutv.com
domain_suffix: edgesrv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
