# cl · IP-сети

Актуальный набор IP-сетей «cl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cl`. Тип: **ip**.

Правил: **9612**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 9612.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cl_c04b6999.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cl_c04b6999.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
