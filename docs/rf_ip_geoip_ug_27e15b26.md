# ug · IP-сети

Актуальный набор IP-сетей «ug» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ug`. Тип: **ip**.

Правил: **371**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 371.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ug_27e15b26.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ug_27e15b26.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ug.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
