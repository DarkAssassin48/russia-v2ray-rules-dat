# mainichi

Актуальный набор доменных правил «mainichi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mainichi`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mainichi_06d6113f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mainichi_06d6113f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mainichi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: machigoto.jp
domain_suffix: mainichi-athletepartners.jp
domain_suffix: mainichi.jp
domain_suffix: mainichibooks.com
domain_suffix: meijinsen.jp
domain_suffix: mirailab.tech

domain_suffix: newsgawakaru.com
domain_suffix: sponichi.co.jp
domain_suffix: weekly-economist.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
