# vg · IP-сети

Актуальный набор IP-сетей «vg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vg`. Тип: **ip**.

Правил: **586**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 586.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_vg_b65dfd47.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_vg_b65dfd47.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-vg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
