# mq · IP-сети

Актуальный набор IP-сетей «mq» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mq`. Тип: **ip**.

Правил: **243**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 243.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mq_8340e6f4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mq_8340e6f4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mq.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
