# uc

Актуальный набор доменных правил «uc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `uc`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_uc_8c0dd498.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_uc_8c0dd498.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-uc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads.uc.cn
domain_suffix: adslot.uc.cn
domain_suffix: open-uc.cn
domain_suffix: uc-engine.cn
domain_suffix: uc.cn
domain_suffix: uc123.com
domain_suffix: ucfly.com
domain_suffix: ucweb.com
domain_suffix: uczzd.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
