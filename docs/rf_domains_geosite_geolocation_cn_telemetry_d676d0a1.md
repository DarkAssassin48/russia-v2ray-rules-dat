# geolocation-cn@telemetry

Актуальный набор доменных правил «geolocation-cn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `geolocation-cn@telemetry`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_geolocation_cn_telemetry_d676d0a1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_geolocation_cn_telemetry_d676d0a1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-geolocation-cn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
