# yandex@ads

Актуальный набор доменных правил «yandex@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yandex@ads`. Тип: **domains**.

Правил: **41**. Точные домены: 16; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yandex_ads_05805761.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yandex_ads_05805761.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yandex@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
