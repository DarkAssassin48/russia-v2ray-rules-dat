# geolocation-!cn@!cn

Актуальный набор доменных правил «geolocation-!cn@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `geolocation-!cn@!cn`. Тип: **domains**.

Правил: **65**. Точные домены: 13; доменные зоны: 52; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_geolocation__cn__cn_9ce1924a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_geolocation__cn__cn_9ce1924a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-geolocation-!cn@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
