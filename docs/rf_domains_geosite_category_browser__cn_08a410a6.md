# category-browser-!cn

Актуальный набор доменных правил «category-browser-!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-browser-!cn`. Тип: **domains**.

Правил: **37**. Точные домены: 2; доменные зоны: 35; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_browser__cn_08a410a6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_browser__cn_08a410a6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-browser-!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
