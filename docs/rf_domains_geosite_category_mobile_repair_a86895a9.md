# category-mobile-repair

Актуальный набор доменных правил «category-mobile-repair» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-mobile-repair`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_mobile_repair_a86895a9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_mobile_repair_a86895a9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-mobile-repair.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: androidfilehost.com
domain_suffix: borneo.world
domain_suffix: borneoasia.com
domain_suffix: borneoschematic.com
domain_suffix: bosharso.net
domain_suffix: easy-jtag.com
domain_suffix: hostborneo.org
domain_suffix: unlocktool.net
domain_suffix: z3x-team.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
