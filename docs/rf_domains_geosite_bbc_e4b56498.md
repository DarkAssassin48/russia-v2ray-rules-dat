# bbc

Актуальный набор доменных правил «bbc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bbc`. Тип: **domains**.

Правил: **28**. Точные домены: 15; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bbc_e4b56498.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bbc_e4b56498.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bbc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
