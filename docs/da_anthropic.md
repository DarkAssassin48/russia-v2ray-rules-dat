# Anthropic / Claude

Claude, Anthropic API и связанные домены из исходной категории Anthropic.

Код: `anthropic`. Тип: **domains**.

Правил: **35**. Точные домены: 17; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_anthropic.txt)
- [Полный JSON с исходной логикой](../details/da_anthropic.json)
- [Готовый SRS](../custom/anthropic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
