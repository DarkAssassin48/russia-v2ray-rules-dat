# zoho

Актуальный набор доменных правил «zoho» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zoho`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zoho_b6bf2f00.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zoho_b6bf2f00.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zoho.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: zoho.com
domain_suffix: zoho.com.au

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
