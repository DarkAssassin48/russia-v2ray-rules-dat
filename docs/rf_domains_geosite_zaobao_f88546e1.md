# zaobao

Актуальный набор доменных правил «zaobao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zaobao`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zaobao_f88546e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zaobao_f88546e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zaobao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: zaobao.com
domain_suffix: zaobao.com.sg
domain_suffix: zaobao.sg
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
