# entermediadb

Актуальный набор доменных правил «entermediadb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `entermediadb`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_entermediadb_d35b04b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_entermediadb_d35b04b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-entermediadb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: entermediadb.net
domain_suffix: entermediadb.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
