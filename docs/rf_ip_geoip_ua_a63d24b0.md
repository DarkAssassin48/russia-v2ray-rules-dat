# ua · IP-сети

Актуальный набор IP-сетей «ua» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ua`. Тип: **ip**.

Правил: **7866**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 7866.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ua_a63d24b0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ua_a63d24b0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ua.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
