# az · IP-сети

Актуальный набор IP-сетей «az» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `az`. Тип: **ip**.

Правил: **675**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 675.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_az_b21e6fd5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_az_b21e6fd5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-az.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
