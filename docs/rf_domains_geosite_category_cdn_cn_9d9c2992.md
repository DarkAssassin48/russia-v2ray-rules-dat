# category-cdn-cn

Актуальный набор доменных правил «category-cdn-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-cdn-cn`. Тип: **domains**.

Правил: **93**. Точные домены: 0; доменные зоны: 93; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_cdn_cn_9d9c2992.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_cdn_cn_9d9c2992.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-cdn-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
