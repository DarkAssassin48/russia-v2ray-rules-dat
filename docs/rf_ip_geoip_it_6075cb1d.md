# it · IP-сети

Актуальный набор IP-сетей «it» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `it`. Тип: **ip**.

Правил: **13487**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 13487.
