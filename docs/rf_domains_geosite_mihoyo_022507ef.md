# mihoyo

Актуальный набор доменных правил «mihoyo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mihoyo`. Тип: **domains**.

Правил: **26**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mihoyo_022507ef.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mihoyo_022507ef.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mihoyo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
