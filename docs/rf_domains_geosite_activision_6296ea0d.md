# activision

Актуальный набор доменных правил «activision» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `activision`. Тип: **domains**.

Правил: **21**. Точные домены: 0; доменные зоны: 21; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_activision_6296ea0d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_activision_6296ea0d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-activision.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
