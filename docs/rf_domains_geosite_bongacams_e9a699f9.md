# bongacams

Актуальный набор доменных правил «bongacams» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bongacams`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bongacams_e9a699f9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bongacams_e9a699f9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bongacams.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bcicdn.com
domain_suffix: bcrncdn.com
domain_suffix: bcvcdn.com
domain_suffix: bgicdn.com
domain_suffix: bongacams.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
