# wargaming

Актуальный набор доменных правил «wargaming» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wargaming`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wargaming_9e6ca470.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wargaming_9e6ca470.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wargaming.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: masteroforion.com
domain_suffix: wargaming.com
domain_suffix: wargaming.net
domain_suffix: wgcdn.co
domain_suffix: wgcrowd.io
domain_suffix: worldoftanks.com
domain_suffix: worldoftanks.eu
domain_suffix: worldofwarplanes.com
domain_suffix: worldofwarships.asia
domain_suffix: worldofwarships.com
domain_suffix: wotblitz.com
domain_suffix: wowsblitz.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
