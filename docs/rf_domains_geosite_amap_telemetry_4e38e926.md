# amap@telemetry

Актуальный набор доменных правил «amap@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amap@telemetry`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amap_telemetry_4e38e926.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amap_telemetry_4e38e926.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amap@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adashx.ut.amap.com
domain_suffix: dualstack-logs.amap.com
domain_suffix: logs.amap.com
domain_suffix: v6-adashx.ut.amap.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
