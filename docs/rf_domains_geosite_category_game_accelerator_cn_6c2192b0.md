# category-game-accelerator-cn

Актуальный набор доменных правил «category-game-accelerator-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-game-accelerator-cn`. Тип: **domains**.

Правил: **45**. Точные домены: 0; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_game_accelerator_cn_6c2192b0.txt)
