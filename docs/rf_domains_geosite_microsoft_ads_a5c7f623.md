# microsoft@ads

Актуальный набор доменных правил «microsoft@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft@ads`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_ads_a5c7f623.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_ads_a5c7f623.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bingads.com
domain_suffix: browser.events.data.msn.cn
domain_suffix: browser.events.data.msn.com
domain_suffix: clarity.ms
domain_suffix: microsoftads.com
domain_suffix: msads.net
domain_suffix: nelreports.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
