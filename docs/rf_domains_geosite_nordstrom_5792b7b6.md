# nordstrom

Актуальный набор доменных правил «nordstrom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nordstrom`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nordstrom_5792b7b6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nordstrom_5792b7b6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nordstrom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nordstrom.com
domain_suffix: nordstrommedia.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
