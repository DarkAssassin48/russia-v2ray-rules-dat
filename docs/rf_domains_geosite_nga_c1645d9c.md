# nga

Актуальный набор доменных правил «nga» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nga`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nga_c1645d9c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nga_c1645d9c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nga.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 178.com
domain_suffix: nga.cn
domain_suffix: ngabbs.com
domain_suffix: ngacn.cc
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
