# xtom

Актуальный набор доменных правил «xtom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xtom`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xtom_9227e927.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xtom_9227e927.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xtom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: v.ps
domain_suffix: vps.hosting
domain_suffix: xtom.au
domain_suffix: xtom.com
domain_suffix: xtom.de

```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
