# petrochina

Актуальный набор доменных правил «petrochina» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `petrochina`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_petrochina_42ea3a74.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_petrochina_42ea3a74.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-petrochina.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 95504.net
domain_suffix: 95504test.com
domain_suffix: cnpc.com.cn
domain_suffix: petrochina.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
