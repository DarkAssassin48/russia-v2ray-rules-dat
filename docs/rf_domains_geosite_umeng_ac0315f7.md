# umeng

Актуальный набор доменных правил «umeng» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `umeng`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_umeng_ac0315f7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_umeng_ac0315f7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-umeng.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
