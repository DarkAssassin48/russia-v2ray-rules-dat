# manhuaren

Актуальный набор доменных правил «manhuaren» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `manhuaren`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_manhuaren_2f834278.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_manhuaren_2f834278.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-manhuaren.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1kkk.com
domain_suffix: cdndm5.com
domain_suffix: dm5.cn
domain_suffix: dm5.com
domain_suffix: dm9.com
domain_suffix: gmanhua.com
domain_suffix: hkmanga.com
domain_suffix: manben.com
domain_suffix: manbenapi.com
domain_suffix: manhuaren.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
