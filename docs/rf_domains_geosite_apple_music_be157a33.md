# apple-music

Актуальный набор доменных правил «apple-music» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-music`. Тип: **domains**.

Правил: **17**. Точные домены: 6; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_music_be157a33.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_music_be157a33.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-music.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
