# 9to5

Актуальный набор доменных правил «9to5» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `9to5`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_9to5_d1fbc273.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_9to5_d1fbc273.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-9to5.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 9to5google.com
domain_suffix: 9to5mac.com
domain_suffix: 9to5terminal.com
domain_suffix: 9to5toys.com
domain_suffix: dronedj.com
domain_suffix: electrek.co
domain_suffix: spaceexplored.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
