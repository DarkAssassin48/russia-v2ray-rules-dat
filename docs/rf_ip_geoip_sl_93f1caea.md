# sl · IP-сети

Актуальный набор IP-сетей «sl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sl`. Тип: **ip**.

Правил: **168**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 168.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sl_93f1caea.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sl_93f1caea.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
