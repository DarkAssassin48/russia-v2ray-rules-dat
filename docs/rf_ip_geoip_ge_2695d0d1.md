# ge · IP-сети

Актуальный набор IP-сетей «ge» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ge`. Тип: **ip**.

Правил: **746**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 746.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ge_2695d0d1.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ge_2695d0d1.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ge.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
