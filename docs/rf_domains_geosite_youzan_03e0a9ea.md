# youzan

Актуальный набор доменных правил «youzan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `youzan`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_youzan_03e0a9ea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_youzan_03e0a9ea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-youzan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: daogou.ai
domain_suffix: koudaitong.com
domain_suffix: quntuantuan.cn
domain_suffix: xinlingshou.com
domain_suffix: youzan.com
domain_suffix: youzanyun.com
domain_suffix: yzcdn.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
