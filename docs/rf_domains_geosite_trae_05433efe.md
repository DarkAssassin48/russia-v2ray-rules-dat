# trae

Актуальный набор доменных правил «trae» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `trae`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_trae_05433efe.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_trae_05433efe.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-trae.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: doudou.com
domain_suffix: marscode.cn
domain_suffix: marscode.com.cn
domain_suffix: mcbaas.work
domain_suffix: mcdemo.show
domain_suffix: mchost.guru
domain_suffix: mcprev.cn
domain_suffix: tcwqqdy.guru
domain_suffix: trae.cn
domain_suffix: trae.com.cn
domain_suffix: trae.guru
domain_suffix: yoma.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
