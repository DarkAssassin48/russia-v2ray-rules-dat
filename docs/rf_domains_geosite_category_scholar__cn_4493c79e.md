# category-scholar-!cn

Актуальный набор доменных правил «category-scholar-!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-scholar-!cn`. Тип: **domains**.

Правил: **466**. Точные домены: 90; доменные зоны: 376; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_scholar__cn_4493c79e.txt)
