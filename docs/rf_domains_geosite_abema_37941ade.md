# abema

Актуальный набор доменных правил «abema» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `abema`. Тип: **domains**.

Правил: **21**. Точные домены: 5; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_abema_37941ade.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_abema_37941ade.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-abema.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
