# 6park

Актуальный набор доменных правил «6park» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `6park`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_6park_55c9db9c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_6park_55c9db9c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-6park.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 6park.com
domain_suffix: 6parkbbs.com
domain_suffix: 6parknews.com
domain_suffix: cool18.com
domain_suffix: parkvv.com
domain_suffix: popo8.com
domain_suffix: xwbo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
