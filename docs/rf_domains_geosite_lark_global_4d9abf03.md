# lark-global

Актуальный набор доменных правил «lark-global» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lark-global`. Тип: **domains**.

Правил: **31**. Точные домены: 0; доменные зоны: 31; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lark_global_4d9abf03.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lark_global_4d9abf03.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lark-global.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
