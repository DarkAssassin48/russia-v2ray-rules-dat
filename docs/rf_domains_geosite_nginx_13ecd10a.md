# nginx

Актуальный набор доменных правил «nginx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nginx`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nginx_13ecd10a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nginx_13ecd10a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nginx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nginx.com
domain_suffix: nginx.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
