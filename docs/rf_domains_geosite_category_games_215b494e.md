# category-games

Актуальный набор доменных правил «category-games» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games`. Тип: **domains**.

Правил: **1063**. Точные домены: 99; доменные зоны: 960; фрагменты: 0; regex: 4; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games_215b494e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games_215b494e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
