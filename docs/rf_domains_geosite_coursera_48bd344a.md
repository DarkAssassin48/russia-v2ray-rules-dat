# coursera

Актуальный набор доменных правил «coursera» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `coursera`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_coursera_48bd344a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_coursera_48bd344a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-coursera.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: coursera-for-business.org
domain_suffix: coursera.community
domain_suffix: coursera.help
domain_suffix: coursera.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
