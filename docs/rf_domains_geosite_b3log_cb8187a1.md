# b3log

Актуальный набор доменных правил «b3log» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `b3log`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_b3log_cb8187a1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_b3log_cb8187a1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-b3log.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: b3log.org
domain_suffix: b3logfile.com
domain_suffix: hacpai.com
domain_suffix: ld246.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
