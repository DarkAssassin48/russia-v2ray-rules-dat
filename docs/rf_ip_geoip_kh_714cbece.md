# kh · IP-сети

Актуальный набор IP-сетей «kh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kh`. Тип: **ip**.

Правил: **747**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 747.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_kh_714cbece.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_kh_714cbece.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-kh.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
