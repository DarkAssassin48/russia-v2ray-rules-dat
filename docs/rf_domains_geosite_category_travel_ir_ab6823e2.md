# category-travel-ir

Актуальный набор доменных правил «category-travel-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-travel-ir`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_travel_ir_ab6823e2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_travel_ir_ab6823e2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-travel-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: alibaba.ir
domain_suffix: flightio.com
domain_suffix: mrbilit.com
domain_suffix: tap30.services
domain_suffix: tap33.me
domain_suffix: tapsi.cab
domain_suffix: tapsi.ir
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
