# intuit

Актуальный набор доменных правил «intuit» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `intuit`. Тип: **domains**.

Правил: **35**. Точные домены: 0; доменные зоны: 35; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_intuit_f068fabd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_intuit_f068fabd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-intuit.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
