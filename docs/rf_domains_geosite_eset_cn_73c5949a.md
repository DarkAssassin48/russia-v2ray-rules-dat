# eset@cn

Актуальный набор доменных правил «eset@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eset@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_eset_cn_73c5949a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_eset_cn_73c5949a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-eset@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cn.eset.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
