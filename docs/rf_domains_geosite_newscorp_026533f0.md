# newscorp

Актуальный набор доменных правил «newscorp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `newscorp`. Тип: **domains**.

Правил: **152**. Точные домены: 0; доменные зоны: 152; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_newscorp_026533f0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_newscorp_026533f0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-newscorp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
