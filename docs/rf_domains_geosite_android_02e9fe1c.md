# android

Актуальный набор доменных правил «android» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `android`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_android_02e9fe1c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_android_02e9fe1c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-android.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: android.googlesource.com
domain_suffix: .android
domain_suffix: android.com
domain_suffix: androidify.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
