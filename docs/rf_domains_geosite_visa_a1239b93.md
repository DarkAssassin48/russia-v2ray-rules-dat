# visa

Актуальный набор доменных правил «visa» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `visa`. Тип: **domains**.

Правил: **160**. Точные домены: 0; доменные зоны: 160; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_visa_a1239b93.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_visa_a1239b93.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-visa.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
