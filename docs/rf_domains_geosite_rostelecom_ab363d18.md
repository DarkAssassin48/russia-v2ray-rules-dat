# rostelecom

Актуальный набор доменных правил «rostelecom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rostelecom`. Тип: **domains**.

Правил: **9**. Точные домены: 1; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rostelecom_ab363d18.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rostelecom_ab363d18.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rostelecom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: sentry.iptv.rt.ru
domain_suffix: azbukainterneta.ru
domain_suffix: more.tv
domain_suffix: restream-media.net
domain_suffix: restream.ru
domain_suffix: rostelecom.ru
domain_suffix: rt.ru
domain_suffix: wink.am
domain_suffix: wink.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
