# nowcoder

Актуальный набор доменных правил «nowcoder» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nowcoder`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nowcoder_21fa4ecc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nowcoder_21fa4ecc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nowcoder.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: newcoder.com
domain_suffix: nowcoder.com
domain_suffix: nowcoder.net
domain_suffix: nowcoder.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
