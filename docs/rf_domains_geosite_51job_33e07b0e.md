# 51job

Актуальный набор доменных правил «51job» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `51job`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_51job_33e07b0e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_51job_33e07b0e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-51job.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 51job.com
domain_suffix: 51jobcdn.com
domain_suffix: yingjiesheng.com
domain_suffix: yingjiesheng.net
domain_suffix: zhiding.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
