# jfrog

Актуальный набор доменных правил «jfrog» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jfrog`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jfrog_1acd7371.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jfrog_1acd7371.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jfrog.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: d29vzk4ow07wi7.cloudfront.net
domain_suffix: bintray.com
domain_suffix: jfrog.com
domain_suffix: jfrog.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
