# apple-tvplus

Актуальный набор доменных правил «apple-tvplus» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-tvplus`. Тип: **domains**.

Правил: **8**. Точные домены: 7; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_tvplus_2b9ec616.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_tvplus_2b9ec616.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-tvplus.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: apple-tv-plus-press.apple.com
domain: hls-amt.itunes.apple.com
domain: hls.itunes.apple.com
domain: np-edge.itunes.apple.com
domain: play-edge.itunes.apple.com
domain: tv.applemusic.com
domain: uts-api.itunes.apple.com
domain_suffix: tv.apple.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
