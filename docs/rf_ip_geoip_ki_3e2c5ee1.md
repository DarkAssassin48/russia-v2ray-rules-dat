# ki · IP-сети

Актуальный набор IP-сетей «ki» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ki`. Тип: **ip**.

Правил: **185**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 185.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ki_3e2c5ee1.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ki_3e2c5ee1.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ki.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
