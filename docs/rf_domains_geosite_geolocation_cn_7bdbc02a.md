# geolocation-cn

Актуальный набор доменных правил «geolocation-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `geolocation-cn`. Тип: **domains**.

Правил: **5440**. Точные домены: 46; доменные зоны: 5391; фрагменты: 0; regex: 3; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_geolocation_cn_7bdbc02a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_geolocation_cn_7bdbc02a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-geolocation-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
