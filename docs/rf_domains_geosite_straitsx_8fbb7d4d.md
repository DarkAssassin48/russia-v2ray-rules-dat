# straitsx

Актуальный набор доменных правил «straitsx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `straitsx`. Тип: **domains**.

Правил: **3**. Точные домены: 2; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_straitsx_8fbb7d4d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_straitsx_8fbb7d4d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-straitsx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: d3r7nsslvs6aaf.cloudfront.net
domain: straitsx-826709081262441084-b790f87a2ae6fd417434295.freshchat.com
domain_suffix: straitsx.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
