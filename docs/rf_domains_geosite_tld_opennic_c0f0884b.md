# tld-opennic

Актуальный набор доменных правил «tld-opennic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tld-opennic`. Тип: **domains**.

Правил: **28**. Точные домены: 0; доменные зоны: 28; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tld_opennic_c0f0884b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tld_opennic_c0f0884b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tld-opennic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
