# zhihu@ads

Актуальный набор доменных правил «zhihu@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zhihu@ads`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zhihu_ads_8733cc4f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zhihu_ads_8733cc4f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zhihu@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: crash2.zhihu.com
domain_suffix: zhihu-web-analytics.zhihu.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
