# vilavpn

Актуальный набор доменных правил «vilavpn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vilavpn`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vilavpn_f4d8b247.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vilavpn_f4d8b247.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vilavpn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: vilavpn.com
domain_suffix: vilavpn.xyz
domain_suffix: vilavpn1.xyz
domain_suffix: vilavpn2.xyz
domain_suffix: vilavpn3.xyz
domain_suffix: vilavpn4.xyz
domain_suffix: vilavpn5.xyz
domain_suffix: vilavpn6.xyz
domain_suffix: vilavpn7.xyz
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
