# is · IP-сети

Актуальный набор IP-сетей «is» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `is`. Тип: **ip**.

Правил: **829**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 829.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_is_214f27b0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_is_214f27b0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-is.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
