# ieee

Актуальный набор доменных правил «ieee» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ieee`. Тип: **domains**.

Правил: **54**. Точные домены: 0; доменные зоны: 54; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ieee_b371eb73.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ieee_b371eb73.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ieee.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
