# ru · IP-сети

Актуальный набор IP-сетей «ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ru`. Тип: **ip**.

Правил: **25265**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 25265.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ru_a7a3b49d.txt)
