# onedrive

Актуальный набор доменных правил «onedrive» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `onedrive`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_onedrive_0d40d347.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_onedrive_0d40d347.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-onedrive.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1drv.com
domain_suffix: 1drv.ms
domain_suffix: livefilestore.com
domain_suffix: onedrive.co
domain_suffix: onedrive.co.uk
domain_suffix: onedrive.com
domain_suffix: onedrive.eu
domain_suffix: onedrive.live.com
domain_suffix: onedrive.net
domain_suffix: onedrive.org
domain_suffix: storage.live.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
