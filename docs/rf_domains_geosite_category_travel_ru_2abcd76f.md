# category-travel-ru

Актуальный набор доменных правил «category-travel-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-travel-ru`. Тип: **domains**.

Правил: **25**. Точные домены: 7; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_travel_ru_2abcd76f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_travel_ru_2abcd76f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-travel-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
