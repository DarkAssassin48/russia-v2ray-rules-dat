# umeng@ads

Актуальный набор доменных правил «umeng@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `umeng@ads`. Тип: **domains**.

Правил: **22**. Точные домены: 0; доменные зоны: 22; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_umeng_ads_ea62f45f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_umeng_ads_ea62f45f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-umeng@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
