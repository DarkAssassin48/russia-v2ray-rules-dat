# hinet

Актуальный набор доменных правил «hinet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hinet`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hinet_775f2114.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hinet_775f2114.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hinet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cht.com.tw
domain_suffix: chtf.org.tw
domain_suffix: emome.net
domain_suffix: gtlsca.nat.gov.tw
domain_suffix: hinet.net
domain_suffix: xuite.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
