# nintendo@cn

Актуальный набор доменных правил «nintendo@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nintendo@cn`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nintendo_cn_9f1a858b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nintendo_cn_9f1a858b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nintendo@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
