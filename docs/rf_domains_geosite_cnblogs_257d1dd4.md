# cnblogs

Актуальный набор доменных правил «cnblogs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cnblogs`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cnblogs_257d1dd4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cnblogs_257d1dd4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cnblogs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: blogjava.net
domain_suffix: cnblogs.com
domain_suffix: cnblogs.vip
domain_suffix: cnitblog.com
domain_suffix: cnweblog.com
domain_suffix: cppblog.com
domain_suffix: phpweblog.net
domain_suffix: teachblog.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
