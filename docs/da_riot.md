# Riot Games — аккаунты и клиент

Известные домены Riot Games, аккаунтов и клиентских сервисов; отдельные IP игровых серверов следует выбирать осознанно.

Код: `riot`. Тип: **domains**.

Правил: **68**. Точные домены: 15; доменные зоны: 53; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_riot.txt)
- [Полный JSON с исходной логикой](../details/da_riot.json)
- [Готовый SRS](../custom/riot.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
