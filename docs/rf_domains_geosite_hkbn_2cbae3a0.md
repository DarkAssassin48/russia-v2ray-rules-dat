# hkbn

Актуальный набор доменных правил «hkbn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hkbn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hkbn_2cbae3a0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hkbn_2cbae3a0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hkbn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: csifund.org
domain_suffix: hkbn.com.hk
domain_suffix: hkbn.net
domain_suffix: hkbnes.net
domain_suffix: jos.com
domain_suffix: speedtest.com.hk
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
