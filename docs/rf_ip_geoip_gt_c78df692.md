# gt · IP-сети

Актуальный набор IP-сетей «gt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gt`. Тип: **ip**.

Правил: **760**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 760.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gt_c78df692.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gt_c78df692.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
