# aliyun-drive

Актуальный набор доменных правил «aliyun-drive» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aliyun-drive`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aliyun_drive_c054b5b2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aliyun_drive_c054b5b2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aliyun-drive.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: alicloudccp.com
domain_suffix: alipan.com
domain_suffix: aliyundrive.cloud
domain_suffix: aliyundrive.com
domain_suffix: aliyundrive.net
domain_suffix: yunpan.aliyun.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
