# lysol

Актуальный набор доменных правил «lysol» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lysol`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_lysol_19ce31cf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_lysol_19ce31cf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-lysol.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: lizol.co.in
domain_suffix: lysol.ca
domain_suffix: lysol.cl
domain_suffix: lysol.cn
domain_suffix: lysol.co.cr
domain_suffix: lysol.com
domain_suffix: lysol.com.cn
domain_suffix: lysol.com.mx
domain_suffix: lysol.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
