# de · IP-сети

Актуальный набор IP-сетей «de» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `de`. Тип: **ip**.

Правил: **73004**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 73004.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_de_12c7dbac.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_de_12c7dbac.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-de.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
