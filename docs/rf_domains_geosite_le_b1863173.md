# le

Актуальный набор доменных правил «le» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `le`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_le_b1863173.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_le_b1863173.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-le.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: apple.www.letv.com
domain_suffix: ark.letv.com
domain_suffix: dc.letv.com
domain_suffix: g3.letv.com
domain_suffix: le.com
domain_suffix: leautolink.com
domain_suffix: lecloud.com
domain_suffix: lecloudapi.com
domain_suffix: lemall.com
domain_suffix: leso.cn
domain_suffix: letv.com
domain_suffix: letvcdn.com
domain_suffix: letvimg.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
