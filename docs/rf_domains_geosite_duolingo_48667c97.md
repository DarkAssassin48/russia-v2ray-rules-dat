# duolingo

Актуальный набор доменных правил «duolingo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `duolingo`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_duolingo_48667c97.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_duolingo_48667c97.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-duolingo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads-api.duolingo.com
domain_suffix: analytics.vpc.duolingo.com
domain_suffix: duolingo.cn
domain_suffix: duolingo.com
domain_suffix: metrics.duolingo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
