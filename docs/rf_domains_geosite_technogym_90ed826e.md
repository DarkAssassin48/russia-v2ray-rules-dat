# technogym

Актуальный набор доменных правил «technogym» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `technogym`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_technogym_90ed826e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_technogym_90ed826e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-technogym.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: letsmoveforabetterworld.com
domain_suffix: technogym.bg
domain_suffix: technogym.ch
domain_suffix: technogym.com
domain_suffix: technogym.com.br
domain_suffix: technogym.ru
domain_suffix: technogym.su
domain_suffix: wellnessinstitute.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
