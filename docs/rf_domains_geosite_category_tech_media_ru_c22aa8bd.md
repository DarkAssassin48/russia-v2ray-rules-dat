# category-tech-media-ru

Актуальный набор доменных правил «category-tech-media-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-tech-media-ru`. Тип: **domains**.

Правил: **34**. Точные домены: 0; доменные зоны: 34; фрагменты: 0; regex: 0; IP-сети: 0.
