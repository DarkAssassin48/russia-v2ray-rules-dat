# supersonic

Актуальный набор доменных правил «supersonic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `supersonic`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_supersonic_7b6138ee.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_supersonic_7b6138ee.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-supersonic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ssacdn.com
domain_suffix: supersonic.com
domain_suffix: supersonicads-a.akamaihd.net
domain_suffix: supersonicads.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
