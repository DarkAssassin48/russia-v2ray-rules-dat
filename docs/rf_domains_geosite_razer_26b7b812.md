# razer

Актуальный набор доменных правил «razer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `razer`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_razer_26b7b812.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_razer_26b7b812.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-razer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: razer.com
domain_suffix: razerapi.com
domain_suffix: razerofficial.com
domain_suffix: razersupport.com
domain_suffix: razersynapse.com
domain_suffix: razerzone.com
domain_suffix: razerzone.jp
domain_suffix: respawnbyrazer.com
domain_suffix: rzr.to
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
