# fr · IP-сети

Актуальный набор IP-сетей «fr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fr`. Тип: **ip**.

Правил: **40577**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 40577.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fr_de4362bd.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fr_de4362bd.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
