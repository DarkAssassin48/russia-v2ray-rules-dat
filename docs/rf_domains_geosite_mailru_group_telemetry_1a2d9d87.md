# mailru-group@telemetry

Актуальный набор доменных правил «mailru-group@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mailru-group@telemetry`. Тип: **domains**.

Правил: **14**. Точные домены: 11; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mailru_group_telemetry_1a2d9d87.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mailru_group_telemetry_1a2d9d87.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mailru-group@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
