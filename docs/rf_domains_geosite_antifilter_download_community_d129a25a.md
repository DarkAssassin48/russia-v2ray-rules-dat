# Antifilter — сообщество

Актуальный набор доменных правил «Antifilter — сообщество» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `antifilter-download-community`. Тип: **domains**.

Правил: **421**. Точные домены: 0; доменные зоны: 421; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_antifilter_download_community_d129a25a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_antifilter_download_community_d129a25a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-antifilter-download-community.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
