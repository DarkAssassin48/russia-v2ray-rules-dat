# category-ecommerce

Актуальный набор доменных правил «category-ecommerce» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce`. Тип: **domains**.

Правил: **1328**. Точные домены: 38; доменные зоны: 1290; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_481a3c07.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_481a3c07.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
