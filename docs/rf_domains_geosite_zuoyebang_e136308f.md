# zuoyebang

Актуальный набор доменных правил «zuoyebang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zuoyebang`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zuoyebang_e136308f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zuoyebang_e136308f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zuoyebang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kuaiduizuoye.com
domain_suffix: syh.zybang.com
domain_suffix: zuoyebang.cc
domain_suffix: zuoyebang.com
domain_suffix: zybang.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
