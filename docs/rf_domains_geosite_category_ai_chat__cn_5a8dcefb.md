# category-ai-chat-!cn

Актуальный набор доменных правил «category-ai-chat-!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ai-chat-!cn`. Тип: **domains**.

Правил: **218**. Точные домены: 37; доменные зоны: 180; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ai_chat__cn_5a8dcefb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ai_chat__cn_5a8dcefb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ai-chat-!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
