# sinopec

Актуальный набор доменных правил «sinopec» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sinopec`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sinopec_60ec0964.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sinopec_60ec0964.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sinopec.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: sinopec-usa.com
domain_suffix: sinopec.com
domain_suffix: sinopecgroup.com
domain_suffix: sinopecnews.com.cn
domain_suffix: sinopecsales.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
