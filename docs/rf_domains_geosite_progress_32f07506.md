# progress

Актуальный набор доменных правил «progress» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `progress`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_progress_32f07506.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_progress_32f07506.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-progress.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chef.io
domain_suffix: getfiddler.com
domain_suffix: kemptechnologies.com
domain_suffix: progress.com
domain_suffix: sharefile.com
domain_suffix: telerik.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
