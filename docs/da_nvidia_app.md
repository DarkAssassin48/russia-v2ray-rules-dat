# NVIDIA App — вход, драйверы и обновления

Домены NVIDIA и GeForce: вход в аккаунт, проверка версий, драйверы, обновления приложения, игровые профили и изображения. Домены Hugging Face исключены из этого профиля. Исходная широкая категория NVIDIA доступна отдельно.

Код: `nvidia-app`. Тип: **domains**.

Правил: **63**. Точные домены: 3; доменные зоны: 60; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_nvidia_app.txt)
- [Полный JSON с исходной логикой](../details/da_nvidia_app.json)
- [Готовый SRS](../custom/nvidia-app.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
