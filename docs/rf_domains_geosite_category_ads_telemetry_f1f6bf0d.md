# category-ads@telemetry

Актуальный набор доменных правил «category-ads@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ads@telemetry`. Тип: **domains**.

Правил: **196**. Точные домены: 50; доменные зоны: 146; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ads_telemetry_f1f6bf0d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ads_telemetry_f1f6bf0d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ads@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
