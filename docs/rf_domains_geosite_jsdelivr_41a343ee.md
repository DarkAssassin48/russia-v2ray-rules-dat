# jsdelivr

Актуальный набор доменных правил «jsdelivr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jsdelivr`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jsdelivr_41a343ee.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jsdelivr_41a343ee.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jsdelivr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: esm.run
domain_suffix: jsdelivr.com
domain_suffix: jsdelivr.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
