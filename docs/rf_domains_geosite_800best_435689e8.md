# 800best

Актуальный набор доменных правил «800best» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `800best`. Тип: **domains**.

Правил: **29**. Точные домены: 0; доменные зоны: 29; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_800best_435689e8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_800best_435689e8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-800best.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
