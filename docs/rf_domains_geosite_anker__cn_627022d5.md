# anker@!cn

Актуальный набор доменных правил «anker@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `anker@!cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_anker__cn_627022d5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_anker__cn_627022d5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-anker@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: anker-in.com
domain_suffix: anker.com
domain_suffix: ankersolix.com
domain_suffix: eufy.com
domain_suffix: eufylife.com
domain_suffix: eufymake.com
domain_suffix: soundcore.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
