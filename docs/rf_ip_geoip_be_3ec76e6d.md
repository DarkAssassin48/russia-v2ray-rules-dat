# be · IP-сети

Актуальный набор IP-сетей «be» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `be`. Тип: **ip**.

Правил: **7545**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 7545.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_be_3ec76e6d.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_be_3ec76e6d.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-be.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
