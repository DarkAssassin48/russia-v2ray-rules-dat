# tencent-games

Актуальный набор доменных правил «tencent-games» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent-games`. Тип: **domains**.

Правил: **87**. Точные домены: 0; доменные зоны: 87; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_games_b5e6f87a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_games_b5e6f87a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent-games.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
