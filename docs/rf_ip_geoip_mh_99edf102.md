# mh · IP-сети

Актуальный набор IP-сетей «mh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mh`. Тип: **ip**.

Правил: **119**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 119.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mh_99edf102.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mh_99edf102.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mh.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
