# category-securities-cn

Актуальный набор доменных правил «category-securities-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-securities-cn`. Тип: **domains**.

Правил: **171**. Точные домены: 0; доменные зоны: 171; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_securities_cn_96e8564d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_securities_cn_96e8564d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-securities-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
