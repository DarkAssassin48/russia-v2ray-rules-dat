# pchome

Актуальный набор доменных правил «pchome» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pchome`. Тип: **domains**.

Правил: **12**. Точные домены: 1; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pchome_f9960900.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pchome_f9960900.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pchome.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: ecapi-pchome.cdn.hinet.net
domain_suffix: ecimg.tw
domain_suffix: pchome.com.tw
domain_suffix: pchomeec.tw
domain_suffix: pchomeonline.com.tw
domain_suffix: pchomepay.com.tw
domain_suffix: pcloud.tw
domain_suffix: pcstore.com.tw
domain_suffix: piapp.com.tw
domain_suffix: rakuya.com.tw
domain_suffix: tagapie.com.tw
domain_suffix: toget.com.tw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
