# tk · IP-сети

Актуальный набор IP-сетей «tk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tk`. Тип: **ip**.

Правил: **106**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 106.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tk_8f5fa6aa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tk_8f5fa6aa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
