# purikonejp

Актуальный набор доменных правил «purikonejp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `purikonejp`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_purikonejp_f8f01eb0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_purikonejp_f8f01eb0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-purikonejp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: prd-priconne-redive.akamaized.net
domain_suffix: api-priconne-redive.cygames.jp
domain_suffix: omotenashi.cygames.jp
domain_suffix: priconne-redive.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
