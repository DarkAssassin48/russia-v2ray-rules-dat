# quip

Актуальный набор доменных правил «quip» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `quip`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_quip_e1fff829.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_quip_e1fff829.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-quip.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: quip-cdn.com
domain_suffix: quip.com
domain_suffix: quipelements.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
