# wantmedia

Актуальный набор доменных правил «wantmedia» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wantmedia`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wantmedia_683b8d02.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wantmedia_683b8d02.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wantmedia.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
