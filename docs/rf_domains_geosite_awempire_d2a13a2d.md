# awempire

Актуальный набор доменных правил «awempire» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `awempire`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_awempire_d2a13a2d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_awempire_d2a13a2d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-awempire.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: awempire.com
domain_suffix: dditsadn.com
domain_suffix: dditscdn.com
domain_suffix: docleradn.com
domain_suffix: doclercdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
