# auxgroup@!cn

Актуальный набор доменных правил «auxgroup@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `auxgroup@!cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_auxgroup__cn_3dd17775.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_auxgroup__cn_3dd17775.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-auxgroup@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aufit-air.com
domain_suffix: aux-global.com
domain_suffix: auxair.com
domain_suffix: auxcac.cn
domain_suffix: auxsmart.com
domain_suffix: sanxingelectric.com
domain_suffix: shinflow.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
