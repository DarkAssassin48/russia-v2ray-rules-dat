# category-enhance-gaming@cn

Актуальный набор доменных правил «category-enhance-gaming@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-enhance-gaming@cn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_enhance_gaming_cn_1ed979df.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_enhance_gaming_cn_1ed979df.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-enhance-gaming@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: heavenlywind.cc
domain_suffix: ldmnq.com
domain_suffix: lsplayer.com
domain_suffix: rpglogs.cn
domain_suffix: steampp.net
domain_suffix: yeshen.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
