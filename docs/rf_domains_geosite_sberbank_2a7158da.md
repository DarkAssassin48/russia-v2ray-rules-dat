# sberbank

Актуальный набор доменных правил «sberbank» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sberbank`. Тип: **domains**.

Правил: **18**. Точные домены: 1; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sberbank_2a7158da.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sberbank_2a7158da.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sberbank.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
