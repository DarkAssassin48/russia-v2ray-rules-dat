# tcl@ads

Актуальный набор доменных правил «tcl@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tcl@ads`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tcl_ads_b18b665b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tcl_ads_b18b665b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tcl@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads-api-o.api.leiniao.com
domain_suffix: ads-api-t.my7v.com
domain_suffix: ads-o.res.leiniao.com
domain_suffix: ads-uo.api.leiniao.com
domain_suffix: ads-ut.api.leiniao.com
domain_suffix: ads.api.my7v.com
domain_suffix: euads-o.api.leiniao.com
domain_suffix: hwads-t.api.my7v.com
domain_suffix: isms-o.api.my7v.com
domain_suffix: testads.api.my7v.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
