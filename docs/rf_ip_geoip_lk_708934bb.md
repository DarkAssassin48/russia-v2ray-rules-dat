# lk · IP-сети

Актуальный набор IP-сетей «lk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lk`. Тип: **ip**.

Правил: **467**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 467.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lk_708934bb.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lk_708934bb.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
