# addtoany

Актуальный набор доменных правил «addtoany» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `addtoany`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_addtoany_d10ff9dc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_addtoany_d10ff9dc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-addtoany.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: addtoany.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
