# soundofhope

Актуальный набор доменных правил «soundofhope» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `soundofhope`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_soundofhope_d388952c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_soundofhope_d388952c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-soundofhope.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: bayvoice.net
domain_suffix: ozvoice.org
domain_suffix: sohcradio.com
domain_suffix: sohfrance.org
domain_suffix: soundofhope.eu
domain_suffix: soundofhope.kr
```
