# yostar

Актуальный набор доменных правил «yostar» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yostar`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yostar_239f176f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yostar_239f176f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yostar.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: stargazer-games.com
domain_suffix: stellasora.global
domain_suffix: stellasora.jp
domain_suffix: yo-star.com
domain_suffix: yostar-pictures.co.jp
domain_suffix: yostar.cn
domain_suffix: yostar.co.jp
domain_suffix: yostar.net
domain_suffix: yostarplat.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
