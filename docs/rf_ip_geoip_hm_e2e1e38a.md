# hm · IP-сети

Актуальный набор IP-сетей «hm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hm`. Тип: **ip**.

Правил: **36**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 36.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_hm_e2e1e38a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_hm_e2e1e38a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-hm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
