# taptap

Актуальный набор доменных правил «taptap» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `taptap`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_taptap_0e69eacd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_taptap_0e69eacd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-taptap.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tapapks.com
domain_suffix: tapimg.com
domain_suffix: tapimg.net
domain_suffix: taptap.cn
domain_suffix: taptap.com
domain_suffix: taptap.io
domain_suffix: taptapdada.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
