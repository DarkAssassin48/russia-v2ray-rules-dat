# cm · IP-сети

Актуальный набор IP-сетей «cm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cm`. Тип: **ip**.

Правил: **287**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 287.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cm_b4c5ed8e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cm_b4c5ed8e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
