# category-retail-ru@telemetry

Актуальный набор доменных правил «category-retail-ru@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-retail-ru@telemetry`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_retail_ru_telemetry_3754e2b0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_retail_ru_telemetry_3754e2b0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-retail-ru@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: sentry.x5.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
