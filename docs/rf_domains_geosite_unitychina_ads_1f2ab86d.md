# unitychina@ads

Актуальный набор доменных правил «unitychina@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `unitychina@ads`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_unitychina_ads_1f2ab86d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_unitychina_ads_1f2ab86d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-unitychina@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads.unitychina.cn
domain_suffix: splash-ads.cdn.unity.cn
domain_suffix: splash-ads.unitychina.cn
domain_suffix: unityads.unity.cn
domain_suffix: unityads.unitychina.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
