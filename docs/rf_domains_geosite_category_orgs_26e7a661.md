# category-orgs

Актуальный набор доменных правил «category-orgs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-orgs`. Тип: **domains**.

Правил: **131**. Точные домены: 10; доменные зоны: 121; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_orgs_26e7a661.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_orgs_26e7a661.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-orgs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
