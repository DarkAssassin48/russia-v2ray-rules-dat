# bs · IP-сети

Актуальный набор IP-сетей «bs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bs`. Тип: **ip**.

Правил: **281**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 281.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bs_ca7ddd21.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bs_ca7ddd21.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
