# category-ddns

Актуальный набор доменных правил «category-ddns» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ddns`. Тип: **domains**.

Правил: **111**. Точные домены: 0; доменные зоны: 111; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ddns_5818a7bc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ddns_5818a7bc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ddns.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
