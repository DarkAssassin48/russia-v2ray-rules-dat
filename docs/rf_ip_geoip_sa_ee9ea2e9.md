# sa · IP-сети

Актуальный набор IP-сетей «sa» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sa`. Тип: **ip**.

Правил: **2598**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2598.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sa_ee9ea2e9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sa_ee9ea2e9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sa.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
