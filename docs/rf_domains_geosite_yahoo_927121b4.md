# yahoo

Актуальный набор доменных правил «yahoo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yahoo`. Тип: **domains**.

Правил: **178**. Точные домены: 1; доменные зоны: 177; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_yahoo_927121b4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_yahoo_927121b4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-yahoo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
