# bytedance-ai-!cn@!cn

Актуальный набор доменных правил «bytedance-ai-!cn@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bytedance-ai-!cn@!cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bytedance_ai__cn__cn_1b5a79fa.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bytedance_ai__cn__cn_1b5a79fa.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bytedance-ai-!cn@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cici.com
domain_suffix: ciciai.com
domain_suffix: ciciaicdn.com
domain_suffix: coze.com
domain_suffix: dola.com
domain_suffix: marscode.com
domain_suffix: trae.ai
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
