# vodafone

Актуальный набор доменных правил «vodafone» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vodafone`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vodafone_a7478c36.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vodafone_a7478c36.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vodafone.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: myvodafone.com.au
domain_suffix: myvodafone.com.ws
domain_suffix: vodafone.co.uk
domain_suffix: vodafone.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
