# netcup

Актуальный набор доменных правил «netcup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `netcup`. Тип: **domains**.

Правил: **24**. Точные домены: 0; доменные зоны: 24; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_netcup_80c44067.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_netcup_80c44067.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-netcup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
