# wholefoodsmarket

Актуальный набор доменных правил «wholefoodsmarket» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wholefoodsmarket`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wholefoodsmarket_eeb52864.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wholefoodsmarket_eeb52864.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wholefoodsmarket.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wfm.com
domain_suffix: wholecitiesfoundation.org
domain_suffix: wholefoods.com
domain_suffix: wholefoodsmarket.co.uk
domain_suffix: wholefoodsmarket.com
domain_suffix: wholekidsfoundation.org
domain_suffix: wholeplanetfoundation.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
