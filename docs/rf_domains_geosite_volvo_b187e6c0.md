# volvo

Актуальный набор доменных правил «volvo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `volvo`. Тип: **domains**.

Правил: **211**. Точные домены: 0; доменные зоны: 211; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_volvo_b187e6c0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_volvo_b187e6c0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-volvo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
