# bo · IP-сети

Актуальный набор IP-сетей «bo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bo`. Тип: **ip**.

Правил: **595**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 595.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bo_51134efa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bo_51134efa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
