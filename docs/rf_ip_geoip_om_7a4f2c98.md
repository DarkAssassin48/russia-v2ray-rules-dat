# om · IP-сети

Актуальный набор IP-сетей «om» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `om`. Тип: **ip**.

Правил: **625**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 625.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_om_7a4f2c98.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_om_7a4f2c98.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-om.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
