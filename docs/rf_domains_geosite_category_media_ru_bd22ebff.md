# category-media-ru

Актуальный набор доменных правил «category-media-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media-ru`. Тип: **domains**.

Правил: **148**. Точные домены: 0; доменные зоны: 148; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_ru_bd22ebff.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_ru_bd22ebff.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
