# hentaichen

Актуальный набор доменных правил «hentaichen» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hentaichen`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hentaichen_6bcce022.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hentaichen_6bcce022.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hentaichen.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: h-chan.me
domain_suffix: hentai-chan.com
domain_suffix: hentai-chan.live
domain_suffix: hentaichan.live
domain_suffix: hentaichan.me
domain_suffix: imgschan.xyz
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
