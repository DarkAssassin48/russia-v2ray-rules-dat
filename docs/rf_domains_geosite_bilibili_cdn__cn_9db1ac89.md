# bilibili-cdn@!cn

Актуальный набор доменных правил «bilibili-cdn@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bilibili-cdn@!cn`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bilibili_cdn__cn_9db1ac89.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bilibili_cdn__cn_9db1ac89.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bilibili-cdn@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: upos-hz-mirrorakam.akamaized.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
