# ddos-guard · IP-сети

Актуальный набор IP-сетей «ddos-guard» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ddos-guard`. Тип: **ip**.

Правил: **18**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 18.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ddos_guard_fea14134.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ddos_guard_fea14134.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ddos-guard.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
