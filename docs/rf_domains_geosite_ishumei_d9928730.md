# ishumei

Актуальный набор доменных правил «ishumei» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ishumei`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ishumei_d9928730.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ishumei_d9928730.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ishumei.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fengkongbao.com
domain_suffix: fengkongcloud.cn
domain_suffix: fengkongcloud.com
domain_suffix: ishumei.com
domain_suffix: portal101.cn
domain_suffix: portal102.cn
domain_suffix: portal201.cn
domain_suffix: portal301.cn
domain_suffix: tebiefuza.cloud
domain_suffix: tebiefuza.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
