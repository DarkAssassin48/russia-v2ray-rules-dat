# mobile01

Актуальный набор доменных правил «mobile01» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mobile01`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mobile01_e980c28c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mobile01_e980c28c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mobile01.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 5i01.com
domain_suffix: mobile01.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
