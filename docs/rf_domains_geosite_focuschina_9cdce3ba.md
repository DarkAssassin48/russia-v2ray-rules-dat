# focuschina

Актуальный набор доменных правил «focuschina» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `focuschina`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_focuschina_9cdce3ba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_focuschina_9cdce3ba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-focuschina.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: focuschina.com
domain_suffix: made-in-china.com
domain_suffix: micstatic.com
domain_suffix: trademessenger.com
domain_suffix: vemic.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
