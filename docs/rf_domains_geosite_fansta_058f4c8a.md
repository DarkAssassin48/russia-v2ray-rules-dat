# fansta

Актуальный набор доменных правил «fansta» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fansta`. Тип: **domains**.

Правил: **5**. Точные домены: 1; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fansta_058f4c8a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fansta_058f4c8a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fansta.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: misa-prod.s3.ap-northeast-1.amazonaws.com
domain_suffix: 2023aga.oen.tw
domain_suffix: aga-expo.com
domain_suffix: cosfans-tw.com
domain_suffix: fansta.me
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
