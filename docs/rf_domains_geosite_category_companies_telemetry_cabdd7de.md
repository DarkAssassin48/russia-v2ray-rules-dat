# category-companies@telemetry

Актуальный набор доменных правил «category-companies@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-companies@telemetry`. Тип: **domains**.

Правил: **63**. Точные домены: 33; доменные зоны: 30; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_companies_telemetry_cabdd7de.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_companies_telemetry_cabdd7de.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-companies@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
