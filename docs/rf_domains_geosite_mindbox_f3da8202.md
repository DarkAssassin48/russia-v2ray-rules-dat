# mindbox

Актуальный набор доменных правил «mindbox» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mindbox`. Тип: **domains**.

Правил: **22**. Точные домены: 7; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mindbox_f3da8202.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mindbox_f3da8202.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mindbox.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
