# sber@ads

Актуальный набор доменных правил «sber@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sber@ads`. Тип: **domains**.

Правил: **9**. Точные домены: 5; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sber_ads_7b24411f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sber_ads_7b24411f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sber@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: error-tracking.megamarket.tech
domain: metrics.21-school.ru
domain: sentry.sberauto.com
domain: tracing-http.megamarket.tech
domain: visor.sberbank.ru
domain_suffix: ads.sber.ru
domain_suffix: clickstream.sberbank.ru
domain_suffix: neon.click
domain_suffix: sbermarketing.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
