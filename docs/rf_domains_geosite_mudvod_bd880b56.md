# mudvod

Актуальный набор доменных правил «mudvod» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mudvod`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mudvod_bd880b56.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mudvod_bd880b56.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mudvod.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: biggggg.com
domain_suffix: mudvod.tv
domain_suffix: nbys.tv
domain_suffix: nbys1.tv
domain_suffix: nbyy.tv
domain_suffix: newpppp.com
domain_suffix: nivod.tv
domain_suffix: nivodi.tv
domain_suffix: nivodz.com
domain_suffix: vod360.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
