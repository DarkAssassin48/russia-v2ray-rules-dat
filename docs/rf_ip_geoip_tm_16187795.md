# tm · IP-сети

Актуальный набор IP-сетей «tm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tm`. Тип: **ip**.

Правил: **151**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 151.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_tm_16187795.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_tm_16187795.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-tm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
