# nikkei

Актуальный набор доменных правил «nikkei» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nikkei`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nikkei_f2eeb41b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nikkei_f2eeb41b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nikkei.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nikkei-cnbc.co.jp
domain_suffix: nikkei.co.jp
domain_suffix: nikkei.com
domain_suffix: nikkei.jp
domain_suffix: nikkei4946.com
domain_suffix: nikkeibp.co.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
