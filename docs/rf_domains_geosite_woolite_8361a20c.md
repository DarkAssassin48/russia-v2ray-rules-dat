# woolite

Актуальный набор доменных правил «woolite» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `woolite`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_woolite_8361a20c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_woolite_8361a20c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-woolite.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: woolite.ca
domain_suffix: woolite.cn
domain_suffix: woolite.com
domain_suffix: woolite.com.cn
domain_suffix: woolite.pl
domain_suffix: woolite.us
domain_suffix: woolitecarpet.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
