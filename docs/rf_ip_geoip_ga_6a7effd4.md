# ga · IP-сети

Актуальный набор IP-сетей «ga» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ga`. Тип: **ip**.

Правил: **146**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 146.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ga_6a7effd4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ga_6a7effd4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ga.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
