# category-android-app-download

Актуальный набор доменных правил «category-android-app-download» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-android-app-download`. Тип: **domains**.

Правил: **11**. Точные домены: 1; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_android_app_download_31c69418.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_android_app_download_31c69418.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-android-app-download.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain: apkmirror.disqus.com
domain_suffix: apkcombo.com

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
