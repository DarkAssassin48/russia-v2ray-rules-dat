# kuaishou@ads

Актуальный набор доменных правил «kuaishou@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kuaishou@ads`. Тип: **domains**.

Правил: **8**. Точные домены: 3; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kuaishou_ads_10292bfb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kuaishou_ads_10292bfb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kuaishou@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: apilog-web.acfun.cn
domain: log-sdk.gifshow.com
domain: wlog.kuaishou.com
domain_suffix: adbkwai.com
domain_suffix: adkwai.com
domain_suffix: adukwai.com
domain_suffix: e.kuaishou.cn
domain_suffix: e.kuaishou.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
