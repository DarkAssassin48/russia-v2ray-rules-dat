# tokyo-toshokan

Актуальный набор доменных правил «tokyo-toshokan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tokyo-toshokan`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tokyo_toshokan_fa3e3806.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tokyo_toshokan_fa3e3806.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tokyo-toshokan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: tokyo-tosho.net
domain_suffix: tokyotosho.info
domain_suffix: tokyotosho.se
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
