# ixbt

Актуальный набор доменных правил «ixbt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ixbt`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ixbt_d60ff745.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ixbt_d60ff745.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ixbt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ixbt.com
domain_suffix: ixbt.games
domain_suffix: ixbt.market
domain_suffix: ixbt.media
domain_suffix: ixbt.pro
domain_suffix: ixbt.ru
domain_suffix: ixbt.shop
domain_suffix: ixbt.site
domain_suffix: ixbt.video
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
