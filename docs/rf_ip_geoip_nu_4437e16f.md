# nu · IP-сети

Актуальный набор IP-сетей «nu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nu`. Тип: **ip**.

Правил: **96**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 96.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_nu_4437e16f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_nu_4437e16f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-nu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
