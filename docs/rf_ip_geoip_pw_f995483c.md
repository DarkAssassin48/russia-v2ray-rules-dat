# pw · IP-сети

Актуальный набор IP-сетей «pw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pw`. Тип: **ip**.

Правил: **116**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 116.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pw_f995483c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pw_f995483c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
