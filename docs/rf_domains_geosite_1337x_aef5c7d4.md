# 1337x

Актуальный набор доменных правил «1337x» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `1337x`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_1337x_aef5c7d4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_1337x_aef5c7d4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-1337x.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1337x.gd
domain_suffix: 1337x.is
domain_suffix: 1337x.st
domain_suffix: 1337x.to
domain_suffix: 1337x.tw
domain_suffix: 1337xto.to
domain_suffix: 1337xx.to
domain_suffix: x1337x.eu
domain_suffix: x1337x.se
domain_suffix: x1337x.ws
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
