# wangsu

Актуальный набор доменных правил «wangsu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wangsu`. Тип: **domains**.

Правил: **29**. Точные домены: 0; доменные зоны: 29; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wangsu_8453980f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wangsu_8453980f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wangsu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
