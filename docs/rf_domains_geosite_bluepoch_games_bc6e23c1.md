# bluepoch-games

Актуальный набор доменных правил «bluepoch-games» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bluepoch-games`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bluepoch_games_bc6e23c1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bluepoch_games_bc6e23c1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bluepoch-games.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: sl916.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
