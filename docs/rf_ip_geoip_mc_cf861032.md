# mc · IP-сети

Актуальный набор IP-сетей «mc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mc`. Тип: **ip**.

Правил: **332**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 332.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mc_cf861032.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mc_cf861032.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
