# chinaunicom@!cn

Актуальный набор доменных правил «chinaunicom@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinaunicom@!cn`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinaunicom__cn_88ebe130.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinaunicom__cn_88ebe130.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinaunicom@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chinaunicom.com.hk
domain_suffix: chinaunicomglobal.com
domain_suffix: cuguplus.com
domain_suffix: cuniq.com
domain_suffix: cuniq.sg
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
