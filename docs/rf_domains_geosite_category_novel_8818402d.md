# category-novel

Актуальный набор доменных правил «category-novel» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-novel`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_novel_8818402d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_novel_8818402d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-novel.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ptzwx.com
domain_suffix: quanben-xiaoshuo.com
domain_suffix: quanben.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
