# bw · IP-сети

Актуальный набор IP-сетей «bw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bw`. Тип: **ip**.

Правил: **238**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 238.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bw_96047bab.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bw_96047bab.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
