# alphabet@cn

Актуальный набор доменных правил «alphabet@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alphabet@cn`. Тип: **domains**.

Правил: **126**. Точные домены: 114; доменные зоны: 10; фрагменты: 0; regex: 2; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alphabet_cn_1188f31b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alphabet_cn_1188f31b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alphabet@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
