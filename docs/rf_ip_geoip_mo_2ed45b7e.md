# mo · IP-сети

Актуальный набор IP-сетей «mo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mo`. Тип: **ip**.

Правил: **753**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 753.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mo_2ed45b7e.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mo_2ed45b7e.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
