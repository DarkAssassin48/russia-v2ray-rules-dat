# bytedance@ads

Актуальный набор доменных правил «bytedance@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bytedance@ads`. Тип: **domains**.

Правил: **44**. Точные домены: 15; доменные зоны: 29; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bytedance_ads_f39b58f8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bytedance_ads_f39b58f8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bytedance@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
