# gree

Актуальный набор доменных правил «gree» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gree`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gree_4841a7cc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gree_4841a7cc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gree.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gree.cn
domain_suffix: gree.com
domain_suffix: gree.com.cn
domain_suffix: greeyun.com
domain_suffix: kinghomechina.com
domain_suffix: tosot.com.cn
domain_suffix: zhlyen.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
