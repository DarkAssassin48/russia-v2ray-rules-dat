# tex

Актуальный набор доменных правил «tex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tex`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tex_ccb7c61b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tex_ccb7c61b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ctan.org
domain_suffix: latex-project.org
domain_suffix: miktex.org
domain_suffix: tug.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
