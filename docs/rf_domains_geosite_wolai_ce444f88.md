# wolai

Актуальный набор доменных правил «wolai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wolai`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wolai_ce444f88.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wolai_ce444f88.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wolai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wol.tv
domain_suffix: wolai.com
domain_suffix: wostatic.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
