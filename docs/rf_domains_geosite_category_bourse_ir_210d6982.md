# category-bourse-ir

Актуальный набор доменных правил «category-bourse-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-bourse-ir`. Тип: **domains**.

Правил: **48**. Точные домены: 0; доменные зоны: 48; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_bourse_ir_210d6982.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_bourse_ir_210d6982.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-bourse-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
