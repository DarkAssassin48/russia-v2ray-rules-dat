# vatsim

Актуальный набор доменных правил «vatsim» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vatsim`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vatsim_809d5589.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vatsim_809d5589.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vatsim.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
