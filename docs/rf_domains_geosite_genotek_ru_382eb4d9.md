# genotek-ru

Актуальный набор доменных правил «genotek-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `genotek-ru`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_genotek_ru_382eb4d9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_genotek_ru_382eb4d9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-genotek-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: eligens.cl
domain_suffix: eligens.com.br
domain_suffix: eligens.io
domain_suffix: genetic-technologies.am
domain_suffix: genotek.am
domain_suffix: genotek.es
domain_suffix: genotek.eu
domain_suffix: genotek.health
domain_suffix: genotek.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
