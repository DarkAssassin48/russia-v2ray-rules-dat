# alibaba@ads

Актуальный набор доменных правил «alibaba@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibaba@ads`. Тип: **domains**.

Правил: **87**. Точные домены: 0; доменные зоны: 87; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibaba_ads_eec5a289.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibaba_ads_eec5a289.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibaba@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
