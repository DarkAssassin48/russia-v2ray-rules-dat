# kkbox

Актуальный набор доменных правил «kkbox» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kkbox`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kkbox_841c1292.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kkbox_841c1292.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kkbox.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kfs.io
domain_suffix: kk.stream
domain_suffix: kkbox.com
domain_suffix: kkbox.com.tw
domain_suffix: kktix.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
