# 36kr

Актуальный набор доменных правил «36kr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `36kr`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_36kr_4b16ccce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_36kr_4b16ccce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-36kr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 36dianping.com
domain_suffix: 36kr.com
domain_suffix: 36krcdn.com
domain_suffix: 36krcnd.com
domain_suffix: 36linkr.com
domain_suffix: adx.36kr.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
