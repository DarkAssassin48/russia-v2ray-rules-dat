# google@telemetry

Актуальный набор доменных правил «google@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google@telemetry`. Тип: **domains**.

Правил: **5**. Точные домены: 5; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_telemetry_052dc20e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_telemetry_052dc20e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: crashlyticsreports-pa.googleapis.com
domain: firebase-settings.crashlytics.com
domain: firebaselogging-pa.googleapis.com
domain: firebaselogging.googleapis.com
domain: update.crashlytics.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
