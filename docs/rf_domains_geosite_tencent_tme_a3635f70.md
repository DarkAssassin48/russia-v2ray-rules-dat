# tencent-tme

Актуальный набор доменных правил «tencent-tme» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent-tme`. Тип: **domains**.

Правил: **45**. Точные домены: 0; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_tme_a3635f70.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_tme_a3635f70.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent-tme.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
