# category-ecommerce@cn

Актуальный набор доменных правил «category-ecommerce@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce@cn`. Тип: **domains**.

Правил: **80**. Точные домены: 0; доменные зоны: 80; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_cn_d00bd259.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_cn_d00bd259.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
