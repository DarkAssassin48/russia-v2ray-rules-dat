# adidas@cn

Актуальный набор доменных правил «adidas@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `adidas@cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_adidas_cn_263f860f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_adidas_cn_263f860f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-adidas@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adidas.cn
domain_suffix: adidas.com.cn
domain_suffix: adidasspecialtysports.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
