# icloud

Актуальный набор доменных правил «icloud» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `icloud`. Тип: **domains**.

Правил: **52**. Точные домены: 1; доменные зоны: 51; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_icloud_0eb0c81c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_icloud_0eb0c81c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-icloud.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
