# oneplus@!cn

Актуальный набор доменных правил «oneplus@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `oneplus@!cn`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_oneplus__cn_473d60a0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_oneplus__cn_473d60a0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-oneplus@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: community.oneplus.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
