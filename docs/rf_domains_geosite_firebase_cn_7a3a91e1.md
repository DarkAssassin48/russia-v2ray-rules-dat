# firebase@cn

Актуальный набор доменных правил «firebase@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `firebase@cn`. Тип: **domains**.

Правил: **3**. Точные домены: 3; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_firebase_cn_7a3a91e1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_firebase_cn_7a3a91e1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-firebase@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: crashlyticsreports-pa.googleapis.com
domain: firebase-settings.crashlytics.com
domain: update.crashlytics.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
