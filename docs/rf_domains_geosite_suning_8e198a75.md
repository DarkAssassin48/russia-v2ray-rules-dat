# suning

Актуальный набор доменных правил «suning» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `suning`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_suning_8e198a75.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_suning_8e198a75.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-suning.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cnsuning.com
domain_suffix: suning.cn
domain_suffix: suning.com
domain_suffix: suningcloud.com
domain_suffix: suningestate.com
domain_suffix: suningholdings.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
