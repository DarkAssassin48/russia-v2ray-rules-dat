# gog

Актуальный набор доменных правил «gog» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gog`. Тип: **domains**.

Правил: **8**. Точные домены: 3; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gog_2e08a4b0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gog_2e08a4b0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gog.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: gog-cdn-lumen.secure2.footprint.net
domain: gog-cdn.akamaized.net
domain: gog.qtlglb.com
domain_suffix: gog-services.com
domain_suffix: gog-statics.com
domain_suffix: gog.com
domain_suffix: gogalaxy.com
domain_suffix: insights-collector.gog.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
