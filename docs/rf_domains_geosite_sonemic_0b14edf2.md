# sonemic

Актуальный набор доменных правил «sonemic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sonemic`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sonemic_0b14edf2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sonemic_0b14edf2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sonemic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: glitchwave.com
domain_suffix: rateyourmusic.com
domain_suffix: rym.fm
domain_suffix: snmc.io
domain_suffix: sonematic.net
domain_suffix: sonemic.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
