# category-dev-cn

Актуальный набор доменных правил «category-dev-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-dev-cn`. Тип: **domains**.

Правил: **134**. Точные домены: 9; доменные зоны: 125; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_dev_cn_1b61b8e0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_dev_cn_1b61b8e0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-dev-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
