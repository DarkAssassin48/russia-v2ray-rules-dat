# brightcove

Актуальный набор доменных правил «brightcove» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `brightcove`. Тип: **domains**.

Правил: **14**. Точные домены: 3; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_brightcove_67ccde30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_brightcove_67ccde30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-brightcove.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: bcovlive-a.akamaihd.net
domain: bcsecure01-a.akamaihd.net
domain: brightcove.imgix.net
domain_suffix: bcove.video
domain_suffix: bcovlive.io
domain_suffix: bcvp0rtal.com
domain_suffix: boltdns.net
domain_suffix: brightcove.com
domain_suffix: brightcove.net
domain_suffix: brightcove.services
domain_suffix: brightcovecdn.com
domain_suffix: videojs.com
domain_suffix: zencdn.net
domain_suffix: zencoder.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
