# aws

Актуальный набор доменных правил «aws» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aws`. Тип: **domains**.

Правил: **80**. Точные домены: 0; доменные зоны: 77; фрагменты: 0; regex: 3; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aws_9c9d2200.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aws_9c9d2200.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aws.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
