# category-game-platforms-download@cn

Актуальный набор доменных правил «category-game-platforms-download@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-game-platforms-download@cn`. Тип: **domains**.

Правил: **24**. Точные домены: 24; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_game_platforms_download_cn_2e5107bc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_game_platforms_download_cn_2e5107bc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-game-platforms-download@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
