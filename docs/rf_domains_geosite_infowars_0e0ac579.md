# infowars

Актуальный набор доменных правил «infowars» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `infowars`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_infowars_0e0ac579.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_infowars_0e0ac579.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-infowars.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: banned.video
domain_suffix: infowars.com
domain_suffix: infowarsmedia.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
