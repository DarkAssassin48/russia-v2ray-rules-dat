# vivo

Актуальный набор доменных правил «vivo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vivo`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vivo_a6a7b7d8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vivo_a6a7b7d8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vivo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: blueos.com.cn
domain_suffix: budingscan.com
domain_suffix: iqoo.com
domain_suffix: vivo.cn
domain_suffix: vivo.com
domain_suffix: vivo.com.cn
domain_suffix: vivoglobal.com
domain_suffix: vvstc.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
