# chinanews

Актуальный набор доменных правил «chinanews» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinanews`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinanews_cd310117.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinanews_cd310117.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinanews.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chinanews.com
domain_suffix: chinanews.com.cn
domain_suffix: chinaqw.com
domain_suffix: cns.com.cn
domain_suffix: cnsimg.net
domain_suffix: ecns.cn
domain_suffix: inewsweek.cn
domain_suffix: jwview.com
domain_suffix: xinmeng.info
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
