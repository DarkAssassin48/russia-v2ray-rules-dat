# bi · IP-сети

Актуальный набор IP-сетей «bi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bi`. Тип: **ip**.

Правил: **131**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 131.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bi_c7e7583c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bi_c7e7583c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
