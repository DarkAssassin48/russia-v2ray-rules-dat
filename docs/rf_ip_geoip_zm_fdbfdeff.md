# zm · IP-сети

Актуальный набор IP-сетей «zm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zm`. Тип: **ip**.

Правил: **271**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 271.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_zm_fdbfdeff.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_zm_fdbfdeff.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-zm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
