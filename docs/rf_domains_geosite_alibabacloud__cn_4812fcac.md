# alibabacloud@!cn

Актуальный набор доменных правил «alibabacloud@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibabacloud@!cn`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibabacloud__cn_4812fcac.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibabacloud__cn_4812fcac.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibabacloud@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: alibabacloud.co.in
domain_suffix: alibabacloud.com
domain_suffix: alibabacloud.com.au
domain_suffix: alibabacloud.com.hk
domain_suffix: alibabacloud.com.my
domain_suffix: alibabacloud.com.sg
domain_suffix: alibabacloud.com.tw
domain_suffix: alicloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
