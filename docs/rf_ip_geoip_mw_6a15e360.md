# mw · IP-сети

Актуальный набор IP-сетей «mw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mw`. Тип: **ip**.

Правил: **220**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 220.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mw_6a15e360.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mw_6a15e360.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
