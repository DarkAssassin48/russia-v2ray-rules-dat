# dmm

Актуальный набор доменных правил «dmm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dmm`. Тип: **domains**.

Правил: **17**. Точные домены: 1; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dmm_e347fe5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dmm_e347fe5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dmm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
