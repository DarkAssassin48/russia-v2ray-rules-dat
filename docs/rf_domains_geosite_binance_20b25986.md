# binance

Актуальный набор доменных правил «binance» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `binance`. Тип: **domains**.

Правил: **45**. Точные домены: 2; доменные зоны: 43; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_binance_20b25986.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_binance_20b25986.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-binance.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
