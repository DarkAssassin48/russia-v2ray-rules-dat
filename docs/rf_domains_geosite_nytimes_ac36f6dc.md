# nytimes

Актуальный набор доменных правил «nytimes» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nytimes`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nytimes_ac36f6dc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nytimes_ac36f6dc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nytimes.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nyt.com
domain_suffix: nyt.net
domain_suffix: nytchina.com
domain_suffix: nytcn.me
domain_suffix: nytco.com
domain_suffix: nyti.ms
domain_suffix: nytimes.com
domain_suffix: nytstyle.com
domain_suffix: timestalks.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
