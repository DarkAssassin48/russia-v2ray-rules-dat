# category-entertainment-ru

Актуальный набор доменных правил «category-entertainment-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment-ru`. Тип: **domains**.

Правил: **35**. Точные домены: 2; доменные зоны: 33; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_ru_54eae9ba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_ru_54eae9ba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
