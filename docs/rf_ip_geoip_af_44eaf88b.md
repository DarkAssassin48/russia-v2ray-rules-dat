# af · IP-сети

Актуальный набор IP-сетей «af» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `af`. Тип: **ip**.

Правил: **720**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 720.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_af_44eaf88b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_af_44eaf88b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-af.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
