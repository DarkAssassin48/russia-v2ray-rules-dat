# unity@ads

Актуальный набор доменных правил «unity@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `unity@ads`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_unity_ads_41505672.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_unity_ads_41505672.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-unity@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: analytics.cloud.unity3d.com
domain_suffix: cdp.cloud.unity3d.com
domain_suffix: config.uca.cloud.unity3d.com
domain_suffix: iads.unity3d.com
domain_suffix: perf-events.cloud.unity3d.com
domain_suffix: perf.cloud.unity3d.com
domain_suffix: prd-lender.cdp.internal.unity3d.com
domain_suffix: unityads.unity3d.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
