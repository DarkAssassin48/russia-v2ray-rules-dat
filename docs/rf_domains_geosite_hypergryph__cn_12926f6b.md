# hypergryph@!cn

Актуальный набор доменных правил «hypergryph@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hypergryph@!cn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hypergryph__cn_12926f6b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hypergryph__cn_12926f6b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hypergryph@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gryphline.cn
domain_suffix: gryphline.com
domain_suffix: gryphline.com.cn
domain_suffix: gryphline.net
domain_suffix: hg-cdn.com
domain_suffix: skport.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
