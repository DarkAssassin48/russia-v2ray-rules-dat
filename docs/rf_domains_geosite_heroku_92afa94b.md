# heroku

Актуальный набор доменных правил «heroku» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `heroku`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_heroku_92afa94b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_heroku_92afa94b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-heroku.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: codei.sh
domain_suffix: codeish.co
domain_suffix: codeish.io
domain_suffix: heroku-app.com
domain_suffix: heroku-charge.com
domain_suffix: heroku.co
domain_suffix: heroku.com
domain_suffix: heroku.me
domain_suffix: herokuapp.com
domain_suffix: herokucdn.com
domain_suffix: herokucharge.com
domain_suffix: herokussl.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
