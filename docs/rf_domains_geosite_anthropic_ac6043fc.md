# Anthropic / Claude

Актуальный набор доменных правил «Anthropic / Claude» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `anthropic`. Тип: **domains**.

Правил: **19**. Точные домены: 1; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_anthropic_ac6043fc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_anthropic_ac6043fc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-anthropic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
