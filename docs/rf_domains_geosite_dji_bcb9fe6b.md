# dji

Актуальный набор доменных правил «dji» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dji`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dji_bcb9fe6b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dji_bcb9fe6b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dji.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dji.com
domain_suffix: dji.ink
domain_suffix: dji.net
domain_suffix: djicdn.com
domain_suffix: djigate.com
domain_suffix: djiits.com
domain_suffix: djiops.com
domain_suffix: djiservice.org
domain_suffix: robomaster.com
domain_suffix: skypixel.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
