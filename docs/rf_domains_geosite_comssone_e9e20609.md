# comssone

Актуальный набор доменных правил «comssone» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `comssone`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_comssone_e9e20609.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_comssone_e9e20609.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-comssone.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: comss.club
domain_suffix: comss.info
domain_suffix: comss.me
domain_suffix: comss.net
domain_suffix: comss.news
domain_suffix: comss.one
domain_suffix: comss.online
domain_suffix: comss.org
domain_suffix: comss.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
