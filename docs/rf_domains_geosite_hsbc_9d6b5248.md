# hsbc

Актуальный набор доменных правил «hsbc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hsbc`. Тип: **domains**.

Правил: **48**. Точные домены: 0; доменные зоны: 48; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hsbc_9d6b5248.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hsbc_9d6b5248.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hsbc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
