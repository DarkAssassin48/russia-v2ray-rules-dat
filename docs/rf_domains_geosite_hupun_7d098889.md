# hupun

Актуальный набор доменных правил «hupun» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hupun`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hupun_7d098889.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hupun_7d098889.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hupun.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hupun.com
domain_suffix: hupun.com.cn
domain_suffix: kata.com.cn
domain_suffix: newniu.com
domain_suffix: wanliniu.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
