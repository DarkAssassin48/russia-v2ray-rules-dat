# jwplayer

Актуальный набор доменных правил «jwplayer» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jwplayer`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_jwplayer_2cca7aa0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_jwplayer_2cca7aa0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-jwplayer.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jwpcdn.com
domain_suffix: jwplatform.com
domain_suffix: jwplayer.com
domain_suffix: jwpltx.com
domain_suffix: jwpsrv.com
domain_suffix: longtailvideo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
