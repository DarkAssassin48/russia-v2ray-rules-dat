# verisign

Актуальный набор доменных правил «verisign» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `verisign`. Тип: **domains**.

Правил: **33**. Точные домены: 0; доменные зоны: 33; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_verisign_2cb390b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_verisign_2cb390b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-verisign.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
