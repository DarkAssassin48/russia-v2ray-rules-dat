# avito@telemetry

Актуальный набор доменных правил «avito@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `avito@telemetry`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_avito_telemetry_2f7e8147.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_avito_telemetry_2f7e8147.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-avito@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: stats.avito.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
