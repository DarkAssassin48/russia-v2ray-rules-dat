# ozon

Актуальный набор доменных правил «ozon» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ozon`. Тип: **domains**.

Правил: **63**. Точные домены: 18; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ozon_fb74b799.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ozon_fb74b799.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ozon.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
