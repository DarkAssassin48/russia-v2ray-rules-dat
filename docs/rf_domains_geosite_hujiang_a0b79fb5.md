# hujiang

Актуальный набор доменных правил «hujiang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hujiang`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hujiang_a0b79fb5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hujiang_a0b79fb5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hujiang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cctalk.com
domain_suffix: hjapi.com
domain_suffix: hjfile.cn
domain_suffix: hujiang.com
domain_suffix: yeshj.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
