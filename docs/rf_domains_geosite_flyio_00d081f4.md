# flyio

Актуальный набор доменных правил «flyio» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `flyio`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_flyio_00d081f4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_flyio_00d081f4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-flyio.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fly.dev
domain_suffix: fly.io
domain_suffix: flyio.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
