# unionpay

Актуальный набор доменных правил «unionpay» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `unionpay`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_unionpay_a51622df.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_unionpay_a51622df.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-unionpay.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 95516.com
domain_suffix: 95516.net
domain_suffix: chinapay.com
domain_suffix: chinaums.com
domain_suffix: chinaunionpay.com
domain_suffix: chinaunionpay.com.cn
domain_suffix: chinaunionpay.net
domain_suffix: cup.com.cn
domain_suffix: cup62.cn
domain_suffix: unionpay.com
domain_suffix: unionpay.net
domain_suffix: unionpayintl.cn
domain_suffix: unionpayintl.com
domain_suffix: unionpaysecure.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
