# dm · IP-сети

Актуальный набор IP-сетей «dm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dm`. Тип: **ip**.

Правил: **164**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 164.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_dm_c7724254.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_dm_c7724254.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-dm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
