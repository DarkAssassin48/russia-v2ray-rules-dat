# ikea@cn

Актуальный набор доменных правил «ikea@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ikea@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ikea_cn_5d0b8421.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ikea_cn_5d0b8421.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ikea@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ikea.cn
domain_suffix: ingka-dt.cn
domain_suffix: ingka-internal.cn
domain_suffix: ingka-system.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
