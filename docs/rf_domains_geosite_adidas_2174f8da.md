# adidas

Актуальный набор доменных правил «adidas» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `adidas`. Тип: **domains**.

Правил: **90**. Точные домены: 0; доменные зоны: 90; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_adidas_2174f8da.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_adidas_2174f8da.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-adidas.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
