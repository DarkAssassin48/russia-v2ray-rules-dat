# amap

Актуальный набор доменных правил «amap» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amap`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amap_7c0097ea.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amap_7c0097ea.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amap.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
