# wink

Актуальный набор доменных правил «wink» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wink`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wink_bef18d61.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wink_bef18d61.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wink.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: more.tv
domain_suffix: restream-media.net
domain_suffix: restream.ru
domain_suffix: wink.am
domain_suffix: wink.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
