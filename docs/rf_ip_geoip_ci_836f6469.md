# ci · IP-сети

Актуальный набор IP-сетей «ci» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ci`. Тип: **ip**.

Правил: **469**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 469.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ci_836f6469.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ci_836f6469.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ci.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
