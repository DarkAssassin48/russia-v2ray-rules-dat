# starworld

Актуальный набор доменных правил «starworld» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `starworld`. Тип: **domains**.

Правил: **25**. Точные домены: 0; доменные зоны: 25; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_starworld_e0b4ffdd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_starworld_e0b4ffdd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-starworld.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
