# metabrainz

Актуальный набор доменных правил «metabrainz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `metabrainz`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_metabrainz_d26e1bfc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_metabrainz_d26e1bfc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-metabrainz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: acousticbrainz.org
domain_suffix: bookbrainz.org
domain_suffix: coverartarchive.org
domain_suffix: critiquebrainz.org
domain_suffix: listenbrainz.org
domain_suffix: messybrainz.org
domain_suffix: metabrainz.org
domain_suffix: musicbrainz.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
