# 2ch

Актуальный набор доменных правил «2ch» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `2ch`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_2ch_1a9265d0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_2ch_1a9265d0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-2ch.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 2ch.hk
domain_suffix: 2ch.life
domain_suffix: 2ch.org
domain_suffix: 2ch.su
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
