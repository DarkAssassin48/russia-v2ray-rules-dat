# pingsx

Актуальный набор доменных правил «pingsx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pingsx`. Тип: **domains**.

Правил: **2**. Точные домены: 1; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_pingsx_5518a811.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_pingsx_5518a811.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-pingsx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: public-us-pingsx.api.clonoth.com
domain_suffix: ping.sx
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
