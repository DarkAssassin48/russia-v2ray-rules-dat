# github-copilot@telemetry

Актуальный набор доменных правил «github-copilot@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `github-copilot@telemetry`. Тип: **domains**.

Правил: **2**. Точные домены: 2; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_github_copilot_telemetry_e46bd61f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_github_copilot_telemetry_e46bd61f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-github-copilot@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: copilot-telemetry-service.githubusercontent.com
domain: copilot-telemetry.githubusercontent.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
