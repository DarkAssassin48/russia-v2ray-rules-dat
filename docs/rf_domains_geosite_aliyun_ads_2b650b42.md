# aliyun@ads

Актуальный набор доменных правил «aliyun@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aliyun@ads`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_aliyun_ads_2b650b42.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_aliyun_ads_2b650b42.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-aliyun@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: acjs.aliyun.com
domain_suffix: adash-emas.cn-hangzhou.aliyuncs.com
domain_suffix: adash.man.aliyuncs.com
domain_suffix: alimama.alicdn.com
domain_suffix: atanx.alicdn.com
domain_suffix: atanx2.alicdn.com
domain_suffix: baichuan-sdk.alicdn.com
domain_suffix: nbsdk-baichuan.alicdn.com
domain_suffix: tce.alicdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
