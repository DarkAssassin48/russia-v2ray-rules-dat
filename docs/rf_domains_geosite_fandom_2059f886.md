# fandom

Актуальный набор доменных правил «fandom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fandom`. Тип: **domains**.

Правил: **12**. Точные домены: 1; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_fandom_2059f886.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_fandom_2059f886.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-fandom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: fandom.zendesk.com
domain_suffix: cortexrpg.com
domain_suffix: cursecdn.com
domain_suffix: dndbeyond.com
domain_suffix: fanatical.com
domain_suffix: fandom.com
domain_suffix: futhead.com
domain_suffix: gamepedia.com
domain_suffix: muthead.com
domain_suffix: wikia.com
domain_suffix: wikia.nocookie.net
domain_suffix: wikia.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
