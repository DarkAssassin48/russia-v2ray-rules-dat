# hr · IP-сети

Актуальный набор IP-сетей «hr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hr`. Тип: **ip**.

Правил: **1163**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1163.
