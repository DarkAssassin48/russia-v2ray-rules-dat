# hanyi

Актуальный набор доменных правил «hanyi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hanyi`. Тип: **domains**.

Правил: **7**. Точные домены: 2; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hanyi_c9c3dbfd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hanyi_c9c3dbfd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hanyi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: hellofontpreview.oss-cn-beijing.aliyuncs.com
domain: hellowebfonts.oss-cn-beijing.aliyuncs.com
domain_suffix: fontstar.com.cn
domain_suffix: hanyi.com
domain_suffix: hanyi.com.cn
domain_suffix: hellofont.cn
domain_suffix: hellowebfont.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
