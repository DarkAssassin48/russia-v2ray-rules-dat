# gr · IP-сети

Актуальный набор IP-сетей «gr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gr`. Тип: **ip**.

Правил: **2604**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2604.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gr_39fc849c.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gr_39fc849c.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
