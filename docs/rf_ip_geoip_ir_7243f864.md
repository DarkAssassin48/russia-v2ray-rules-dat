# ir · IP-сети

Актуальный набор IP-сетей «ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ir`. Тип: **ip**.

Правил: **2769**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2769.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ir_7243f864.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ir_7243f864.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
