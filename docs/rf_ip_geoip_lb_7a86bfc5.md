# lb · IP-сети

Актуальный набор IP-сетей «lb» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lb`. Тип: **ip**.

Правил: **628**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 628.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lb_7a86bfc5.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lb_7a86bfc5.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lb.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
