# elsevier

Актуальный набор доменных правил «elsevier» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `elsevier`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_elsevier_561e8d7f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_elsevier_561e8d7f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-elsevier.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
