# cw · IP-сети

Актуальный набор IP-сетей «cw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cw`. Тип: **ip**.

Правил: **206**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 206.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cw_1003cb3f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cw_1003cb3f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
