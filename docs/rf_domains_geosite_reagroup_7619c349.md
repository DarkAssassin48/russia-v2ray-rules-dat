# reagroup

Актуальный набор доменных правил «reagroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `reagroup`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_reagroup_7619c349.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_reagroup_7619c349.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-reagroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
