# sk · IP-сети

Актуальный набор IP-сетей «sk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sk`. Тип: **ip**.

Правил: **1913**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1913.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_sk_4038a739.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_sk_4038a739.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-sk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
