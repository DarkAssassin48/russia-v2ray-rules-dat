# amplitude

Актуальный набор доменных правил «amplitude» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amplitude`. Тип: **domains**.

Правил: **22**. Точные домены: 0; доменные зоны: 22; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amplitude_19f1f6ae.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amplitude_19f1f6ae.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amplitude.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
