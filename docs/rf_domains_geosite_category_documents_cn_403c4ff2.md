# category-documents-cn

Актуальный набор доменных правил «category-documents-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-documents-cn`. Тип: **domains**.

Правил: **23**. Точные домены: 0; доменные зоны: 23; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_documents_cn_403c4ff2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_documents_cn_403c4ff2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-documents-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
