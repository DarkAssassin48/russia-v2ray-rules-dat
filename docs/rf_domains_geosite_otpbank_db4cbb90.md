# otpbank

Актуальный набор доменных правил «otpbank» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `otpbank`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_otpbank_db4cbb90.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_otpbank_db4cbb90.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-otpbank.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
