# category-dev-cn@ads

Актуальный набор доменных правил «category-dev-cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-dev-cn@ads`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_dev_cn_ads_d350423d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_dev_cn_ads_d350423d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-dev-cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ads.unitychina.cn
domain_suffix: badjs.weixinbridge.com
domain_suffix: splash-ads.cdn.unity.cn
domain_suffix: splash-ads.unitychina.cn
domain_suffix: unityads.unity.cn
domain_suffix: unityads.unitychina.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
