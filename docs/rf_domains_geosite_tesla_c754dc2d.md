# tesla

Актуальный набор доменных правил «tesla» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tesla`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tesla_c754dc2d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tesla_c754dc2d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tesla.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: solarcity.com
domain_suffix: tesla.cn
domain_suffix: tesla.com
domain_suffix: tesla.com.cn
domain_suffix: tesla.services
domain_suffix: teslaenergy.services
domain_suffix: teslamotors.cn
domain_suffix: teslamotors.com
domain_suffix: teslamotors.com.cn
domain_suffix: teslazta.net
domain_suffix: ts.la
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
