# mm · IP-сети

Актуальный набор IP-сетей «mm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mm`. Тип: **ip**.

Правил: **778**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 778.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mm_922c6494.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mm_922c6494.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
