# category-logistics-cn

Актуальный набор доменных правил «category-logistics-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-logistics-cn`. Тип: **domains**.

Правил: **158**. Точные домены: 0; доменные зоны: 158; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_logistics_cn_62b7426b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_logistics_cn_62b7426b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-logistics-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
