# 5ch

Актуальный набор доменных правил «5ch» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `5ch`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_5ch_b8dcb80e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_5ch_b8dcb80e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-5ch.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 2ch.net
domain_suffix: 5ch.io
domain_suffix: 5ch.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
