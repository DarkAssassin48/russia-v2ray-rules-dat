# sakurafrp

Актуальный набор доменных правил «sakurafrp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sakurafrp`. Тип: **domains**.

Правил: **58**. Точные домены: 0; доменные зоны: 58; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sakurafrp_519e1aca.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sakurafrp_519e1aca.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sakurafrp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
