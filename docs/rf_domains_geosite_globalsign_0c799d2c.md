# globalsign

Актуальный набор доменных правил «globalsign» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `globalsign`. Тип: **domains**.

Правил: **21**. Точные домены: 2; доменные зоны: 19; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_globalsign_0c799d2c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_globalsign_0c799d2c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-globalsign.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
