# qianxin

Актуальный набор доменных правил «qianxin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qianxin`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qianxin_ec1bf2c5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qianxin_ec1bf2c5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qianxin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 95015.com
domain_suffix: ceati.org.cn
domain_suffix: datacon.org.cn
domain_suffix: qianxin.com
domain_suffix: qianxincdn.com
domain_suffix: seclab.online
domain_suffix: tianshucup.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
