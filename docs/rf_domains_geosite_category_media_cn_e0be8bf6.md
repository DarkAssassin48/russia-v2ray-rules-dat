# category-media-cn

Актуальный набор доменных правил «category-media-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media-cn`. Тип: **domains**.

Правил: **459**. Точные домены: 1; доменные зоны: 458; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_cn_e0be8bf6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_cn_e0be8bf6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
