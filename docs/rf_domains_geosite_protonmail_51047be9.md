# protonmail

Актуальный набор доменных правил «protonmail» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `protonmail`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_protonmail_51047be9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_protonmail_51047be9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-protonmail.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: pm.me
domain_suffix: proton.me
domain_suffix: protonmail.ch
domain_suffix: protonmail.com
domain_suffix: protonstatus.com
domain_suffix: protontech.ch
domain_suffix: protonvpn.ch
domain_suffix: protonvpn.com
domain_suffix: protonweb.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
