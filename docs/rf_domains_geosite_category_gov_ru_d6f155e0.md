# category-gov-ru

Актуальный набор доменных правил «category-gov-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-gov-ru`. Тип: **domains**.

Правил: **145**. Точные домены: 0; доменные зоны: 145; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_gov_ru_d6f155e0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_gov_ru_d6f155e0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-gov-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
