# qualcomm@cn

Актуальный набор доменных правил «qualcomm@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qualcomm@cn`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qualcomm_cn_3a9b576b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qualcomm_cn_3a9b576b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qualcomm@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gpsonextra.net
domain_suffix: izatcloud.net
domain_suffix: qceventscenter.com.cn
domain_suffix: qualcomm.cn
domain_suffix: qualcomm.cn.cdn.cloudflare.net
domain_suffix: xtracloud.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
