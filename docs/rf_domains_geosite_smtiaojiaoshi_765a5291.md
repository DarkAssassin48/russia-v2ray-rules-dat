# smtiaojiaoshi

Актуальный набор доменных правил «smtiaojiaoshi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `smtiaojiaoshi`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_smtiaojiaoshi_765a5291.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_smtiaojiaoshi_765a5291.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-smtiaojiaoshi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jhxl.org
domain_suffix: xn--sgt856gbjl.cc
```

Полный перечень без сокращений доступен по ссылкам выше.
