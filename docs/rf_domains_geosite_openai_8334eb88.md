# OpenAI / ChatGPT

Актуальный набор доменных правил «OpenAI / ChatGPT» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `openai`. Тип: **domains**.

Правил: **25**. Точные домены: 10; доменные зоны: 14; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_openai_8334eb88.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_openai_8334eb88.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-openai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
