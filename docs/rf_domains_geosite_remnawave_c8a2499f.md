# remnawave

Актуальный набор доменных правил «remnawave» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `remnawave`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_remnawave_c8a2499f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_remnawave_c8a2499f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-remnawave.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: docs.rw
domain_suffix: log.rw
domain_suffix: remna.st
domain_suffix: try.rw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
