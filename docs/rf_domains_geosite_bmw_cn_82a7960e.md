# bmw@cn

Актуальный набор доменных правил «bmw@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bmw@cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bmw_cn_82a7960e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bmw_cn_82a7960e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bmw@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: alphabet.com.cn
domain_suffix: alphabet.net.cn
domain_suffix: bmw.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
