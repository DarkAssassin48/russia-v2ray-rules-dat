# aq · IP-сети

Актуальный набор IP-сетей «aq» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `aq`. Тип: **ip**.

Правил: **799**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 799.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_aq_6804a9aa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_aq_6804a9aa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-aq.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
