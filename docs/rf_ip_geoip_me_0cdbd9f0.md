# me · IP-сети

Актуальный набор IP-сетей «me» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `me`. Тип: **ip**.

Правил: **243**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 243.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_me_0cdbd9f0.txt)
