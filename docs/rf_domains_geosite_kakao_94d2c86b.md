# kakao

Актуальный набор доменных правил «kakao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kakao`. Тип: **domains**.

Правил: **57**. Точные домены: 0; доменные зоны: 57; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kakao_94d2c86b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kakao_94d2c86b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kakao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
