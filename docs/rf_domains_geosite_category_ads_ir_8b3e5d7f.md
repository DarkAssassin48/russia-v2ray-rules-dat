# category-ads-ir

Актуальный набор доменных правил «category-ads-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ads-ir`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ads_ir_8b3e5d7f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ads_ir_8b3e5d7f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ads-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adivery.com
domain_suffix: adivery.ir
domain_suffix: kaprila.com
domain_suffix: najva.com
domain_suffix: sabavision.com
domain_suffix: tapsell.ir
domain_suffix: yektanet.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
