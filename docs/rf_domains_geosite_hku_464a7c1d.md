# hku

Актуальный набор доменных правил «hku» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hku`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hku_464a7c1d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hku_464a7c1d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hku.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hku.edu.hk
domain_suffix: hku.hk
domain_suffix: xn--pssu7cv61af44b.hk
domain_suffix: xn--pssu7cv61af44b.xn--j6w193g
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
