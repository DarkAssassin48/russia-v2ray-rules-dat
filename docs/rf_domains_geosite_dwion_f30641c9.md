# dwion

Актуальный набор доменных правил «dwion» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dwion`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dwion_f30641c9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dwion_f30641c9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dwion.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: acadn.cn
domain_suffix: acadn.com
domain_suffix: bbbcdns.com
domain_suffix: dlgslb.cn
domain_suffix: dlgslb.net
domain_suffix: dwion.com
domain_suffix: fastcdn.com
domain_suffix: fastcdn.com.cn
domain_suffix: flxdns.cn
domain_suffix: flxdns.com
domain_suffix: globalcdn.cn
domain_suffix: mcadn.cn
domain_suffix: tlgslb.cn
domain_suffix: tlgslb.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
