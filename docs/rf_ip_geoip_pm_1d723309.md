# pm · IP-сети

Актуальный набор IP-сетей «pm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pm`. Тип: **ip**.

Правил: **122**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 122.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pm_1d723309.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pm_1d723309.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
