# ch · IP-сети

Актуальный набор IP-сетей «ch» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ch`. Тип: **ip**.

Правил: **11761**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 11761.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ch_f6d02984.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ch_f6d02984.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ch.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
