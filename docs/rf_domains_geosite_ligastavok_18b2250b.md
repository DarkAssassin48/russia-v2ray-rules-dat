# ligastavok

Актуальный набор доменных правил «ligastavok» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ligastavok`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ligastavok_18b2250b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ligastavok_18b2250b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ligastavok.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ligadobra.ru
domain_suffix: ligastavok-csr.ru
domain_suffix: ligastavok.ru
domain_suffix: sozvezdie-dobra.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
