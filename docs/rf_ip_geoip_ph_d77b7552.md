# ph · IP-сети

Актуальный набор IP-сетей «ph» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ph`. Тип: **ip**.

Правил: **3280**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 3280.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ph_d77b7552.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ph_d77b7552.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ph.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
