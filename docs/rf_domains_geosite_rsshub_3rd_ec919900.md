# rsshub-3rd

Актуальный набор доменных правил «rsshub-3rd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rsshub-3rd`. Тип: **domains**.

Правил: **19**. Точные домены: 19; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rsshub_3rd_ec919900.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rsshub_3rd_ec919900.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rsshub-3rd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
