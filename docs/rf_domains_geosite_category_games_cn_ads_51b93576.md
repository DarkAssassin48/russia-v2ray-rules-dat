# category-games-cn@ads

Актуальный набор доменных правил «category-games-cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games-cn@ads`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games_cn_ads_51b93576.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games_cn_ads_51b93576.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games-cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: log-upload.mihoyo.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
