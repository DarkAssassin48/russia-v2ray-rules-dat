# category-ip-geo-detect@cn

Актуальный набор доменных правил «category-ip-geo-detect@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ip-geo-detect@cn`. Тип: **domains**.

Правил: **54**. Точные домены: 9; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ip_geo_detect_cn_0e73c6b5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ip_geo_detect_cn_0e73c6b5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ip-geo-detect@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
