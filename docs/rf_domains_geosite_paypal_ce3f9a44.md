# paypal

Актуальный набор доменных правил «paypal» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `paypal`. Тип: **domains**.

Правил: **245**. Точные домены: 1; доменные зоны: 244; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_paypal_ce3f9a44.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_paypal_ce3f9a44.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-paypal.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
