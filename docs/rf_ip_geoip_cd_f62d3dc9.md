# cd · IP-сети

Актуальный набор IP-сетей «cd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cd`. Тип: **ip**.

Правил: **383**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 383.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cd_f62d3dc9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cd_f62d3dc9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
