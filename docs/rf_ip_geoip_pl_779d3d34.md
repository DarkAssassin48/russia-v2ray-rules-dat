# pl · IP-сети

Актуальный набор IP-сетей «pl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pl`. Тип: **ip**.

Правил: **11776**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 11776.
