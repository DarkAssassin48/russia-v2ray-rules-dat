# anker

Актуальный набор доменных правил «anker» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `anker`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_anker_c2144f6d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_anker_c2144f6d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-anker.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: anker-in.com
domain_suffix: anker.com
domain_suffix: anker.com.cn
domain_suffix: ankersolix.com
domain_suffix: ankerwork.cn
domain_suffix: eufy.com
domain_suffix: eufycn.com
domain_suffix: eufylife.com
domain_suffix: eufymake.com
domain_suffix: eufymake.com.cn
domain_suffix: soundcore.com
domain_suffix: soundcore.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
