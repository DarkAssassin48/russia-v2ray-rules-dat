# udn

Актуальный набор доменных правил «udn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `udn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_udn_d5aa2e00.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_udn_d5aa2e00.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-udn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: udn.com
domain_suffix: udn.com.tw
domain_suffix: udndata.com
domain_suffix: udnfunlife.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
