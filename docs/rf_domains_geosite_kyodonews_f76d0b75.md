# kyodonews

Актуальный набор доменных правил «kyodonews» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kyodonews`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kyodonews_f76d0b75.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kyodonews_f76d0b75.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kyodonews.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 47gyosei.jp
domain_suffix: 47news.jp
domain_suffix: kyodo-d.info
domain_suffix: kyodo-d.jp
domain_suffix: kyodoimages.jp
domain_suffix: kyodonews.jp
domain_suffix: kyodonews.net
domain_suffix: newsmart.jp
domain_suffix: nna.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
