# github1s

Актуальный набор доменных правил «github1s» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `github1s`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_github1s_fdc8243c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_github1s_fdc8243c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-github1s.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: github1s.com
domain_suffix: sourcegraph.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
