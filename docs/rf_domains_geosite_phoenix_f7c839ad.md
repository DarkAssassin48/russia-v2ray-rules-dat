# phoenix

Актуальный набор доменных правил «phoenix» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `phoenix`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_phoenix_f7c839ad.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_phoenix_f7c839ad.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-phoenix.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fengcx.com
domain_suffix: fengedu.com
domain_suffix: ifeng.com
domain_suffix: ifengimg.com
domain_suffix: ifengweekly.com
domain_suffix: phoenixcenter.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
