# miniso

Актуальный набор доменных правил «miniso» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `miniso`. Тип: **domains**.

Правил: **36**. Точные домены: 0; доменные зоны: 36; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_miniso_0d27b719.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_miniso_0d27b719.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-miniso.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
