# colorfulclouds

Актуальный набор доменных правил «colorfulclouds» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `colorfulclouds`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_colorfulclouds_38beca01.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_colorfulclouds_38beca01.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-colorfulclouds.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: caiyunai.com
domain_suffix: caiyunapp.com
domain_suffix: caiyuncdn.com
domain_suffix: colorfulclouds.com
domain_suffix: colorfulclouds.net
domain_suffix: xiaomengai.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
