# nike

Актуальный набор доменных правил «nike» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nike`. Тип: **domains**.

Правил: **196**. Точные домены: 0; доменные зоны: 196; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nike_7367dcf1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nike_7367dcf1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nike.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
