# gemfury

Актуальный набор доменных правил «gemfury» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gemfury`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gemfury_ea5f9835.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gemfury_ea5f9835.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gemfury.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fury.blog
domain_suffix: fury.co
domain_suffix: fury.dev
domain_suffix: fury.help
domain_suffix: fury.io
domain_suffix: gemfury.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
