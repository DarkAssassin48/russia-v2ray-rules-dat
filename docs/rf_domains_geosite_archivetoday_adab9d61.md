# archivetoday

Актуальный набор доменных правил «archivetoday» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `archivetoday`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_archivetoday_adab9d61.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_archivetoday_adab9d61.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-archivetoday.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: archive.fo
domain_suffix: archive.is
domain_suffix: archive.li
domain_suffix: archive.md
domain_suffix: archive.ph
domain_suffix: archive.today
domain_suffix: archive.vn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
