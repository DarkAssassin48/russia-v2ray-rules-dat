# category-mooc-cn

Актуальный набор доменных правил «category-mooc-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-mooc-cn`. Тип: **domains**.

Правил: **11**. Точные домены: 3; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_mooc_cn_b86bdb57.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_mooc_cn_b86bdb57.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-mooc-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: moocs.unipus.cn
domain: opencourse.pku.edu.cn
domain: study.163.com
domain_suffix: chinesemooc.org
domain_suffix: cnmooc.org
domain_suffix: icourse163.org
domain_suffix: icourses.cn
domain_suffix: icve.com.cn
domain_suffix: mooc.cn
domain_suffix: openlearning.com
domain_suffix: pmphmooc.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
