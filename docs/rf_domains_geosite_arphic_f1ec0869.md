# arphic

Актуальный набор доменных правил «arphic» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `arphic`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_arphic_f1ec0869.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_arphic_f1ec0869.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-arphic.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: arphic.com
domain_suffix: arphic.com.cn
domain_suffix: arphic.com.tw
domain_suffix: ifontcloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
