# disqus

Актуальный набор доменных правил «disqus» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `disqus`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_disqus_083bf8a4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_disqus_083bf8a4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-disqus.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: disq.us
domain_suffix: disqus.com
domain_suffix: disquscdn.com
domain_suffix: disqusservice.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
