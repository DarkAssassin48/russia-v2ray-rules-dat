# xd

Актуальный набор доменных правил «xd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xd`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xd_9bc0da01.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xd_9bc0da01.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ro.com
domain_suffix: tapapks.com
domain_suffix: tapimg.com
domain_suffix: tapimg.net
domain_suffix: taptap.cn
domain_suffix: taptap.com
domain_suffix: taptap.io
domain_suffix: taptapdada.com
domain_suffix: xd.cn
domain_suffix: xd.com
domain_suffix: xdcdn.net
domain_suffix: xindong.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
