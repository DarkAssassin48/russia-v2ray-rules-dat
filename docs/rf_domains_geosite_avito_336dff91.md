# avito

Актуальный набор доменных правил «avito» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `avito`. Тип: **domains**.

Правил: **5**. Точные домены: 1; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_avito_336dff91.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_avito_336dff91.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-avito.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: stats.avito.ru
domain_suffix: avito.com
domain_suffix: avito.ru
domain_suffix: avito.st
domain_suffix: avito.tech
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
