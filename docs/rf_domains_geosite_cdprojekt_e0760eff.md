# cdprojekt

Актуальный набор доменных правил «cdprojekt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cdprojekt`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cdprojekt_e0760eff.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cdprojekt_e0760eff.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cdprojekt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cdpred.services
domain_suffix: cdprojekt.com
domain_suffix: cdprojekt.red
domain_suffix: cdprojektred.com
domain_suffix: cyberpunk.net
domain_suffix: playgwent.com
domain_suffix: thewitcher.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
