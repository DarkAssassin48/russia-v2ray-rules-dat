# huawei@ads

Актуальный набор доменных правил «huawei@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huawei@ads`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huawei_ads_5b86a78c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huawei_ads_5b86a78c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huawei@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dt.dbankcloud.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
