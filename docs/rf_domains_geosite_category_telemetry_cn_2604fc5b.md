# category-telemetry@cn

Актуальный набор доменных правил «category-telemetry@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-telemetry@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 3; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_telemetry_cn_2604fc5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_telemetry_cn_2604fc5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-telemetry@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: crashlyticsreports-pa.googleapis.com
domain: firebase-settings.crashlytics.com
domain: update.crashlytics.com
domain_suffix: cloudflareinsights-cn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
