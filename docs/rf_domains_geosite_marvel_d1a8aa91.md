# marvel

Актуальный набор доменных правил «marvel» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `marvel`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_marvel_d1a8aa91.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_marvel_d1a8aa91.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-marvel.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
