# category-medicine-ru

Актуальный набор доменных правил «category-medicine-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-medicine-ru`. Тип: **domains**.

Правил: **45**. Точные домены: 0; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_medicine_ru_087c7f63.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_medicine_ru_087c7f63.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-medicine-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
