# category-media-ru-blocked

Актуальный набор доменных правил «category-media-ru-blocked» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media-ru-blocked`. Тип: **domains**.

Правил: **132**. Точные домены: 0; доменные зоны: 132; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_ru_blocked_56d9e305.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_ru_blocked_56d9e305.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media-ru-blocked.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
