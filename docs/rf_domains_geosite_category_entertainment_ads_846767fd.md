# category-entertainment@ads

Актуальный набор доменных правил «category-entertainment@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment@ads`. Тип: **domains**.

Правил: **9**. Точные домены: 4; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_ads_846767fd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_ads_846767fd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
