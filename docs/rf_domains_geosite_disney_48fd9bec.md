# disney

Актуальный набор доменных правил «disney» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `disney`. Тип: **domains**.

Правил: **225**. Точные домены: 6; доменные зоны: 218; фрагменты: 0; regex: 1; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_disney_48fd9bec.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_disney_48fd9bec.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-disney.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
