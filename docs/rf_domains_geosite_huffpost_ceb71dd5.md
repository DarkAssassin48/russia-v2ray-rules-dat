# huffpost

Актуальный набор доменных правил «huffpost» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huffpost`. Тип: **domains**.

Правил: **18**. Точные домены: 0; доменные зоны: 18; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huffpost_ceb71dd5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huffpost_ceb71dd5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huffpost.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
