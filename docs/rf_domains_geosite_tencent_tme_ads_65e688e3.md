# tencent-tme@ads

Актуальный набор доменных правил «tencent-tme@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent-tme@ads`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_tme_ads_65e688e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_tme_ads_65e688e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent-tme@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
