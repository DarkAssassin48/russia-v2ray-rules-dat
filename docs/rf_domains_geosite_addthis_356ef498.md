# addthis

Актуальный набор доменных правил «addthis» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `addthis`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_addthis_356ef498.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_addthis_356ef498.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-addthis.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: addthis.com
domain_suffix: addthiscdn.com
domain_suffix: addthisedge.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
