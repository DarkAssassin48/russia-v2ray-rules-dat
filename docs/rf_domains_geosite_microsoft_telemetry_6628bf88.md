# microsoft@telemetry

Актуальный набор доменных правил «microsoft@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft@telemetry`. Тип: **domains**.

Правил: **17**. Точные домены: 6; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_telemetry_6628bf88.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_telemetry_6628bf88.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
