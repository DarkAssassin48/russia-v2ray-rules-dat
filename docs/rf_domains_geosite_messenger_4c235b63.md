# messenger

Актуальный набор доменных правил «messenger» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `messenger`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_messenger_4c235b63.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_messenger_4c235b63.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-messenger.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fbmessenger.com
domain_suffix: m.me
domain_suffix: messenger.com
domain_suffix: nbabot.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
