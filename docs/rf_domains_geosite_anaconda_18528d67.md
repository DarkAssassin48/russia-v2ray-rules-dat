# anaconda

Актуальный набор доменных правил «anaconda» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `anaconda`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_anaconda_18528d67.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_anaconda_18528d67.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-anaconda.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: anaconda.cloud
domain_suffix: anaconda.com
domain_suffix: anaconda.org
domain_suffix: conda.io
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
