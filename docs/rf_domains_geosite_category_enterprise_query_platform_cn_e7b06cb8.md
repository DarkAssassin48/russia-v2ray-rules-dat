# category-enterprise-query-platform-cn

Актуальный набор доменных правил «category-enterprise-query-platform-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-enterprise-query-platform-cn`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.
