# kontur

Актуальный набор доменных правил «kontur» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kontur`. Тип: **domains**.

Правил: **7**. Точные домены: 2; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kontur_08fb22b9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kontur_08fb22b9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kontur.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: metrika.kontur.ru
domain: sentry.kontur.host
domain_suffix: kontur-inc.com
domain_suffix: kontur.host
domain_suffix: kontur.ru
domain_suffix: ktalk.host
domain_suffix: ktalk.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
