# zto-express

Актуальный набор доменных правил «zto-express» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zto-express`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zto_express_86901fdc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zto_express_86901fdc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zto-express.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

```text
domain_suffix: 95311.com
domain_suffix: izto.com
domain_suffix: izto.com.cn
domain_suffix: mlzt.com.cn
domain_suffix: tuxi.com

domain_suffix: ztogroup.com
domain_suffix: ztoyh.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
