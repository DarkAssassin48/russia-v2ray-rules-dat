# category-entertainment

Актуальный набор доменных правил «category-entertainment» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment`. Тип: **domains**.

Правил: **2166**. Точные домены: 283; доменные зоны: 1873; фрагменты: 0; regex: 10; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_05aae4da.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_05aae4da.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
