# umeng@telemetry

Актуальный набор доменных правил «umeng@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `umeng@telemetry`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_umeng_telemetry_f2dfb4f5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_umeng_telemetry_f2dfb4f5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-umeng@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: alog.umeng.com
domain_suffix: alog.umengcloud.com
domain_suffix: alogs.umeng.com
domain_suffix: alogus.umeng.com
domain_suffix: cnlogs.umeng.com
domain_suffix: cnlogs.umengcloud.com
domain_suffix: plbslog.umeng.com
domain_suffix: ulogs.umeng.com
domain_suffix: ulogs.umengcloud.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
