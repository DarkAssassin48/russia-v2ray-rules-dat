# gd · IP-сети

Актуальный набор IP-сетей «gd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gd`. Тип: **ip**.

Правил: **189**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 189.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gd_305ea8f9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gd_305ea8f9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
