# mindbox@ads

Актуальный набор доменных правил «mindbox@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mindbox@ads`. Тип: **domains**.

Правил: **10**. Точные домены: 7; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mindbox_ads_547d65ba.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mindbox_ads_547d65ba.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mindbox@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: api-js.mindbox.ru
domain: api-ru.mindbox.cloud
domain: api-staging.mindbox.ru
domain: api.mindbox.cloud
domain: api.mindbox.ru
domain: sentry.mindbox.ru
domain: sentry.popmechanic.ru
domain_suffix: e.mindbox.ru
domain_suffix: g.mindbox.ru
domain_suffix: s.mindbox.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
