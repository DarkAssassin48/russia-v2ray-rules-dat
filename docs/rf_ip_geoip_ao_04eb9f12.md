# ao · IP-сети

Актуальный набор IP-сетей «ao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ao`. Тип: **ip**.

Правил: **593**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 593.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ao_04eb9f12.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ao_04eb9f12.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
