# to · IP-сети

Актуальный набор IP-сетей «to» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `to`. Тип: **ip**.

Правил: **119**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 119.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_to_d626bb37.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_to_d626bb37.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-to.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
