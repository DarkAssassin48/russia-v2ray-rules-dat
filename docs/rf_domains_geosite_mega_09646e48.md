# mega

Актуальный набор доменных правил «mega» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mega`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mega_09646e48.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mega_09646e48.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mega.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mega.co.nz
domain_suffix: mega.io
domain_suffix: mega.nz
domain_suffix: megaad.nz
domain_suffix: megapay.nz
domain_suffix: megas4.com
domain_suffix: transfer.it
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
