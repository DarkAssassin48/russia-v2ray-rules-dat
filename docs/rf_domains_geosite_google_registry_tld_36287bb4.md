# google-registry-tld

Актуальный набор доменных правил «google-registry-tld» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `google-registry-tld`. Тип: **domains**.

Правил: **20**. Точные домены: 0; доменные зоны: 20; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_google_registry_tld_36287bb4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_google_registry_tld_36287bb4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-google-registry-tld.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
