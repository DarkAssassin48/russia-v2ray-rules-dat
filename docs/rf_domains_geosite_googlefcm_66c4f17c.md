# googlefcm

Актуальный набор доменных правил «googlefcm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `googlefcm`. Тип: **domains**.

Правил: **12**. Точные домены: 12; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_googlefcm_66c4f17c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_googlefcm_66c4f17c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-googlefcm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
