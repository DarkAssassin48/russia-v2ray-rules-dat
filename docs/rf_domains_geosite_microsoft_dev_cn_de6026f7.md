# microsoft-dev@cn

Актуальный набор доменных правил «microsoft-dev@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft-dev@cn`. Тип: **domains**.

Правил: **4**. Точные домены: 1; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_dev_cn_de6026f7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_dev_cn_de6026f7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft-dev@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: download.visualstudio.microsoft.com
domain_suffix: microsoftreactor.cn
domain_suffix: microsoftreactor.com.cn
domain_suffix: reactorms.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
