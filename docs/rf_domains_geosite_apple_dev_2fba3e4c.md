# apple-dev

Актуальный набор доменных правил «apple-dev» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-dev`. Тип: **domains**.

Правил: **47**. Точные домены: 15; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_dev_2fba3e4c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_dev_2fba3e4c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-dev.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
