# huawei-dev

Актуальный набор доменных правил «huawei-dev» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huawei-dev`. Тип: **domains**.

Правил: **23**. Точные домены: 0; доменные зоны: 23; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huawei_dev_033ab391.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huawei_dev_033ab391.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huawei-dev.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
