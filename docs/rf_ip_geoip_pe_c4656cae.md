# pe · IP-сети

Актуальный набор IP-сетей «pe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pe`. Тип: **ip**.

Правил: **1786**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1786.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pe_c4656cae.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pe_c4656cae.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
