# kn · IP-сети

Актуальный набор IP-сетей «kn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kn`. Тип: **ip**.

Правил: **166**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 166.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_kn_1e9562fa.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_kn_1e9562fa.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-kn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
