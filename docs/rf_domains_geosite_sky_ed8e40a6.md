# sky

Актуальный набор доменных правил «sky» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sky`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sky_ed8e40a6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sky_ed8e40a6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sky.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .sky
domain_suffix: cn-cdn1.skymansion.net
domain_suffix: sky.com
domain_suffix: skyassets.com
domain_suffix: skymansion.net
domain_suffix: skyoceanrescue.com

domain_suffix: skysports.com

domain_suffix: skysportsonline.com

```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
