# ps · IP-сети

Актуальный набор IP-сетей «ps» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ps`. Тип: **ip**.

Правил: **461**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 461.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ps_4a1fe0e9.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ps_4a1fe0e9.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ps.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
