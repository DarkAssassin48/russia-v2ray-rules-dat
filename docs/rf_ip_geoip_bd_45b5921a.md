# bd · IP-сети

Актуальный набор IP-сетей «bd» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bd`. Тип: **ip**.

Правил: **4855**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 4855.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bd_45b5921a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bd_45b5921a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bd.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
