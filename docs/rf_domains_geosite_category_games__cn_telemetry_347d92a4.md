# category-games-!cn@telemetry

Актуальный набор доменных правил «category-games-!cn@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-games-!cn@telemetry`. Тип: **domains**.

Правил: **3**. Точные домены: 1; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_games__cn_telemetry_347d92a4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_games__cn_telemetry_347d92a4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-games-!cn@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: sentry.ppy.sh
domain_suffix: insights-collector.gog.com
domain_suffix: log-upload-os.hoyoverse.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
