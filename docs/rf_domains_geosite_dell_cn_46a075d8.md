# dell@cn

Актуальный набор доменных правил «dell@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dell@cn`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dell_cn_46a075d8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dell_cn_46a075d8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dell@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dell-alw.com
domain_suffix: dell-brand.com
domain_suffix: dell.com.cn
domain_suffix: dellemc.com.cn
domain_suffix: dellmobile.cn
domain_suffix: delltechnologies.com.cn
domain_suffix: platform.dell.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
