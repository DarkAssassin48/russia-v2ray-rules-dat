# dk · IP-сети

Актуальный набор IP-сетей «dk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dk`. Тип: **ip**.

Правил: **5078**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5078.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_dk_95e84ab0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_dk_95e84ab0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-dk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
