# gaijin

Актуальный набор доменных правил «gaijin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gaijin`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gaijin_b6008812.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gaijin_b6008812.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gaijin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
