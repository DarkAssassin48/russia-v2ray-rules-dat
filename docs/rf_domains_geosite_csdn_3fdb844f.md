# csdn

Актуальный набор доменных правил «csdn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `csdn`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_csdn_3fdb844f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_csdn_3fdb844f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-csdn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: atomgit.com
domain_suffix: codechina.net

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
