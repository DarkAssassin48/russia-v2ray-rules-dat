# pornhub

Актуальный набор доменных правил «pornhub» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pornhub`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
