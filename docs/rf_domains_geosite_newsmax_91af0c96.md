# newsmax

Актуальный набор доменных правил «newsmax» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `newsmax`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_newsmax_91af0c96.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_newsmax_91af0c96.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-newsmax.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: andysparis.com
domain_suffix: newsmax.com
domain_suffix: newsmax.in
domain_suffix: newsmaxtv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
