# ficbook

Актуальный набор доменных правил «ficbook» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ficbook`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ficbook_22dc3cce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ficbook_22dc3cce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ficbook.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: fanfictionero.com
domain_suffix: fic.fan
domain_suffix: ficador.com
domain_suffix: ficbook.net
domain_suffix: ficmania.com
domain_suffix: teinon.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
