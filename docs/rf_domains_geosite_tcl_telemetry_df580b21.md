# tcl@telemetry

Актуальный набор доменных правил «tcl@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tcl@telemetry`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tcl_telemetry_df580b21.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tcl_telemetry_df580b21.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tcl@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: base.api.my7v.com
domain_suffix: dc-conf-o.api.leiniao.com
domain_suffix: dc-conf-t.api.leiniao.com
domain_suffix: dc-o.api.leiniao.com
domain_suffix: dc-t.api.leiniao.com
domain_suffix: dc-uo.api.leiniao.com
domain_suffix: dc-ut.api.leiniao.com
domain_suffix: qms-report-o.api.leiniao.com
domain_suffix: qms-report-t.api.leiniao.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
