# dz · IP-сети

Актуальный набор IP-сетей «dz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dz`. Тип: **ip**.

Правил: **407**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 407.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_dz_5fd94379.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_dz_5fd94379.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-dz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
