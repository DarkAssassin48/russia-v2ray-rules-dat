# alibaba@!cn

Актуальный набор доменных правил «alibaba@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `alibaba@!cn`. Тип: **domains**.

Правил: **38**. Точные домены: 0; доменные зоны: 38; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_alibaba__cn_a54a803a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_alibaba__cn_a54a803a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-alibaba@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
