# huobi

Актуальный набор доменных правил «huobi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `huobi`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_huobi_c0c87fe0.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_huobi_c0c87fe0.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-huobi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hbabit.com
domain_suffix: hbfile.net
domain_suffix: htx.com
domain_suffix: huobi.com
domain_suffix: huobi.me
domain_suffix: huobi.pro
domain_suffix: huobi.sc
domain_suffix: huobiasia.vip
domain_suffix: huobigroup.com
domain_suffix: huobitoken.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
