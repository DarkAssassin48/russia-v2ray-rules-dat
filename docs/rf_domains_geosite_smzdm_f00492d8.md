# smzdm

Актуальный набор доменных правил «smzdm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `smzdm`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_smzdm_f00492d8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_smzdm_f00492d8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-smzdm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: smzdm.com
domain_suffix: smzdmimg.com
domain_suffix: zdmimg.com
domain_suffix: zhidemai.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
