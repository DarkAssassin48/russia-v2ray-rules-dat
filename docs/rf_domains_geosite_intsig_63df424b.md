# intsig

Актуальный набор доменных правил «intsig» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `intsig`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_intsig_63df424b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_intsig_63df424b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-intsig.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: camcard.com
domain_suffix: camscanner.com
domain_suffix: intsig.com
domain_suffix: intsig.net
domain_suffix: qixin.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
