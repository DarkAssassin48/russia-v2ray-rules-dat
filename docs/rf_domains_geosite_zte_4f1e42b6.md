# zte

Актуальный набор доменных правил «zte» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zte`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zte_4f1e42b6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zte_4f1e42b6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zte.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: nubia.cn
domain_suffix: nubia.com
domain_suffix: redmagic.com
domain_suffix: zte.com.cn
domain_suffix: ztedevices.com
domain_suffix: ztemall.com
domain_suffix: ztems.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
