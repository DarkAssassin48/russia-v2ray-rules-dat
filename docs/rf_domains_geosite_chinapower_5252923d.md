# chinapower

Актуальный набор доменных правил «chinapower» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chinapower`. Тип: **domains**.

Правил: **1**. Точные домены: 1; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chinapower_5252923d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chinapower_5252923d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chinapower.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: chinapower.csis.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
