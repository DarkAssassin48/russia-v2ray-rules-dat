# wildberries

Актуальный набор доменных правил «wildberries» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wildberries`. Тип: **domains**.

Правил: **114**. Точные домены: 15; доменные зоны: 99; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wildberries_55659263.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wildberries_55659263.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wildberries.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
