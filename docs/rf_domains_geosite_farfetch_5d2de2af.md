# farfetch

Актуальный набор доменных правил «farfetch» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `farfetch`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_farfetch_5d2de2af.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_farfetch_5d2de2af.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-farfetch.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: farfetch-apps.com
domain_suffix: farfetch-contents.com
domain_suffix: farfetch.cn
domain_suffix: farfetch.com
domain_suffix: farfetch.com.cn
domain_suffix: farfetch.net
domain_suffix: farfetch.net.cn
domain_suffix: fflnk.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
