# olevod

Актуальный набор доменных правил «olevod» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `olevod`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_olevod_7dd34bc6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_olevod_7dd34bc6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-olevod.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: haiwaikan.com
domain_suffix: iole.tv
domain_suffix: olehd.com
domain_suffix: olelive.com
domain_suffix: olemovienews.com
domain_suffix: olevod.com
domain_suffix: olevod.io
domain_suffix: olevod.tv
domain_suffix: olevodtv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
