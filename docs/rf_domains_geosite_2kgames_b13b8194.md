# 2kgames

Актуальный набор доменных правил «2kgames» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `2kgames`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_2kgames_b13b8194.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_2kgames_b13b8194.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-2kgames.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 2k.com
domain_suffix: 2kcoretech.online
domain_suffix: 2kct.onl
domain_suffix: 2kgames.com
domain_suffix: 2ksports.com
domain_suffix: 2kweb.online
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
