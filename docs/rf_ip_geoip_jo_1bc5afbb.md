# jo · IP-сети

Актуальный набор IP-сетей «jo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `jo`. Тип: **ip**.

Правил: **620**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 620.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_jo_1bc5afbb.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_jo_1bc5afbb.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-jo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
