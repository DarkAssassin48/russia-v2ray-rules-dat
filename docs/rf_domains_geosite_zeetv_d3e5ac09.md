# zeetv

Актуальный набор доменных правил «zeetv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `zeetv`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_zeetv_d3e5ac09.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_zeetv_d3e5ac09.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-zeetv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: z5.app
domain_suffix: z5.com
domain_suffix: zee5.com
domain_suffix: zee5.in
domain_suffix: zee5.tv
domain_suffix: zeebioskop.com
domain_suffix: zeetv.co.uk
domain_suffix: zeetv.com
domain_suffix: zeeuk.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
