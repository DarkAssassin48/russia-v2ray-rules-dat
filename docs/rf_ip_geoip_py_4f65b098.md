# py · IP-сети

Актуальный набор IP-сетей «py» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `py`. Тип: **ip**.

Правил: **685**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 685.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_py_4f65b098.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_py_4f65b098.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-py.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
