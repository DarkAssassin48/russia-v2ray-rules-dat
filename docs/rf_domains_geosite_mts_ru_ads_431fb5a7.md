# mts-ru@ads

Актуальный набор доменных правил «mts-ru@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mts-ru@ads`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mts_ru_ads_431fb5a7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mts_ru_ads_431fb5a7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mts-ru@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: a.mts.ru
domain_suffix: obs.mts.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
