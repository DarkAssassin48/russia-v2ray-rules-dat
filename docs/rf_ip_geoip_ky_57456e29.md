# ky · IP-сети

Актуальный набор IP-сетей «ky» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ky`. Тип: **ip**.

Правил: **235**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 235.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ky_57456e29.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ky_57456e29.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ky.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
