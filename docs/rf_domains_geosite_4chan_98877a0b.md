# 4chan

Актуальный набор доменных правил «4chan» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `4chan`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_4chan_98877a0b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_4chan_98877a0b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-4chan.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 4cdn.org
domain_suffix: 4chan.org
domain_suffix: 4channel.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
