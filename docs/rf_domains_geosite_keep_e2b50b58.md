# keep

Актуальный набор доменных правил «keep» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `keep`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_keep_e2b50b58.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_keep_e2b50b58.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-keep.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: calorietech.com
domain_suffix: gotokeep.com
domain_suffix: keep.com
domain_suffix: keep.com.cn
domain_suffix: keepcdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
