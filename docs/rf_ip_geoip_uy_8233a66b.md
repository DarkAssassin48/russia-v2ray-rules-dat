# uy · IP-сети

Актуальный набор IP-сетей «uy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `uy`. Тип: **ip**.

Правил: **428**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 428.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_uy_8233a66b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_uy_8233a66b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-uy.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
