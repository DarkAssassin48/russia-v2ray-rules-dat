# thescoregroup

Актуальный набор доменных правил «thescoregroup» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thescoregroup`. Тип: **domains**.

Правил: **111**. Точные домены: 0; доменные зоны: 111; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thescoregroup_d25cfd3f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thescoregroup_d25cfd3f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-thescoregroup.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
