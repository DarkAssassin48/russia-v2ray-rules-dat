# projectpoi

Актуальный набор доменных правил «projectpoi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `projectpoi`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_projectpoi_a5604581.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_projectpoi_a5604581.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-projectpoi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: poi.icu
domain_suffix: poi6.net
domain_suffix: poihub.com
domain_suffix: project-poi.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
