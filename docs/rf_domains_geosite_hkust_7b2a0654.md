# hkust

Актуальный набор доменных правил «hkust» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hkust`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hkust_7b2a0654.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hkust_7b2a0654.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hkust.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hkust.edu.hk
domain_suffix: hkust.hk
domain_suffix: xn--pssu7ci2j23mp9ny48b.hk
domain_suffix: xn--pssu7ci2j23mp9ny48b.xn--j6w193g
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
