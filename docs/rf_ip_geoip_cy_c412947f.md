# cy · IP-сети

Актуальный набор IP-сетей «cy» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cy`. Тип: **ip**.

Правил: **1473**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1473.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cy_c412947f.txt)
