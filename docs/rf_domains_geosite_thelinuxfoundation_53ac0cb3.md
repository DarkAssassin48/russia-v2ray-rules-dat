# thelinuxfoundation

Актуальный набор доменных правил «thelinuxfoundation» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thelinuxfoundation`. Тип: **domains**.

Правил: **17**. Точные домены: 2; доменные зоны: 15; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thelinuxfoundation_53ac0cb3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thelinuxfoundation_53ac0cb3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-thelinuxfoundation.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
