# upai

Актуальный набор доменных правил «upai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `upai`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_upai_d9f25a2d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_upai_d9f25a2d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-upai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aicdn.com
domain_suffix: oncdp.com
domain_suffix: upai.com
domain_suffix: upaiyun.com
domain_suffix: upcdn.net
domain_suffix: upyun.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
