# nhk

Актуальный набор доменных правил «nhk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nhk`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nhk_33f8b57e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nhk_33f8b57e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nhk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .nhk
domain_suffix: nhk.jp
domain_suffix: nhk.or.jp
domain_suffix: nhkworld.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
