# meadjohnson

Актуальный набор доменных правил «meadjohnson» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `meadjohnson`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_meadjohnson_30eba1e9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_meadjohnson_30eba1e9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-meadjohnson.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: enfinitas.com.cn
domain_suffix: meadjohnson.com
domain_suffix: meadjohnson.com.cn
domain_suffix: meadjohnson.com.hk
domain_suffix: meadjohnson.com.tw
domain_suffix: meadjohnson.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
