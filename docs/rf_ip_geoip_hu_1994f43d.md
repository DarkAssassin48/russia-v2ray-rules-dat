# hu · IP-сети

Актуальный набор IP-сетей «hu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hu`. Тип: **ip**.

Правил: **2846**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2846.

- [Все адреса в текстовом виде](../details/rf_ip_geoip_hu_1994f43d.txt)
