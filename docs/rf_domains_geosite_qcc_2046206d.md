# qcc

Актуальный набор доменных правил «qcc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qcc`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qcc_2046206d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qcc_2046206d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qcc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: qcc.com
domain_suffix: qichacha.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
