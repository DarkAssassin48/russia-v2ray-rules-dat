# hunantv@ads

Актуальный набор доменных правил «hunantv@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hunantv@ads`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hunantv_ads_7068c79b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hunantv_ads_7068c79b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hunantv@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: click.hunantv.com
domain_suffix: da.hunantv.com
domain_suffix: da.mgtv.com
domain_suffix: log.hunantv.com
domain_suffix: log.v2.hunantv.com
domain_suffix: res.hunantv.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
