# taihe

Актуальный набор доменных правил «taihe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `taihe`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_taihe_453c06f4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_taihe_453c06f4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-taihe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 91q.com
domain_suffix: dmhmusic.com
domain_suffix: showstart.com
domain_suffix: taihe.com
domain_suffix: taihemusic.cn
domain_suffix: th-music.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
