# rt

Актуальный набор доменных правил «rt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rt`. Тип: **domains**.

Правил: **112**. Точные домены: 0; доменные зоны: 112; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_rt_c0a655e2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_rt_c0a655e2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-rt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
