# apple-dev@cn

Актуальный набор доменных правил «apple-dev@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-dev@cn`. Тип: **domains**.

Правил: **14**. Точные домены: 10; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_dev_cn_da13042a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_dev_cn_da13042a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-dev@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: cdn-cn.apple-mapkit.com
domain: cdn-cn1.apple-mapkit.com
domain: cdn-cn2.apple-mapkit.com
domain: cdn-cn3.apple-mapkit.com
domain: cdn-cn4.apple-mapkit.com
domain: cdn.apple-mapkit.com
domain: cdn1.apple-mapkit.com
domain: cdn2.apple-mapkit.com
domain: cdn3.apple-mapkit.com
domain: cdn4.apple-mapkit.com
domain_suffix: researchkit.cn
domain_suffix: researchkit.com.cn
domain_suffix: swiftui.cn
domain_suffix: swiftui.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
