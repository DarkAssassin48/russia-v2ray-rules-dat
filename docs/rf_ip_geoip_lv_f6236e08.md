# lv · IP-сети

Актуальный набор IP-сетей «lv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lv`. Тип: **ip**.

Правил: **1715**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1715.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lv_f6236e08.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lv_f6236e08.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
