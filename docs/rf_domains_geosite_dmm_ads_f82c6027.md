# dmm@ads

Актуальный набор доменных правил «dmm@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dmm@ads`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dmm_ads_f82c6027.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dmm_ads_f82c6027.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dmm@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ad.games.dmm.com
domain_suffix: bluekai.com
domain_suffix: fout.jp
domain_suffix: gmossp-sp.jp
domain_suffix: i-mobile.co.jp
domain_suffix: im-apps.net
domain_suffix: impact-ad.jp
domain_suffix: ladsp.com
domain_suffix: microad.co.jp
domain_suffix: microad.jp
domain_suffix: socdm.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
