# suishouji

Актуальный набор доменных правил «suishouji» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `suishouji`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_suishouji_6e88627f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_suishouji_6e88627f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-suishouji.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: feidee.cn
domain_suffix: feidee.com
domain_suffix: feidee.net
domain_suffix: ssjlicai.com
domain_suffix: sui.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
