# gamersky@ads

Актуальный набор доменных правил «gamersky@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gamersky@ads`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gamersky_ads_af4b3a22.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gamersky_ads_af4b3a22.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gamersky@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: click.gamersky.com
domain_suffix: ja.gamersky.com
domain_suffix: ja1.gamersky.com
domain_suffix: ja2.gamersky.com
domain_suffix: wmbd.gamersky.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
