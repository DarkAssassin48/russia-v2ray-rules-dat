# fk · IP-сети

Актуальный набор IP-сетей «fk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fk`. Тип: **ip**.

Правил: **94**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 94.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fk_b5bcfd49.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fk_b5bcfd49.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
