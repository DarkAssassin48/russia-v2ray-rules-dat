# avaxhome

Актуальный набор доменных правил «avaxhome» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `avaxhome`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_avaxhome_c04fad89.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_avaxhome_c04fad89.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-avaxhome.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: avh.world
domain_suffix: avxde.org
domain_suffix: avxhm.is
domain_suffix: avxhm.se
domain_suffix: avxlive.icu
domain_suffix: xsava.xyz
domain_suffix: zavat.pw
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
