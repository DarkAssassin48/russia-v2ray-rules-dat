# getui

Актуальный набор доменных правил «getui» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `getui`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_getui_8ac1fd66.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_getui_8ac1fd66.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-getui.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gepush.com
domain_suffix: getui.cn
domain_suffix: getui.com
domain_suffix: getui.net
domain_suffix: igehuo.com
domain_suffix: igetui.com
domain_suffix: igexin.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
