# sh · IP-сети

Актуальный набор IP-сетей «sh» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sh`. Тип: **ip**.

Правил: **34**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 34.
