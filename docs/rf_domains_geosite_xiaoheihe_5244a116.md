# xiaoheihe

Актуальный набор доменных правил «xiaoheihe» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xiaoheihe`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xiaoheihe_5244a116.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xiaoheihe_5244a116.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xiaoheihe.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1xhh.cn
domain_suffix: accxiaoheihe.com
domain_suffix: chat.top
domain_suffix: debugmode.cn
domain_suffix: max-c.com
domain_suffix: maxadmin.cn
domain_suffix: maxjia.com
domain_suffix: xiaoheihe.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
