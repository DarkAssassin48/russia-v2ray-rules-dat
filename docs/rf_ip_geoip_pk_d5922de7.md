# pk · IP-сети

Актуальный набор IP-сетей «pk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pk`. Тип: **ip**.

Правил: **2036**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 2036.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pk_d5922de7.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pk_d5922de7.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
