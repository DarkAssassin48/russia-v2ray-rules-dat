# category-social-media-ir

Актуальный набор доменных правил «category-social-media-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-social-media-ir`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_social_media_ir_daffd18d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_social_media_ir_daffd18d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-social-media-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
