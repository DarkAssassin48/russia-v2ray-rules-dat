# openx

Актуальный набор доменных правил «openx» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `openx`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_openx_febf6372.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_openx_febf6372.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-openx.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: openx.net
domain_suffix: openxadexchange.com
domain_suffix: openxcdn.net
domain_suffix: openxenterprise.com
domain_suffix: openxmarket.asia
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
