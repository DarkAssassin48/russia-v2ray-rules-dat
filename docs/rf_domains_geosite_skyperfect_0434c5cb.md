# skyperfect

Актуальный набор доменных правил «skyperfect» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `skyperfect`. Тип: **domains**.

Правил: **7**. Точные домены: 0; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_skyperfect_0434c5cb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_skyperfect_0434c5cb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-skyperfect.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hominis.media
domain_suffix: jsati.com
domain_suffix: jsatmobile.com
domain_suffix: skyperfectjsat.space
domain_suffix: skyperfectv.co.jp
domain_suffix: spcc-sp.com
domain_suffix: sptvbroadcast.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
