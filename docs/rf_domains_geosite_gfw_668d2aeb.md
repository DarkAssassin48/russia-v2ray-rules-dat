# gfw

Актуальный набор доменных правил «gfw» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gfw`. Тип: **domains**.

Правил: **4432**. Точные домены: 0; доменные зоны: 4432; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gfw_668d2aeb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gfw_668d2aeb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gfw.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
