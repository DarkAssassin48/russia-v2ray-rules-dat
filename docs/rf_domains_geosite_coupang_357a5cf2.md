# coupang

Актуальный набор доменных правил «coupang» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `coupang`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_coupang_357a5cf2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_coupang_357a5cf2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-coupang.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: coupang.com
domain_suffix: coupangcdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
