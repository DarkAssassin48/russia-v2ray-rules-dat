# ae · IP-сети

Актуальный набор IP-сетей «ae» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ae`. Тип: **ip**.

Правил: **6517**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 6517.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_ae_53df51a4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_ae_53df51a4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-ae.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
