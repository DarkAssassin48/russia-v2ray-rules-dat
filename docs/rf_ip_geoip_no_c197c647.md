# no · IP-сети

Актуальный набор IP-сетей «no» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `no`. Тип: **ip**.

Правил: **4375**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 4375.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_no_c197c647.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_no_c197c647.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-no.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
