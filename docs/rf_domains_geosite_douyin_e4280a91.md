# douyin

Актуальный набор доменных правил «douyin» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `douyin`. Тип: **domains**.

Правил: **71**. Точные домены: 0; доменные зоны: 71; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_douyin_e4280a91.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_douyin_e4280a91.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-douyin.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
