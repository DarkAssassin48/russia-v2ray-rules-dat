# wikihow

Актуальный набор доменных правил «wikihow» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wikihow`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wikihow_d17a3beb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wikihow_d17a3beb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wikihow.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: wikihow.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
