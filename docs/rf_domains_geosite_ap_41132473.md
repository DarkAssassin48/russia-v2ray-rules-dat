# ap

Актуальный набор доменных правил «ap» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ap`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ap_41132473.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ap_41132473.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ap.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ap.org
domain_suffix: apnews.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
