# veet

Актуальный набор доменных правил «veet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `veet`. Тип: **domains**.

Правил: **45**. Точные домены: 0; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_veet_761524b3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_veet_761524b3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-veet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
