# um · IP-сети

Актуальный набор IP-сетей «um» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `um`. Тип: **ip**.

Правил: **84**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 84.
