# openstreetmap

Актуальный набор доменных правил «openstreetmap» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `openstreetmap`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_openstreetmap_3b5ddea2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_openstreetmap_3b5ddea2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-openstreetmap.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: openmaps.org
domain_suffix: openstreetmap.com
domain_suffix: openstreetmap.net
domain_suffix: openstreetmap.org
domain_suffix: openstreetmaps.org
domain_suffix: osm.org
domain_suffix: osmfoundation.org
domain_suffix: stateofthemap.com
domain_suffix: stateofthemap.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
