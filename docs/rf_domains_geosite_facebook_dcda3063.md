# Facebook

Актуальный набор доменных правил «Facebook» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `facebook`. Тип: **domains**.

Правил: **397**. Точные домены: 1; доменные зоны: 396; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_facebook_dcda3063.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_facebook_dcda3063.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-facebook.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
