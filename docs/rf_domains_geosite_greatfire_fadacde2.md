# greatfire

Актуальный набор доменных правил «greatfire» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `greatfire`. Тип: **domains**.

Правил: **12**. Точные домены: 0; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_greatfire_fadacde2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_greatfire_fadacde2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-greatfire.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: applecensorship.com
domain_suffix: freebrowser.org
domain_suffix: freewechat.com
domain_suffix: freeweibo.com
domain_suffix: freezhihu.org
domain_suffix: googlecensorship.org
domain_suffix: googleplaycensorship.com
domain_suffix: greatfire.org
domain_suffix: greatfirevpn.com
domain_suffix: manyvoices.news
domain_suffix: pao-pao.net
domain_suffix: wikiunblocked.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
