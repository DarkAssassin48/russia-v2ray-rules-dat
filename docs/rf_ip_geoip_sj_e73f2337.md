# sj · IP-сети

Актуальный набор IP-сетей «sj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sj`. Тип: **ip**.

Правил: **43**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 43.
