# rs · IP-сети

Актуальный набор IP-сетей «rs» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `rs`. Тип: **ip**.

Правил: **1392**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1392.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_rs_a082c199.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_rs_a082c199.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-rs.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
