# webex

Актуальный набор доменных правил «webex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `webex`. Тип: **domains**.

Правил: **16**. Точные домены: 0; доменные зоны: 16; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_webex_1ff008d1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_webex_1ff008d1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-webex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
