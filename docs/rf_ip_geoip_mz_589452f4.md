# mz · IP-сети

Актуальный набор IP-сетей «mz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mz`. Тип: **ip**.

Правил: **268**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 268.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_mz_589452f4.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_mz_589452f4.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-mz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
