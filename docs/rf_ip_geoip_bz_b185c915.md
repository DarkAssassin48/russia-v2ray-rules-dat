# bz · IP-сети

Актуальный набор IP-сетей «bz» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bz`. Тип: **ip**.

Правил: **297**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 297.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_bz_b185c915.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_bz_b185c915.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-bz.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
