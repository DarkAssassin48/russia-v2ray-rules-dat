# qimao

Актуальный набор доменных правил «qimao» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qimao`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qimao_a5f0b2f9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qimao_a5f0b2f9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qimao.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: jiuyue919.com
domain_suffix: qimao.com
domain_suffix: qm989.com
domain_suffix: qmniu.com
domain_suffix: quehu.com
domain_suffix: wtzw.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
