# do · IP-сети

Актуальный набор IP-сетей «do» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `do`. Тип: **ip**.

Правил: **1081**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 1081.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_do_fe063d5a.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_do_fe063d5a.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-do.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
