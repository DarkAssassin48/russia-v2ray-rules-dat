# miniso@cn

Актуальный набор доменных правил «miniso@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `miniso@cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_miniso_cn_b4b2d52c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_miniso_cn_b4b2d52c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-miniso@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: miniso.cn
domain_suffix: minisohome.cn
domain_suffix: minsio.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
