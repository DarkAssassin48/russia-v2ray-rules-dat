# Microsoft

Актуальный набор доменных правил «Microsoft» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft`. Тип: **domains**.

Правил: **756**. Точные домены: 116; доменные зоны: 640; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_1fa9830f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_1fa9830f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
