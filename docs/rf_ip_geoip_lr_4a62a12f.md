# lr · IP-сети

Актуальный набор IP-сетей «lr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lr`. Тип: **ip**.

Правил: **170**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 170.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lr_4a62a12f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lr_4a62a12f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
