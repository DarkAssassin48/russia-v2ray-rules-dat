# category-entertainment-cn@ads

Актуальный набор доменных правил «category-entertainment-cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-entertainment-cn@ads`. Тип: **domains**.

Правил: **52**. Точные домены: 18; доменные зоны: 34; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_entertainment_cn_ads_8494f2cd.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_entertainment_cn_ads_8494f2cd.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-entertainment-cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
