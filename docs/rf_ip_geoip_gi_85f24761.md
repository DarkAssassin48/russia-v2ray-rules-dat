# gi · IP-сети

Актуальный набор IP-сетей «gi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gi`. Тип: **ip**.

Правил: **227**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 227.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_gi_85f24761.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_gi_85f24761.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-gi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
