# Реклама — общий набор [большой набор]

Актуальный набор доменных правил «Реклама — общий набор» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ads-all`. Тип: **domains**.

Правил: **184440**. Точные домены: 0; доменные зоны: 184440; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ads_all_7d384895.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ads_all_7d384895.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ads-all.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
