# category-forums-ru

Актуальный набор доменных правил «category-forums-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-forums-ru`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_forums_ru_713afc5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_forums_ru_713afc5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-forums-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain_suffix: dtf.ru
domain_suffix: joyreactor.cc

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
