# X / Twitter · IP-сети

Актуальный набор IP-сетей «X / Twitter» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `twitter`. Тип: **ip**.

Правил: **20**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 20.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_twitter_ef1f790b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_twitter_ef1f790b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-twitter.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
