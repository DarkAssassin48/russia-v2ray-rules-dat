# bethesda

Актуальный набор доменных правил «bethesda» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `bethesda`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_bethesda_5367070c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_bethesda_5367070c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-bethesda.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: beth.games
domain_suffix: bethesda.net
domain_suffix: bethesdagamestudios.com
domain_suffix: bethsoft.com
domain_suffix: doom.com
domain_suffix: elderscrolls.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
