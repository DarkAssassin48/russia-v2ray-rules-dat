# category-public-tracker

Актуальный набор доменных правил «category-public-tracker» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-public-tracker`. Тип: **domains**.

Правил: **433**. Точные домены: 402; доменные зоны: 31; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_public_tracker_c12bf51a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_public_tracker_c12bf51a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-public-tracker.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
