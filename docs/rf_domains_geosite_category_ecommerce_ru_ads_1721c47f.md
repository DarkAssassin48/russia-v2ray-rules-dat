# category-ecommerce-ru@ads

Актуальный набор доменных правил «category-ecommerce-ru@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ecommerce-ru@ads`. Тип: **domains**.

Правил: **34**. Точные домены: 34; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ecommerce_ru_ads_1721c47f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ecommerce_ru_ads_1721c47f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ecommerce-ru@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
