# chatwhores

Актуальный набор доменных правил «chatwhores» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `chatwhores`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_chatwhores_9f9d3ac7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_chatwhores_9f9d3ac7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-chatwhores.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: chatwhores.com
domain_suffix: chatwhores.net
domain_suffix: chatwhores.org
domain_suffix: chatwhores.sex
domain_suffix: chatwhores.tv
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
