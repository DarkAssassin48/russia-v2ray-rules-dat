# category-voip

Актуальный набор доменных правил «category-voip» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-voip`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_voip_e4eb5ae7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_voip_e4eb5ae7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-voip.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: agkn.com
domain_suffix: cohere.com
domain_suffix: inmobi.com
domain_suffix: ip-api.com
domain_suffix: kochava.com
domain_suffix: mobilefuse.com
domain_suffix: talkatone.com
domain_suffix: tktn.at
domain_suffix: tktn.be
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
