# sonypictures

Актуальный набор доменных правил «sonypictures» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sonypictures`. Тип: **domains**.

Правил: **14**. Точные домены: 0; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sonypictures_92552e2a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sonypictures_92552e2a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sonypictures.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
