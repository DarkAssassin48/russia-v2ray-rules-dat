# vk

Актуальный набор доменных правил «vk» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vk`. Тип: **domains**.

Правил: **52**. Точные домены: 9; доменные зоны: 43; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vk_03d0501c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vk_03d0501c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vk.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
