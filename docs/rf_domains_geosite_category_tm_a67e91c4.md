# category-tm

Актуальный набор доменных правил «category-tm» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-tm`. Тип: **domains**.

Правил: **72**. Точные домены: 0; доменные зоны: 72; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_tm_a67e91c4.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_tm_a67e91c4.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-tm.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
