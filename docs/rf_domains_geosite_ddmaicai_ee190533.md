# ddmaicai

Актуальный набор доменных правил «ddmaicai» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ddmaicai`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ddmaicai_ee190533.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ddmaicai_ee190533.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ddmaicai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 100.me
domain_suffix: ddcorp.net
domain_suffix: ddfresh.net
domain_suffix: ddimg.mobi
domain_suffix: ddmaicai.net
domain_suffix: ddmc.mobi
domain_suffix: dduser.mobi
domain_suffix: ddxq.mobi
domain_suffix: imaicai.mobi
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
