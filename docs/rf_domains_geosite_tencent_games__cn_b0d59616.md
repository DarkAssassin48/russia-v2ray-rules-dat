# tencent-games@!cn

Актуальный набор доменных правил «tencent-games@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tencent-games@!cn`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tencent_games__cn_b0d59616.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tencent_games__cn_b0d59616.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tencent-games@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: levelinfinite.com
domain_suffix: nikke-en.com
domain_suffix: tencentgames.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
