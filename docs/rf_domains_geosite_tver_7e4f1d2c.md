# tver

Актуальный набор доменных правил «tver» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `tver`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_tver_7e4f1d2c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_tver_7e4f1d2c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-tver.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dogatch.jp
domain_suffix: gorin.jp
domain_suffix: screens-lab.jp
domain_suffix: tver.co.jp
domain_suffix: tver.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
