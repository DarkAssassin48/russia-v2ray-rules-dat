# didi@!cn

Актуальный набор доменных правил «didi@!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `didi@!cn`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_didi__cn_5901840e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_didi__cn_5901840e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-didi@!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: didi-food.com
domain_suffix: didiaustralia.blog
domain_suffix: didiglobal.com
domain_suffix: didimobility.co.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
