# firebase

Актуальный набор доменных правил «firebase» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `firebase`. Тип: **domains**.

Правил: **23**. Точные домены: 16; доменные зоны: 7; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_firebase_0b7d972c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_firebase_0b7d972c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-firebase.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
