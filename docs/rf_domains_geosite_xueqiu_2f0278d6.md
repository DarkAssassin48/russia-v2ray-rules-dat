# xueqiu

Актуальный набор доменных правил «xueqiu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xueqiu`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xueqiu_2f0278d6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xueqiu_2f0278d6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xueqiu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aiganggu.com
domain_suffix: danjuanfunds.com
domain_suffix: imedao.com
domain_suffix: snowballsecurities.com
domain_suffix: xueqiu.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
