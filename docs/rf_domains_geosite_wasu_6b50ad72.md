# wasu

Актуальный набор доменных правил «wasu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wasu`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wasu_6b50ad72.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wasu_6b50ad72.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wasu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aichongzoo.cn
domain_suffix: hzdtv.tv
domain_suffix: hzman.net
domain_suffix: wasu.cn
domain_suffix: wasu.tv
domain_suffix: wasumedia.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
