# thetimes

Актуальный набор доменных правил «thetimes» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thetimes`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thetimes_5895db9b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thetimes_5895db9b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-thetimes.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: driving.co.uk
domain_suffix: mytimesplus.co.uk
domain_suffix: sportswomanoftheyear.co.uk
domain_suffix: sportswomenoftheyear.co.uk
domain_suffix: the-tls.co.uk
domain_suffix: thesundaytimes.co.uk
domain_suffix: thetimes.co.uk
domain_suffix: thetimes.ie
domain_suffix: timesmembership.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
