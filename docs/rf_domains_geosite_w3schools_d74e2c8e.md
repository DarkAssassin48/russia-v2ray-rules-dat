# w3schools

Актуальный набор доменных правил «w3schools» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `w3schools`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_w3schools_d74e2c8e.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_w3schools_d74e2c8e.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-w3schools.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: w3schools.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
