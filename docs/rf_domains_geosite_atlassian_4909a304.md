# atlassian

Актуальный набор доменных правил «atlassian» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `atlassian`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_atlassian_4909a304.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_atlassian_4909a304.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-atlassian.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: atl-paas.net
domain_suffix: atlassian-dev.net
domain_suffix: atlassian.com
domain_suffix: atlassian.net
domain_suffix: bitbucket.io
domain_suffix: bitbucket.org
domain_suffix: jira.com
domain_suffix: ss-inf.net
domain_suffix: statuspage.io
domain_suffix: trello.com
domain_suffix: trellocdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
