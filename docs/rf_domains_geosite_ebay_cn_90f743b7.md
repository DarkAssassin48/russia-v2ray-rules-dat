# ebay@cn

Актуальный набор доменных правил «ebay@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ebay@cn`. Тип: **domains**.

Правил: **37**. Точные домены: 0; доменные зоны: 37; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ebay_cn_90f743b7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ebay_cn_90f743b7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ebay@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
