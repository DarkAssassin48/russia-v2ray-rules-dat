# quora

Актуальный набор доменных правил «quora» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `quora`. Тип: **domains**.

Правил: **6**. Точные домены: 1; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_quora_afa54101.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_quora_afa54101.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-quora.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: www.quora.com.cdn.cloudflare.net
domain_suffix: poe.com
domain_suffix: poecdn.net
domain_suffix: qr.ae
domain_suffix: quora.com
domain_suffix: quoracdn.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
