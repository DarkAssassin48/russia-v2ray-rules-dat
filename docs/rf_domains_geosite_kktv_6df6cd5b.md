# kktv

Актуальный набор доменных правил «kktv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `kktv`. Тип: **domains**.

Правил: **3**. Точные домены: 0; доменные зоны: 3; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_kktv_6df6cd5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_kktv_6df6cd5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-kktv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: kktv.com.tw
domain_suffix: kktv.me
domain_suffix: theater-kktv.cdn.hinet.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
