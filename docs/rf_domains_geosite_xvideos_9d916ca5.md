# xvideos

Актуальный набор доменных правил «xvideos» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xvideos`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xvideos_9d916ca5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xvideos_9d916ca5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xvideos.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: xv-ru.com
domain_suffix: xvideos-ar.com
domain_suffix: xvideos-cdn.com
domain_suffix: xvideos-india.com
domain_suffix: xvideos.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
