# hn · IP-сети

Актуальный набор IP-сетей «hn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hn`. Тип: **ip**.

Правил: **617**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 617.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_hn_8a39365f.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_hn_8a39365f.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-hn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
