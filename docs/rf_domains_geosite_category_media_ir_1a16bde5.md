# category-media-ir

Актуальный набор доменных правил «category-media-ir» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-media-ir`. Тип: **domains**.

Правил: **28**. Точные домены: 0; доменные зоны: 28; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_media_ir_1a16bde5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_media_ir_1a16bde5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-media-ir.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
