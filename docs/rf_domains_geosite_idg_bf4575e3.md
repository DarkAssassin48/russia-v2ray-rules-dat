# idg

Актуальный набор доменных правил «idg» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `idg`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_idg_bf4575e3.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_idg_bf4575e3.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-idg.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: idg.com
domain_suffix: idgcommunications.net
domain_suffix: idgconnect-direct.com
domain_suffix: idgconnect-resources.com
domain_suffix: idgconnect.com
domain_suffix: idgesg.net
domain_suffix: idginc.com
domain_suffix: idginsiderpro.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
