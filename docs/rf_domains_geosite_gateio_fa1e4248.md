# gateio

Актуальный набор доменных правил «gateio» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gateio`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gateio_fa1e4248.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gateio_fa1e4248.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gateio.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: gate.com
domain_suffix: gate.io
domain_suffix: gate.tv
domain_suffix: gateapi.io
domain_suffix: gatedata.org
domain_suffix: gateimg.com
domain_suffix: gateio.live
domain_suffix: gateio.services
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
