# qwant

Актуальный набор доменных правил «qwant» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `qwant`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_qwant_f504d670.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_qwant_f504d670.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-qwant.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: qwant.com
domain_suffix: qwant.de
domain_suffix: qwant.fr
domain_suffix: qwant.it
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
