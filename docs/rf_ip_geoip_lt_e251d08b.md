# lt · IP-сети

Актуальный набор IP-сетей «lt» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `lt`. Тип: **ip**.

Правил: **5259**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 5259.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_lt_e251d08b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_lt_e251d08b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-lt.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
