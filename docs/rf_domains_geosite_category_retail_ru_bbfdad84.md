# category-retail-ru

Актуальный набор доменных правил «category-retail-ru» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-retail-ru`. Тип: **domains**.

Правил: **82**. Точные домены: 4; доменные зоны: 78; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_retail_ru_bbfdad84.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_retail_ru_bbfdad84.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-retail-ru.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
