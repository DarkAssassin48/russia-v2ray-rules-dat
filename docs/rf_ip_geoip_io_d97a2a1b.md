# io · IP-сети

Актуальный набор IP-сетей «io» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `io`. Тип: **ip**.

Правил: **102**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 102.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_io_d97a2a1b.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_io_d97a2a1b.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-io.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
