# transtelecom

Актуальный набор доменных правил «transtelecom» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `transtelecom`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_transtelecom_5d26f21d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_transtelecom_5d26f21d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-transtelecom.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: baikal-ttk.ru
domain_suffix: kttk.ru
domain_suffix: myttk.ru
domain_suffix: sakhttk.ru
domain_suffix: ttc-net.ru
domain_suffix: ttk.ru
domain_suffix: ttkdv.ru
domain_suffix: zsttk.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
