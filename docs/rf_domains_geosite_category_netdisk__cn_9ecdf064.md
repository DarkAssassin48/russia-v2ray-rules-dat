# category-netdisk-!cn

Актуальный набор доменных правил «category-netdisk-!cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-netdisk-!cn`. Тип: **domains**.

Правил: **59**. Точные домены: 3; доменные зоны: 56; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_netdisk__cn_9ecdf064.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_netdisk__cn_9ecdf064.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-netdisk-!cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
