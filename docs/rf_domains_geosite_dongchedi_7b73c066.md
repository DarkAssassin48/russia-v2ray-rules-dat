# dongchedi

Актуальный набор доменных правил «dongchedi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dongchedi`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dongchedi_7b73c066.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dongchedi_7b73c066.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dongchedi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: dcarapi.com
domain_suffix: dcarimg.com
domain_suffix: dcarlive.com
domain_suffix: dcarstatic.com
domain_suffix: dcarvod.com
domain_suffix: dcdapp.com
domain_suffix: dongchedi.com
domain_suffix: dongchediapp.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
