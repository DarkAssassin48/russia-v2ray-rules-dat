# sci-hub

Актуальный набор доменных правил «sci-hub» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sci-hub`. Тип: **domains**.

Правил: **6**. Точные домены: 0; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sci_hub_86a8d1b8.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sci_hub_86a8d1b8.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sci-hub.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: sci-hub.ee
domain_suffix: sci-hub.it.nf
domain_suffix: sci-hub.mksa.top
domain_suffix: sci-hub.se
domain_suffix: sci-hub.st
domain_suffix: sci.hubg.org
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
