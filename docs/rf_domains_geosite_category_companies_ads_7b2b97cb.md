# category-companies@ads

Актуальный набор доменных правил «category-companies@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-companies@ads`. Тип: **domains**.

Правил: **223**. Точные домены: 85; доменные зоны: 138; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_companies_ads_7b2b97cb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_companies_ads_7b2b97cb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-companies@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
