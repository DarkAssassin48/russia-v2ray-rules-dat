# gmo-internet

Актуальный набор доменных правил «gmo-internet» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gmo-internet`. Тип: **domains**.

Правил: **145**. Точные домены: 2; доменные зоны: 143; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gmo_internet_5fd6af75.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gmo_internet_5fd6af75.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gmo-internet.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
