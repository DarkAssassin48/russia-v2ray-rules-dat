# sxl

Актуальный набор доменных правил «sxl» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `sxl`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_sxl_95e990ce.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_sxl_95e990ce.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-sxl.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mysxl.cn
domain_suffix: sxl.cn
domain_suffix: sxlcdn.cn
domain_suffix: sxlcdn.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
