# garena

Актуальный набор доменных правил «garena» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `garena`. Тип: **domains**.

Правил: **16**. Точные домены: 4; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_garena_9290bcf5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_garena_9290bcf5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-garena.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
