# nintendo

Актуальный набор доменных правил «nintendo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `nintendo`. Тип: **domains**.

Правил: **124**. Точные домены: 0; доменные зоны: 124; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_nintendo_70bbd15c.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_nintendo_70bbd15c.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-nintendo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
