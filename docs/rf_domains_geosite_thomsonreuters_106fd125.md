# thomsonreuters

Актуальный набор доменных правил «thomsonreuters» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `thomsonreuters`. Тип: **domains**.

Правил: **32**. Точные домены: 0; доменные зоны: 32; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_thomsonreuters_106fd125.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_thomsonreuters_106fd125.json)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
