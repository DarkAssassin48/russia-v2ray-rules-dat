# wsj

Актуальный набор доменных правил «wsj» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `wsj`. Тип: **domains**.

Правил: **13**. Точные домены: 0; доменные зоны: 13; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_wsj_cbf4dd94.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_wsj_cbf4dd94.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-wsj.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: careerjournal.com
domain_suffix: collegejournal.com
domain_suffix: getwsj.com
domain_suffix: opinionjournal.com
domain_suffix: realestatejournal.com
domain_suffix: startupjournal.com
domain_suffix: wsj.com
domain_suffix: wsj.jobs
domain_suffix: wsj.net
domain_suffix: wsjmediakit.com
domain_suffix: wsjplus.com
domain_suffix: wsjshop.com
domain_suffix: wsjwine.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
