# agilebits

Актуальный набор доменных правил «agilebits» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `agilebits`. Тип: **domains**.

Правил: **15**. Точные домены: 1; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_agilebits_67a473bb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_agilebits_67a473bb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-agilebits.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

domain: 1password.drift.click
domain_suffix: 1infra.net

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
