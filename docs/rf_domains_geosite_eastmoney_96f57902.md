# eastmoney

Актуальный набор доменных правил «eastmoney» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `eastmoney`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_eastmoney_96f57902.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_eastmoney_96f57902.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-eastmoney.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 1234567.com.cn
domain_suffix: 18.cn
domain_suffix: 18.com.cn
domain_suffix: dfcfw.com
domain_suffix: eastmoney.com
domain_suffix: eastmoneyfutures.com
domain_suffix: emsec.hk
domain_suffix: guba.com.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
