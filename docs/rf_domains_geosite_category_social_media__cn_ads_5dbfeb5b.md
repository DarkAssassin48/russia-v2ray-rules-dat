# category-social-media-!cn@ads

Актуальный набор доменных правил «category-social-media-!cn@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-social-media-!cn@ads`. Тип: **domains**.

Правил: **21**. Точные домены: 9; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_social_media__cn_ads_5dbfeb5b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_social_media__cn_ads_5dbfeb5b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-social-media-!cn@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
