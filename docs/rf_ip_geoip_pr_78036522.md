# pr · IP-сети

Актуальный набор IP-сетей «pr» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `pr`. Тип: **ip**.

Правил: **992**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 992.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_pr_78036522.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_pr_78036522.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-pr.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
