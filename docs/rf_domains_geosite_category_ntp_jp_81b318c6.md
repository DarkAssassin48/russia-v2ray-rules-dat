# category-ntp-jp

Актуальный набор доменных правил «category-ntp-jp» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ntp-jp`. Тип: **domains**.

Правил: **28**. Точные домены: 0; доменные зоны: 28; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ntp_jp_81b318c6.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ntp_jp_81b318c6.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ntp-jp.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
