# dewu

Актуальный набор доменных правил «dewu» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `dewu`. Тип: **domains**.

Правил: **45**. Точные домены: 0; доменные зоны: 45; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_dewu_5bf3ac79.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_dewu_5bf3ac79.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-dewu.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
