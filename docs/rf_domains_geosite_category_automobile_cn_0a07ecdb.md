# category-automobile-cn

Актуальный набор доменных правил «category-automobile-cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-automobile-cn`. Тип: **domains**.

Правил: **51**. Точные домены: 0; доменные зоны: 51; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_automobile_cn_0a07ecdb.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_automobile_cn_0a07ecdb.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-automobile-cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
