# category-ru@telemetry

Актуальный набор доменных правил «category-ru@telemetry» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `category-ru@telemetry`. Тип: **domains**.

Правил: **50**. Точные домены: 33; доменные зоны: 17; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_category_ru_telemetry_60492580.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_category_ru_telemetry_60492580.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-category-ru@telemetry.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
