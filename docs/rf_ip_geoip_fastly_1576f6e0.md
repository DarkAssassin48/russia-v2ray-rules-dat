# fastly · IP-сети

Актуальный набор IP-сетей «fastly» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `fastly`. Тип: **ip**.

Правил: **94**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 94.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_fastly_1576f6e0.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_fastly_1576f6e0.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-fastly.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
