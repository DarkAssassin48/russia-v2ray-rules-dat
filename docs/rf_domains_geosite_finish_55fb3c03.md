# finish

Актуальный набор доменных правил «finish» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `finish`. Тип: **domains**.

Правил: **41**. Точные домены: 0; доменные зоны: 41; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_finish_55fb3c03.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_finish_55fb3c03.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-finish.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
