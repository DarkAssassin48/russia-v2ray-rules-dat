# creativecommons

Актуальный набор доменных правил «creativecommons» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `creativecommons`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_creativecommons_3d23cd30.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_creativecommons_3d23cd30.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-creativecommons.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: ccstatic.org
domain_suffix: creativecommons.engineering
domain_suffix: creativecommons.org
domain_suffix: licensebuttons.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
