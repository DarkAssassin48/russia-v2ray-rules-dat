# hinet-eca

Актуальный набор доменных правил «hinet-eca» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hinet-eca`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hinet_eca_55098eac.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hinet_eca_55098eac.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hinet-eca.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: eca.hinet.net
domain_suffix: gtlsca.nat.gov.tw
domain_suffix: pki.hinet.net
domain_suffix: publicca.hinet.net
domain_suffix: tls.hinet.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
