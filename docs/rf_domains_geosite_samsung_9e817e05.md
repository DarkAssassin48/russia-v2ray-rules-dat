# samsung

Актуальный набор доменных правил «samsung» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `samsung`. Тип: **domains**.

Правил: **27**. Точные домены: 0; доменные зоны: 27; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_samsung_9e817e05.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_samsung_9e817e05.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-samsung.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
