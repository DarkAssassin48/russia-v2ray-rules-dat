# att

Актуальный набор доменных правил «att» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `att`. Тип: **domains**.

Правил: **135**. Точные домены: 0; доменные зоны: 135; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_att_9b026091.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_att_9b026091.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-att.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
