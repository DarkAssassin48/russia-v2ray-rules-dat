# likee

Актуальный набор доменных правил «likee» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `likee`. Тип: **domains**.

Правил: **35**. Точные домены: 23; доменные зоны: 12; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_likee_77ac08c1.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_likee_77ac08c1.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-likee.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
