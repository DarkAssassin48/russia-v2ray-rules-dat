# cnn

Актуальный набор доменных правил «cnn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cnn`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_cnn_cf49892f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_cnn_cf49892f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-cnn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: cnn.com
domain_suffix: cnn.io
domain_suffix: cnn.it
domain_suffix: cnnarabic.com
domain_suffix: cnnlabs.com
domain_suffix: cnnmoney.ch
domain_suffix: cnnmoney.com
domain_suffix: cnnmoneystream.com
domain_suffix: cnnpolitics.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
