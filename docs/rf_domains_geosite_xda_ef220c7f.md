# xda

Актуальный набор доменных правил «xda» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xda`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xda_ef220c7f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xda_ef220c7f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xda.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: xda-cdn.com
domain_suffix: xda-developers.com
domain_suffix: xdaforums.com
domain_suffix: xdaimages.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
