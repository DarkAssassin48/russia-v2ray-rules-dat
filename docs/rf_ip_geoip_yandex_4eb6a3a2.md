# yandex · IP-сети

Актуальный набор IP-сетей «yandex» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `yandex`. Тип: **ip**.

Правил: **51**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 51.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_yandex_4eb6a3a2.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_yandex_4eb6a3a2.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-yandex.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
