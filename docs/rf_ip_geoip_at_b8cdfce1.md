# at · IP-сети

Актуальный набор IP-сетей «at» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `at`. Тип: **ip**.

Правил: **6928**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 6928.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_at_b8cdfce1.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_at_b8cdfce1.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-at.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
