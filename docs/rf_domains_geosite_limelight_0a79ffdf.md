# limelight

Актуальный набор доменных правил «limelight» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `limelight`. Тип: **domains**.

Правил: **8**. Точные домены: 0; доменные зоны: 8; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_limelight_0a79ffdf.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_limelight_0a79ffdf.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-limelight.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: delvenetworks.com
domain_suffix: limelight.com
domain_suffix: lldns.net
domain_suffix: llnw-trials.com
domain_suffix: llnw.com
domain_suffix: llnw.net
domain_suffix: llnwd.net
domain_suffix: llnwi.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
