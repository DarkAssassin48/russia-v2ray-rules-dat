# hoyoverse

Актуальный набор доменных правил «hoyoverse» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `hoyoverse`. Тип: **domains**.

Правил: **9**. Точные домены: 0; доменные зоны: 9; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_hoyoverse_a024df50.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_hoyoverse_a024df50.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-hoyoverse.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: genshinimpact.com
domain_suffix: honkaiimpact3.com
domain_suffix: honkaistarrail.com
domain_suffix: hoyo.link
domain_suffix: hoyolab.com
domain_suffix: hoyoverse.com
domain_suffix: log-upload-os.hoyoverse.com
domain_suffix: n0vadesktop.com
domain_suffix: zenlesszonezero.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
