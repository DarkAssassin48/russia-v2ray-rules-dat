# barrons

Актуальный набор доменных правил «barrons» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `barrons`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_barrons_cb0d54bc.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_barrons_cb0d54bc.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-barrons.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: barrons-advisor.com
domain_suffix: barrons-conferences.com
domain_suffix: barrons.com
domain_suffix: wsjbarrons.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
