# amap@ads

Актуальный набор доменных правил «amap@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `amap@ads`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_amap_ads_2c1f407f.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_amap_ads_2c1f407f.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-amap@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: adashx.ut.amap.com
domain_suffix: dualstack-logs.amap.com
domain_suffix: logs.amap.com
domain_suffix: optimus-ads.amap.com
domain_suffix: v6-adashx.ut.amap.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
