# microsoft-dev

Актуальный набор доменных правил «microsoft-dev» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `microsoft-dev`. Тип: **domains**.

Правил: **76**. Точные домены: 18; доменные зоны: 58; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_microsoft_dev_52bb6af5.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_microsoft_dev_52bb6af5.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-microsoft-dev.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
