# mortein

Актуальный набор доменных правил «mortein» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `mortein`. Тип: **domains**.

Правил: **11**. Точные домены: 0; доменные зоны: 11; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_mortein_b25e346b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_mortein_b25e346b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-mortein.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: mortein.cn
domain_suffix: mortein.co.in
domain_suffix: mortein.co.nz
domain_suffix: mortein.co.za
domain_suffix: mortein.com
domain_suffix: mortein.com.au

domain_suffix: mortein.com.ng

domain_suffix: morteincam.com

```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
