# niconico

Актуальный набор доменных правил «niconico» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `niconico`. Тип: **domains**.

Правил: **10**. Точные домены: 0; доменные зоны: 10; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_niconico_6a34fb2b.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_niconico_6a34fb2b.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-niconico.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: .nico
domain_suffix: nico.ms
domain_suffix: nicochannel.jp
domain_suffix: nicodic.jp
domain_suffix: nicomanga.jp
domain_suffix: niconico.com
domain_suffix: nicoseiga.jp
domain_suffix: nicovideo.jp
domain_suffix: nimg.jp
domain_suffix: simg.jp
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
