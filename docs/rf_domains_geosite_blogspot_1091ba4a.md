# blogspot

Актуальный набор доменных правил «blogspot» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `blogspot`. Тип: **domains**.

Правил: **76**. Точные домены: 0; доменные зоны: 76; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_blogspot_1091ba4a.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_blogspot_1091ba4a.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-blogspot.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
