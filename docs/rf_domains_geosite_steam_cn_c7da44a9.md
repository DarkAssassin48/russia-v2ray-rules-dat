# steam@cn

Актуальный набор доменных правил «steam@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `steam@cn`. Тип: **domains**.

Правил: **17**. Точные домены: 3; доменные зоны: 14; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_steam_cn_c7da44a9.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_steam_cn_c7da44a9.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-steam@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
