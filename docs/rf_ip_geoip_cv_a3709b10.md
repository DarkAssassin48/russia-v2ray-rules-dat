# cv · IP-сети

Актуальный набор IP-сетей «cv» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `cv`. Тип: **ip**.

Правил: **171**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 171.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_cv_a3709b10.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_cv_a3709b10.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-cv.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
