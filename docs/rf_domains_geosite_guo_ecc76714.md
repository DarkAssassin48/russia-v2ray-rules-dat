# guo

Актуальный набор доменных правил «guo» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `guo`. Тип: **domains**.

Правил: **21**. Точные домены: 1; доменные зоны: 20; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_guo_ecc76714.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_guo_ecc76714.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-guo.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
