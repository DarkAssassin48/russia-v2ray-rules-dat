# test-ipv6@cn

Актуальный набор доменных правил «test-ipv6@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `test-ipv6@cn`. Тип: **domains**.

Правил: **1**. Точные домены: 0; доменные зоны: 1; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_test_ipv6_cn_d2438b6d.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_test_ipv6_cn_d2438b6d.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-test-ipv6@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: testipv6.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
