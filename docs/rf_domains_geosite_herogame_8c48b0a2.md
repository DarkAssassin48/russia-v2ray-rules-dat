# herogame

Актуальный набор доменных правил «herogame» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `herogame`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_herogame_8c48b0a2.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_herogame_8c48b0a2.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-herogame.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: hero.com
domain_suffix: heroesports.com
domain_suffix: herogame.com
domain_suffix: shyxhy.com
domain_suffix: yingxiong.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
