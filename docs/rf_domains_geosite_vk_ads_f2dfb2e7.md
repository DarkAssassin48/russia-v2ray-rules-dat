# vk@ads

Актуальный набор доменных правил «vk@ads» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `vk@ads`. Тип: **domains**.

Правил: **15**. Точные домены: 9; доменные зоны: 6; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_vk_ads_f2dfb2e7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_vk_ads_f2dfb2e7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-vk@ads.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: adblogger.vk.com
domain: adblogger.vk.ru
domain: ads.vk.com
domain: ads.vk.ru
domain: adv.vk.ru
domain: advk.vk.ru
domain: analytics.vk.ru
domain: stats.vk-portal.net
domain: target.vk.com
domain_suffix: adv.vk.com
domain_suffix: analytics.vk.com
domain_suffix: ms.vk.com
domain_suffix: ms.vk.ru
domain_suffix: target.vk.ru
domain_suffix: vk-analytics.ru
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
