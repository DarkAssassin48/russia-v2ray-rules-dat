# xiaomi

Актуальный набор доменных правил «xiaomi» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `xiaomi`. Тип: **domains**.

Правил: **73**. Точные домены: 0; доменные зоны: 73; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_xiaomi_090aa317.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_xiaomi_090aa317.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-xiaomi.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
