# adobe-activation

Актуальный набор доменных правил «adobe-activation» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `adobe-activation`. Тип: **domains**.

Правил: **134**. Точные домены: 134; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_adobe_activation_78d9cbb7.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_adobe_activation_78d9cbb7.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-adobe-activation.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
