# by · IP-сети

Актуальный набор IP-сетей «by» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `by`. Тип: **ip**.

Правил: **759**. Точные домены: 0; доменные зоны: 0; фрагменты: 0; regex: 0; IP-сети: 759.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_ip_geoip_by_b1323357.txt)
- [Полный JSON с исходной логикой](../details/rf_ip_geoip_by_b1323357.json)
- [Готовый SRS](../sing-box/rule-set-geoip/geoip-by.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
