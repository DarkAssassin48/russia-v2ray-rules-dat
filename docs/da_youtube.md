# YouTube — видео, сайт и миниатюры

Домены YouTube, загрузки видео и изображений. Состав наследуется из актуальной категории YouTube runetfreedom.

Код: `youtube`. Тип: **domains**.

Правил: **191**. Точные домены: 14; доменные зоны: 177; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_youtube.txt)
- [Полный JSON с исходной логикой](../details/da_youtube.json)
- [Готовый SRS](../custom/youtube.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
