# ganji

Актуальный набор доменных правил «ganji» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `ganji`. Тип: **domains**.

Правил: **4**. Точные домены: 0; доменные зоны: 4; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_ganji_c7e86f98.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_ganji_c7e86f98.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-ganji.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 58ganji-corp.com
domain_suffix: 58ganji.com
domain_suffix: ganji.com
domain_suffix: ganjistatic1.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
