# gigabyte@cn

Актуальный набор доменных правил «gigabyte@cn» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `gigabyte@cn`. Тип: **domains**.

Правил: **2**. Точные домены: 0; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_gigabyte_cn_c27a6d26.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_gigabyte_cn_c27a6d26.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-gigabyte@cn.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: aoruszone.cn
domain_suffix: gigabyte.cn
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
