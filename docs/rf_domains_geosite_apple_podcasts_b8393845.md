# apple-podcasts

Актуальный набор доменных правил «apple-podcasts» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `apple-podcasts`. Тип: **domains**.

Правил: **3**. Точные домены: 1; доменные зоны: 2; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_apple_podcasts_b8393845.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_apple_podcasts_b8393845.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-apple-podcasts.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain: amp-api.podcasts.apple.com
domain_suffix: applepodcasts.com
domain_suffix: podcasts.apple.com
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
