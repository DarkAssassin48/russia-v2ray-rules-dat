# 8btc

Актуальный набор доменных правил «8btc» из runetfreedom. Полный текущий состав приведён в файлах JSON и TXT.

Код: `8btc`. Тип: **domains**.

Правил: **5**. Точные домены: 0; доменные зоны: 5; фрагменты: 0; regex: 0; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/rf_domains_geosite_8btc_ea8e1802.txt)
- [Полный JSON с исходной логикой](../details/rf_domains_geosite_8btc_ea8e1802.json)
- [Готовый SRS](../sing-box/rule-set-geosite/geosite-8btc.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.

## Первые адреса

```text
domain_suffix: 8btc.com
domain_suffix: bystack.com
domain_suffix: chainnode.com
domain_suffix: matpool.com
domain_suffix: matpool.net
```

Полный перечень без сокращений доступен по ссылкам выше.

По умолчанию выключен. Добавление каталога само по себе не включает маршрут.
