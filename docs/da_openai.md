# OpenAI / ChatGPT / Codex

ChatGPT, OpenAI API, Codex, вход, статические ресурсы и пользовательские файлы. Состав основан на категории OpenAI и дополнен основными доменными зонами.

Код: `openai`. Тип: **domains**.

Правил: **49**. Точные домены: 10; доменные зоны: 14; фрагменты: 0; regex: 25; IP-сети: 0.

## Полный состав

- [Все адреса в текстовом виде](../details/da_openai.txt)
- [Полный JSON с исходной логикой](../details/da_openai.json)
- [Готовый SRS](../custom/openai.srs)

`domain_suffix` охватывает сам домен и все поддомены. Точное правило `domain` охватывает только указанное имя. IP-набор может направлять через VPN несколько сервисов, использующих одну сеть.
